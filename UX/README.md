# UX 线稿说明（王国守望）

## 打开方式

直接双击 [wireframe.html](./wireframe.html) 用浏览器打开即可（单文件、零依赖、无外部请求）。

## 页面结构

| 区块 | 内容 |
| --- | --- |
| 左侧导航 | 8 张战斗相关界面线稿 + 美术资源清单 + 设计规范&对接 |
| 中间手机框 | 750×1334 设计分辨率的半比例（375×667）线稿，所有占位框标注 `资源ID` 与 `设计尺寸` |
| 右侧面板 | 当前屏幕的布局说明 / 交互与状态 / 与《向僵尸开炮》参考图差异 |

## 顶部开关

- **资产标注**：开/关每个占位框上的资源 ID 与尺寸（关闭后看整体布局观感）
- **安全区**：显示顶部 96px / 底部 68px 安全区（刘海与手势条避让）
- **网格**：50px 设计网格

## 资源替换对接

线稿中每个虚线框 = 一个资源位（ID + 尺寸）。Cocos 侧约定：

1. 资源落在 `assets/resources/ux/<资源ID>.png`（ID 中的 `{id}` 替换为实例名，如 `hero_aila_portrait`）；
2. UI 组件只认 `assetMap` 配置表（资源ID → 路径），换皮只替换图片文件，零代码改动；
3. 导出规格与命名规范见线稿内「设计规范 & 对接」页。
