## 1. 项目概述

**一句话定位**：竖屏守线射击游戏——玩家作为王国将军，指挥最多 4 名英雄镇守王国防线，抵御哥布林、兽人、亡灵的持续入侵；局内像《向僵尸开炮》一样虫海压境、升级三选一、按英雄构筑强化，局外用《王国保卫战》的题材与手绘卡通美术呈现王国保卫的世界观。

**核心决策记录（已与需求方对齐）**：

| 决策点 | 结论 |
| --- | --- |
| 首发规模 | 3 大章节 × 10 关（共 30 关），6 名英雄（全部远程），约 20 种怪物（含 3 BOSS） |
| 局外养成 | 中度养成：英雄等级 + 技能/大招等级 + 装备（固定词条、关卡掉落）+ 全局城墙升级 |
| 广告设计 | 激励视频 5 点位（复活为无限次核心点位）+ 适度插屏，不接 Banner |
| 美术方案 | AI 生成为主，统一提示词模板 + 后期风格化 |
| 战斗操作 | 普攻、技能全自动（有索敌范围）；大招手动点击；玩家其余操作为三选一选卡 |
| 体力系统 | 无体力 |
| 剧情呈现 | 游戏内无剧情文本，世界观只用于商店页与美术氛围 |
| 货币系统 | 双货币：金币（养成）+ 钻石（三选一钻石刷新等），均无支付获取 |
| 开发节奏 | 竖切优先：**第一阶段只做弓箭手跑通全流程**，再横向铺英雄/内容，最后 MCP 提审上架 |

## 2. 世界观与美术风格

### 2.1 世界观（仅用于商店简介与氛围，不进游戏文本）

> 王国的边境烽火再燃。哥布林从腐朽森林倾巢而出，兽人战团翻越灰牙山脉，而静默沼泽深处，亡者正在苏醒。国王将王国最后的精锐交到你手中——将军，守住防线，王国存亡在此一举。

| 章节 | 主题 | 敌对势力 | 氛围基调 |
| --- | --- | --- | --- |
| 第 1 章 | 腐朽森林 | 哥布林部落 | 明亮绿意、阴湿藤蔓、篝火哨塔 |
| 第 2 章 | 灰牙山脉 | 兽人战团 | 岩石要塞、战鼓烽烟、暮色雪线 |
| 第 3 章 | 静默沼泽 | 亡灵军团 | 灰绿雾沼、枯树墓碑、幽蓝磷火 |
| 第 4 章+（上架后） | 红沙荒漠 / 恶魔裂隙 | 恶魔军团 | 预留 |

### 2.2 美术风格

- **总体基调**：参考《王国保卫战》——手绘卡通、粗描边、高饱和、形体圆润夸张、厚重奇幻插画感。
- **色彩策略**：三章各一套主色调（森林绿 / 山岩棕橙 / 沼泽灰蓝），怪物剪影与背景强对比，竖屏小屏一眼可读。
- **英雄设计**：6 名英雄各占一个色相域，放大职业特征（弓/火法杖/雷法杖/狙击弩/火炮/冰法杖），头像 72px 下可辨识。
- **特效风格**：大色块粒子 + 描边光效；打击感主要靠受击闪红、硬直、飘字、怪物受击挤压形变。
- **生产方式（AI 生成为主）**：统一提示词模板 → 批量生成 → 人工筛选 → 统一后期（描边/饱和度/色阶）；动效降级方案为原画拆层 + 程序动画（位移/挤压/倾斜/闪红）+ 粒子，主力英雄视产出质量决定是否上 2D 骨骼。
- **图标与商店素材**：图标以"防线 + 盾徽 + 主角剪影"构图；商店截图 5 张（战斗全景、三选一强化、英雄阵容、BOSS 战、选关地图）。

## 3. 关卡战斗详细设计（已对齐）

### 3.0 战斗规则速查（本轮对齐结论）

| 规则 | 结论 |
| --- | --- |
| 刷怪模式 | 波次组织出怪，但**波与波无任何间歇**；**清场驱动**——清完当前波立即出下一波，无限时、无防拖延设计 |
| 胜利条件 | 打完最后一波并清场即胜；BOSS 关 = BOSS 死亡即胜（残余小怪溃散消失） |
| 失败条件 | 防线耐久归零；看广告复活恢复 30% 耐久，**可无限复活** |
| 星级 | 按通关时耐久比例：≤40% 一星，40%~90% 二星，≥90% 三星（满星）；复活后照常评定 |
| 英雄无敌性 | 怪物只攻击防线耐久，英雄本体无敌不可被选中（BOSS 控制英雄的机制为上架后扩展，首发不做） |
| 索敌范围 | **每英雄有普攻圆形索敌范围与技能索敌范围（逐英雄配置），怪物不在范围不被攻击/不放技能**；大招全屏不受范围限制（默认，可改） |
| 索敌优先级 | 普攻优先攻击范围内**最靠下**（最接近防线）的目标，距离相同取血少 |
| 怪物行进 | 顶部全宽随机生成，松散虫群直线向下 + 轻微横移游动 + 自动分离防重叠 |
| 怪物攻击 | 攻击距离逐怪配置：近战怪贴线才攻击，远程怪距防线≤射程即停位攻击；攻击间隔/攻击力逐怪配置、个体独立计时，**全部怪物可同时进攻不排队**，一直攻击直到被杀 |
| 受击反馈 | 闪**红** + 0.1s 轻微硬直（减速），不击退 |
| 血条 | 小怪/精英不显示血条（靠闪红+飘字），仅 BOSS 头顶常显血条 |
| 属性Tips | 点击普攻/技能/未充满大招图标，图标侧边弹出数值详情（伤害/冷却/充能/索敌范围/生效范围），战斗不暂停 |
| 经验 | 全队共享经验条；击杀经验逐怪配置；**关内等级无上限**，每级需求递增，强化卡永远抽不完，无溢出问题 |
| 强化卡 | **按英雄单独强化**（非全队）；每个英雄的卡池独立配置；三选一 = 上阵英雄卡池混合抽 3 张 + 少量全局卡，卡面标注归属英雄 |
| 刷新 | 每次三选一弹窗内：广告刷新 ×1 + 钻石刷新 ×1（2 钻/次）；跨弹窗不共享、关卡级不限次数 |
| 大招 | 手动点击释放，演出极简（直接放，只带技能特效）；充能 = **击杀者**获得该怪物配置的充能值；充能上限逐英雄配置 |
| 金币 | 局内击杀金币自动收取，计入本局结算奖励；不设局内消耗 |
| 倍速 | 2x 倍速，通关 1-2 解锁，战斗内随时切换 |

### 3.1 战场空间与坐标（750×1334 设计分辨率）

- **顶部 y=-50**：怪物生成带（全宽随机 x），生成后进入行进状态。
- **中部 y=0~1100**：怪物行进区。虫群下行，个体带轻微横向正弦游动（±10px），分离力防止重叠（简单排斥半径 ≈ 体型半径之和）。
- **防线判定线 y≈1180**：怪物（近战怪）抵达即停止移动进入攻击状态；远程怪在"距防线距离 ≤ 自身攻击距离"时提前停位攻击。防线视觉区（城墙/栅栏）占 y 1180~1334。
- **英雄站位**：防线之上横排 4 槽（x ≈ 110 / 287 / 463 / 640），站位顺序仅影响排列，无机制差异。
- **索敌范围可视化**：选中/升级英雄时短暂显示圆形范围圈；平时不显示，避免遮挡。

### 3.2 战斗状态机

```
PREPARE（3s，展示阵容与"敌军来袭"） 
  → WAVE_RUNNING（当前波出怪+战斗；波内怪物全部生成且全部被消灭 → 立即进入下一波）
      ⇄ LEVEL_UP_PAUSE（升级弹三选一，全场冻结；连升多级排队弹窗）
  → …循环直至最后一波清完…
  → VICTORY（清场演出 → 结算）
失败分支：LINE_BROKEN（耐久归零）
  → DEFEAT_POPUP（失败结算弹窗，内含：看广告复活 耐久+30% 无限次 / 不看广告 → 按失败结算）
```

- 暂停按钮：全场冻结，面板含 继续 / 重试 / 退出 / 音量开关；中途退出无奖励（二次确认）。
- 三选一、暂停期间：出怪计时、技能 CD、大招充能全部冻结。

### 3.3 波次系统（清场驱动）

- 每关 **10~14 波**，波 = 出怪批次配置（怪物类型 × 数量 × 波内生成间隔 0.3~1s）。
- **无间歇**：当前波怪物"全部生成完毕且全部被消灭"的瞬间立即开始下一波，无倒计时无等待。
- 杀得快关就短（普通关预期 2~4 分钟浮动），**不做防拖延设计**。
- 每关第 4、8 波为**大波**（狂潮：数量约 ×2，屏幕预警横幅"敌军大部队来袭！"）；精英怪从第 4 波起穿插混编；最后一波为高潮波（普通关=数量峰值，BOSS 关=BOSS 登场）。
- **BOSS 波结构**：BOSS 登场 + 小怪持续刷新（刷新不停直到 BOSS 死亡）；**BOSS 死亡即胜利**，场上残余小怪溃散消失。BOSS 登场时有短暂出场演出（横幅 + 定场动画）。
- 进度条 = 波次序号（第 N / 共 M 波）。

### 3.4 怪物行为

- **行进**：虫群下行 → 接触防线（近战）或进入自身攻击距离（远程）→ 停止移动进入攻击状态。
- **攻击**：攻击力、攻击间隔逐怪配置，个体独立计时（随机相位错开，避免全场同步拍线）；持续攻击直到被杀。
- **受击**：闪红 + 0.1s 轻微硬直（移速/攻击暂缓），不击退、不打断攻击意图。
- **死亡**：爆裂粒子 + 金币飘出（自动飞向金币计数器，计入本局结算）+ 经验（全队共享经验条）+ 大招充能（仅归击杀者英雄）。
- **同屏上限 60 只**：超限时后续生成排队延迟（不丢弃）；弹道 ≤ 80。
- 逐怪配置字段：`hp / atk / atkInterval / atkRange(0=近战) / moveSpeed / physRes / magicRes / expValue / chargeValue / goldValue / 体型半径 / 特殊机制`。

### 3.5 索敌与弹道

- **普攻索敌**：普攻圆形范围内"最靠下优先"，距离相同取血少；目标不在范围则不攻击（待机）。
- **技能索敌**：技能范围内选取怪物最密集点/最优目标释放；范围内无怪则不释放，CD 保持就绪。
- **大招**：手动点击，全屏生效，不受索敌范围限制。
- **弹道**：可见飞行弹道（各英雄速度不同），自动追踪；目标死亡自动转移至最近的合法目标。
- **连射卡**：每次普攻在同一直线上串行追加子弹（微延迟连成一串），各子弹独立命中判定。
- **齐射卡**：主弹道索敌目标 + 固定扇形角度射出子弹道（直线飞行、随缘命中），可叠层增加子弹道数。
- **分裂卡**：普攻命中后分裂出小弹道；分裂弹同样继承命中词条（爆炸/减速等，倍率可配置）。

### 3.6 伤害公式与状态效果

```
最终伤害 = 攻击力 × 技能倍率 × (1 + 攻击加成%) × 暴击倍率 × (1 - 对应抗性%) × (1 + 易伤加成%)
暴击：基础 5% 概率 / 150% 伤害（可被卡强化）
物理伤害吃物抗、魔法伤害吃魔抗；抗性逐怪配置
```

- **DoT（灼烧/中毒类）**：每 0.5s 跳一次，同类 DoT 只保留最高、刷新时长，不叠加层数。
- **减速**：同类取最高值，不叠加；**冻结**：完全停止行动，BOSS 免疫冻结（改为受 50% 减速）。
- **易伤**（感电/寒冰碎裂等"受伤加深"）：加法叠加，上限 +100%。

### 3.7 英雄行为（普攻自动 / 技能自动 / 大招手动）

| 行为 | 触发 | 规则 |
| --- | --- | --- |
| 普攻 | 全自动 | 普攻圆形范围内按优先级索敌，攻击间隔到点即射；骑士已移除，全部英雄为远程 |
| 技能 | 全自动 | CD 转好且技能范围内有合法目标即释放；不打断普攻；索敌取最密集处 |
| 大招 | **手动点击** | 充能满后头像高亮呼吸，点击直接释放（极简演出：仅技能特效，无慢动作/顿帧）；可多英雄连续释放，无限制 |

**大招充能规则（对齐确认）**：
- 充能归属击杀者：英雄 A 击杀怪物 → 仅英雄 A 获得 `该怪物配置的 chargeValue`；
- 每个英雄的充能上限（`chargeMax`）逐英雄配置；
- 初版基准（全配置可调）：普通怪 chargeValue=1、治疗/增益怪=2、精英=10、BOSS=40；chargeMax：弓箭手 60 / 火法 70 / 雷法 65 / 狙击 55 / 炮手 80 / 冰法 70。
- 数值注意：AOE 英雄击杀多、单体英雄击杀少 → 用 chargeMax 差异制衡，确保各英雄每关 1~3 次大招。

### 3.8 经验升级与三选一强化卡

- **全队共享经验条**：任何英雄击杀的 expValue 全部进入共享经验条；屏幕下缘显示等级与进度。
- **关内等级无上限**：每级需求递增（`EXP(L→L+1) = 50 × 1.35^(L-1)`，初版基准），配合逐怪 expValue 配置，理论上整关可以一直升级——强化卡永远抽不完。
- **升级 → 全场暂停 → 三选一弹窗**；连升多级则排队依次弹出。
- **抽卡规则（对齐确认）**：从当前上阵 4 名英雄的卡池中按权重混合抽 3 张不重复卡，卡面标注归属英雄头像；另保留少量**全局卡**（防线/经验/金币类，不属英雄）。稀有度权重：白 60% / 蓝 32% / 紫 8%。
- **刷新**：每次三选一弹窗内，广告刷新 ×1（免费）+ 钻石刷新 ×1（2 钻/次）；进入下一个弹窗后重新可用；关卡级不限刷新次数。
- 强化分三类：**普攻强化**（普攻定位英雄为主）、**技能/大招强化**（技能定位英雄为主）、**全局卡**（防线耐久/经验/金币）。每个英雄可抽到哪些卡**完全由配置表决定**（`heroCards: [cardId...]` + 权重）。

### 3.9 胜负、星级与复活

- **胜利**：最后一波清完（BOSS 关 = BOSS 死亡）。
- **失败**：防线耐久归零 → **失败结算弹窗**（不单独弹复活层，复活入口为弹窗右下圆形广告按钮，与胜利结算双倍按钮同位同尺寸）：
  - **看广告复活**：耐久 +30% 继续本局，**可无限次**（广告加载失败时按钮置灰可重试加载）；
  - 不看广告即接受失败：本局已收金币的 30% 保底发放，可重试或退出。
- **星级（通关时耐久比例 P）**：`P ≤ 40%` 一星；`40% < P < 90%` 二星；`P ≥ 90%` 三星。复活不降星、不封顶，照常评定（复活只回 30%，冲三星仍需高质量防守）。
- 星级用途：首通三星额外金币；每章累计星数里程碑宝箱（金币+钻石+装备）；**不设星数门槛拦截关卡**，通关即解锁下一关，通关本章 BOSS 关解锁下一章。

### 3.10 局内金币与结算

- 击杀掉落的金币自动飞入计数器（飘字反馈），**计入本局结算奖励池**；局内无任何金币消耗点。
- 结算金币 = 局内击杀金币 + 关卡基础奖励（首通/重复通关公式见 §11）。
- 中途退出/失败放弃：只发 30% 保底，装备不掉落。

### 3.11 HUD 与战斗表现

| 元素 | 规则 |
| --- | --- |
| 顶部 | 波次进度条（第 N/共 M 波）+ 大波/BOSS 预警横幅 |
| 血条 | 仅 BOSS 头顶常显；小怪/精英不显示血条，靠闪红 + 伤害飘字反馈 |

### 3.12 新手引导（仅 1-1 强引导）

1. 进关展示阵容（仅弓箭手）+"英雄会自动攻击范围内怪物"提示；

4. 必须看完视频才发奖励；
5. 广告按钮不得伪装普通功能按钮。

### 11.3 难度成长公式

```
敌人最终属性 = 基准 × 章节系数 × 关卡系数 × 波次系数
章节系数：第1章 1.0｜第2章 2.8｜第3章 7.5
关卡系数：1 + (关内序号-1) × 0.08
波次系数：1 + 波序号 × 0.03（清场驱动下波序即进程）
经验需求：EXP(L→L+1) = 50 × 1.35^(L-1)，等级无上限
英雄充能上限：弓 60 / 火 70 / 雷 65 / 狙 55 / 炮 80 / 冰 70
结算金币 = 局内击杀金币 + 首通奖励（或首通的 40% ×(1+星数×10%)）
防线耐久 = 关卡基础 ×(1 + 城墙等级 × 6%)
开局盾值 = 城墙阶段奖励（每 5 级一档逐档递增，全配置化），伤害先扣盾再扣耐久
```

## 12. 技术方案

### 12.1 引擎与构建

- **Cocos Creator 3.8.8**（本机 `C:\ProgramData\cocos\editors\Creator\3.8.8`），TypeScript。
- 构建目标 **Web Mobile**，`build/web-mobile` 即上传包体来源。TapTap MCP 当前仅支持 H5 小游戏，路线一致。

### 12.2 taptap-minigame MCP 工作流

1. 下载 `AI_SETUP_GUIDE.md` 放入项目根目录 → AI 按指引安装配置 MCP → TapTap App 扫码授权；
2. 游戏管理：创建《王国守望》、更新商店截图/信息、查询审核进度；
3. 上传：构建完成让 MCP 上传 dist 目录；
4. 平台能力按需：云存档、振动、分享、排行榜（无尽模式）；
5. 排障：连接/广告不显示/登录失效走 MCP 会话。

> ⚠️ 当前会话尚未安装 taptap-minigame MCP。M1 结束前完成配置与授权（真机广告验证硬依赖）。

### 12.3 竖屏适配

- 设计分辨率 **750×1334**，Fit Width，长屏上下延伸战场背景；UI Widget 对齐 + 刘海/手势条安全区避让；锁定竖屏。

### 12.4 性能预算（WebView 容器）

| 指标 | 预算 |
| --- | --- |
| 首包体积 | ≤20MB（章节资源 Asset Bundle 按需加载） |
| 首屏可玩 | 4G ≤5s |
| 同屏怪物 | ≤60（超限排队）；弹道 ≤80（对象池强制） |
| DrawCall | ≤60（怪物/英雄/UI 图集合并） |
| 帧率 | 中端机 30fps 稳定；战斗逻辑 dt 步进与渲染解耦 |
| 索敌计算 | 圆形范围 = 距离平方比较，免开方；怪物 >30 只时启用空间网格分桶 |

### 12.5 存档

- `localStorage` JSON 主存档（进度/金币/钻石/英雄/装备/设置/统计）+ 版本迁移；写档时机：结算、养成变更、选卡后；云存档（MCP 能力）为上架后 P2。

### 12.6 广告接入

- 封装 `AdService`（load/show/onReward/超时与失败降级/插屏频次控制），UI 只调 `AdService`；Debug 开关本地 Mock 直发奖；复活为无限次高频调用，需处理广告未加载完的按钮状态与重试。

### 12.7 工程结构

```
KingdomWatch/
  assets/
    scenes/        # Launch / MainCity / Battle
    scripts/
      core/        # 状态机、存档、事件总线
      battle/      # 波次(清场驱动)、虫群移动、索敌范围、弹道、伤害、大招充能、强化卡
      config/      # 关卡/怪物/英雄/卡池/数值 JSON + 类型
      ui/
      platform/    # AdService、存档、MCP 桥
    resources/     # 图集、音频、章节 Bundle
```
