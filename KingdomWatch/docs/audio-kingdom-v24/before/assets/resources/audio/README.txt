正式游戏音频 v1
===============
GameAudio.ts 统一混音，AudioCatalog.ts 配置事件/变体/音量。
v1/ 内为2首立体声 BGM（MP3 192kbps）及42条单声道音效（WAV 44.1kHz/16bit）。
大厅与战斗配乐交叉淡入，暂停与结算压低音乐；H5首次手势解锁，切到后台停止战斗声音并挂起音频。
真实长弓/重弩、火焰、雷电、冰裂、UI和弦乐提示取代程序占位音。
高频音效有变体、微量音高变化、跨类型命中限流及14声部预算；重要提示会压低音乐。
来源、作者、许可、制作参数与原素材见 docs/audio-upgrade-v1/。
CREDITS.txt 及 /audio-credits.html 保留署名，暂停→设置→音乐与音效鸣谢可打开。
修改素材后需保持许可署名并重新构建发布，旧 sfx_* 命名的占位方案已停用。
