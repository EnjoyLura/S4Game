## 两套动作怎样复用

**四足模板**：四条腿使用错开的落脚相位，支撑阶段缓慢后移、摆腿阶段抬起前送；肩/膝/脚之间用连续纹理网格连接，头部轻微抵消身体晃动，尾巴延迟摆动。雪狼的蓬松轮廓采用较轻步幅，猎兽的长前肢采用更明显的抬爪。面部保持整体，不逐像素拉伸眼睛或嘴。

**飞行模板**：左右翼分别有翅根和外翼两段，翼尖稍微落后于翅根；下拍与恢复时间不同，配合躯干起伏、头部稳定和尾部跟随。双翼置于完整躯干后方，以原图羽毛/毛发纹理叠合翅根；脚爪和耳朵不会进入拍翼蒙版。老鹰慢拍、蝙蝠快拍，沿用同一套模板代码。

`rigs.json` 记录每只怪物的关节、部件蒙版、步幅/拍翼幅度、相位与节奏。复用的是动作逻辑；新怪物仍需人工校准轮廓、关节和遮挡，不能承诺任意一张图都自动得到同样效果。单图中被遮住的侧面、背面没有被重新绘制。

## 输入与制作方式

没有使用新 AI 图片或 AI 视频生成动作，没有抽取视频帧。所有运动由 Python、Pillow、NumPy 的变换/加权网格和时间函数计算。

- 雪岭灰狼：现有 `assets/resources/ux/mobs_snow_v66.png` 中的 `snow_wolf`。
- 虚空猎兽：现有 `assets/resources/ux/mobs_rift_v66.png` 中的 `rift_hound`。
- 老鹰：现有 `docs/frontier-new-enemies-v1/sources/eagle-front-green-v2-safe-margin.png`。
- 蝙蝠：现有 `docs/frontier-new-enemies-v1/sources/bat-front-green-v2-safe-margin.png`。

`sources.json` 保存原路径、图集裁切、工作画布位置、原图/抠图/工作图 SHA-256。`sources/*-cutout.png` 是存档的原始尺寸 RGBA 输入；四足沿用图集透明通道，飞行原图用纯绿色差键抠除背景并作边缘去绿。飞行动物原图的绿色镂空也会保持透明，没有凭空绘制被遮挡部位。`sources/*.png` 是固定 1024×1024 工作画布，`*-grid.jpg` 用于校准关节。

## 复现

依赖 Python 3、Pillow、NumPy。字体优先使用 Windows 微软雅黑，预览标签不影响透明序列帧。

```powershell
python prepare_sources.py
python animate.py
```

只重做某只：`python animate.py --only eagle`。全部单只素材已生成后重建对照与 ZIP：`python animate.py --package-only`。

ZIP 包含 128 张透明帧、4 张图集、4 份帧配置、两套共用模板代码、4 份怪物参数、来源记录及存档输入，可以在解压目录重现导出。

## 检查记录与边界

已检查四只各 8 个关键姿势及关节/翅根放大图，修订了初版飞行模板把脚爪带入翅膀变形的问题，并限制雪狼腿根局部挤压。最终 128 帧的网格三角形均无翻转，角色透明轮廓均在画布内；这些是离线几何检查，不等同于用户对自然度的认可。
