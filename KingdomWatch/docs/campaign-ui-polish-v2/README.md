# 章节地图与完整准备抽屉 v2

2026-10-17，按用户连续反馈调整关卡地图、准备面板和返回行为。

- 地图内容顶部加入随地图一起滚动的原生树冠延伸，并把这一段计入滚动范围、初始聚焦和位置记忆。第 10 关完整触摸范围留在悬浮章节栏下方，第 9 关也能拖到可点区域。底图仍是当前章节的一张原图，未添加固定重复地图或顶部整块背板。
- 当前关卡横条从 102 加高到 150，增加深色边沿、暖色纸面和淡城堡纹样，出战按钮加高；章节牌、箭头、关卡石质底座、锁牌、星星和选中名称签采用少量明确的明暗面。深林木牌和兽穴铁骨牌特色保留。
- 准备抽屉采用完整纸面，取消内部 ScrollView。内容按星级宝箱、通关必得、概率装备、编队排列，底部固定开始按钮。高屏装备六列换行；短屏装备紧凑单排，内容按可用高度统一适配，所有实际装备条目保留。普通难度的空装备区直接显示提示。地图打开/关闭抽屉时不重新聚焦，残余惯性会停止。
- 木、蓝、红三种原生宝箱，金色难度签、头像金环、纸面明暗与金色主按钮向用户效果图靠拢，不生成新图片或下载新素材。
- 从战斗返回关卡页时清除抽屉打开状态，回到章节地图与当前关卡横条。离开关卡页切换其他主页面时立即收起抽屉，返回关卡页保持关闭。编队完成仍局部刷新原准备抽屉。
- 编队界面和下阵确认注册一个可复用的 H5 history 边界，手机返回键先关闭最上层注册界面；下阵确认返回编队，编队返回来源页面。界面销毁时移除注册，反复按钮开关不重复堆积历史。
