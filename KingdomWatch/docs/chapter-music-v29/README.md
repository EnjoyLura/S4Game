## 音乐来源与制作

两首新音乐均为 The Cynic Project / Alex Smith（cynicmusic）在 OpenGameArt 发布的 CC0 1.0 曲目，与原有音乐作者一致。作者页面与源文件保存在 `sources/`，下载地址和散列见 `sources.json`，制作参数见 `manifest.json`。

- [Dark Forest Theme 作者页面](https://opengameart.org/node/80219)：原速保留完整音乐主体，去首尾空白，0.7 秒等功率循环重叠，响度整理后导出立体声 44.1 kHz / 192 kbps MP3，约 92.36 秒。
- [Battle Theme B for RPG 作者页面](https://opengameart.org/content/battle-theme-b-for-rpg)：同样处理，约 65.06 秒。作者说明提及定音鼓及兽人阵营音乐的创作参考，作为兽穴主题选材依据。

均未叠加合成旋律或改变播放速度。随包鸣谢与 `build-templates/web-mobile/audio-credits.html` 已更新。
