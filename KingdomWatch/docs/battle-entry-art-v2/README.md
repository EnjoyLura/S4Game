# 入场美术、陨石与三选一反馈 v2

2026-10-16。此轮合并用户连续提出的入场关门过久、缺少美术、陨石坑偏小、落点预警改影子、大招不压暗、选卡及刷新缺少力度、卡面描述断行问题。

## 三选一

- 选择约 480ms：短促压下至 94%，回弹峰值 112%，抬高 28px 后收稳；金色边缘辉光、角部短光芒和碎光配合 100ms 时的确认音。未选卡向两侧收退并覆暗，纸卡保持不透明。
- 刷新约 520ms：旧卡先收拢，各列间隔 45ms；新卡美术准备完成后，在同一次更新中替换旧卡，再从 92.5% 弹至 104% 后归位。边缘扫光与碎光、收牌和发牌音同步，不翻成空白纸面。
- 进场、选择和刷新各有独立阶段，卡面变换由一个时钟管理；保留重复点击拦截、后台冻结、减少动态偏好及失效回调保护。
- 描述统一 18px 正文字体、25px 行高、196×112 文本框。按效果、代价、条件、层数手动分行，关闭自动换行，缩字仅作兜底；所有英雄卡及技能/大招解锁说明一起整理。

例：小范围爆炸改为“命中触发爆炸 / 溅射伤害 40% / 攻击力 -10%”；猎手本能改为“目标血量低于30%时 / 伤害 +100%”。仅调整描述，不改卡牌公式、数值、归属、品质、权重和叠层。

## 战斗入场

原程序旗帜换为原创蓝钢、木材与金饰双扇城门。合拢 240ms、最短闭合停留 60ms、展开 320ms；温缓存下动作本身约 620ms，实际总耗时另有场景交接和绘制帧，冷加载不保证固定耗时。

关卡页提前加载当前关卡背景、防线、上阵英雄待机缓存及战斗场景；攻击片段在待机完成后继续预载。大厅优先加载城门。完整遮挡后才切场，关键首屏资源完成并经过绘制帧再展开，小型 HUD 装饰不阻塞；场景构建后额外美术等待封顶 900ms，资源异常沿用现有兜底。进场倒计时仍等展开结束才开始。

画作等比覆盖，两张独立半幅 SpriteFrame 从中心分开，不镜像、不拉伸。宽高比不同时裁掉外侧多余部分，底层保留不透明遮挡和接缝重叠。减少动态、后台冻结、重复进入及失败回退处理保留。

## 火法与大招亮度

陨石坑基础半径 88→114.4，半径与直径均增大 30%，面积增大 69%；美术与实际持续灼烧/易伤范围同步，原等级倍率继续应用。落点间距同步使用新半径。瞬间爆炸半径 140、伤害、颗数、飞行速度、坑持续 4 秒及灼烧/易伤强度保持。

落点预警换为柔边深色椭圆影子，在实际固定落点随飞行进度增大、加深；发射前短暂出现，到实际接地回调时撤去。取消预警圆圈、十字和橙色脉冲。五英雄大招共同取消全屏压暗，保留局部能量光、原演出节拍和轻微世界震动。
