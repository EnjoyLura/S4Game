## 实际限制

生图模型没有可靠地执行精确时序和均匀网格指令：部分行出现相似相位，形态／亮度仍有跳变，尚不能称为可直接上线的无缝动画。原图格间距也不均匀。按原图透明空隙测量分格行边界，再根据底部尘团做整数位移，把各格脚点对齐到384格的(192,336)；没有逐帧缩放、重画或放大像素细节。宽边缘的原生细节约314px级，打包到1536图集不等于生成了更高分辨率的画面。切图和对齐数据见 [frames.json](frames.json)。

因此这份预览用于判断“生图的卷流造型、材质与扬尘是否更合适”。不能把动画帧差指标当作视觉认可或无缝证明。如后续采用，应先解决帧间一致性再谈接入；本次没有执行接入。
