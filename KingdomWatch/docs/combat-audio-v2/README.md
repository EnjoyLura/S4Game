# 战斗音效重制 v2

用户否定 v1 战斗音效：重弩怪异，整体尖锐刺耳，要求以游戏打击爽感为目标。本版重新制作 48 条离线采样，接入五英雄普攻、普通／重命中、技能、大招、击杀、防线受击与就绪。保留 BGM、胜负／升级提示和上一轮 UI 交互。

## 声音设计

- 弓箭：短促弹性弓弦与风切；重弩：弦机瞬态、木质低响、厚实冲击和短风切，不再叠加金属卡扣。
- 火：圆润点燃与低频爆发；雷：短电击脉冲、低中频冲击，去掉持续电击嗡鸣；冰：柔和冰裂、霜气和实体接触，停止使用 UI 玻璃铃声。
- 五位普攻各 3 变体，五类普通命中各 3 变体；重命中有独立更厚的声音。原始尖锐素材只作为短小纹理层，低通、共振削减、短包络后配合实体低中频主体，不直接播放录音整段。
- 击杀改成轻短实音，取消频繁怪物怪叫；重弩狙击、元素技能及大招单独设计，响度与持续时间有层次。
- 普攻约 0.13–0.25 秒，技能／大招约 0.3–0.6 秒；实际每条时长、峰值、全部来源和处理参数见 assets.json。短促清晰主要来自声音构造和包络，不靠扩大总音量。

## 采样与混音接入

`assets/resources/audio/v2` 使用新的 UUID 与资源路径，避免旧原生素材缓存混用；保留 v1 源档与许可。`prepare_audio.py` 可重现生产，使用已授权录音和新补充的 Kenney Impact Sounds（CC0），无付费生成或第三方游戏音频复制。新增包许可、来源、哈希、逐层编辑配方一并保留，网页鸣谢同步更新。

GameAudio 保留捕获真实手势解锁、预热、暂停／后台、BGM 跨场景及存档开关。战斗声音单独经过 65Hz 低切、3.1kHz -2.5dB 共振处理、5.2kHz -2dB 高架和 2.5:1 温和压缩，UI 与音乐不经过这一处理。总线原 -8dB 重压缩改为 -3dB 安全限制，让短瞬态保留力度。

取消全英雄共用的 25ms 发射互斥，五英雄同帧发射能分别出声；保留各英雄的防重复间隔。小命中共用 45ms 限流，重命中优先；同一音效最多 2 声部，发射／命中／施法分别限制 7／4／3，总计最多 14。120ms 内的密集声部按数量做响度补偿，大招期间普通声压低而不直接消失。音调变化缩小到 ±1.25%，避免怪异漂移。雷法师连锁技能补独立施法音，普通／重元素命中与弩箭命中正确分开。
