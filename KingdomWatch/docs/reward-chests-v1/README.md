# 关卡宝箱一键领取与获得奖励弹窗

点击当前关卡、当前难度下任意可领取宝箱或其“一键领取”按钮，会一次领取全部已达成且尚未领取的星级宝箱。不会跨关卡、跨难度领取，也不会进入页面就自动发奖。

数据层从已保存的星级确定最高可领档，沿用原来的逐档累计发奖，一次更新最高已领档、金币和钻石并保存。返回本次实际到账的金币、钻石和宝箱数量，弹窗只展示该回执。例如三个宝箱均未领，则合并展示金币及两档钻石；一星箱已领、升至三星后再点击，则只展示新增两箱的钻石。重复输入由界面忙态和数据已领记录共同拦截。

弹窗复用漫画米纸切角板、货币插画和金色按钮。标题“获得奖励”，注明关卡／难度与本次领取箱数。只显示正数奖励，金币、钻石各合并成一张卡，一种奖励时居中。卡片错峰回弹、数量滚动、落位轻弹及货币周围金色碎光，约一秒收稳，复用既有奖励／确认音。减少动态时直接显示最终数量；切后台冻结动画，关闭／销毁清理绘制和事件，不产生延后音效。

奖励在弹窗出现前已到账，点击“收下”、关闭或空白只关闭弹窗。关卡宝箱状态和共用资源栏在弹窗下方同步更新；保持当前章节、关卡、难度、奖励页签及上半区滚动位置，不整页重建或重复叠遮罩。新动画不限制领奖或等待动画结束才能关闭。

相关源码：`core/GameData.ts`（回执和一键发奖）、`ui/RewardPopup.ts`（展示与有限动效）、`ui/pages/LevelsPage.ts`（入口、同步和防重）。未生成新美术、未改宝箱数值与掉率、未重置存档。上一轮章节改动保留，本轮不另行 Git 提交。
