# 雷电标枪与新英雄说明修复 v140

雷枪最终按用户追加反馈做成**修长金色雷电标枪**：连续枪身、长尖锋，主体轻微曲折，只保留五处短小的不对称电弧，不使用密集树杈。普攻、枪雨、大招、插地与回收共用同一纯代码绘制。没有新增或替换图片。

## 飞行与落地

原先伤害弹道走直线，绘制层单独叠加高度；落地后又切成独立随机倾斜角，所以会出现末尾突然转向。现在由 `lanceFlightPlan / lanceFlightPose` 共用位置、速度和到达时间：水平匀速、竖直恒定向下加速度，普通/巨枪先上抛再落下，枪雨从上方加速落下。弹体实际位置即所见枪尖；抵达时只结算一次原有伤害和插地。

枪身通常沿速度方向，接近竖直投掷的最高点时保留连续翻转，避免瞬间 180° 掉头；插地直接保留末速度的切线角。飞行与插地还保留同一电弧种子和时间相位，入土裁切与前景土唇延用。普攻预判按实际飞行时长迭代，大招演出与落点标记时长也使用该时长。

保留伤害数值、雷域时长/范围、枪雨数量、大招落地爆炸与持续电冲击波；投掷的实际飞行时长随新轨迹变化。历史英雄实现不改。

## 说明 tip

雷枪、魔法弓、镰刀法师的 `showTips` 分支已有六行说明，但没有赋值 `px/py`。随后边界钳制把它们变成 NaN，范围圈已画而面板不可见。新增统一最终定位：缺省时贴对应图标，之后收进可视区；已有英雄提供的坐标继续使用。保留满充能大招图标点击释放、未满点击查看说明的既有交互。
