# 战斗弹窗复用主界面按钮

用户提供三选一、暂停和设置截图，指出亮面宝石切边按钮与主界面不搭，要求使用主界面的按钮美术风格。本轮直接复用主界面的 `ComicUI.ts`，不重新生成图片。

主界面已有规则保持：单层大色块、2.4 设计像素深色轮廓、9 像素小切角、窄顶部高光；按下时同一钮面下降 2 像素。绿钮奶白字、金钮深字，禁用状态使用同轮廓灰绿色。`comicButton` 沿用现有 API，内部共享 `comicButtonControl`，后者增加动态文案与可用状态，供异步结算领取操作复用。

- 三选一广告刷新、钻石刷新使用同款绿／金按钮；保留 300／180 的不同宽度、原位置、字号、扣钻与广告回调，次数耗尽保持禁点。
- 暂停退出、继续战斗、倍速按钮直接使用 `comicButton`。设置行改为同系深色平面底板，开关使用相同轮廓色与平面绿／灰色，保留原开关位置、状态和即时设置回调。
- 暂停与成功／失败页签继续保持连体无缝、原分段宽度与位置，通过分段遮罩共用完整 `comicPlate` 外轮廓，金色选中、深色未选。未选文字使用主界面奶白色。
- 成功／失败的返回、下一关、重试、双倍奖励、广告复活按钮使用同一控件，广告动作沿用主界面绿色。动态“领取中”、领取后禁用、跨页签状态、回调和资源发放保持原逻辑，禁用按钮不播放按下动作或点击声。

标题横幅、奖励图标、三选一卡片与纸纹、伤害统计、窗口布局及入场动画保持。原宝石按钮／设置控件图片保留历史文件，以上正式入口不再加载它们。主界面本身的几何、颜色、按钮反馈与功能保持，未新增全局换肤。

沿用上一轮最新发布目录，保留已发布的强化纯程序发射、BGM／采样音效、英雄动画、防线显示与战斗数据。只执行源代码改动、Cocos web-mobile 构建、DPR 补丁和 Pages main 发布；依用户持续要求，不运行测试、游戏、浏览器或线上视觉验收。视觉结果由用户人工查看。
