# 关键玩法正向反馈 v15

这一轮直接完善正式游戏的成功反馈，沿用 v14 领奖横幅和渐隐双线通知。

| 入口 | 本轮表现 |
| --- | --- |
| 关卡胜利 | 皇冠后方暖金放射光、两侧庆祝碎片、星星逐枚落点与扩散环、星级音效、真实奖励数字收尾 |
| 星级宝箱与图鉴领奖 | 金色标题弹入、奖励依次揭晓、图标扫光、真实数量滚动、独立领奖旋律；收下金币/钻石后飞向资源栏并脉冲 |
| 商品购买 | 成功扣费后显示实际商品、品质和实际数量，播放购买音效；失败仍给出原因 |
| 英雄购买 | 成功招募后展示现有完整立绘、英雄名称与已解锁提示，配合更大的放射光、碎片及招募音效 |
| 英雄/武器/技能/装备成长 | 非阻塞庆祝条展示真实等级前后、实际属性增量及可用的真实战力增量；英雄/武器培养另有脚底双环、背后上升暖光和战力累计 |
| 长按连升与阶段突破 | 每次原事务只执行一次；同一目标合并累计，数字延续当前显示值，不重复淡入；连升短音限频，突破用更强提示与音效 |
| 主城升级 | 实际等级、防线耐久和护盾增量、独立建设旋律，更新后的主城预览有局部金色放射光和扩散环 |

演出只在原操作成功后触发，不写入奖励或成长数值。购买仍由 `shopBuy` 扣费/发货，图鉴奖励仍由 `claimCodexReward` 一次性发放，宝箱仍由 `claimAllChests` 发放，培养仍由原 GameData 操作执行。战斗结算位置/按钮/事务和普通 Toast 样式保持。

普通成长不打开模态窗，长按按钮与当前界面保留。获得展示点击任意位置收下，可用手机返回关闭，关闭不再播放普通关窗声。装饰动画均有限时长；后台暂停、销毁清理，降低动态效果偏好会减少或跳过演出。低资源/满级提示与成长展示使用不同位置。

音频为本轮离线原创合成的八条短促和声提示，参数和生成程序见 [generate_audio.py](generate_audio.py)，规格/散列见 [audio-manifest.json](audio-manifest.json)。单声道 24 kHz / PCM16，总计 353,632 字节，峰值控制在 0.79 以下，无外部采样来源。接入原 `GameAudio`，保留音效开关、浏览器手势解锁、后台静音、音乐压低及声部限制；旧战斗发射/命中、配乐和胜负素材保持。未进行试听。

只进行源码复核、TypeScript 静态诊断、Cocos 生产构建、DPR/缓存准备、静态产物散列核对和 Wrangler 发布。不运行测试、模拟、游戏、浏览器、音频试听或线上验收。已有九项类型诊断保持，本轮模块无新增诊断；不将构建和发布视为效果认可。最终视觉、手感和听感待用户人工确认。
