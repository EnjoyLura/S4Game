# 风刃术士、忍者与雷电领域 v120

本轮实现用户指定的两位英雄首版与雷法强化卡，沿用已有伤害、抗性、击杀充能、投射物、养成、存档及资源缓存流程。

## 可玩内容

- **赛兰·逐风（风刃术士）**：青绿／象牙白。普攻从手部发射水平圆弧风刃，可额外穿透2个敌人，每次穿透保留80%伤害。技能在密集敌群处生成固定风眼，持续4秒、每0.5秒切割并聚拢敌人。大招召唤5秒移动龙卷风，平滑追踪密集敌群、每0.4秒卷击。精英受到35%牵引，首领不被拉动，仅受到减速与伤害。风系三种攻击均可对空，使用真实身体坐标。
- **胧·影刃（忍者）**：靛蓝／银色／青色。普攻优先选择未留标记且无在途手里剑的敌人，实际命中后才将手里剑留在活体上。技能回收范围内的手里剑，造成一次回收伤害，弹道完整飞回原发射位置；目标接触去重、池化生命周期检查、满池重试、死亡清理均有处理。大招在密集敌群位置放置旋转螺旋手里剑，持续4秒、每0.25秒伤害。三种攻击均可对空。
- **雷电领域（雷法紫卡）**：需已解锁大招，只能获取一次。大招实际落雷后留下3秒地面雷电领域，每0.5秒造成20%技能伤害，共6次；重叠区域对同一敌人取最高伤害，近处落雷刷新领域，最多8处。领域属于地面效果，不命中飞行怪，不额外触发眩晕、感电或新领域。

两位新英雄按既有方式进入英雄页、商店、编队、升级与训练页。风刃术士5200钻、忍者5400钻，1-4开放；新旧存档均不自动赠送。当前只加入通用强化卡。忍者未来的“普攻自动原路返回、去回两段伤害”机制保留路径数据，未加入卡池。

技能与大招细节参数统一在 `assets/scripts/config/WindNinjaConfig.ts`，数值为首版，后续根据手机试玩调整。

## 美术与包体

使用内置 **image_gen** 生成两位英雄正背立绘、头像和6个技能图标，以及雷电领域卡图标。圆形图标保持实心画面、透明圆外、不加装饰外环。原始生成文件留在本地 `local/art-archive/wind-ninja-v120/`；正式资源为 `assets/resources/ux/wind_ninja_v120/` 的3张图集，合计2910937字节PNG母版。制作只做均匀缩放、裁切、排版，不改写语义像素。运行版继续既有Q95 RGB、无损透明通道导出，3张新增图集共698750字节（最终以导出记录为准）。

提示词与选择记录：`character-prompts.json`、`icon-prompts.json`、`art-selection.json`。图集坐标、SHA和UUID见 `art-manifest.json`；可重复制作脚本为 `prepare-art.cjs`。战斗风刃、风眼、龙卷、手里剑、留标与电场为受限数量的代码几何，无新增视频或大幅特效序列图。

依用户最新要求，开发期间不再以200MB作为发布上限，不因包体目标降低画面质量；继续既有压缩、版本缓存和资源校验，保留发布器原有950MiB托管安全检查。仅扩展原有两种中文子集字体的10个新字形，保留全部原字形。
