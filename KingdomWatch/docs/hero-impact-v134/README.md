# 英雄特效精修 v134

本轮按用户连续反馈完成御剑师、忍者、风法师与空间法师的表现调整，基于 `d80042b0`。普通攻击与大招保持各自可辨认的轮廓；正式特效通过现有数学 Shader 和已有龙卷序列帧完成，无新生图/视频、无新增媒体纹理。

## 御剑师

普攻飞剑接入玉色双刃、护手、剑脊和收束尾焰。剑体采用带覆盖率的预乘混合，让剑看起来更实。落地的连续亮环改成不等长破土气浪，增加地面裂痕、灰尘、带亮面的碎石和上冲剑芒。巨剑先轻微下沉插地，约0.82秒后开始淡出，完整落地效果1.4秒；小剑约0.38秒后淡出、总0.82秒，技能终结剑总1.08秒。技能/大招的伤害、落点、剑数、飞行与命中时机保持。

## 忍者与风法师

手里剑大招保留四尖锐刃，改为实心蓝白光体，四条随尖端转动的拖影、七条外围短流线、零散切割光点与亮芯形成层次。释放飞行复用相同材质，保持原大招时间与伤害。

风刃保留朝目标凸出的圆弧刀锋，增强前缘和刃面；拖尾改成随机分布、不等长、弯曲且随噪声破碎的细流，减少梳子状平行线。线段碰撞和穿透规则保持。龙卷显示宽度从3.3r到4.6r，宽高等比放大39.4%；原图集、脚底锚点、48帧循环、两倍转速、移动方向与伤害范围保持。v133已认可的风眼80%透视和下移9参数保留。

## 空间法师

普攻改为紫晶尖矢、明暗切面、亮脊与破碎光尾，真实命中时触发小型裂光。技能采用0.35秒消失、0.45秒隐藏、0.50秒重现，原伤害与减速仍在施放时结算；位移延迟到消失结束且只执行一次。没有额外无敌或定身，首领仍免位移；死亡、池化重生、禁锢中断会恢复透明度，全部使用模拟dt。

大招先以不透明发光球体包住整只怪物，球面纹理/高光以约0.45rad/s缓慢转动，轮廓固定。球体尺寸由立绘宽高共同决定，防止宽体怪露出。首领有视觉包裹但仍免控。地面光柱有短喷发起手、较宽紫色能量体、上升亮芯/光束与持续上行波纹。原6/8目标、0.95秒起手、3秒/10次范围法伤、重叠只结算一次、lifeId与首领规则保持。
