# 第一章前线敌兵美术初稿 v1

2026-10-18 用户要求暂停数值平衡，先迭代一个普通近战小怪和一个普通远程小怪。原版哥布林观感被用户否定，允许换皮，保留类似行为；新设计需适合第一章前线。

本轮采用边境人类劫掠队，同阵营赭红布料、米白袖子、旧皮革和灰铁。用深色轮廓、大色块与较少装饰呈现。使用内置 image_gen，输出两张1254×1254 RGBA透明原画，原生alpha保留，无抠图或后期图像修改。完整实际提示词见 prompts.txt，文件散列和透明通道信息见 assets.json。

- 劫掠步卒：铁盔、短砍刀、破木圆盾，偏矮壮，设计对应现有苦工成群冲线/近战攻击定位。木盾只是当前外观设定，不代表新增格挡或护甲机制。
- 投石散兵：赭红兜帽、皮背心、投石索与石袋，轮廓较窄，设计对应现有投石手后排停步投射/较脆定位。

近战源图：sources/frontline-raider-melee-v1.png。生成时以现有弓箭手战斗原画和前哨地形作为线条/世界参考，没有使用旧哥布林外形。远程源图：sources/frontline-raider-ranged-v1.png；以本轮近战稿作为画法、配色和视角参考。

两只角色为俯视约30度的正面三分之四视角，朝画面右下方，展示完整身体和武器。当前只完成角色初稿，不是动作图集或已经接入的游戏资产。没有修改资源加载、怪物ID/名称、波次、数值、存档、图鉴或动画，没有生成视频；未构建部署或运行游戏。本轮没有游戏代码/正式资源变更。尚未获得用户视觉认可，后续可根据反馈调整，再制作行走与攻击动作、对齐战斗尺寸后接入。
