## 卡面

修改五英雄及全局卡中 58 处定义文案，当前描述最多三行。移除选择卡面自动追加的叠层变化及搭配提示；原字号 18、196×112 描述框、25 行距与原布局保留。未改变效果、代价、层数上限、前置、权重或应用代码；本局强化清单仍可主动查看真实已选层数和组合。

余烬爆破现为：

移除卡面内部半径单位，保留自身点燃、死亡触发、伤害与不连锁限制；实际爆炸半径仍为 100。穿林箭改为「普攻额外穿透1个目标」；贯颅弩矢明确普攻和技能都生效；「额外枪线」更名「额外弩矢」，卡 ID、存档和图片映射保留。每张旧/新文字见 [card-copy.json](card-copy.json)。

## 普通难度 1-1～1-6

逐关只增加普通哥布林数量并缩短其出怪间隔，末波普通怪开场延迟各缩短一秒。沿用用户原先波次、缓急变化、精英/骑兵/投手/萨满/Boss 组合及它们的数量、时间、血量、攻击。所有普通怪单体血量、攻击也保留；其他难度、1-7 之后及无尽配置没有修改。

| 关卡 | 波数 | 总怪物数 | 增幅 | 静态排程秒数（原→新） |
| --- | ---: | ---: | ---: | ---: |
| 1-1 | 6 | 101 → 139 | +37.6% | 186.8 → 178.89 |
| 1-2 | 7 | 136 → 192 | +41.2% | 202.05 → 204.5 |
| 1-3 | 8 | 228 → 332 | +45.6% | 239.35 → 242.0 |
| 1-4 | 8 | 269 → 401 | +49.1% | 244.35 → 245.03 |
| 1-5 | 8 | 283 → 437 | +54.4% | 238.03 → 238.61 |
| 1-6 | 10 | 343 → 531 | +54.8% | 298.75 → 301.63 |

静态排程为逐波 `max(delay + (count − 1) × interval)` 的总和，仅计算配置字面量，不运行战斗或模拟。增加目标密度的同时让原出怪时间跨度接近；这些值不是实测通关时长。实际时长仍受移动、清怪、暂停、大招及存活上限影响。

保留现有 60 只存活上限与未生成怪物的排队行为。更多普通怪会自然带来更多击杀经验、能量与掉落；每只怪奖励、击杀充能和共享比例不变。英雄伤害、技能冷却、大招各自能量需求、0 起始能量、v70 选卡时序及胜利延迟、v71 精英图标、v72 物品详情保持。此版是密度调整，实际难度与性能以手机试玩为准。
