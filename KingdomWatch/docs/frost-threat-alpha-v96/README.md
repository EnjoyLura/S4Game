## 英雄待机

用户文件按顺序对应弓箭手、火法师、重弩手、雷法师，原片均为 720×1280、24fps、97 帧。按 12fps 等时采样，保留整段 4.041667 秒和最后一帧的真实剩余时长；每人 49 格、352×576 固定画布、3168×3456 图集。全片使用同一裁剪、缩放、脚底基线，未逐帧重新居中。没有倒放、长停帧、姿态扭曲或交叉淡化；没有提交新视频生成任务。

灰底弓箭手按中性蓝灰背景连通域提取，单独处理弓弦内空隙；白底火法、黑底弩手/雷法按背景连通域提取，保留人物内部深色/高光，去掉独立水印。雷法杖旁的黑底辉光转为半透明。透明帧经深浅背景接触表检查；源视频的细节、动作与首尾差异仍可能存在，数值像素差不作为视觉认可。

`HeroLobbyIdle` 只用于英雄页与升级页的英雄立绘，按资源清单真实帧时长播放。仅加载当前展示英雄，动画就绪前保留原立绘；失败仍显示原立绘。固定脚底、等比适配当前展示框，不叠加摆动/呼吸。隐藏/裁剪不可见/后台停止推进，节点销毁清理帧和纹理引用；降低动态设置时保持静态。没有修改战斗英雄动作、头像、奖励弹窗或武器升级页的展示。

可直接打开 [四英雄待机预览](hero-idle-preview.html)，该页面只绘制图片，不启动游戏。处理脚本 `hero_idle_frames.py`；逐帧校验和预览生成 `verify_pixels.py`。

## 冰面与大招

冰领域使用原 v10 的 44 帧、锚点、尺寸和 Alpha；展开到最后成熟帧后按实际地带寿命延长，随后继续原 0.68 秒收尾。移除 v95 另叠较早成熟帧的交接，避免消散时冰面重新变满。没有改变伤害、范围、冰封、减速或卡牌提供的地带寿命。

冰法大招蓄力 0.65 秒，三个实际伤害落点统一为 0.65 / 1.60 / 2.55 秒；每波落冰在其后 0.48 秒内错峰落地，保留全场随机覆盖与现有 256 颗配置，落点不跟踪敌人。最后落点 3.03 秒，其收尾在总时长 3.75 秒内完成。每次实际伤害触发一次对应冰音，预加载音效、缩短单次尾音与限流间隔，避免中间波次被吞或装饰冰针重复播放音效。三次伤害的数量、倍率和控制效果保持。
