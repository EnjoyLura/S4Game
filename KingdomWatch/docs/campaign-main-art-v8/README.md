# 关卡主页、准备抽屉与出战编队美术 v8

本轮连续三个用户请求合并落地，以已选效果图为参照：

- 主页：保留真实 PNG 深蓝金边章节背板，补充雕刻边饰、箭头和粗标题；前哨盾牌增加金属厚度、铆钉、亮边和漆面；深林保留木路标、木纹、铁钉和苔藓，兽穴保留黑铁与骨牙。石台采用两层石鼓、分块接缝、顶面倒角和落影。真实星级、锁标、奖励红点、选中光环和名称牌统一。出战准备仍以 x=0 居中，编队位于其右，无通栏底板。
- 准备：浅白暖纸、细金边、粗标题、三枚难度旗和金色难度签；三色宝箱及独立领奖按钮、浅白金币/材料卡、居中装备标题、金色开始按钮。沿用既有实际插画资源和奖励事务。装备区按用户最新要求改为一行半的独立滚动视口，完整显示所有装备池条目；其余内容固定。此要求替代之前“两行全部展开、无内部滚动”的版本。三个难度共用同一布局高度；普通模式同尺寸留白仅显示说明。
- 编队：深蓝金边标题牌及左上返回入口、站位框、四张浅白站位卡、五张浅白英雄卡、真实已上阵/未解锁状态；金色选中边与绿色勾，非选中钢蓝边。上部营房插画保留，下部复用英雄大厅透暖纸、低对比盾徽水印及地面。完成按钮使用同套金色斜面样式。
