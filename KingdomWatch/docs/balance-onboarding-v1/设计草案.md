# 数值平衡与新手引导：第一轮设计草案

2026-10-18。依据当前项目源码静态梳理。本文是设计提案，没有修改运行参数、玩家存档、关卡或发布线上版本，也没有运行测试、模拟或游戏。文中的建议区间不是已验证结果或行业标准。

## 先确定首局体验

用户已确认：首局直接进入第一关（1-1），净战斗3–4分钟，保留弓箭手＋重弩手。时长口径沿用1倍速、不含选卡等暂停。首局不另设独立教学关，引导融入第一关。

用户要求继续提问，让其通过选择完成平衡设计，直到方案足以动工。用户曾要求使用Codex询问功能，随后反馈选择卡片未选完就自动结束，最新明确要求停用卡片，改为文字一次列出多个问题供其选择。后续只用文字批量提问；已确认内容保留，未回复不视为选择推荐项。当前处于设计决策阶段，不能因单项选择就视为整体方案已定稿。

第一轮只打磨1-1普通，固定英雄/武器/三个能力槽均1级、初始白武器、无其他装备、主城1级、GM关闭、不买道具、不复活。已有养成账号不能直接当新玩家基准；不能为此清空用户原存档。

首关目标建议：看懂自动攻击 → 做出一次有感强化 → 学会技能与大招的区别 → 手动释放一次大招 → 得到一次可立即使用的成长奖励。技能自动冷却、大招手动充能，保留当前每局通过卡牌学习的设计。

## 五轮调参顺序

1. **首关基准**：先确定初始队伍、首局时长、普通怪被几次攻击击杀。冻结局外养成、装备和英雄基础值，调1-1专属怪物参数与出怪，不用全局倍率连带改变30关。
2. **首关成长与引导**：明确第一次强化、技能、大招的出场顺序和供给，保证教学所需的卡可获得。再根据每次成长后的输出调整下一段出怪；体验成形后开放正常随机。
3. **五英雄定位**：同预算装备与等级，对比单体、密集怪、快速怪、精英压力。弓箭手持续输出，重弩高血目标，火法密集群体，雷法中等规模连锁，冰法减速保线。冰法以减少触墙数量/损失的贡献评价，不追求伤害榜一样高。
4. **装备与卡牌**：固定关卡及英雄，测一件装备或一张卡相对基准增加的有效清怪能力。攻击×攻速×暴击×目标数会相乘，多发/贯穿/分裂也要计入命中率与溢出；不能把“每条都+10%”当作总提升10%。随后检查冷却下限、叠层上限和不同乘区组合。
5. **局外经济与后续关卡**：确定玩家在第几关前能免费得到第二英雄、第一件装备、第一轮升级；按该阶段实际可获得的阵容设难度。每次成长消耗可除以典型免费通关收益，估计需要几次通关；一次性首胜/星箱与可重复收益分开。最后扩展1-2/1-3及精英、地狱。

优先调整首局中的“何时变强”和“何时受到压力”，而不是同时重写所有英雄、怪物和装备。

## 首关初稿：建议目标，待用户选择

以下时间从关门动画完成并开始战斗计起，不含选卡、说明和其他暂停。按事件触发引导，时间只作节奏目标，不以倒计时强行弹窗。

| 阶段 | 暂定净战斗时间 | 战斗与教学 |
| --- | --- | --- |
| 初次接敌 | 0–25秒 | 少量慢速苦工，简短提示“英雄会自动攻击，守住防线”；通过观察完成，不强制点击英雄 |
| 第一次变强 | 约20–35秒出现首选卡 | 首次三选一必含明显可见的弓箭手强化，标记推荐；正常保留选择权。先让玩家看见强化效果 |
| 学技能 | 约45–80秒 | 后续教学卡组必含一张技能学习卡，选择后解释“冷却好会自动施放”；确认选到了再推进该教学步骤 |
| 学大招 | 约80–125秒 | 必含大招学习卡，解释能量与手动释放；后续安排可获得充能的敌群，必要时设计只在首次教学触发的一次性充能补给 |
| 使用大招 | 第一次充满时 | 暂停并轻提示实际大招按钮；点击确认、真实释放成功且有命中反馈后再恢复教学推进，避免对空释放 |
| 收尾 | 约175–240秒 | 一只教学精英配少量杂兵，检验已经学过的能力，不一次引入萨满、快怪和多精英 |
| 首胜回营 | 结算后 | 一次性明确奖励一件适用装备或足够完成一次升级的材料；只引导领取并使用一次，然后放开 |

首波苦工可把280–300生命作为第一组候选：在当前武器与无暴击前提下，弓箭手约6次、重弩约2次命中。这个区间只改善击杀阈值，不能单独解决出怪过密；出怪总量/间隔也要与固定队伍及教学成长配合。没有把候选值写入运行配置。

首关减少敌人机制种类比单纯削血更有价值。建议首关以苦工为主和一只尾段精英，第二关再教远程怪，第三关再引入快速怪，萨满治疗更晚出现；具体推进需与用户希望的内容密度协调。

## 引导的实现约束草案

- 步骤完成条件用实际事件：卡被成功领取、技能被实际施放、大招命中、装备穿戴成功。条件未发生不提前进入下一步。
- 普通提示短暂出现；只有必须操作的步骤才暂停并限制到目标控件。处理误触、切后台、重进、翻页和目标尚未加载，不能把玩家锁死。
- 教学卡仍经过正常领取、前置和上限校验。通过保证供给和推荐引导，不偷偷替玩家选；若用户选了其他卡，后续继续提供缺少的教学能力。
- 单独保存tutorialVersion与步骤；只对新账号启用完整流程，已有账号不强行补播。返回重进可恢复步骤，已发奖励不能重复发；不重置原存档或养成。
- 新手保护若需要，放在明确的教学流程/补给中，不根据刚买的装备暗中把同关怪物血量同步抬高。

## 用户试玩时最少记录

每轮同一基准账号/设备/1倍速，记录：第一次命中时间、第一次选卡时间、第一次技能/大招时间、通关时间或失败波次、最低及最终防线比例、选卡列表、哪一刻无聊或突然堆怪。首关至少应不依赖购买、广告或复活即可通关。

有多人试玩后再统计首通率；只有一个人的数次结果不能当作新玩家总体胜率。一次只改一组变量，保留前后参数和主观反馈，循环形成可用初稿。现有伤害占比只能辅助判断；群伤、控制与辅助的价值需要结合敌群与防线损失。
