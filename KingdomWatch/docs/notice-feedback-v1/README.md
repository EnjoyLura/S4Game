# 通知与成长反馈

统一 `PageKit.toast` 为可区分信息、成功、提醒、奖励和升级的非阻塞通知。沿用主界面的深色纸牌和细轮廓，使用状态色与图形标识，展示标题和正文；通知位于资源栏下方，约 2–2.65 秒后淡出，底部细线提示剩余停留时间。

升级／强化使用更丰富的成功卡：对应英雄头像、武器／装备／能力图标，等级前后对比、两项主要属性的实际增量、数值变化、轻微回弹和六枚短促光屑；达到阶段突破时补充提示。英雄、武器、普攻／技能／大招、已穿戴装备及主城升级入口共用 `GrowthFeedback.growthAction`，在原存档操作前后读取数据，失败显示具体原因。普攻倍率和大招单次系数读取战斗配置，装备读取 `equipStat`，英雄数值读取 `heroStats`。

同一对象连续升级合并首个等级与属性基线至最新值，数字从当前显示值继续变化；单次只保留一条通知，重复提醒延长停留，其他事件替换当前通知。无排队积压，不拦截输入，不创建遮罩。通知独立于页内刷新，载入图标后再入场，带版本校验；后台、禁用和销毁清理，无通知时组件停止逐帧更新，支持减少动态效果。

购买／招募、星级宝箱、图鉴奖励、穿戴／替换／卸下、出售／分解及编队更新已接入相应状态。成功、奖励、提醒、升级使用已有授权采样，同一动作按语义优先合并按钮声，沿用原音效开关与频率限制，不新增音频或图像生成。

功能代码：新增 `UINotice.ts`、`GrowthFeedback.ts`；更新 `PageKit`、`UIAudio`、`TrainingLobby`、`HeroPage`、`UpgradePage`、`BasePage`、`ShopPage`、`LevelsPage` 和 `SquadPanel`。原升级、购买、奖励数值和存档操作保持。
