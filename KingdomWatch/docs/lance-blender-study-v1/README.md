## 可重复制作

Windows PowerShell，在 `D:/AI/S4Game` 执行：

```powershell
& 'D:/program/Blender 5.2/blender.exe' --background --python KingdomWatch/docs/lance-blender-study-v1/build_scene.py -- --all --size 1280 --samples 64
python KingdomWatch/docs/lance-blender-study-v1/compose_preview.py --all
python KingdomWatch/docs/lance-blender-study-v1/verify_artifacts.py
```

安装的 Blender 版本为 5.2.3 LTS。合成脚本使用 Pillow、NumPy、imageio 和 imageio-ffmpeg；未调用付费模型、未下载外部美术资源。

`build_scene.py` 创建真实三维曲线、纵向刃面、体积电离尘、带重力的碎石和火星。对象按枪体、飞行电弧、爆发、地电、传播前沿、碎屑分组，场景时间线标有触地和各次放电。透明地面 holdout 裁掉地面以下的几何。

`compose_preview.py` 添加固定展示底色、局部触地照明和多尺度金色辉光。辉光是后期合成步骤；直接查看原始透明帧不会包含最终光晕。森林示意只使用现有项目素材，未启动 Cocos、浏览器、真实战斗、音频或 WASM。
