# 防线蓝色外盾、数值排列与普攻特效 v2

本轮连续要求合并发布：模仿用户提供的外层包覆思路，防线蓝盾改为空心外框；生命在上、盾值在下；耐久条稍微上移；大招入口上移；普攻发射更明显，并补齐飞行拖尾和弹体两侧装饰。

防线绿色耐久仍宽640、高18，底基从198提高到212设计像素。蓝色盾量包在完整耐久槽外侧：外形652×30，内部留空644×22，中间不绘蓝色覆盖生命。盾量/最大耐久决定蓝框从左到右的覆盖长度；盾耗尽仅隐藏外框，第二行盾值保留0。右上两行右对齐、生命心形在上、盾形在下。最低大招入口底基从240提高至340，仍按已解锁英雄紧凑排列，每项间距110。

发射使用四张内置 image_gen 独立生成的透明贴图：风压、短焰流、紫色电弧、冰霜，弩复用风压并更宽厚。原生成像素和透明通道完整复制进项目，没有把其他游戏截图提交给模型。源图、实际提示词、尺寸和SHA分别保存在 sources/、prompts/ 和 generation.json。弓箭0.32秒、重弩0.36秒、火0.36秒、雷0.30秒、冰0.38秒；配合原生扩散风压和碎屑，以快速展开、短促保留、渐隐消散表现出手。只有实际普攻回调触发，弓箭每排一次，齐射不重复叠加，连射每排独立触发。36个预建Sprite槽，没有逐发Node或Tween。

BasicProjectileFlightVFX增加一个Graphics，绘制按真实飞行距离逐渐增长的锥形渐隐拖尾，最大长度126／146／112／118／136设计像素。三层透明尾迹从弹体尾部向后延伸，弹体两侧加少量风线、余烬、电丝或霜晶。保留现有彩绘箭矢、火球、冰棱和原有很轻的尾迹，新增统一元素层；普通弩箭和雷弹替代旧通用尾迹，避免两个强尾巴重复叠加。只装饰普攻及强化普攻箭，不改变技能、大招或敌方弹体。相位来自每枚弹丸固定种子与战斗年龄，长度来自弹速×年龄，暂停和倍速同步。

没有改英雄媒体、尺寸、攻速、伤害、弹速、方向、碰撞、索敌、技能或命中特效。按用户要求只构建web-mobile、执行DPR补丁并发布main，不运行测试、游戏、浏览器或线上视觉验收，视觉效果交由用户人工查看。
