# 陨石落地同步与音量 v31

## 改动

- 以已提交的 v30（`a02434d5`）为基准，陨石播放增益从约 0.17797973 增加到 0.31649769，乘 `10^(5/20)`。雷声、冰声、章节 BGM、其他音效及总线增益均保持。
- 陨石仍只在 `Projectile.hitGround` 的真实接地调用中发声，不改落点、伤害或动画。
- 原音频长 2.3 秒，前奏逐渐增强，50ms 窗 RMS 从开头约 0.00002 升到 1.6 秒时约 0.554。落地后从源文件零秒播放，会让撞击主体晚出现。现在从源第 70101 帧（44.1kHz 下约 1.58959 秒）附近低振幅位置起播，保留约 0.71041 秒撞击主体与尾声。原文件不重剪、不改速、不替换；这是播放偏移，源文件仍完整保留。
- 原 2.35 秒全局重复间隔会挡住连续陨石的接地声；改为 0.18 秒，过滤同一瞬间重复触发。新一次陨石接地替换同种旧尾音，旧尾按既有 15ms 渐退，避免长尾叠加。原八声部预算和其他组策略保持。
- 陨石音频加入优先预载列表，并在火法大招蓄力时再次请求同一缓存，落地播放仍不排队等待网络，避免出现过期补声。
