# 升级页布局实施

2026-10-10，按已确认的四张概念图实施等级、武器、技能、装备四个培养页签。

- 共用资源栏保留手机顶部防遮挡空间；五名英雄选择、图标在左文字在右的培养分类、暖木色底部导航保持一致。
- 等级：英雄立绘站在石台上，右侧羊皮纸显示当前/下一等级攻击力和技能伤害，下方横向展示等级突破。
- 武器：英雄专属武器独立展示，右侧属性预览，下方武器突破。强化的是原有 `weaponLv`，沿用原有费用和效果。
- 技能：三个大图标选择普攻、技能、大招，单张羊皮纸只预览当前选中技能，突破路线随英雄和技能切换。底部按钮升级选中技能。
- 装备：四格木柜展示已穿戴头盔、饰品、手套、衣服，选中装备后在羊皮纸上预览各词条提升，底部按钮强化选中装备。装备没有突破路线。
- 消耗与按钮固定在底部导航上方。较短屏幕只滚动中间内容，不缩小全部界面文字。
- 所有数值、英雄归属、穿戴实例、费用、材料扣除均来自现有存档与 GameData；材料持有显示强化石和精铁锭的合计，符合原有扣除顺序。
- 将火、雷、冰三名法师的技能伤害预览对齐现有 heroStats 的每级 8% 成长。未修改战斗、经济或突破配置。
- 保留英雄页/基地共用的 `equipModal` 与 `zoneTab`。

代码：`assets/scripts/ui/TrainingLobby.ts`；原升级页保留数据适配与共享弹窗。

## 美术资产

通过 imagegen 技能的内置 image_gen.imagegen 工具生成，透明背景。选定输出直接复制，未处理图像像素；frames JSON 只记录透明区内的独立对象矩形供运行时取帧。

- `assets/resources/ux/lobby_training_v1.png` / `.frames.json`：空白羊皮纸木支架、石台、武器架、四格装备柜。
- `assets/resources/ux/lobby_weapons_v1.png` / `.frames.json`：五名英雄的长弓、重弩、火杖、雷杖、冰杖。
- 石台、装备柜、展示架使用独立帧；羊皮纸采用九宫格，横版技能/装备预览与竖版等级/武器预览共用。
- 英雄立绘、头像、技能、装备和货币图标沿用现有资产。

生成要求摘要：暖色手绘中世纪铁匠铺、粗轮廓、木材/黄铜/石材、透明背景、无文字和内置数值。四个空容器分成 2×2，四周留透明间隔；五件完整武器独立排列，保持各英雄已有武器颜色和材质。空容器不含角色/道具，以便接入真实存档；武器不含架子或人物。

参考概念图与完整设计提示词：`docs/ui-concepts/upgrade-layout-20261009-v1.md`、`docs/ui-concepts/upgrade-tabs-20261009-v1.md`。

## 交付

使用 Cocos Creator 3.8.8 的 web-mobile 构建，运行既有 DPR/缓存版本补丁，发布到 kingdom-watch 的 main 分支。按用户要求，交互与手机视觉由用户人工体验，不运行浏览器验证或测试。
