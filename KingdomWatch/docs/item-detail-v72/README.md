## 实装

新增 `assets/scripts/ui/ItemDetails.ts`，复用 DetailDialog 的纸张、标题、概览、滚动内容、段落、属性组、底部操作区，以及 ComicUI、LobbyChrome、HeroComic 的现有组件和物品图标。布局为左侧大图、右侧名称/类别/真实持有量，下方道具说明、获取途径与关闭。装备增加品质/阶级/初始属性和适用说明，英雄显示解锁状态/等级/技能/大招；经验明确只在本局生效。短屏滚动正文，标题/概览和关闭按钮保持固定。获取途径使用当前已有系统的信息卡，不放置无实际跳转行为的「前往」按钮。

胜利、失败、暂停奖励总览的金币/钻石/经验/材料/装备/英雄卡均绑定具体物品 ID，打开对应详情；不再用任意装备点击打开整份战利品列表。无尽结算的金币、战利品清单也有独立入口。原结算卡片几何、动画、双倍/复活操作及数值均保留。

宝箱、图鉴奖励、商城购买和英雄加入共用 RewardPopup 的点击详情入口。各调用方明确提供语义 ID，不从图片路径或翻译名称推测物品。展示的是已发放奖励与真实数量；查看前结束当前装饰揭示，关闭详情后回到同一奖励弹窗，点击空白处才确认收下并触发原有装饰飞入。原领取锁、回调一次性与持久化位置不变。

关卡金币/钻石、首胜英雄、装备预览和无尽掉落列表改用同一详情。保留各难度真实基础/首胜奖励、普通怪/精英怪/无尽首领的实际掉落概率和池内占比；首胜英雄回到原列表，装备初始属性显式以 Lv.1 计算，不读取已培养武器等级。列表打开详情时复用遮罩并保留原列表节点及滚动位置。

详情只读取存档及定义，持有量包含已穿戴装备，实际奖励数量与持有数量分别标注。单宿主防止叠开，点击物品与详情关闭均吞事件；关闭 X、底部按钮、空白处与浏览器返回只关闭本层。详情不调用 Panels.begin、不重新领取/抽取/购买、不切换战斗状态。
