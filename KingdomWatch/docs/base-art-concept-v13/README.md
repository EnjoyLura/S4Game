## 待实装美术升级清单

1. **营地标题**：远征营地采用浅薄的深蓝细金名牌；副标题层级、字距和建筑避让统一。
2. **建筑名牌**：主城金色、研究院深蓝、工坊锁定态；切角细边、名称/等级、说明文字对齐；研究院红点数字大小与贴边位置统一。
3. **防线建设栏**：全宽浅纸面与清晰顶部分割；城堡图标、标题、等级比较分列；耐久和护盾使用近白分组卡，数字与图标统一基线。
4. **建设入口与状态**：保留原单层升级按钮；可升级绿色、金币不足灰绿、满级展示状态清楚；费用与金币图标对齐，按钮下方及导航上方保留空间。
5. **弹窗通用背板**：三类弹窗统一商品详情纸面、薄金边、内收深蓝标题、原关闭X；遮罩、间距、滚动边界和底部留白统一。
6. **主城建设内容**：城堡展示、等级变化、耐久/护盾的当前值→下一值及增量；整组近白底，不加逐行底条；建设消耗与持有数分组，短缺红色。
7. **图鉴概览**：书本图标、已发现数量、待领奖数量与细进度提示；解锁说明与卡片区分隔清楚。
8. **图鉴卡片**：两列卡片统一尺寸、细框、浅白底与浅圆插画承托；怪物名称/奖励统一位置，完整显示插画与底部文字。
9. **图鉴状态**：未发现项单色剪影+锁+问号；待领奖红点及钻石奖励；已领奖勾标和收敛文字色；仅更新美术表达。
10. **怪物详情展示区**：原怪物完整插画、名称、小型/大型/近战/远程/BOSS等真实标签；BOSS与普通怪物复用同一布局。
11. **详情内容区**：行动特征、怪物描述、应对弱点分别为整块近白内容组；标题深蓝、正文灰褐、应对信息绿色，适度分隔与留白。
12. **首览奖励操作区**：统一钻石图标、一次性奖励说明、已领取与可领取状态；原绿色/灰绿单层按钮，按钮底部约30单位留白。
13. **适配细节**：短屏只滚动内容，固定建设栏/操作区；列表返回保留位置、建筑入口随场景同步、图鉴详情沿用一个遮罩。
14. **共用组件一致性**：资源栏、原圆角金色导航选中、浅分隔线与原按钮几何沿用全局组件；工坊仍为尚未开放提示。

实装复用现有连续庭院、建筑和六种怪物原画，保留 `upKeep`、发现条件、`claimCodexReward`、每种一次20钻石、建设公式及上限，不增加图鉴一键领取或工坊新功能。
