# 火法特效 V2：轮廓、连续帧与力量感

图片能够作为高质量 2D 特效的主要素材，但图片的缩放和淡化无法替代动画设计。上一版采用三个独立火焰形态长时间交叉淡化，缩到手机后细节碎、轮廓软，噪点消散又削弱了实体感。运行与功能检查通过并不代表视觉质量达标。

本次保持原有对象池、真实碰撞触发、伤害、怪物行为、大招队列和持续灼烧区计时，重做素材和演出。

## 本次改变

| 问题 | 调整 |
| --- | --- |
| 细节过密，手机显示发糊 | AI 重做大色块、清楚轮廓的卡通火焰；减少细碎烟火纹理 |
| 三张独立图互相淡化 | 改为八个连续形态：点燃、撑开、峰值、展开、分裂、火舌、残焰、消散 |
| 主体透明叠加、失去体积 | 峰值保持约 248/255 的 Sprite 顶点不透明度；仅在切帧前约 8ms 混合 |
| 消散呈现细碎噪点 | 共享局部材质保留原生透明度，不做高频噪声溶解 |
| 碎片移动慢，缺少力度 | 爆炸碎片初速度约 225 游戏单位/秒，接触约 145，随后由重力与短淡出收束 |
| 溅射群怪重复铺火球 | 周围目标只出现短小接触火花，主目标升级为一次爆炸主体 |
| 焦痕像发光圆环 | 单独用 AI 编辑成不规则焦黑区域；重叠焦痕降低透明度 |
| 边缘可能受黑色透明像素影响 | 图集打包增加四像素 RGB 外扩，原生 alpha 不变，仍保留透明边距 |

普通火焰接触、爆炸主体、烟尘和地面残留错峰出现。主体约 360ms，整个短特效含贴地余痕约 780ms；持续灼烧区域仍使用游戏原有 4 秒寿命。没有战场震动、全屏闪光或相机缩放。

## 做出高质量特效需要什么

图片负责火焰的轮廓、色块和材质；连续帧负责变化；纹理粒子负责方向与速度；时间曲线负责爆发和停留；分层与透明混合负责空间感；声音、飘字和敌人反馈共同确认命中。这些都能在当前 Cocos 2D 工程内完成。

复杂的流体形变、很长的持续火焰或三维绕身效果，才可能值得进一步使用程序形变、网格或 3D 渲染后导出序列。增加这些技术之前，先把一个短命中特效在手机尺寸下做清楚，比增加图层和粒子数量更有效。
