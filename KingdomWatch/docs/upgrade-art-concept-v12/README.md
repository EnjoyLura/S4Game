## 待落地的美术升级清单

1. **英雄头像栏**：五张完整正圆头像、紧凑间距、细描边与选中名字签；英雄名字、等级、职业统一层级。
2. **培养分类页签**：等级、武器、技能、装备共用深蓝连体底条，统一图标、文字、选中金色面及间隔。
3. **等级页展示与成长面板**：立绘与石台衔接；纸面金框、内收深蓝标题，等级箭头、当前值、下一级数值和绿色增量对齐。
4. **武器页展示与成长面板**：完整大号武器展示、名称与培养继承说明，统一强化对比面板。
5. **技能页选择与预览**：普攻、技能、大招三张选择卡，正圆插画、等级、选中态；技能倍率成长面板与解锁说明。
6. **装备页选择与预览**：四张装备选择卡、方形品质底板铺满槽位、细选中框与勾标、装备强化对比面板；去掉品质角标与阶数文字。
7. **突破区**：等级、武器、技能分别沿用对应图标；切角纸卡、下一阶段强调、未解锁锁标、效果排版、横向浏览提示。
8. **属性与说明区**：整组连续近纯白背景（接近 #FFFFFF），不做每条词条一张底板；深蓝标题、灰黑正文、绿色增益、足够行距和清晰对齐。
9. **消耗与底部操作区**：金币/强化石图标、消耗与持有数量并列清楚；数量充足使用常规字色，不足才用红色；原单层操作按钮保留窄高光、轻斜面与底部空隙。
10. **通用弹窗背板与标题**：复用商品详情的浅纸切角框、细金轮廓、内收深蓝标题、原深蓝关闭X、遮罩与自适应高度。
11. **属性总览弹窗内容**：英雄头像与信息、五行英雄属性整组浅白底、单个关闭操作区。
12. **突破详情弹窗内容**：技能/武器/等级图标和名称、突破效果整组浅白底、解锁条件与状态；不新增购买或手动解锁流程。
13. **武器培养与装备强化弹窗内容**：完整品质槽、等级变化、强化属性对比、消耗材料、说明和单个强化操作，按钮下方留白。
14. **分割与一致性**：细线与菱形明确划分展示、突破、消费区域，统一色彩、字号、切角和边距；底部导航沿用原金色圆角选中面及浅竖分割线。

## 原图与核对说明

所有选定 PNG 均从内置工具输出直接复制到本目录，未额外裁切、调色或二次压缩，复制前后 SHA-256 一致。武器培养弹窗中材料充足却显示红色的数字，经一次 imagegen 定点编辑修正后再保存最终原图。

已逐张查看生成原图：三个培养页内容不同、四类弹窗齐全，属性为整组近白背板，装备槽没有品质角标，完整视口内没有桌面任务栏。生成图中的数值、技能文字、角色细节和按钮描边仅供视觉排版参考；实际落地以源代码数据、用户已确认的角色资产及原单层按钮为准。
