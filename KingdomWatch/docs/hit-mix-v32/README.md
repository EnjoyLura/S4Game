## 受击规则

此前普通命中共用 `v26/hit_common`，但 `Monster.takeDamage` 对暴击/重击不发声，依赖弹道的额外调用，导致雷链、冰法直接范围结算等入口覆盖不完整。三法师重击又通过别名复用普通声。

现在正数的直接攻击扣血统一由 `Monster.takeDamage` 调用 `Sfx.impact`，识别 `heavy || crit`。普攻、技能、大招、链式命中、溅射、致死命中都走同一入口。移除 `Projectile.hitMob`、`Projectile.hitGround` 和雷链内的重复声音调用；伤害数值、暴击判定和效果逻辑没有改变。灼烧周期扣血与 GM 清怪沿用静音，不将持续状态扣血当成一次新攻击。

| 英雄 | 普通受击 | 暴击/重击受击 |
| --- | --- | --- |
| 弓箭手 | hit_common | 原 crit |
| 重弩手 | hit_common | 原 pierce_heavy |
| 火、雷、冰法师 | hit_common | 共用原 crit |

弓弩认可的素材及播放增益保留。火法 `ultimateImpact` 额外请求重击层，包含没有怪物的真实地面撞击；有怪物时与扣血入口的同瞬间重击合并。保留 v31 陨石起播偏移、+5dB 增益及旧尾音接替。

普通受击/重击不再受原 0.18/0.2 秒全局间隔限制，改为 8ms 内合并同类请求，覆盖分开的快速攻击，同时防群伤同瞬间堆出大量相同录音。两类各允许最多两声部，仍受八声部总预算、优先级和暂停/后台/关闭音效控制；不排队补播旧事件。属于混音上的聚合，并非给群伤每只怪物保留一个独立音轨。

## 批量音量基准

`tools/calibrate-audio.py` 读取实际可播放音效与别名，离线测量 50ms 有效段 RMS，排除低于 -70dBFS 或相对最大段 -24dB 的静段，陨石按实际播放偏移测量。当前覆盖 26 个入口、32 个入口/素材组合。自动写入 `AudioMixCalibration.ts` 及 `calibration.json`，不重编码、裁剪、滤波或播放任何音频。

八类基准为攻击、普通受击、重击、大招、界面、奖励、结算和场景事件，分别参考当前弓箭、通用受击、暴击、陨石、点击、领奖、胜利和关门。保留轻重差异；每素材校正最多 ±6dB，并预留单素材峰值 -3dBFS。用户认可的弓、弩及其大招/重击、刚调好的火法陨石固定现有增益，作为保留项，不被批量校准覆盖。其他包括雷/冰大招会按基准纠偏，见报告的 `trimDB`。

该测量是短音效的可重复电平基准，**不是标准综合 LUFS，也不能保证不同音色在人耳听来绝对等响**。总线压缩、音乐避让、声部密度和最终限幅仍影响实际输出。实际听感由用户人工试玩。

- 全部音效一次调整：`assets/scripts/core/AudioMix.ts` 的 `SFX_MASTER_TRIM_DB`。
- 一类声音一次调整：同文件的 `SFX_CATEGORY_TRIM_DB`。
- 批量基准/保留项：`tools/audio-mix-policy.json`。
- 修改/新增素材后重新校准：项目目录执行 Python `tools/calibrate-audio.py`。默认更新本轮的校准报告，可用 `--report` 指定新路径。

游戏播放读取批量修正值，再叠加总控/分类 dB 与已有单音效增益。音乐是独立总线，本轮章节 BGM 音量与切换保持。
