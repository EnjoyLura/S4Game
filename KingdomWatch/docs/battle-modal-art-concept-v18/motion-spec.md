## 动效节奏

胜利总长约 1.4 秒，各段有少量重叠，完成后停稳：

| 时间 | 表现 |
| --- | --- |
| 0–120ms | 战场平滑压暗，保留场景辨识，避免全屏白闪。 |
| 80–440ms | 金冠号角与标题短距落定，一次约 2.5% 回弹。局部暖光短亮，7个以下微光点随后消失。 |
| 300/470/640ms 起 | 按真实获得星数依次点亮，每颗约230ms落定，轻音阶同步；未得星保留灰色。预览用三星示例。 |
| 440–800ms | 已有位置的奖励纸面与两张奖励卡轻移渐显，不重排。 |
| 700–1120ms | 金币滚动至实际值；经验为0时保持0，材料完整数量轻显。 |
| 850–1100ms | 原按钮向上8px渐显。约1.4秒画面全部收稳，不持续抖动、呼吸或闪烁。 |

失败总长约 0.85 秒：

| 时间 | 表现 |
| --- | --- |
| 0–160ms | 战场平缓压暗，不使用红色闪屏。 |
| 100–460ms | 银冠蓝缎带短距落定、减速收稳，无庆祝回弹、星星和金色放射光。 |
| 220–550ms | 关卡、保底比例、奖励与到账状态依次渐显，金币直接显示最终保底值。 |
| 470–690ms | 原位复活和再来一次按钮轻显，不自动选择。 |
| 690–850ms | 保持清晰可读状态，等玩家决定下一步。 |

暂停总长约0.4秒：压暗和标题120ms，当前奖励60–280ms，页签与操作120–340ms。没有庆祝声和持续光效。

各类弹窗关闭统一约140ms淡出、微上移6px。实际接入时继续保留广告忙态、重复点击保护、离场导航锁、复活进度和领奖状态，不因动画重复到账。后台暂停与减少动态模式必备；减少动态下直接呈现完整结果。音效预览默认关闭，手动打开后仅复用现有victory/defeat/star音频，不改写游戏音频。动作与音频均未由代理运行或试听，待人工确认。

录屏只离线参考“结果先确立、奖励分段出现、最后停稳”的节奏，没有复制外部游戏标题、美术或强烈放射光。

## 需要落地的美术升级清单

1. 暂停标题：深蓝面、金色细边、克制高光与对称端饰。
2. 暂停奖励区：标题分隔、金币/经验圆座、原插画清晰度与数量层级。
3. 暂停页签：奖励总览/伤害统计/设置的连体边缘、金色选中和深蓝未选中态；相关伤害条、设置行和开关沿同一风格细化。
4. 胜利顶部：原金冠、号角、缎带的边缘与明暗；三颗星的金/灰状态和克制局部光。
5. 失败顶部：原银色破冠、蓝缎带的冷色层次与清晰文字。
6. 结算主背板：原切角纸面范围内的细边、高光和分隔，保持当前布局。
7. 奖励卡：金币/经验两卡、材料与装备卡的浅白填充、统一单轮廓、图标比例及实际数量；到账/保底/双倍说明清楚。
8. 文本与间距：标题深蓝、正文灰褐、结果说明浅色；保持原文字、字号和位置，仅细化美术对比和留白边界。
9. 操作按钮：沿用金色/绿色单层切角，细高光、按下/松开/禁用/广告忙态一致；保持原位置和尺寸。
10. 动效与声音：胜利分段揭晓和星级音阶，失败克制落定与短提示音，暂停安静快速，统一关闭收尾；不使用硬边风车光或全屏白闪。

正式接入时以现有 Cocos 原生分层和原始字体渲染，不把整张生成效果图贴进游戏；细边装饰要服从清晰度，不能堆叠厚重双框。
