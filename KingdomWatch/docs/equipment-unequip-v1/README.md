# 已穿戴装备卸下入口

点击英雄装备栏中的已穿戴武器或装备，详情弹窗底部显示“卸下装备”和“装备锻造”两个按钮。背包装备对比弹窗的当前装备卡也提供“卸下”和“锻造”。按钮沿用主界面美术、弹性反馈和确认音效。

卸下调用已有 `takeOff` 并保存，装备实例保留，随后关闭弹窗、刷新装备栏、穿戴数量、属性和战力。背包切到武器／装备对应分类并回到顶部，便于找到刚卸下的物品。卸下前校验当前装备 UID，避免旧弹窗误卸下后来替换的装备。

本次功能代码仅修改 `assets/scripts/ui/pages/HeroPage.ts`。依用户约定仅源码调整、Cocos 构建、DPR 补丁和发布，不运行测试、游戏、浏览器或线上验收，实际体验由用户人工确认。
