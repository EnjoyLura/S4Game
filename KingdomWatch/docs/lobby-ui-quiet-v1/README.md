# 升级页与关卡奖励区视觉收敛 v1

按用户认可的方向图落地，范围为升级页四个培养分类及关卡奖励区域。参考图见 `approved-direction.png`；这是上一轮 imagegen 生成的方向图，不是运行截图。本轮复用现有漫画插画，由 Cocos 原生图形和文本实现，没有新增运行时图片请求。

- 升级页去掉英雄选择卡的大方框，以圆头像、单一金环和金色名字签表示选中。保留原水平滚动、英雄锁定及选择记录；英雄页自身选择卡不变。
- 分类页签统一成一条深色导航，选中项金色，去掉每项描边与细高光。属性入口同步弱化。
- 普攻／技能／大招去掉方卡，图标从 112 增至 136，选中项以局部金环及名字签突出。技能属性不再套背板；等级、武器属性仍有无描边的米色面，保证场景上可读。
- 等级／武器／技能突破外层框移除，阶段卡改圆角淡底，下一阶段用柔金色。保留 194 间距、622 视口、吸附与拖动判定、全部可点详情和各英雄的偏移记忆。
- 装备培养的整栏和属性外框移除，部位选择用中性色和金色状态。消耗区取消分隔线，升级主按钮保留单轮廓、原位连升及战力动效。技能区最小内容高度 704→736，为更大图标留出空间；短屏沿用内容滚动，材料和操作固定。
- 关卡奖励改全宽连续米色底，去掉外描边、顶部高光及标题分隔线。奖励分类用淡底与金色选中；未达成和已领取改文字状态，可领取保留小金色提示，整块宝箱区域仍可一键领取当前关卡当前难度的全部可领星箱并显示真实到账弹窗。
- 共享 ComicUI 新增纯填充 `comicSurface`、可选高光开关和按钮 `quiet` 选项，均需显式启用。其他页面、弹窗和战斗按钮保持默认样式。

改动只涉及 `ComicUI.ts`、`TrainingLobby.ts`、`pages/LevelsPage.ts`。数值、存档、奖励事务、章节推进及战斗资源保持；前两轮章节与奖励弹窗的未提交工作保留，未追加 Git 提交。
