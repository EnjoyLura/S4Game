# 音效重制 v21

用户认为战斗、三选一、领奖、胜败和升级音效质量不足、正反馈偏弱。本轮制作并接入新的音效版本，实际听感待用户人工确认。

- 83 条 44.1 kHz / 16 bit WAV，约 4.97 MB。来源为授权录音及作者制作的完整短乐句，停止使用 v15 手写振荡器庆祝音作为这些玩法的主要反馈。
- 五位英雄的普攻、普通/重命中、技能、大招和击杀材料重新处理。保留清楚起音，补足中段质感，扩大普通攻击与大招的层次；高频事件有变体、限频和分组预算。
- 三选一分为书页/卡牌出现、翻牌刷新、选中落点三个声音；删除 BattleDirector 延后的第二次选中确认声。
- 胜败音效跟随结算素材就绪后的首帧播放一次；减少动态效果的设置不会关掉胜败声音。结算重绘、广告双倍后的重绘不重复整段胜败音。
- 领奖使用完整庆祝短乐句，购买使用金币与物品落袋；英雄升级使用魔法上升与亮音，主城升级增加木石落点，突破使用更强的庆祝。数字落定、星级、长按连续升级使用单独短音，不重复叠满段旋律。
- 保持既有总线音量；录音源包络/峰值与听觉层次重做，不通过提高全局音量增加爽感。宽频素材保留瞬态，离线峰值控制最多 6 dB，无削波样本。技能与大招会让已经播放的普通命中尾声退让，关键提示让背景音乐短时退让。
- 场景切换和离开战斗清理音效尾声；原可信手势解锁、音乐/音效开关、后台静音和暂停行为保留。背景音乐文件不变。

新增 Fantasy Sound Effects Library 署名 Little Robot Sound Factory，CC BY 3.0；来源与修改说明加入游戏设置可访问的 `audio-credits.html`。其他录音沿用已有署名和许可。原始下载、实际使用的 60 个录音、每条编辑参数和散列见 `sources/` 与 `assets.json`。

`prepare_audio.py` 只做离线录音编辑，`prepare_preview.py` 只打包手动新旧对比页。两者均不播放音频、不运行游戏。保留既有奖励/购买/成长/保存事务、数值、战斗动作与美术。

按既有要求仅执行静态源代码/类型/组件注册检查、音频样本指标和生产资源引用检查，以及构建/DPR/发布。未执行测试、模拟、游戏、浏览器、试听或线上验收；制作、构建和发布不代表音质已经获用户认可。
