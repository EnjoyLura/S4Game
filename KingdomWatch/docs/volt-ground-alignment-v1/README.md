# 雷电落点、重弩枪线与火法陨石修复

用户截图显示雷柱正常，但底部光圈少半边且明显向右错位。

根因在`volt-ultimate-procedural.effect`地面分支：进入分支前，横坐标已经由`(u - 0.5) × 宽度`居中；分支中又减去半个宽度，使横坐标变为`(u - 1) × 宽度`。因此光圈圆心落在绘制四边形右边缘，右半圈超出范围被裁掉，同时相对节点落点向右偏移半宽。默认半径90、宽274.5时，偏移为137.25。

修复为地面分支独立使用中心坐标`(u - 0.5, 0.5 - v) × 尺寸`，光圈、中心辉光、电裂纹及雷柱脚点共用同一落点。原载体横向半宽1.525倍半径、纵向反投影半高约1.558倍半径，均覆盖径向淡出的1.48倍半径，无需放大特效或移动战斗节点。

雷电仅修正程序材质的地面坐标，不改雷柱造型、亮度、节奏、半径、伤害、目标、怪物位置、人物动作、音频，以及上一版界面交接。

随后用户补充重弩大招选取额外枪线后，锁定演出仍只有一条线。现改为整帧清理一次共享Graphics，再按本英雄`ultBolts`追加每个目标的蓝色瞄准轴、汇聚光点和收拢准星。无卡1组、1层2组、2层3组；敌人不足时与实际可发射目标数一致。出手处汇聚光点只画一次，避免多枪线叠加发白。

锁定主目标保持原规则，死亡时转向当前全场最高血量目标；附加目标仍为其余存活怪物中血量最高者，无重复。以最多3项的小排序复用锁定数组，不逐帧复制排序整个怪群。0.5秒锁定期间同步目标移动、死亡、血量排序与当前枪线数，最后一帧的同一组目标直接传给发射，避免演出目标与实际弩矢脱节。手动与90级自动大招共用。原弹速、伤害、贯穿和数量规则保持。

火法随后收到预警与实际陨石位置不符、落点过密的反馈。旧陨石是普通向下火球，沿途命中任何怪物都会提前爆炸；预警和火坑则通过另一倒计时在原位置独立产生，存在两套落点和时钟。现在固定地面弹绕过途中碰撞，越过最后一段飞行时钳到预告中心；同一真实落地事件负责爆炸、范围伤害、音效、预警撤除和火坑创建，落空也正常爆炸留坑。大招弹预算满时保留预警并重试，发射接受后才进入飞行状态，不靠倒计时凭空生坑。

5/7颗陨石由同一小范围梅花改为分散选点：根据排队间隔和坠落时间预估怪物下行、减速及冻结，优先覆盖尚未被本轮计划覆盖的怪群，再考虑覆盖率和落点间隔。默认优先间距147设计像素，大坑升级后176；有新目标但空间不足时可适当靠近，只有单簇/Boss时优先有效命中并在簇周围错开，不为了分散砸空地。已有待落陨石和预计落地时仍存在的火坑也参与间距判断。预警出现后位置固定，不随怪物漂移。预测不保证战局变化后每颗都能命中，效果和平衡由用户体验。

预警外缘固定为实际爆炸半径140，内准星和光强微动，不缩放真实边界。保留5/7颗、800弹速、0.5秒首发与0.32秒间隔、单中心全额与其余原溅射倍率、中心原暴击/附带状态、4秒火坑和原易伤/灼烧数值。演出锁时长按实际落点飞行距离估算，技能说明同步。复用既有火焰与火坑美术、音频素材，无新媒体生成。三项修复共包发布，上一版界面交接保留。
