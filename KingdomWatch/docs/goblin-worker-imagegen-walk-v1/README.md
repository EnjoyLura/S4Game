# 哥布林苦工：直接生图生成8帧行走

使用内置 imagegen，以游戏当前正式图集里的绿皮持斧苦工为参考，生成一张4列×2行的正面行走精灵表。此目录是独立实验预览，未修改游戏美术、动作、脚本、构建或部署。

## 查看

- `index.html`：离线预览，原图对照、播放/暂停、逐帧、速度和背景选择。
- `walk-preview.gif`：8帧、10FPS、0.8秒正向循环。
- `source-and-walk.gif`：左侧当前游戏原图，右侧本次生成动作。
- `goblin-worker-walk-8f.png`：2048×1024透明精灵表，单格512×512。
- `frames/`：8张独立透明PNG。
- `walk-preview.apng`：保持透明度的动画。
- `goblin-worker-walk-8f.zip`：原始生成图、PNG帧、图集、预览、提示词和元数据。
- `generated-sheet-original.png`：生成工具原始输出，不覆盖、不改绘。
- `prompt.txt`：提交给内置imagegen的完整实际提示词。
- `prompt-correction.txt`：第二轮纠正第6、7帧左右脚相位的实际提示词。
- `generated-sheet-correction.png`：第二轮生成原图，最终只采用其中第6、7格，其余六格仍取第一轮。
- `manifest.json`：素材来源、切图范围、统一缩放、逐帧整体对齐及原游戏文件散列。
- `validation-report.json`：PNG/GIF文件与帧数检查，不代表视觉通过。

## 素材与生成

参考图从 `assets/resources/ux/battle_mobs_v2.png` 的 `goblin_worker` 区域 `[59,24,393,464]` 无损裁出。正式游戏仍由 `MobAnim.ts` 读取原 `battle_mob_anim_v1`，并保留 `current-game-frame.png` 作为现有步态首帧对照。

生成原文件：`C:/Users/user/.codex/generated_images/01a1494f-e0d3-7423-88a3-3e1079c0ca5f/exec-3a58588d-fc19-4630-8903-73639d4ebc82.png`。原文件保留，另复制到本目录；原始尺寸1774×887，实际alpha透明。生成工具输出不是严格的整数格尺寸，因此按整张4列×2行比例分界切图。

第一轮第6、7格的抬脚相位重复了前半周期，第二轮由内置imagegen定向修正为画面右侧腿在前，不对整个角色镜像，因此斧头仍在画面左侧。第二轮原文件 `C:/Users/user/.codex/generated_images/01a1494f-e0d3-7423-88a3-3e1079c0ca5f/exec-b1a1f4a2-e395-49c6-9c73-354e88947a7d.png` 及其副本均保留。导出脚本只从第二轮读取索引5、6的两整格，其他六格直接沿用第一轮；不拼接身体局部。

`bake_preview.py` 只做切帧、一个共同缩放比例、整帧平移对齐与导出，不使用网格变形、肢体拆分、交叉淡化、反向播放或补帧。保留生成alpha。按头部绿色区域的横向中心对齐；可见鞋底对齐同一基线。绘制本身的姿势/比例变化仍需用户判断，不能由程序对齐自动修复。

## 提示词要点

保留当前苦工身份、绿皮、大耳、黄眼、獠牙、皮带、破布围裙、护腕、皮靴以及画面左手侧的粗斧；8帧分别描述左右脚接触、承重、抬腿、摆腿。正面、原地、固定相机与比例、透明背景；禁止转身、攻击、跑跳、重复姿势、增加服饰或改变斧头。完整英文提示词在 `prompt.txt`。

本轮仅生成和整理预览素材，没有运行游戏、浏览器或交互验收。所有结论均限于静态图检查和文件检查，实际步态与循环自然度待用户审阅。
