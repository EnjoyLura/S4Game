# 商店主页面与商品详情美术 v3

按用户选定的[商店主页面](../shop-art-concept-v2/shop-main-v2.png)和[商品详情](../shop-art-concept-v2/shop-product-modal-v2.png)效果稿实装。原有商品插画、场景与原生文字继续复用；本轮的渐变、斜面、薄边、属性条和小花饰由 Cocos Graphics 静态绘制，不新增位图资源。

商店保持大图、横向分类和三列商品布局。分类共用深蓝条，选中签有窄金色斜面；米纸商品卡有柔和渐变及克制的折角。品质槽由158增至180，铺满同大方形，插画由132增至154，品质左上标签不恢复。卡高330、行距346，给商品图、名称、说明和有厚度的绿色价格按钮各自留空间。

五页共用底部导航继续128高、五入口相同位置，改用深蓝渐变和金色选中面；入口之间加入四条低对比度浅分割线。

商品详情重做暖纸薄金框、深蓝弧形标题栏、168方形品质槽大图与商品说明。初始属性、武器特性、持有情况、获取说明分组，使用小花饰标题、浅米色属性条和绿色加成数字。详情按真实内容分配高度，上限1120；短视口仍可滚动信息区，底部价格、余额、购买数量、关闭和购买按钮固定。

用户明确要求购买/关闭按钮不加效果稿金边：关闭使用深蓝斜面，购买使用绿色斜面，高光与薄边均保持自身色相；不可购买使用灰绿禁用态。按钮的按压、取消、音效、余额不足提示、重复输入拦截、实际购买事务和成功返回沿用原实现。商品预览与购买处理函数在源码差异中逐段保持相同。

本轮只修改`MainUI.ts`、`ShopPage.ts`，新增`LobbyChrome.ts`及其导入元数据。`before/`与`source-baseline.json`记录改动前源码。`release.py inspect`只读取源码、类型日志及编译产物，保存差异、哈希与原逻辑保留情况；不执行游戏代码。项目仍有此前十项主类型诊断，改动模块无新增诊断。

遵守人工验收要求：不运行测试、模拟、游戏、浏览器、截图验收或线上验收。Cocos生产构建、DPR补丁、production/MD5准备与Wrangler main发布完成后，保存部署回执与版本链接。实际视觉和点击体验由用户人工确认。未新增Git提交。
