# 装备品质、掉落详情、图鉴与战斗结算反馈

2026-10-16，本轮合并用户连续提出的改动，构建发布后由用户人工体验。

## 装备与图鉴

- 普通灰、优秀绿、稀有蓝、史诗紫：共享饱和色切角边框、同色名称、品质文字标签及浅色内底。商店大图另有同色光座，蓝紫品质用少量静态星芒区分。背包、已穿戴装备、商品详情、关卡掉落和战利品清单使用同一规则。购买按钮保留其操作语义色。
- 关卡掉落预览的装备、金币和材料图标可直接点开各自详情；设备属性读取真实 Lv.1 定义。装备详情分别列出普通怪/精英怪每次击杀概率与掉落成功后的抽取占比，前者等于总掉落率乘装备池权重占比。详情列表到单件详情共用遮罩、保留原列表位置。底部掉落详情入口保留全关规则。
- 未解锁怪物使用现有图鉴图像的真实轮廓，RGB 归零并以固定透明度呈现暖灰剪影，配以“？？？”。不展示名称和奖励；已解锁项目保持现有图像、名称和领奖逻辑。此前待用户确认的新怪物概念图没有接入。

## 城门与瞄准线

- 暂停退出、胜利退出、失败重试及 GM 离场经统一退出方法播放现有城门；合拢 240ms、闭合至少 1.5 秒、展开 320ms。闭合后才加载主场景；目标关卡页的嵌套刷新、美术和完整绘制就绪后开门。保留当前关卡/难度，输入防重入；场景请求失败回滚导航与战斗状态。
- 重弩大招瞄准轴改为高可见度蓝色，从起始阶段保持 alpha 235–255、宽度 2.6–3.2；辅以细海军蓝对比边、浅蓝光芯。主线、额外枪线共用绘制方法，锁定数量、目标、时长、伤害不变。

## 结算、动画与到账

- 胜利和失败结算移除伤害统计及其页签，仅保留固定“奖励总览”、奖励、评级/关卡信息和原操作区。战斗中与暂停中的伤害统计仍保留。
- 皇冠与标题组成同一容器。胜利轻弹收稳、少量金色装饰，评级星星按 190ms 间隔从灰星点亮、落位回弹及局部金环碎光；失败使用较小幅度下沉回稳和蓝灰碎光。金币/本局经验依次缓出滚动，到达最终值短促弹起；原胜负音之外仅少量短确认声，禁止逐帧数字声。
- 约 1.65 秒内收净，完成后停用更新。单一组件时钟、单 Graphics，无持续节点/粒子生成、无循环 Tween。后台冻结；关闭/离场取消待绘制监听和引用；减少动态偏好直接显示最终值。按钮不等待动画结束。
- 双倍金币成功后从原金额滚到新金额，不重新播放皇冠/评级演出。广告取消保留既有结果。
- 用户明确确认“修复奖励到账，保留30%金币保底”。原失败流程只计算显示、未入账，现失败按 `floor((当前难度关卡基础金币 + 累计击杀金币) × 0.3)` 发放。将关卡基础金币纳入保底，避免没有击杀时整场 0 金币。全局金币加成与难度加成沿原击杀收益/基础金币配置生效，不重复乘。
- 单局 `goldSettled` 记录已发目标，每次只补差额。复活后相同收益再次失败不重复发放；最终通关扣除先前已发保底，广告双倍也按本局目标补差，并加一次性回调保护。主动暂停离场不额外发失败奖励。装备按原 UID 去重入包，通关材料仍仅通关获得。
- 经验没有现成的永久货币字段，沿用本局升级用途，卡片明确为“本局经验”；新增累计获得值用于结算，避免误把升级扣除后的经验条余量当成本局所得。未新增永久经验货币或修改存档结构。
