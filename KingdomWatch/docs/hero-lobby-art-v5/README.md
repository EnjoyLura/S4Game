# 英雄页美术落地 v5

参照 [英雄页效果稿v4](../hero-art-concept-v4/README.md) 实装指定区域，复用原有角色、场景和物品插画。文字仍由原生Label显示；不把效果稿整张贴入游戏，也不使用图稿示意数值。

- 头像栏：保留原横向滚动尺寸和选中记忆，圆头像配深蓝细托边，金色选中环和圆角名字签；未拥有继续半透明并显示锁。
- 英雄信息：姓名34号加粗、职业/等级20号，描边收细、信息层次更清楚；原人物大小、脚底与石台位置保持，战力牌保持。
- 穿戴：浅纸主面板、穿戴计数、完整方形品质槽。使用商店同一品质绘制，武器左图与其余槽同高同宽，等级/数量角标保留，无品质角签。空槽统一浅色与低透明度剪影。
- 属性/故事入口：150×52原单层ComicUI深色按钮，图标与名称同行；独立操作区64→80，底部多留8单位空隙，场景石台锚点同步补偿。
- 背包：浅纸主背板、深蓝分类条与浅分隔、原金色选中、五列完整品质槽；大空区用现有背包图标的淡化插画，短区保留文字空态。继续过滤所有英雄已穿戴装备，按英雄/分类记住滚动。
- 弹窗：属性、故事、当前/背包装备、双栏对比、出售确认、强化和材料详情统一暖白纸框/深蓝标题/金棕细分隔。属性、特性、说明使用整组接近白色的底面。
- 操作区：装备和强化按钮距外框底边30–32单位，保持单层按钮和原功能。装备对比仍为两张直接卡片、点空白关闭，不增加外层框或关闭X。
- 商店属性同步提白：整组底面由#FBEED1→#FFF8E5调整为#FFFCF6→#FFFFFF，底部不再渐变到黄色。

当前大武器卡820高、双栏武器卡800高、非武器卡680高，留出最多三条武器属性、两条突破说明和继承等级；对比价格与动作单独排布。强化700、属性680、故事600、材料548、出售确认528。金币/钻石/材料数、成长、穿戴、出售、购买和存档规则均使用原代码数据。
