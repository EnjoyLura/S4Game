# 普通前六关微调与胜利收尾 v74

本版按此前讨论的普通 1-1～1-6 微调血量、数量，并将主线胜利改为清场后继续运行至少两秒再弹窗。法抗兵和编队配合仍是下一步方案，见 [设计方案](enemy-cooperation-plan.md)。

1-5 首领血量 7000 → 7800。逐波分组、缓急顺序、特殊怪数量/间隔/延迟、所有怪物攻击力保持。其他难度、1-7 之后和无尽数值不变。逐组旧新数值见 [字面量核对](wave-literal-review.json)。

静态排程仅为逐波 `max(delay + (count − 1) × interval)` 的总和，不是实测通关时长；配置总血量增幅也不等于实际难度增幅。更多击杀仍按原规则产生经验、充能和掉落，单怪收益与英雄输出未调整。现有 60 只存活上限及满池延后生成保留。

## 两秒胜利收尾

最后一只怪物死亡且末波出怪队列清空后，仍保持 `running`，继续推进英雄动作、现有攻击队列、飞行弹体、死亡效果、场景、掉落、飘字和大招。两秒使用真实时间，独立于 1/1.5 倍速和顿帧；若最后的大招仍在收尾，则待它结束后结算。

清场结果固定后，延迟飞来的敌方攻击和防线自动回复不再改变耐久、星级；这段时间不打开选卡、暂停、GM，也不接受新大招和战斗详情点击。末次伤害之后再次检查清场，优先于升级弹窗，避免最后击杀升级时先弹出选卡。完成标志避免重复发送清场事件，原奖励和双倍领取防重入代码保持原样。

无尽仍沿用原层间结算和三秒休息；本次两秒规则只作用于主线胜利。
