# 冰法师大招：错峰落冰与场景深度

2026-10-11 用户反馈：冰棱雨仍然很假，可能是出现位置与视角的问题；上一版太密，数量稍减。追加要求是“不要一股脑儿全部落下，一颗一颗落下的感觉”。

这一版把出现位置、形体、前后遮挡和先后节奏一起调整，复用已有冰晶与连续碎冰素材，没有新 AI 生成调用。

| 项目 | v2 | v3 |
| --- | --- | --- |
| 落冰数量 | 固定 128 | 上限 96；`min(96,48+2×可视目标数)`，7 个目标时 62 枚 |
| 出现节奏 | 24 枚主冰棱在起手 55ms 内全部发出 | 每枚有独立先后时刻，发射分散到 0.94 秒；主要冰棱穿插其中 |
| 空中位置 | 所有来源位于同一屏幕上方生成带 | 以各自地面落点为基准投影共同的空中高度，不按屏幕高度拉长轨迹 |
| 地面分布 | 全场抖动网格 | 以目标附近为主，辅以散落；去掉网格的排列感 |
| 形体与远近 | 双尖菱形、大致同样尺寸 | 复用材质的单尖与宽肩，空中主体更小、更窄；远处略小、近处略大 |
| 方向 | 沿固定近竖直角度移动 | 少量水平漂移与加速下落结合，主体朝向随速度切线转动 |
| 角色遮挡 | 所有雨都在怪物上层 | 冰棱加入怪物深度层，以地面落点排序，被更近的身体遮住 |
| 碎裂节奏 | 多处碎冰几乎同时展开，单处 1.38 秒 | 每颗接地才启动对应碎裂；原视频顺序保留，单处播放 0.68 秒 |

主碎冰上限仍为 24 处，维持用户上一轮需要的地面碎屑；每次落冰仍有固定阴影、局部闪光、短裂纹与小碎块回落。整体演出 2 秒，各次撞击先后发生，最后自然清空。普通技能 v10、立即一次伤害和既有减速机制沿用。

新深度注册组件 [BattleDepth.ts](../../assets/scripts/battle/BattleDepth.ts) 让 [FrostUltimateVFX.ts](../../assets/scripts/battle/FrostUltimateVFX.ts) 的冰棱与 `MonsterManager` 共用原有地面排序。所有节点保持预建池；在演出更新后重排激活的冰棱和怪物。场景退出销毁外置节点、注销深度条目，释放图集包装帧及资源引用。
