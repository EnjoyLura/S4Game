# 风体与尖刃手里剑 v122

用户指出v121的四条曲线像风扇、风眼和龙卷仍只有几根亮线。本轮以清楚的武器轮廓和真实风体取代这两种造型。

## 最终方案

- 忍者大招改为尖锐四角的青蓝能量手里剑：长刀尖、内凹切边、透明中心小孔、亮刃和三层转动残影；中心不再大面积过曝。另加低亮度切风与8枚切向碎光。几何后备也改成尖刃，而非圆弧风扇。
- 风眼和龙卷改用原创四帧风体图集，提供云雾的体积、明暗和撕裂边缘。程序以相邻帧预乘插值、内部切向/上升UV平流和细微流纹驱动动画，叠加原有叶片；主风体不再靠几条发光曲线表示。
- 风场只在风英雄的战前预热时创建，图集使用既有uxFrame缓存，与出战准备的预加载路径完全相同。忍者不加载风场图集。每英雄最多8个绘制槽、每帧复用材质、每个效果固定视觉路径；事件销毁清理自有材质和载体，共享美术跨场景保留。
- 真实图像alpha形状决定可见范围，预乘每一帧后插值，覆盖上限0.65，防止黑边和不透明方板；图集单元有55px透明留边、2像素采样内缩、双线性过滤、禁mipmap与动态打包。特效位于伤害数字下方，原有普攻风刃、伤害、命中、聚怪、移动、对空、时长与冷却沿用v121。
