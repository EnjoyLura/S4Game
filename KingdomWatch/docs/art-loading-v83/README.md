## 已实现

- 正常启动不显示「王国守望／正在校验运行入口／托管诊断」页面。校验在后台继续，连接失败或浏览器不兼容时才显示错误与重试。独立 `hosting-diagnostics.html` 保留。
- GitHub 导出根据当前真实 ImageAsset 生成首屏提示。引擎初始化时提前请求当前章节地图及两个货币图标；新档首次教学请求第一战背景。最多三张，使用真实内容版本路径、同源 anonymous 模式与低优先级，不预取全部章节。
- `Ux.ts` 统一去重、缓存与可提升优先级的图片队列。总共最多四个加载；下一步预测在有前台任务时最多一个、其余时间最多两个；纯后台最多一个。已有后台请求在被实际页面需要时直接提升，不重复下载。页面隐藏时不开始新的预测任务。
- 关卡页构建时就安排出战准备的材质、宝箱、难度图标和实际掉落图；掉落素材直接读取渲染共用的 `stageGuaranteedEntries` 和当前关卡装备池。点击与难度切换会立即提升对应资源。
- 出战准备素材随后安排本队合法强化卡。大幅面英雄待机、攻击与怪物图集在这些资源之后准备。原来的顺序是大图完成之后才开始强化卡。
- 当前页面稳定后，后台准备另外四页的场景、当前英雄立绘与共用头像；背包只预测有限条目。章节地图、英雄视频仍按当前章节／本队准备。
- 只等待实际落在裁剪窗口内的图片；屏幕外滚动内容后台加载，靠近视口时提升。保留原页面到目标页面交接、原布局与动画。网络异常下通用等待最多八秒，避免永久输入锁。
- 三选一的装饰图片最多等待250毫秒，再按原动画展示完整名称、描述和程序占位。动画结束即可选择；图片迟到不阻塞选择、刷新和战斗回调。推荐、钻石消费、广告次数、防连点与旧版面板失效检查保留。

头像路径经复核本来已通过 `BattlePanelSkin` 转到共用头像，与 `heroPortraitKey` 一致，此项没有错误替换。
