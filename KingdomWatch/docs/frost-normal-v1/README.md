技能完整恢复 `frost_domain_video_v10`：原 44 帧、统一锚点、0.4 秒起手 +0.42 秒主体 +0.68 秒收尾。v11 实验素材保留，但不再加载用于技能；冻结、减速和伤害配置沿用。
