# 英雄镜像朝向与待机播放规则

2026-10-13 用户要求使用镜像控制英雄攻击朝向，攻击时停止待机，随后明确修正为空闲条件：英雄攻击范围内没有敌人，而不是全场没有敌人。沿用用户此前要求：由用户人工验证，Codex 完成改动、构建、DPR 补丁和发布，不运行游戏效果／交互验收脚本。

五位英雄共用 `HeroBase.faceAttack`，按目标左右位置镜像人物图像，近正上方有方向缓冲，保留当前朝向以避免来回翻转。只修改人物美术节点的横向缩放符号，脚底镜像中心、站位、阴影、HUD 和射击起点固定。镜像按用户本次明确要求处理，服装、武器与持武器的手会一起翻转。

英雄普通攻击范围内有存活目标、存在待发攻击或正在收势时，不推进待机时钟；攻击范围内无存活目标且攻击结束后，继续原待机相位。范围外的敌人不阻止待机，目标判断沿用真实索敌的 `stats.range`；超出普攻范围的技能实际施放时仍通过攻击状态暂停待机。弓箭手射箭方向回调更新镜像，后续已用用户提供的第二段视频接入 [攻击序列帧](../archer-attack-v1/README.md)。其余四位英雄暂停呼吸和衣摆待机相位，保留原有攻击与回位动作；目标方向改由镜像表现，不再用上身横向倾斜模拟转向。

预览沿用 `previews/archer-idle-v1/`，增加空闲、向左攻击、向右攻击按钮，方便用户人工查看待机停止和镜像。发布信息在 `release.json`，构建发布不代表用户已认可效果。
