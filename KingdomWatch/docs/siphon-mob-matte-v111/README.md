# 紫色吸取体积、萨满/投石兵手臂残底 v111

本轮连续反馈合并：用户认为v110吸取过于细线、不如之前有莫伊拉式抽离感；另报萨满与“斧头兵”手臂残底，随后明确纠正为投石兵。最终清理目标只包含萨满goblin_shaman与投石兵goblin_slinger，斧头兵不改。用户还询问弓箭手震退箭与重炮是否共用击退代码，本轮只核对，不改击退。

## 吸取

v110纯ONE/ONE发光在土黄地面上容易变为几根粉白细线，移除了过多紫色实体厚度。本轮增加第三种ONE/ONE_MINUS_SRC_ALPHA预乘混合，生命法师专用；原普通爆炸/烟、地面以及第二种发光配置保持。吸取输出为紫色体积色和局部辐射光的预乘结果，透明度只存在于有形的能量束内，载体外RGB/Alpha都归零。

恢复柔软紫色能量主体、沿怪物到手掌移动的粗细脉冲、内部卷动亮纹、较淡断续侧流，以及敌人和掌心的旋流团。使用物理距离上的连续解析函数，不恢复格点噪声或大黑雾底；不画贯穿整束的白线。保留v110更宽载体、固定8单位边缘羽化与收尖精华粒子。实际扣血/回血触发、锁定、分流、0.25秒结算、主副伤害与所有战斗数值保持。

## 两只怪物局部透明修正

实际资源：萨满chapter1_mob_walk_v94，27帧；投石兵chapter1_mob_walk_v95，43帧中只有0起23～37帧的臂下残底需要修正，余帧保持。原静态帧别名都指向w0。已在蓝底与Alpha图放大确认：萨满左手持杖手臂与身体间为浅色封闭残底；投石兵步态中段左臂和身体间同样有残底。

不重绘/重编码原图集、不新增动作或新图集。新增24,414字节数值JSON，按原固定帧坐标记录局部透明清除矩形：萨满15,520像素/1083小矩形，投石兵5,496像素/437小矩形。仅已确认浅色背景连通区，原区域内RGB最大最小差<48、最低通道>140，限定在相应臂下ROI，避开身体、护腕、石头、骷髅、衣服及其他怪物。

MobArmAlpha在原RGBA8纹理下载/解析后、暴露给人物显示前，使用一次批次GPU局部全透明上传。清除数据不含新角色RGB；边界外原RGBA保持。仅纹理尺寸与旧atlas版本匹配时应用，旧图集无mipmap；非RGBA8未来压缩纹理跳过，不能用不兼容上传。纹理对象/GPU对象双重识别共享结果，资源重建后可重新准备；不每帧上传、不做全图Canvas读回。

BattleSprite静态人物、MobAnim序列、Ux图鉴/提示头像三个消费者都等待同一准备，修正图集的帧禁用动态打包，避免从旧CPU图像再次复制残底。冻结/减速/死亡直接取这张已修正的共享GPU纹理，无单独色键材质，不会因状态切换露回浅底。数值清理清单在进入大厅的导航预热时就请求，关卡预热也等待人物图集完成，失败仍能结束准备。

PNG/WebP源资源和动作顺序/坐标/周期/鞋底/体型保持；原文件仍供本地制作复用。源清单/图集SHA、每帧修改像素数与bbox见alpha-patch-analysis.json。对比图只本地alpha-before-after.jpg，运行包无新PNG/视频。

## 击退核对

弓与重炮均调用Monster.applyKnockback：普通56单位、0.18秒；精英距离乘0.4，首领免疫，临近出生边界时限距。清除突进/攻击动作并回move状态。弓为每4轮成功普攻的首支主箭，连射/分裂不复制；重炮为选取震荡冲击后技能爆炸范围内的多个目标。原击退机制早于重炮加入，不能描述为把重炮技能伤害逻辑复制给弓。差别主要为单箭触发与群体同时推动的反馈；本轮Monster/Hero/Projectile/Cards/技能数值均不改。

- audit_types.cjs以555b4300比较，9条既有类型诊断保持、无新增；只编译。
- check_alpha.py将原PNG上传独立GPU纹理，按实际数值计划局部清空再读回：两图集修补外RGBA完全一致，修补内全透明；只有指定27/15帧受影响。桌面离屏上传约2.825ms/0.944ms，仅说明一次局部上传成本，不能当作手机实测。
