# 雷法师大招：紫电落雷 v2

用户否定旧版宽描边折线效果，提供紫色落雷参考。新版本用程序材质表现亮白电芯、紫色柔光和不规则分叉，落地后电裂纹短暂扩散并衰减。本说明仅记录雷法师组件；随后的重弩大招和界面修复合并至[完整发布](../hero-ultimate-ui-v3/README.md)，构建与发布记录以该目录为准。

- 雷柱使用连续光强衰减的加色材质：细白芯、紫红内辉光、紫蓝外辉光；三种尺度的非周期折转与沿高度变化的粗细，替代旧版等宽多层折线。一次主闪与85ms后的回击沿同一通道，310ms内收净。
- 雷柱向下贯穿目标，终点与地面反馈统一为目标脚下。地面光晕、断续扩散环按0.43纵向比例贴地，约580ms淡去；8条不等长主电裂纹、8条分叉及8条交联形成电网，在约65ms内向外显现，550ms收净。少量亮屑有抛物线运动，430ms收净。
- 地面特效位于怪物下方，雷柱与飞散亮屑位于怪物上方，伤害数字仍在更高层。没有全屏白闪或新的持久残迹。
- 12组固定池，每组空中/地面各一四边形材质，裂纹与亮屑分别共用Graphics；不逐次创建Node/Tween，不读取系统时间，不调用战斗随机流。所有演出跟随战斗模拟dt、暂停、倍速及顿帧，退出释放材质和载体。
- 材质首次未就绪的事件全程采用细电芯回退，不会在播放中切换模式或露出白色四边形。就绪后新事件使用新材质。旧大招描边渲染已移除，避免叠加发白。
- 相近落点按相邻事件的衰减能量压低重复辉光；单个Boss连续被15道落雷击中时，仍保留每次爆发，但减少多层光晕相加发白。
