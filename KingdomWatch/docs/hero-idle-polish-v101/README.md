# 弓箭手披风选段与冰法师法杖抠图修正 v101

用户指出v100弓箭手披风首尾差异较大、冰法法杖有洋红背景残留。本轮继续使用原视频，仅修这两项，其他三位英雄与战斗逻辑保持。按当前仅本地约定不部署GitHub/Cloudflare，不提交源库。

## 披风优先选段

原v100选段评分以全身为主，静止身体区域稀释了披风下摆的误差。新增针对左右下摆绿色区域的轮廓、颜色、相邻帧与运动方向比较，再检查肩臂姿态作为约束。选用第13–49帧（0起，含首尾），37格/1.233333秒，替换原第1–57帧/1.9秒。固定画布352×576、统一裁剪/缩放/脚底，源30fps原速正向播放。

此片段优先缩小披风尾部的衔接差异，代价是肩臂仍有源片轻微位移。原视频并不是完整闭合的全身周期，不能只凭选段把全身变成绝对无缝。未倒放、长停帧、交叉淡化、补帧或改变人物形状。

查看 `cloak-specific-candidates.json`、`cloak-specific-seams.jpg` 与 `archer/seam-contact.jpg`。评分是筛选依据，不是用户视觉认可。

## 法杖残底修正

v100的实体保护遮罩把部分“洋红背景与发光混合”误保护为不透明，造成截图中的大片粉紫色残块。此次对冰法法杖区域单独按洋红色差降低Alpha，并清理发丝/衣缘外轮廓的薄串色；剩余轻度粉色偏色向原有青白光收敛。保留晶体实体、法杖、白发与衣服内部像素，宁可减弱无法干净分离的外圈光晕，也不保留背景块。

原第7–55帧49格/1.633333秒、源帧序和速度保持，画布/固定空间策略不变。`mora-spill-repair.json`记录60个源帧处理情况，修复掩码外RGBA不变、Alpha只降低；指定法杖范围内高洋红残色且高Alpha的像素已清除。深浅背景对照见`mora/alpha-contact.jpg`。不声称原片所有发光都能无损恢复。
