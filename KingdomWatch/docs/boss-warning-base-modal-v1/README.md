# 中央预警、基地弹窗与入场停留

本轮处理四项用户要求：原创 BOSS 中央预警、主城升级后保持弹窗、图鉴与详情往返遮罩白闪、入场关门后停留 2 秒。

中央预警采用暗红布旗、交叉战斧盾徽、代码渲染的中文标题。战旗约 270ms 展开、徽章轻压落位、标题收稳，少量局部金色火星，完整演出约 2.35 秒；减少动态模式约 1.8 秒。没有屏幕红边、全屏变色、故障字效或战斗暂停。两张插画为内置 image_gen 工具原创生成，未使用参考图的骷髅、警示三角或机械齿轮构图。原图完整复制，保留透明通道，未做像素编辑。

当前关卡只配置了大哥布林精英，没有独立 Boss。每个精英波次显示“精英来袭”；未来 `boss:true` 的怪物会显示“首领来袭”，Boss 优先。每波只触发一次，触发时间为首个对应怪组出场前 0.8 秒，最早波次开始时；刷怪时刻、数量、伤害、血量和精英/Boss 判定保持。普通大部队波次保留原提示，特殊波次不叠放旧横幅与声音。

预警走独立的可见时间，不被 1.5 倍速缩短；暂停、三选一、GM 弹窗期间隐藏并冻结，恢复后继续，胜败立即清理，不延后选卡。声音复用已授权的 surge 采样，3500Hz 低通、0.85 倍增益、0.95 倍播放速率、最长约 1.05 秒，沿用音效开关和音频系统的限流与音乐短压。未新增音频资源，未在线试听。

原图鉴路径先 `dismissUI` 销毁旧遮罩，再创建新遮罩并淡入，中间会露出亮色基地。现在同一弹窗会话持有一层遮罩，列表、详情、关闭详情返回列表、领取后回列表都只替换内部内容。保留旧完整面板，等新面板美术与绘制帧准备好再以全透明度交接，前后仅 8px/160ms 轻位移。首次打开和最终关闭仍有原有短动画，图鉴滚动位置保留，过渡期间拦截重复输入。

主城升级成功后同一会话原位显示新等级→下一级、耐久、护盾、消耗、余额和按钮状态；沿用真实保存逻辑与升级通知，不自动关闭，不反复播放开窗动画。共享资源栏即时刷新，底下基地页在最终关闭前完成刷新和绘制，再移除遮罩。余额不足仍显示原警告，满级仍保持弹窗可查看。

根据最后补充，入场正常合拢仍 240ms，完全关上后至少保持 2 秒，展开仍 320ms；温缓存基准动作约 2.56 秒，加上场景交接。冷加载可能保持更久，仍等战场首帧准备好，加载失败回退、后台暂停、重复点击拦截沿用。此要求取代上一版 60ms 最短停留。
