源图：`../goblin-worker-reference-style-v1/goblin-worker-front-blue-v1.png`。这是此前的 AI 静态概念稿，尚未获用户认可；本次仅用作动画技术试验，不能视为用户选定了此怪物形象。

- `goblin-code-walk.gif`：640×640，32 帧，每帧 40ms，1.28 秒循环；米色底和脚下阴影仅用于展示。
- `frames/walk_000.png`～`walk_031.png`：640×640 真透明 PNG，固定画布，不逐帧重新裁切或居中。
- `goblin-code-walk-atlas.png`：8×4 排列的透明图集，5120×2560。
- `goblin-code-walk.frames.json`：帧矩形、时长、锚点、源图 SHA256 与部件裁切信息。循环不重复末端帧。
- `goblin-code-walk-frames.zip`：32 张透明帧、图集与 JSON。
- `walk-contact.jpg`：八个动作阶段的检查图；`parts-contact.jpg`：拆分部件总览。
- `animate.py`：完整可复现源码，仅依赖 Pillow、NumPy。修改步幅、抬脚高度、摆臂、重量感均可重新导出。

实现：按原图坐标手工定义 11 个部件的遮罩，色键去蓝底，使用矩阵驱动分层关节。步态分为接地、支撑、蹬离、摆动，双脚错开半周期；抬脚时重心移向支撑腿，头部与下摆有少量相位延迟。靴子保留比例，腿部用投影长度连接，斧头和持斧下臂整体运动。遮挡处以取自原图的色块和少量确定性多边形补足关节重叠区域；不是从静态图恢复真实三维运动。

已查看部件与八阶段静帧，清理颈部接缝、肘部碎片，确认 GIF 32 帧/1280ms、PNG 真透明、动作极值未触边。实际运动观感由用户查看 GIF 评价，未运行游戏或浏览器。
