# 无尽挑战 · 沿用关卡页出战与编队布局 v62

本轮继续界面设计迭代。用户要求：直接参考关卡页「出战准备＋编队」的布局；无尽模式用于刷金币、刷装备，没有星级宝箱，也没有难度选择。该用途取代v59最初「不发装备」的设计限制，后续实现必须接上真实装备掉落。

## 两个界面状态

- [地图选择页](endless-map-deployment-v62.png)
- [出战准备展开态](endless-preparation-v62.png)

地图继续使用v61连续世界地图，一面旗帜对应一章的无尽模式，支持后续扩展到很多章节。章节地貌和编号位置是临时示意，保留顶部返回、标题与章节目录。

**地图底部直接沿用关卡页操作排列**：左边约四分之三宽的金色「出战准备」，右边较窄的深蓝色「编队」，并显示当前人数/上限，例如3/4。两按钮同高、同基线，在公共底部导航上方。移除v61占据大面积的固定米色详情栏和绿色直接开始按钮，将空间归还地图。

公共金币/钻石资源栏和五页导航保持项目现有样式。无尽从基地进入，导航仍高亮「基地」；资源栏中的钻石只是账户余额，不代表该模式掉落钻石。

## 操作流程

1. 在地图选择某章的旗帜，仅更换当前选中章节，不自动开战。
2. 点击「编队」进入现有关卡页的编队界面，沿用英雄顺序、人数上限与空队拦截；完成后回到无尽地图，更新人数，保留所选章和地图视角。
3. 点击「出战准备」，沿用关卡页从下方展开的准备面板；整个无尽入口仍是独立二级页面，这个面板只是同页的出战准备状态，不将整个无尽模式装回旧弹窗。
4. 准备面板底部复用关卡页金色交叉双剑「开始战斗」按钮，确认当前章节与编队后开战。
5. 收起准备面板回到原地图位置。未解锁章节显示「通关N-10解锁」，不提供可用的出战入口；尚未上线地区显示待开放。

## 准备面板内容

采用关卡页相同的米色底板、标题层次、关闭入口、掉落物品呈现方式和底部金色按钮。删掉难度和星级宝箱后，面板按内容收短，不保留原宝箱区的大块空白。

| 区域 | 内容 |
| --- | --- |
| 标题 | 第2章 · 深林挑战（示例） |
| 纪录/规则 | 最高已通15层；从第1层开始 |
| 怪物范围 | 第1～2章怪物，随解锁章节累计 |
| 挑战掉落 | 金币：击败怪物获得；装备：概率掉落 |
| 装备预览 | 本章真实可掉落装备的图标/详情入口 |
| 主要操作 | 金色双剑「开始战斗」 |

不出现普通/精英/地狱选择、难度旗帜、星数、三星进度、宝箱、一键领取、钻石掉落和通关经验奖励。

准备页可展示已有装备美术，最终应从该章真实掉落池读取。效果图中展示的物品仅说明排版，不批准某件装备、品质、数量或概率；不将主线「普通难度不掉装备」的限制文字带入无尽模式。

## 玩法约束与接入状态

已确定的需求：

- 定位为可重复刷金币和装备的模式。
- 通关普通N-10解锁第N章无尽模式；怪池取第1至N章的实际怪物种类并集。
- 无尽按层推进，没有可切换的三档难度，不使用星级宝箱体系。
- 每次从第1层开始，最高已通层是纪录，不是续关入口。
- 金币和实际掉落装备应进入玩家库存，并使用已有保存、防重复发放逻辑。

本轮未改游戏代码或正式资源引用。只读检查当前Endless.ts仍为gearPool: []，所以线上v59目前并没有无尽装备掉落，不能把本次效果图当作功能已完成。具体掉落池、掉落频率、品质及层数收益曲线需在实现时配置；图中不编造固定收益或保底承诺。
