# 战局能力解锁

本次改动仅调整战局内能力学习、卡池前置和 HUD，不改技能数值、已有特效或主界面美术。

## 游戏规则

- 艾拉、凯尔、焰辉、沃尔、莫拉每次进入新战局，技能和大招均未解锁；已有英雄等级、技能等级与突破继续影响数值，不替代本局学习。
- 每名英雄各有一张白色「解锁技能」和「解锁大招」卡，最多学习一次，只进入上阵英雄的三选一卡池。卡面复用该英雄原技能／大招图标与头像。
- 技能学习后可以按原有冷却自动释放；大招学习后从零开始自然回能与击杀充能，充满后手动释放。
- 技能升级卡要求对应技能已学习，大招升级卡要求对应大招已学习。火法「余烬」需要学习任一可灼烧的能力；冰法普攻冰冻、减速及碎冰卡仍可在入场时出现。
- 首抽、广告／钻石刷新、连续升级后的下一组三选一和 GM 卡注入共用前置与叠层上限检查。保留弓箭手爆炸升级卡的原有前置。
- 技能未学习时，英雄脚底只有一个居中的普攻图标；学习后普攻与技能左右并排。右侧只显示已经学习的大招入口，并紧凑排列。
- 狙击手突破的自动大招、雷法突破的附带连锁同样需要先学习。GM 常满和技能无冷却不绕过学习。
- 复活延续本局学习；重新开局恢复未学习状态。此状态不写入外线存档。

## 验证

`tools/ability-unlock-check.cjs` 使用真实 Cards、Hero 与 BattleDirector 源码、最小引擎替身检查：五英雄普攻／技能／回能、独立解锁、重开、各职业大招拒绝未学习释放、5000 次卡牌抽取、各升级前置、叠层、队列、刷新、未上阵归属，以及高等级附带能力。结果见 `logic-validation.json`。

`check_hud.cjs` 在真实 web-mobile 引擎中合成背景、城墙、英雄、HUD 和三选一，不启动真实战斗、不生成怪物。在 430×932 四英雄与 375×667 单英雄视口检查整组隐藏、普攻居中、独立解锁、冷却显示、大招紧凑排序、现有素材加载，以及实际点击卡牌完成动画后学习能力。使用独立浏览器存档，不影响用户存档。结果见 `hud-validation.json` 和 `online-hud-validation.json`。
