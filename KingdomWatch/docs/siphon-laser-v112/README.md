射线终点与可见战场左右/顶部相交，按有限线段加宽度/怪物半径判断命中，不受最近一只怪物阻挡、无穿透伤害衰减、不命中屏外出生带。基础全宽56，按原技能范围加成缩放；每0.15战斗秒独立结算沿线当前敌人。Lv.1每秒倍率5.2（使用原技能伤害公式/大招加成/暴击/法抗/忽略防御/实际伤害统计），普通1.8秒共12跳；Lv.10后2.1秒14跳。新大招替代旧5秒多连接/主束1.6倍，独立于普攻和技能结算。
