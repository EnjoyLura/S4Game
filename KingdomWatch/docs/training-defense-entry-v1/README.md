# 突破滑动、主城防线与入场停留修复 v1

## 横向突破栏

- 旧组件在父 ScrollView 捕获之后动态关闭纵向轴，首个 8px 位移即判方向，且横向需超过纵向1.15倍，轻微起拖偏移容易锁成纵向；旧纵向接管用的偏移符号也与原生 ScrollView 不同。
- 改用引擎公开 ViewGroup 作为独立手势组，覆盖整个702×244突破纸板（含标题与卡片空隙），卡片仍由原622×174窗口裁剪。父 ScrollView 会识别嵌套组并跳过原事件，不再修改父 vertical 或 cancelInnerEvents。
- 横向6px起拖且允许轻斜向；纵向至少12px、明显纵向才交接。按父公开事件分发原生 ScrollView 的开始、移动、结束或取消，保留纵向惯性与页面滚动记录；初始待定距离只补一次，方向正确。
- 拖动使用纸板本地坐标，不把屏幕/UI坐标直接当本地距离。实时位移直接跟手，不对拖动位置加滞后；松手按35ms平滑速度、130ms有界位移预估决定目标，140–230ms吸附。边缘改连续阻尼，抓住未完成吸附可直接继续拖。
- 等级、武器、技能三栏共用修复。卡片点按详情仍保留，拖动先取消按钮按下；英雄/分类各自位置记忆、减少动态、单指占有、后台/禁用/销毁清理保留。

## 主城属性真正带入战斗

`BattleDirector.start`原来用关卡静态`lineHp`创建防线，且盾默认0，完全未读取主城等级。现在每局用同一次存档keepLv快照，复用基地`keepHp`与`keepShield`创建满耐久/初始盾。Lv.7按既有公式为1700/1700耐久、400护盾。

`LineDefense`新增可选初始盾参数；伤害先扣盾机制保持。`HUD`构建完成立即同步，避免进场与准备倒计时仍露出旧1000/1000、0占位。所有难度、任意关卡和直进下一关均共用；不在每波或复活重新补盾，不改成长公式、星级条件和存档。

## 闭合静止2秒

旧常量本身已是2秒，但每帧至多累计100ms，会遗漏场景构建造成的实际阻塞。现在闭合停留按performance.now前台真实时间计2秒，场景构建和载入与其并行；后台恢复重置取样，不把后台时间算进停留。原240ms关门、320ms开门、美术首次绘制屏障和失败展开保持。素材/场景未就绪的冷加载仍可能超过2秒，不为凑时长打开空战场。
