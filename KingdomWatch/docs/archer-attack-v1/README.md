`build_attack.py` 从视频提取 29 格完整角色透明帧，包含准备、放箭、收势、取箭和举弓回位。删除开头长静止等待；源帧 40、41 是已离弓的飞箭，跳过这两格，飞行箭继续由原投射物逻辑渲染。角色区域固定裁切 `[480,16,908,684]`，避开画面右下标识；保留深色皮革、轮廓和原视频人物，不拆肢体、不变形。

图集 `assets/resources/ux/archer_attack_v1/attack.png` 为 2048×1408，约 1.66 MiB，格子 256×352。源脚底原点固定为 `[650,684]`，格内原点为 `[128,344]`；使用一次固定比例匹配现有待机的举弓高度。运行时两个图集共享相同屏幕缩放和脚底位置 `(0,-76)`，显示高度沿用 146 设计单位；只镜像人物节点。

`ArcherIdleAnimation.ts` 现在同时管理待机与攻击。真实 `fireRow`／`fireFanRow` 的方向回调触发放箭段，动画时钟只随战斗模拟推进。普通攻击前最后约 0.16 秒使用准备帧；放箭后用完整收势／取箭帧，默认最长 0.62 秒，随攻速缩短以配合下一次攻击。连射排在同一动作尚未结束时不重启动作，避免每 0.12 秒强制退回第一格。强化技能本身不触发假射箭，后续金色箭使用同一攻击动作。射速、伤害、射击起点、索敌、弹道和队列沿用原实现。

待机规则继续按每位英雄的普通攻击范围判断：范围内有敌人、存在待发攻击或攻击动作尚未完成时停播；范围外敌人不阻止待机；收势结束且范围内无敌人后恢复原待机相位。其他四位英雄的动作沿用上一版本。

构建后 `node docs/archer-idle-v1/build_preview.cjs` 打包同一套攻击／待机资源，发布到 `previews/archer-idle-v1/`；预览提供空闲、左右攻击、攻速与暂停，供用户人工验收。发布信息在 `release.json`。
