- 编队分割线改为文字内侧的空心菱形、朝外渐细的金棕线，重排站位说明和人数说明两侧的距离；完成按钮沿用同样的镂空菱形。已上阵英雄卡加厚金色内外边、切角肩部和局部高光；上方站位卡用浅金细框，未上阵英雄用蓝银框，卡内浅纸面连续。
