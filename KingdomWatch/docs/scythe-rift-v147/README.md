# 镰刀原裂隙与红黑双镰漩涡 v147

用户已否定 v144 的梳齿普攻、简单长柄镰刀及平面大招；随后否定 v146 试作，未发布。此版按新的明确方向重做，不将此前测试通过视为视觉认可。

## 最新要求与实现

- 普攻参考用户 `codex-clipboard-8fcd8b17-169d-40b1-ac79-8769966a329c.gif`（115帧，首帧70ms）：厚亮弧刃，赤红过渡，连续黑红焰尾随时间撕动。采用连续曲面与颜色／透明度场，去掉梳齿细丝。弧刃的24段扫掠碰撞对齐新曲线，伤害、速度、宽度与穿透次数不变。
- 技能去掉镰刀柄，使用两片对向弯镰、红黑卷流、中心发光碎晶与外围弧形光丝。对照现有忍者 `ninjaFlow` 的主体／尾迹／不同半径气流／核心分层，素材独立制作。32帧、120fps，加1.8倍视觉旋转时钟，约6.75转/秒；模拟位置、投出／停留／回收时序和伤害不变。前后半幅分层围绕怪物，纹理共享，不增加场景节点到逐帧循环中。
- 大招明确沿用 v144 的原始红黑裂隙 PNG，字节不变。各次裂隙缩至0.145—0.21秒，确定性种子变化控制方向、偏移、长度、厚度与前后景；各次切割附带红雾、暗碎屑、少量短火星，随切割散开。背景领域中心更深暗，边缘破碎渐隐与上升余烬。
- 最后主裂隙快速张开并略作停顿，随后错时出现两道辅助裂隙，不做等角放射星形。最后一击前约45ms清空旧痕；九次伤害、总倍率、真实伤害圆、双倍终结、无交叉蓄势均不变。
- 雷枪保持上层与已认可素材、轨迹；v145 贴防线选敌修复保留。忍者仅作为参考，没有修改其素材或代码。

## 制作与验证

`build_scythe.py` 使用 Blender 5.2.3 LTS，双倍分辨率渲染两张独立动画元素；`pack_layers.py` 固定画布、直通RGBA、透明边缘与图集间隔。`scythe-elements.blend` 保存可编辑模型和脚本，连续动画由脚本重建。

原裂隙继续使用 `scythe_slash_v144`；新 `blade/spin` 为 `v147`，旧素材保留便于回退。新增贴图仅在镰刀预热时加载。切割及装饰使用固定池与战斗模拟时钟；暂停、结束与销毁清理沿用原生命周期。

`verify.cjs` 隔离实际视觉类与结算回调，650帧记录，检查九次伤害／双倍终结、暂停、边界、固定池、25个新弧线碰撞样本、原裂隙图字节不变、雷枪与镰刀英雄伤害代码未变。`render_review.py` 使用实际GLSL和正式图集，在静态战场素材上合成；8种着色模式共56个GPU样本。前后景包含真实精灵裁切，不是预览专用变换。

静态场景动态预览：`normal-review.mp4`、`skill-review.gif`、`ultimate-review.gif`（另存完整MP4），接触表 `contact-sheet.jpg`。没有启动游戏、浏览器、真实战斗、音频或WASM。视觉与手机实战待用户评价。
