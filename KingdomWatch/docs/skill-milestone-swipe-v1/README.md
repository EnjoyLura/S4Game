# 技能突破横向滑动

用户要求去掉技能突破的左右切换按钮，改为左右滑动。

技能页普攻、技能、大招的突破卡片完整放入裁剪横排，移除左右箭头。滑动过程中卡片跟手，松手后200ms吸附，短促甩动可切换阶段，边界有阻力与回弹；标题右侧显示“左右滑动”和当前位置。切换只移动卡片，不刷新整个培养页，位置按英雄与技能分别记忆。

保留卡片点击查看详情。拖动达到方向阈值后取消卡片按压和点击，横向手势暂时锁住外层纵向滚动，纵向手势交还原滚动容器；结束、取消、后台及销毁时恢复容器状态。实际切换播放既有选择音，减少动态效果时直接吸附。等级突破和武器突破保持原操作方式。
