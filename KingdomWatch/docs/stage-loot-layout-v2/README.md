# 掉落预览布局与展示简化 v2

2026-10-16：按用户连续三条要求调整展示与准备面板行为。

- 出战准备保留星级宝箱优先；关卡掉落分为通关必得、击杀概率装备。普通、精英、地狱均显示基础金币和实际配置中的强化石、精铁锭、魔法尘图标与数量，金币标注基础收益并保留击杀额外收益说明。
- 通关收益采用无轮廓的紧凑横排信息块，装备使用单独的品质小底板、底部色条与左上角品质签。装备按六列换行，展示完整池，取消原先截断六件的逻辑。纸面整体仍保持中性色；内容高度由装备行数计算，编队排在掉落后，战斗按钮固定。
- 掉落目录同样先显示通关收益，再列出概率装备。两列装备卡展示名称和条件抽取占比；金币/材料与装备都可点进详情。详情与目录共用遮罩，返回保留列表及滚动位置。普通难度的提示改为金币/材料说明。
- 商店、英雄穿戴/背包/详情/强化/出售、升级和掉落使用的品质签统一只显示普通、优秀、稀有、史诗。信息行保留 Lv. 等级，移除显示的装备阶数。tier 数据、属性系数、价格和存档沿用原定义。
- 出战准备打开时停止地图残余惯性并记录当前位置，取消开关面板的地图自动定位；恢复准备页时先还原地图偏移，再显示纸面。关闭面板不再触发地图返回动画。

不新增图片、音频或付费生成。仅修改八个 UI 源文件；章节美术、解锁规则、金币/材料/装备概率、发奖和存档源文件保持原散列。

审阅限定为源码、TypeScript 静态诊断与本地构建产物。按用户既有约定，不运行测试、模拟、游戏、浏览器或线上验收。已知 ButtonFeedback、MilestoneSwipe、Panels 和 UINotice 类型问题保留；不将构建成功等同于实际视觉验收。

`before/` 与 `source-baseline.json` 保存本轮前源码；`source-review.diff` 保存本轮差异；`type-review.log`、`bundle-inspection.json`、`build-record.json`、`web-release.json`、`deployment-stage.json`、`publish.log`、`release.json` 保存静态审阅与发布回执。
