# 镰刀法师 v139

新增英雄 **艾登·烬镰**（`scythe`），赤橙色法术输出。沿用 1-4 后的英雄商店入口，5600 金币解锁，接入编队、旧存档迁移、专属初始武器、养成、通用数值卡、技能就绪与释放演出。

- 普攻「赤焰弧刃」：78 基础攻击，0.95 次/秒，86 宽弧刃朝目标飞行；法术伤害，可对空，基础命中后再穿透 2 个敌人。圆弧扫掠碰撞贴合刃身，包含两侧刃尖，使用原弹道的生命 ID 去重。
- 技能「回旋猎镰」：甩出一把完整长柄镰刀，到达敌群密集处后旋转 4 秒，每 0.4 秒切割一次（共 10 次），基础半径 155、每次 0.48 技能倍率；收镰无额外伤害。基础冷却 12 秒。
- 大招「三重断界」：蓄力 0.48 秒后挥出三道横贯屏幕的巨型弧刃，间隔 0.34 秒、向上速度 820，每道基础 2.7 技能倍率，穿过全场；每道对同一敌人只命中一次。80 能量。堵塞时保留未发波次和后续间隔，不丢波次。

攻击判定、展示说明与升级取值共用 `ScytheConfig.ts`。刃身用 24 段胶囊近似可见曲线，连续扫掠防止高速穿漏；巨刃在整个弧形离开上边界后才回收。技能落点锁定，不抖动追踪。全部效果使用战斗时间，暂停时冻结；效果缓存和待发队列有上限。保留已有英雄实现与素材。
