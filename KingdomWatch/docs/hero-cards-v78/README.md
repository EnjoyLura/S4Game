## 与已有强化衔接

- 爆裂范围放大新技能火区及巨弹半径，保留既有普攻、技能和陨石爆炸的效果；不改变陨石坑大小。
- 余火绵延延长火区，以及原灼烧和陨石坑的持续时间；余烬强化灼烧强度。火区与其他灼烧仍按原规则取最高强度，不变成重复扣血。
- 极寒扩散放大霜地，凛冬之息强化其减速，寒冬延续延长地带；冰封延长仍只影响原冰封。
- 卡面只保留2～3行效果，不加叠层或自动搭配提示。火区与霜地的范围/持续强化说明同步原卡文案。
- 选项通常仍限制最多一张纯数值卡；当该限制会使卡池末段缺项时，才回退到剩余合法卡牌。有至少3张合法卡就补齐3选1，不改变正常权重或引入选满卡。

## 复用和范围

只改 Cards、Hero、Projectile、Monster、FireVFX、FrostVFX、ImpactFX 七个 TS。新卡全部复用现有图标；火区复用焦痕与余烬，最多保留4处技能火区，地面渲染槽从8扩到16以兼顾陨石。每个区域使用自身半径和真实寿命，消除原延长陨石坑在前段被写死4秒淡入公式隐藏的问题。霜地最多4处，用单个 Graphics 复用现有冰晶绘制函数。没有新增游戏资源或美术制作任务。

用户认可的完整冰霜技能v10、128颗全场随机落冰、原灼烧0.62秒动画及每0.5秒扣血节奏、人物动作与全部媒体保持。基础大招从0开始、英雄充能差异、共享击杀充能、关卡数值及胜利后的2秒收尾沿用现版。
