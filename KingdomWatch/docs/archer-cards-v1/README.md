# 弓箭手强化卡迭代 v1

| 品质 | 卡牌 |
| --- | --- |
| 白 | 攻击强化（攻击+20%）、攻速强化（攻速+15%） |
| 蓝 | 暴击强化（暴击率+15%）、爆伤强化（暴伤+30%）、连射、齐射、猎手本能 |
| 紫 | 快速充能、分裂、小范围爆炸、寒霜附魔、烈焰附魔、爆炸范围、爆炸威力 |
| 黄 | 解锁大招、解锁技能、多轮箭雨 |

连射、齐射最大均为5层，原效果每层增加1排／1支箭；二者及分裂、爆炸、寒霜附魔、烈焰附魔每领取一次，该英雄当前攻击倍率乘0.9。卡面明确显示代价。齐射附加箭间隔从10°改7°，保持主箭沿原瞄准方向以及附加箭交替向两侧展开。

爆炸、寒霜、烈焰原本最多2层，但重复只重设相同值；本轮改为1次，避免出现只有减攻、没有收益的第二张。分裂仍可叠2层。爆炸范围／威力各3层且先学爆炸；快速充能仍2层、多轮箭雨仍2层，均先解锁大招；其他未指定数值维持原效果。

新增黄色品质，复用原纸纹品质色带染金、标题用深色字；两套卡片呈现和GM边框同步。相对稀有度权重白0.6／蓝0.3／紫0.1／黄0.05；保留此前数值卡0.3、战斗机制卡2、防线辅助1的类型乘权，不是固定出现概率。

四类通用数值卡由同一工厂生成，各英雄分别归属、分别抽取和叠层，仅共享对应类型的既有美术资源。弓／弩原卡ID不变，火／雷／冰补齐12张独立副本。两种白卡和蓝色双暴卡名称统一。其他英雄专属卡的旧品质和效果、全局防线／经验卡待后续迭代，本轮不重排。

保留双基础伤害模型、上一版雷法特效、人物动作、音频及交互布局。按既定流程只完成 Cocos web-mobile 构建、DPR补丁、main发布；不运行测试、抽样模拟、游戏、浏览器或线上验收，实际卡池与平衡由用户人工体验。
