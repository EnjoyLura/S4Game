# 重弩手与雷法师完整攻击动作

用户授权继续完成两人的攻击。分别从当前待机原片第一帧制作视频输入，沿用已确认站姿、武器握持、身体比例和背景取景。使用项目 MiniMax H3 生成完整攻击与自然收势，雷法师请求两秒；重弩手原通道反复加特效／改变握持后，改用项目内另一条 H3 通道请求四秒。所有帧正向保留，不倒放、不裁短、不透明度过渡；源片四边留白不足则重新生成。长源片使用多个最大 4096 像素图集页，待机图集格式保持。

重弩手：扣弩、轻微受力、自然恢复；雷法师：小幅抬手向前施法、自然回到原握持姿势。禁止人物内烘焙枪焰、火星、魔法粒子和弹道。运行时根据实际发弹／施法回调切到标注释放帧，短暂蓄势提前播放；攻击与收势优先于待机。仅自身攻击范围内无目标、无待发队列、收势完成后播放待机。各攻速下收势时间适配出手间隔。

尺寸与待机共用：重弩手高度 153、画内基准 467.1111；雷法师高度 146、画内基准 468.7165；脚底图集坐标 `(256,496)`，节点坐标 `(0,-76)`。每段只使用一次固定裁框、统一缩放与脚底定位，整图镜像。弓箭手媒体与高度 185.64 保持。雷法师认可的待机视频、图集和循环时长保持。

制作入口：`prepare_sources.py`、`generate_video.py`；图集入口：`../hero-stance-rebuild-v1/package_frames.py`；预览入口：`build_preview.cjs`；发布入口：`publish.ps1`。原视频、实际提示词、源帧标注、生成任务、图集清单均位于相邻 `sniper-attack-natural-v1` 与 `volt-attack-natural-v1` 目录。
