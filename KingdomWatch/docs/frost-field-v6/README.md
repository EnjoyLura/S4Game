# 冰领域视频序列帧预览 v6

本版按纯提示词生成，未提交参考图片。仅制作素材与离线地面合成预览，尚未接入游戏，等待人工确认。

## 交付文件

- `frost-domain-preview.gif`：完整释放的地面合成预览，技能动画播放 1 秒，前后留空方便观察。
- `frost-domain-video-2s.mp4`：整段动画的 2 秒视频。
- `contact-sheet.jpg`：从完整序列中抽取的 16 张关键帧总览。
- `sequence/frost_domain_video_v6.png`：56 帧透明图集，8 列 × 7 行，每格 384 × 384。
- `sequence/frost_domain_video_v6.frames.json`：图集坐标与播放信息。
- `sequence/frames-alpha/`：56 张独立透明帧。
- `prompts/text-only-2s.txt`：实际生成提示词。
- `build_review.py`：提取与预览制作脚本。

## 制作说明

通过本地 `美术/tools/art_video_gen.py` 请求 2 秒文本生成视频。服务返回 56 帧、24 FPS 的原始视频（约 2.333 秒）；交付视频保留全部原始画面，统一为 28 FPS，时长 2 秒。图集按相同顺序播放 1 秒。

提取使用整段动画的固定裁切范围、缩放和中心位置，没有逐帧重新居中，也没有插帧。末尾 0.12 秒仅增加透明度淡出，确保最终画面完全消失。GIF 使用共同调色板，减少编码造成的颜色跳变。

本版构成为结冰闪光、低矮冰晶与寒气、碎冰消散。预览采用现有地面素材合成，没有进入真实战斗画面。冻结时长、伤害、减速等战斗逻辑未修改。

之前的参考图片试验未用于此版最终序列。相关生成记录保留于 `generation.json`，临时输入 Worker 已删除。
