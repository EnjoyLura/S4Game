# 配乐与采样音效更新

按用户要求，首先将此前积累的英雄动画、战斗特效与界面美术提交为 Git `fec68d9`（`保存英雄动画、战斗特效与界面美术当前版本`），随后再制作本轮音频改动。未推送 Git 远端。

大厅使用 cynicmusic 的 Town Theme RPG，战斗使用同作者 Battle Theme A；源曲保存在 sources 中，制作时保留约一分半的曲长，去除编码静音并做 0.7 秒首尾重叠，统一到 -18 LUFS 目标，输出立体声 MP3 192kbps。没有付费生成调用。

42 条正式音效由真实长弓、重弩、火焰、电流、冰裂、UI 与弦乐短句制作。高频武器和法术有多个变体，弓弩保持弦声、风切和机括质感，三系施法保持各自元素；技能、大招、升级、就绪、失败、成功与按钮分别接入。音效统一单声道 44.1kHz/16bit；选取单次动作录音，处理滤波、短尾、淡入淡出和峰值（最多 -3dBFS），避免将一整串武器试录作为一次发射播放。详细来源、切点、叠层与哈希见 assets.json 和 prepare_audio.py。

GameAudio 为跨场景单例 WebAudio 混音器。沿用 Sfx 原调用接口，新增英雄技能／大招的家族映射。资源通过 Cocos resources 目录的 UUID 与版本信息定位原生音频，单份解码缓存，不创建逐发 Cocos AudioSource。三个并发预热工人只在首个用户手势解锁后工作，不阻塞场景进入；尚未完成加载的攻击不会延迟补播，也不会回退旧合成占位音。两首长曲仅在首次进入相应场景时解码。

大厅／战斗音乐交叉淡入 0.65 秒；暂停与三选一压低配乐，结算让出声音空间。重要音效会暂时压低音乐；普通命中共享最短 75ms 的预算，发射共享 25ms，同事件另有限流与变体，最多 14 个活动音效声部，并用总线压缩器控制叠加。切入后台挂起 AudioContext 并停止战斗声；回到页面尝试恢复，浏览器需要时由下次手势解锁。战斗倍速不改变音高。暂停中的音乐／音效开关立即生效并沿用原存档。

除音频设置页增加一行“音乐与音效鸣谢”外，保持现有界面、角色动画、攻速、伤害、技能触发、弹道和特效。源素材包含 CC0 与 qubodup 的 CC BY 3.0，作者、来源、许可及编辑说明保存在 CREDITS.txt，并随游戏发布 audio-credits.html，由暂停→设置打开。

按用户持续要求，只执行素材制作、源代码改动、Cocos web-mobile 构建、DPR 补丁与发布，不运行测试、游戏、浏览器或线上试听验收。素材来源和构建成功不代表听感已获用户认可，最终由用户人工体验。
