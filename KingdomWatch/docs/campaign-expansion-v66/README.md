## 本轮内容

- 第2～16章各有3种普通单位、1种精英、1种章末首领；前线/远程/支援混编，稀疏喘息、后程精英、10关首领。普通每关7～10波，精英/地狱分别加2/4波与少量敌人；章阶强度按线性增长，避免16章使用指数翻倍。
- 新怪物实际接入：11种周期冲锋、12种周期防御、4种毒伤、3种回复、4种攻击光环、10种有上限召唤、3种分裂、3种一次复生、7种可控制打断的蓄力攻击、15种首领低血强化、10种飞行。各机制可重叠，不是互斥分类。飞行不参与地面分离，仍可被全部英雄攻击。
- 防御用脚下蓝环提示，蓄力用头上进度条提示；眩晕/冰封中止待发蓄力，首领沿原规则免疫冰封，仅眩晕可打断。控制与这些机制均沿游戏时钟推进，暂停、选卡不偷偷计时。
- 召唤/分裂援军共用60存活上限，单次最多4只；援军不会继续召唤/分裂/复生，不产生金币、经验、充能或装备，避免无限刷取。援军在父体附近出现，主线与无尽都等待其清理。
- 图鉴改按章翻页、每章5～6种，发现/领奖沿原存档。战斗介绍、图鉴列表、详情与剪影全部引用同一怪物图集登记，不再回退表情头像。
- 主线地图可切换16章；前3章沿已有地区插画，第4～16章新增13张地图与13张战场。地图顶部按地区换色，不在沙海/火山保留绿树林冠。新无尽世界底图含各地区，16章旗标与可拖动缩放/目录/返回/编队/出战准备沿既有二级页；无难度、星级宝箱或底导航。
- 无尽怪物池按1～所选章累计，后期每层选2～4种进攻者、少量支援，精英层最多2精英、每5层1首领；不会把81种都塞进一层。单层普通怪数量封顶56，支援最多2，血伤继续随层增长。金币与真实装备掉落仍沿v63规则。
- 进入关卡前预热对应敌人图集，池化怪物切换图集时有请求版本保护；图鉴只加载当前章所需图集。未改变英雄技能、培养、原音效或雷法大招修复。
