# 前段加压、中后段强化怪群 v75

用户再次试玩反馈：怪物仍在半场被清光，要求开场提高数量和血量，中后段提高更多。本版继续调整普通 1-1～1-6，沿用 [v74 两秒胜利收尾](../combat-balance-v74/README.md)。

## 实际调整

相对 v74，前两波普通哥布林数量提高 25%～48%，血量提高 33%～58%；中后段主力波数量约提高 47%～89%，血量约提高 65%～157%。原较轻的中段波也增加数量和血量，仍比相邻主力波轻，保留缓急节奏。

投手、骑兵、治疗与精英的血量同步上调，数量、出场顺序和时间保持；1-5 首领由 v74 的 7800 提高到 12000。所有怪物攻击力和移动速度、英雄输出、单怪经验/充能/掉落规则都保持。更多击杀会自然产生更多收益和构筑机会。

普通怪增加数量的同时缩短间隔，逐波静态出怪时间跨度接近 v74，不靠长时间等待增加怪量。总跨度分别为 178.33、204.27、242.15、244.11、238.31、301.99 秒；这些只是 `max(delay + (count − 1) × interval)` 的逐波总和，不是实测通关时长。实际时长仍会受清怪和存活上限影响。

保留 60 只存活怪上限，满池时延后生成，不消耗未生成队列。没有提高并发怪物上限或新增美术/音频。其他难度、1-7 之后与无尽的数值保持。

逐波具体数值见 [配置字面量](wave-literal-review.json) 和 [每波普通怪增幅](worker-wave-review.json)。这轮目标是开场有持续目标，中后段形成更长时间的怪群与推进压力；实际手机难度、时长和性能仍需用户试玩确认。

## 继续保留两秒胜利收尾

最后一只怪物死亡且出怪队列已清空后，战场继续运行至少两秒，推进英雄动作、弹体、死亡、掉落与大招收尾，再显示胜利弹窗；真实时钟不受倍速影响，尚未结束的大招会继续等待。

最终伤害步骤之后、升级弹窗之前确认清场，避免末次击杀升级先弹选卡。收尾时锁定战斗点击和选卡，防线不会被延迟敌方攻击扣血或回复而改变星级，原奖励和双倍领取防重入保持。无尽沿用原三秒层间休息。v74 的全部运行代码在这轮数值调整中保持原样。
