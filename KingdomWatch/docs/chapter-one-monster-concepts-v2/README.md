2026-10-20，按用户“怪物种类自由发挥，先生成两张”的要求，准备两种新的边境异兽。第一章现有地貌为农田、林缘、石砌前哨。

| 名称 | 拟定职责 | 造型核心 | 动作方向 |
| --- | --- | --- | --- |
| 铲颚兽 | 地面近战、冲撞 | 占体积一半的天然铲形锈红头甲、低矮四足、粗大掘爪 | 低头蓄力、后足蹬地、整身短冲 |
