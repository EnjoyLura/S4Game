# 冰棱雨 v4：全场随机、128 颗、逐颗错峰

2026-10-11 用户录像反馈：怪物集中上方时，中段冰棱太少；落点不要跟随怪物，数量从 96 增到 128。同时修正普通技能收尾向上飞散的问题。

每次大招固定 128 颗。战场纵深分为 8 个宽区域，各自生成 16 个随机点，横坐标独立随机；全体落点打乱后，逐颗在 0.94 秒内错峰生成。这样中段、下段和上段覆盖量相同，画面没有网格、排队或按行扫过的排列。怪物数量、位置、半径均不参与落点、时间或随机数消耗；24 处较大的碎冰也对应随机雨滴，不再绑到怪物脚下。

保留 v3 的地面相对空中高度、加速下落、单尖材质、速度切线角度、远近尺寸、与角色共同的地面深度遮挡。每颗接地才出现固定阴影、短闪光、裂纹及 6 片小碎块；主碎裂采用原 H3 连续素材。完整大招仍为 2 秒，立即一次全场伤害及既有减速机制沿用。

预览从实际 TypeScript 渲染器导出位置、矩形、转角、透明度、图层与 Graphics 绘制命令，再以已有地面和怪物素材合成。导出器现在保存每帧独立的绘制命令快照，避免后续清空池内命令时丢失先前的碎屑及尾迹。没有进入真实战斗进行自动浏览器检查。

普通技能收尾见 [v11](../frost-field-v11/README.md)：前 0.82 秒沿用 v10 原帧，最后 0.68 秒将原冰晶切成固定碎片，向下加速、触地、消散；完整技能仍为 1.5 秒。

验证覆盖 20 个随机种子：相同种子搭配不同怪物分布，落点及先后时刻完全一致；每个纵深区域固定 16 个点。还验证了逐颗错峰、接地触发、暂停/倍速、100 次复用、资源加载失败/销毁及原有伤害与减速。普通技能首段、固定锚点、1.5 秒清空均验证通过。修复了项目原有 GM 开关辅助函数的 `void` 返回类型错误，仅改成函数块，不改开关行为。
