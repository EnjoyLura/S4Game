# 升级页：清爽漫画奇幻 v1

重做等级、武器、技能、装备四个培养页签，沿用用户认可的商店／英雄页风格。暖木梁、蓝旗、冷色城堡窗景形成前后层次；下半部用全宽米色底色，组件采用 ComicUI 单层轮廓，避免偏移底板和底部叠影。

- 英雄选择仍为方卡，头像用正圆裁切；当前英雄姓名无额外大底牌。共享资源栏、底部导航保持一致。
- 等级页使用现有漫画立绘，石台与脚底校准。武器页复用商店弓／弩，新绘三系法杖；展示保持素材比例，不压扁、不额外加泛光。
- 技能页保留玩家熟悉的战斗图标，统一选择卡、当前／下一等级对比、绿色增量、阶段突破与详情弹窗。界面明确提示技能、大招仍需本局三选一解锁，培养等级不会自动解锁战斗能力。
- 装备页复用商店装备插画，展示已穿戴四种装备、品质、阶数和等级；未穿戴时展示说明，强化入口不可扣费。
- 材料持有／消耗和升级按钮固定在底部。短屏只滚动中间内容；按英雄、页签、技能／装备保存滚动位置，石台随立绘同步。升级后突破栏保留位置，方便看到刚解锁的效果。
- 金币／材料扣除、成长公式、上限与突破均继续由 GameData 执行；点击资源不足按钮仍给出原有原因反馈，不新增存档字段。

## 素材与制作

使用内置 `image_gen.imagegen` 生成场景、锤子和三系法杖，以 `bg_shop_comic_v1.jpg` 与商店风格参考约束画风；法杖另做一次去除外部光晕的编辑。完整实际提示词、参考与源图路径见 [generation.json](generation.json)，原图保存在 `sources/`，生产素材和尺寸见 [assets.json](assets.json)。导入只清除 alpha 1–7 的残留透明噪点，等比缩放和留边，保留清晰轮廓；不将 AI 生成的文字、价格、边框放进 UI。

生产素材：`assets/resources/scenes/bg_upgrade_comic_v1.jpg` 和 `assets/resources/ux/upgrade_comic_v1/`。旧木质培养／武器／奖励图集保留源文件，升级页不再使用。

## 验证

已发布：[升级页漫画版](https://kingdom-watch.pages.dev/?v=upgrade-comic-1791716054)。Creator 构建与类型检查通过，本地 19 项检查、线上 4 项检查通过，在线入口／DPR 引擎／配置／5 张新素材共 9 个文件哈希与本次构建一致。部署快照：`https://5d7616db.kingdom-watch.pages.dev`。

`check_upgrade.cjs` 使用浏览器独立存档，检查四个页签、五位英雄武器、三种技能、四个装备升级的实际扣费及等级，突破分页与弹窗、空装备、未拥有英雄、金币／材料不足、等级上限、375×667／375×600 的触摸滚动、脚底与石台对齐、固定按钮和导航。不进入真实战斗，也不修改用户浏览器存档。`ui-validation.json` 和 `online-validation.json` 保存结果；各页 PNG 用于素材合成后的实际界面预览。

每次发布使用 Creator 3.8.8 web-mobile 构建，再运行 `tools/patch-web-dpr.py`。发布后比对在线入口、资源配置、DPR 引擎和生产素材文件哈希；最终链接见 `deployment-validation.json`。
