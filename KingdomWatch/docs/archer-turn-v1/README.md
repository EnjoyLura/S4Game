# 弓箭手短转身 GIF 演示

2026-10-13 用户要求解释如何让镜像转身自然，并制作 GIF。本轮为独立演示，不修改战斗代码或当前线上动画。

推荐使用约 0.2–0.25 秒短转身，配合中线缓冲区和方向稳定确认；攻击正在放箭时锁定方向，到收势后再转。GIF 对照左侧直接镜像、右侧 5 姿态 / 0.24 秒转身 + 防抖，包含放大与 146 设计单位显示尺寸。目标最后在中线附近来回移动，展示减少反复翻面的作用。

补充姿态由内置 image_gen 生成：`turn-poses.png` 的左半格是左向中间姿态；`center-pose.png` 是收弓到身前的正背面姿态。端点使用此前战斗基准图，右半段镜像相应左向帧。提示词在 `turn-poses-prompt.txt`、`center-pose-prompt.txt`。生成原始文件保留，PNG 按原文件复制。

`render_demo.py` 将完整姿态绘制到 GIF，每张姿态的显示比例与脚底原点只在导入时设定；没有肢体拆分、UV 变形或动态宽度压缩。GIF 是方案示意；AI 补帧的比例、披风与箭袋衔接仍需用户人工判断，不能等同已完成生产级转身动画。

输出 `archer-turn-comparison.gif`，900×740，5.6 秒循环，25fps。播放参数、来源与文件信息见 `demo.json`、`generation.json`。不运行游戏或线上视觉验收脚本，由用户查看 GIF。
