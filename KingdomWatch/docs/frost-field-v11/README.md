# 冰领域 v11：碎开后往地面掉

**后续验收：用户认为这版不如原版，已按要求恢复完整 v10。下面保留实验记录；v11 不再是当前技能资源。**

2026-10-11 用户指出：v10 收尾冰晶向上碎开，不符合冰封解除的重力感。这次只替换收尾运动，复用认可的材质；没有新 AI 调用。

起手 0.4 秒与主体 0.42 秒的前 24 帧保留原像素。以 v10 最后完整冰晶帧为素材，按 6 处固定冰晶簇切分出 54 块不规则碎片；每块身份、材质、初始位置在整个收尾保持一致。原生图集没有覆盖或重新生成。

碎片从原位稍微分散，初速度向下 18px/s，重力 900px/s²，落向各自冰晶根部对应的地面。没有向上喷射、反弹或整张底图下移。接地后略微放平、短暂保留再消散；地面的薄寒气在原位淡去。收尾仍为 0.68 秒，总计 1.5 秒。

画布、地面中心、参考半径、逐格时长和常规透明混合沿用 v10：44 格 384×384，8×6 图集，地面中心 (192,214)，参考半径 126px。冻结 1.5 秒、解除后减速 2 秒及技能伤害倍率 ×2 沿用。
