# 王国守望：代表声音 r1

用户要求先交付几个代表声音，确认后再扩展。此前 v21、growth-r1 与 cartoon-r1 的整体音质均被用户否定；历史上“保留旧版”只代表当时相对选择，不能记为质量认可。

本轮仅制作 7 个同步画面的配音场景及 v21 对比，不改游戏脚本、运行资源、播放逻辑或存档，不拓展其余音效。主观听感仍待用户确认。

## 来源

1. [Sonniss GDC 官方免费发行](https://sonniss.com/gameaudiogdc/) 的 2015 专业录音样本，来自官方页面列出的 Your.org 镜像。使用 Membrans 的 Cartoon Arrow 09 / Ice Cube In The Glass 09 与 NoizBoy Hong Kong Action Kit #1 的 Seq 2.1 whoosh #1 / Hit #1。
2. [VSCO 2 Community Edition](https://github.com/sgossner/VSCO-2-CE)，CC0 1.0。实录乐器为 Sam Gossner、Simon Dalzell 录制，Elan Hickler / Soundemote 切分。本轮重新编排短乐句，不直接使用成品曲，不使用振荡器或 AI 生成音频。

原始音频保存在 `sources/`，VSCO 来源锁定 Git revision，原许可与作者 Readme 一并保留。`instrument-sources.json`、`source-hashes.json`、`recipes.json` 保存来源、散列与编辑记录。未使用的调查目录与额外候选文件不构成试听采用，Adobe 的目录仅作来源调查，没有使用 Adobe 音频。

[Sonniss GDC Bundle License 2.0](https://sonniss.com/gdc-bundle-license/) 2026-10-17 核对：允许免费用于商业或个人媒体制作及修改；不允许将原始或重设计音效作为独立音效分发；不允许 AI/ML 训练。本轮将采用录音同步到游戏美术分镜的 MP4 成片中，公开目录不包含 Sonniss WAV、FLAC、AIFF 或 ZIP。CC0 乐器采样同样只随成片交付，原始素材留在项目中。

官方 Sonniss 下载主站对脚本请求返回 Cloudflare 验证，2026 Google Drive 镜像显示配额超限，另一官方镜像连接超时。本轮没有绕过验证，改从可访问的官方 2015 镜像按 ZIP 目录下载所需片段，并核对每个 ZIP member 的 CRC/长度。`sonniss_fetch.py` 为可重复的范围下载代码。

## 制作与检查边界

- 44.1 kHz / 16 bit 立体声母带；保留原始房间声。素材剪裁、录音音符移调、包络和事件分层均保存配方。
- 每组新旧只以活动段电平作标量参考匹配，并留至少 3 dB PCM 峰值余量。不以加总音量作为质量提升，不以信号指标宣称主观音质过关。
- `render-stats.json` 保存 14 条母带的电平、时长、散列和削波检查结果；公开成片 H.264 + AAC 192 kbps。
- 分镜使用项目既有美术，显示动作与数值同步；不是对正式游戏界面/动画的替换或实机录像。
- 只运行离线素材处理、文件散列/引用与编码检查、JS 语法检查；未运行游戏、浏览器、模拟/交互验收或音频播放。实际听感由用户试听。
- `stage.py` 从上一版已发布完整目录复制并逐文件验证，游戏与历史预览保持原文件；只增加独立预览路径。`publish.ps1` 使用既有 Wrangler 项目与 main 分支。

确认前禁止自动接入或拓展；只根据用户明确通过的场景继续。
