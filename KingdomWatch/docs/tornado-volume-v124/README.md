# 龙卷风体积样板 v124

用户要求继续尝试。此次集中验证龙卷风，风眼与忍者暂时保持，先建立一个可比较的样板。纯代码实现，没有生成或引入图片、风场纹理、序列帧。

原版在两个锥面上绘制规则风带，容易形成空心弹簧和纸条。新版在锥体内沿视线固定取12个深度样本，对旋转上升的三维密度做前后累积，增加有厚度的风体。细风纹、较亮卷流和顶部散丝提供清楚的旋转方向；地面尘旋和叶片继续复用代码绘制。密度、细纹与叶片统一为每秒上升1/6高度、顺时针1.5弧度的运动，避免多层反向滑动。

用户进一步反馈方向比之前好、仍有隐约丝带感，并要求增加底尘。最终稿加强了随风上升的形变，降低细亮边的连续性与亮度，给带间补充淡风体。底部改为7团低矮、向外滚散的灰褐尘团和3团被带入下部风体的轻粉尘；各自生长消散，避免整块半透明遮罩。没有向线上发布中途的第一稿，最终只发布包含此次反馈的版本。

修改仅涉及 `wind-ninja-flow.effect` 的龙卷风和专用噪声函数，以及 `WindNinjaVFX.ts` 中龙卷叶片的路径。风眼、忍者、圆弧风刃和材质混合方式保持；所有战斗数值、聚怪、命中、范围、时长、技能释放流程与资源预热均不变。已有8区域／12绘制槽上限保留。普通怪物等场景图片仅用于离屏预览背景，不参与特效生成。

## 动态对照与技术检查

- `make_preview.cjs`：在惰性节点、Graphics与材质替身下运行新旧真实绘图类，记录300帧龙卷表现。额外比较300帧风眼／忍者绘图，保持相同。不执行英雄或战斗逻辑。
- `prototype.py`：编译新旧实际片元程序，在原森林背景与怪物素材上离屏绘制。输出 `before-after.webp` 和 `tornado-motion.webp`，覆盖5秒生命周期；数字只是用于检查遮挡的静态样例，不代表真实战斗伤害。
- `check_scope.cjs`：保护其他全部已跟踪assets，确认只有两份活动文件变化；风眼、忍者、风刃和最终片元函数保持，运行时无特效贴图。
- `gpu-review.json`：检查有限像素、透明边缘、零强度与四种未修改模式的逐像素一致性；附桌面独立绘制耗时，不能当作手机帧率结论。

这是一轮视觉尝试。对照图能够显示风体和运动方式的变化，不代表已经达到参考图的质量。没有启动游戏、浏览器、真实战斗、音频或WASM；最终动态观感与手机开销需要用户试玩。

静态范围检查通过，9项既有类型诊断、无新增。离屏实际片元检查覆盖30个模式／时刻，另外四种模式24次与旧版逐像素相同；300帧实际绘图对照中的风眼与忍者保持。AMD RX9070XT最终稿单区域独立绘制中位耗时：DPR1旧0.0163ms／新0.0681ms，DPR2旧0.0565ms／新0.1662ms。这里只量到桌面GPU执行，不包含引擎、CPU、手机或满场战斗；新算法确实更重。
