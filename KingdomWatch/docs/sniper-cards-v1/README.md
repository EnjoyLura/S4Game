# 重弩手强化卡迭代 v1

| 品质 | 卡牌 |
| --- | --- |
| 白 | 攻击强化（+20%）、攻速强化（+15%） |
| 蓝 | 暴击强化（+15%）、爆伤强化（+30%）、处决标记（对精英/Boss+35%）、猎手本能、冷却缩减、远距校准 |
| 紫 | 多目标锁定、快速充能、贯颅弩矢 |
| 黄 | 解锁大招、解锁技能、额外枪线、死亡准星 |

远距校准：技能索敌范围每层乘1.3，初设最多3层。共用技能起手检测和每发连狙的重新索敌范围，面板实时显示实际范围；不改变普攻范围。

贯颅弩矢：技能弩箭每层额外穿透1个目标，初设最多3层，对应每发最多命中2／3／4个不同目标。复用现有直线弹道、碰撞去重和穿透余量，只写入技能弹，不改普攻或大招。

死亡准星：用户已明确“+30”为受到伤害提高30%。最多1层；大招每条枪线实际命中的存活目标获得红色头顶准星及5秒易伤。标记在伤害命中后施加，提升后续所有来源伤害。技能等级原20%标记与新卡30%取高；同类易伤与火法坑取高，不额外叠乘，但各自独立计时，火坑不能续长准星。重复大招命中刷新5秒，死亡立即清理、到期消失、对象池初始化重置。准星在完整怪物画幅上方，由单个共享Graphics绘制，使用战斗时钟，跟随暂停／倍速／顿帧，无逐怪Tween或额外贴图。

处决标记和猎手本能接入重弩手普攻／技能／大招；精英判定补齐Boss，即使Boss没有elite标志也生效。其他旧卡数值、层数及技能／大招前置保持；四张通用数值卡继续按英雄独立生效、共用图标。弓箭手卡池、双基础伤害模型、雷法特效、人物动作、音频和其他英雄专属卡保持。

三张新增图标采用 **内置 image_gen** 分别生成，沿用游戏的圆形奇幻手绘图标风格；保留原像素和透明通道，复制入项目并接入运行时和预加载。没有用代码图案替代卡面美术，也没有覆盖旧图。图标为生成的新插画，未宣称用户已视觉验收。
