# 战斗进度条与盾量显示

依据用户提供的绿色生命条、橙色伤害统计，以及当前血条／护盾错位截图实现。

- 防线血条：保留宽 640、底基 198，改为高 18 的浅圆角细灰框、亮绿填充与克制的顶部／斜向高光；右上心形图标与当前／最大耐久，低耐久填充转红。
- 护盾：独立高 6 的细蓝条位于血条下方，左上盾形图标与“护盾 数值”。按盾量／耐久上限显示，零盾隐藏整组。去除原覆盖血条的蓝色大胶囊、最小 40 宽度与旧底基 176 引起的数值错位；盾量不变而耐久上限变化时也刷新比例。显示数值向上取整，实际耗盾与伤害逻辑保持。上方数值控制在底基 240 以下，避让右侧最低的大招按钮。
- 伤害：简洁橙色填充、深色细槽、浅圆角，移除金色胶囊框与条内数值。伤害数值以原 fmtWk 规则放在右上，较小字体保留真实全队占比。参考图中的最长条占满，因此条宽按本局最高伤害归一，百分比仍按全队总伤害计算；未改 DamageService。
- 战斗统计弹窗原 360×470 背板、头像、标题、点击空白关闭保留；行距由 100 微调至 96，末行与底部关闭提示保留间隔。暂停及胜败页伤害统计共用同一条样式和数值规则，其他布局保持。
- 顶部经验条同步使用轻量细槽，原经验增长、闪光与升级节奏保持。

这些资源属于简单 UI 几何，使用 Cocos Graphics 原生绘制，避免拉伸位图和异步换肤造成显示差异。心形、盾形也是原生矢量，无新增 AI 生图或视频任务。

按用户要求仅实现、构建、DPR 补丁、发布，不运行测试、游戏、浏览器或线上验收；视觉由用户人工验收。英雄媒体、战斗数值、技能和伤害结算不变。构建与发布记录见 build-record.json、deployment-stage.json 与 release.json。
