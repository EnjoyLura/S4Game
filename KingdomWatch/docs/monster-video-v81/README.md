从 56 帧、24fps 的四宫格视频逐帧提取角色，去除浅色背景，按连通前景区分四只角色，避免法杖、长矛被相邻格子的裁剪边缘切断或残留其他角色。每只角色以整个循环的联合边界确定一次性裁剪、缩放和摆放；所有帧使用同一变换，保留原视频身体与装备的像素和运动。没有逐帧居中、比例变化、倒放、补帧或透明度叠加。原片的轻微造型变化仍属于原始视频内容。

循环区间取连续正向帧，区间后一帧仅作为相位比较参考，不重复添加到末尾。所选四段的末帧接首帧差异，分别为源片相邻帧变化中位数的 0.744、0.867、0.941、0.294 倍；该数值辅助判断是否突跳，不代表视觉已获用户认可。参见 `loop-seams.jpg`，以及各自的 GIF。四宫格 GIF 使用 264 帧／11 秒，使四种周期都完整重复后再循环。

正式资源为 `assets/resources/ux/chapter1_mob_walk_v81.png` 和 `.frames.json` 及其 meta：82 帧、320×320 固定画布、3240×2916 共用图集，最小透明边距 12 像素。清单记录每怪周期、正常移动速度、固定地面高度、逐帧鞋底点和头顶位置。运行时按原速播放，沿用现有减速／冰封／眩晕逻辑；战斗静态首帧与图鉴头像也来自同套新图集。没有对应的新攻击源片，因此驻足时使用新形象首帧，不切回旧形象。

原有1856份 assets 中仅修改4份 TypeScript，新增1张PNG、1份帧清单及2份meta，其余文件散列保持，无删除。原关卡、伤害、抗性、治疗、奖励、英雄与特效资源不变。静态类型检查与 v79 原10项诊断完全一致，没有新增诊断。Creator 3.8.8 正式构建完成，退出码36，耗时25528ms，DPR及缓存版本准备完成。
