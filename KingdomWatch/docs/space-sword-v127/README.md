## 炮手

原先穿透后的弱化弹只有0.65秒寿命，且走普通直击分支，没有爆炸。现在按可视战场对角线计算足够的飞行寿命，再命中时执行直击、范围溅射和现有 CannonBlastVFX 爆炸。保持原穿透次数、30%穿透弹伤害及地面攻击规则，溅射为该弹伤害的70%；主目标排除使用 lifeId。爆炸在直接命中致死后仍执行，不递归触发额外炮弹强化。

## 空间法师：伊芙·折界

- 主色 `#BB63D8`，银白短发、深梅紫衣装、空间晶核。法术伤害，可对空。
- 普攻：发射裂隙晶矢。
- 技能「空间放逐」：14秒基础冷却，优先选靠近防线的4个范围内敌人，造成伤害后瞬移到可视上方并减速20%、持续2秒。首领免疫传送但仍受伤害；不把敌人向防线传送，保留飞行高度，清理攻击前冲和旧站位锚点。
- 大招「双重界刃」：76基础充能，两道半长423的横向魔法刃从防线前向上贯穿，间隔0.65秒。连续线段扫掠判定，每道对每个生命实例命中一次，可同时打多个目标；不是中心点碰撞。

## 御剑师：凌霄·御锋

- 主色 `#63D2A4`，墨绿／象牙白衣装、金色护甲、银色灵剑。物理伤害，可对空。
- 普攻：发射飞剑，实际命中积攒1点剑意，每发至多获得1点，上限6；剑意以角色身边的小剑表示。
- 技能「御剑追锋」：10秒基础冷却，发射3柄追踪飞剑，消耗全部剑意、每点再加1柄。优先首领、精英和高生命目标，原目标死亡或对象池复用后重新索敌。
- 大招「万剑归宗」：72基础充能，选择敌人密集处展开剑阵，12柄落剑分布轰击，末尾落下终结巨剑。范围伤害与伤害统计复用现有伤害入口。
