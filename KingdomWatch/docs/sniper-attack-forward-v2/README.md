# 重弩手朝前平举弩攻击 v2

本轮在制作时发现武器被画成大型拉弓形状，未打包正式动作、未接入游戏。源视频和提示词保留为历史；当前制作改为 `../sniper-attack-forward-v3/` 的刚体弩加双臂／肩背反应。

用户要求完成当前重弩手攻击动作序列。本次沿用正式 `sniper_idle_forward_v2` 的红底母版，用项目 MiniMax H3 请求两秒弩弦弹动、双臂轻震、回位的单次动作，保留朝前平举弩和无枪焰要求。当前待机与弓箭手保持原样。

首轮攻击视频 `../sniper-attack-forward-v1/source.mp4` 在制作发射帧标注时出现枪械形状和枪焰，未用于正式战斗。旧待机 v1 中的射击片段也有弩形变化，未用于本次动作。本版只使用新任务的原始视频，任务、提示词与原片保存在本目录。

完整人物帧采用统一裁切、固定脚底、固定比例，与当前待机显示高度 170 和画内人物高度对齐；发射帧标注用于制作时序，实际效果仍由用户人工判断。正式攻击由普攻、技能及大招的实际出箭回调触发，攻击／收势时停播待机，左右直接镜像。序列单向播放，不做往返。

本轮制作、接入、Cocos web-mobile 构建、DPR 补丁及 Wrangler main 发布；按用户要求不运行测试、浏览器、游戏或线上验收，不将生成成功记作视觉认可。
