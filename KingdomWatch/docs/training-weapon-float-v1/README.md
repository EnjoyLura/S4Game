# 养成连升、悬浮展示与英雄栏滑动

升级页武器大图增加上下各7个设计单位、4秒一轮的正弦悬浮，上下端自然减速。只移动独立展示容器，图片加载不覆盖动画位置，名称、属性、培养等级和按钮固定。共享游戏时间相位使强化后重新构建的武器与旧展示位置连续；关闭页面随组件停止，减少动态偏好下静止，无循环Tween或额外计时器。

英雄页将装备底板、已穿戴标题、数量和五个装备槽归入一组，整体下移，以英雄大图的脚底和展示高度计算垂直中心。保持装备组尺寸、内部间距以及上轮武器栏左右等分，属性和故事按钮仍在独立页脚。

英雄和武器升级支持点击一级、长按450ms开始连升，间隔从240ms逐步缩到160ms。沿用ButtonFeedback的触点、移动取消、松手与后台清理，不在松手后补升一级；每帧最多进行一次真实升级。资金/材料不足、满级、页面禁用或切换时停止。每次调用原upHero/upWeapon并保存，成本和属性公式不变；技能和装备仍单次升级。

连升只原位更新等级、当前/下级属性、培养等级、消耗、持有量和顶栏钱包，不重建页面及按钮。十级突破才局部重建突破栏，保留滑动位置并使用既有突破通知。普通升级使用局部金色光环、10条上升碎光、英雄/武器轻回弹、锤头敲击、战力徽章回弹；战力数字280ms追赶真实值，战力增量在一条浮字中累计，不堆通知。短按复用升级音，连升用更短确认音，突破复用升级音；没有新增或合成声音。

等级/武器的属性板改为展示区局部y=16居中，最大高432、小屏保留顶部4单位安全空间，不再贴展示区底边。属性使用两行布局，底部独立放战力徽章，避免增量和数值重叠。

英雄页和升级页英雄栏共用原生水平ScrollView：686宽视口，144宽卡片、156步长、两侧8留白；右侧露出后续英雄作为滑动提示。跟手、惯性及220ms边缘回弹，拖动取消卡片点击，不触发选中；两页分别记忆位置，选择变化时保证目标可见。新旧页面交接时旧实例不能覆盖新实例的记忆。
