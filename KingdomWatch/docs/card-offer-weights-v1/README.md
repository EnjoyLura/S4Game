# 强化卡抽取权重

用户要求降低攻击力、攻速、经验等数值卡的出现率，提高普攻、技能、大招相关强化卡的出现率。

抽取仍先过滤上阵归属、前置卡和叠层上限，然后按“原稀有度权重 × 卡类型权重”进行三张不重复的加权抽取。首次三选一和广告／钻石刷新共用 `draw3`。

| 卡类型 | 相对原抽取权重 |
| --- | --- |
| 通用攻击力、攻速、暴击率、暴击伤害、经验 | 0.3 倍 |
| 普攻机制、元素特性、技能及大招解锁和后续强化 | 2 倍 |
| 防线耐久和修理 | 1 倍 |

通用数值卡通过 `offerGroup: 'stats'` 显式标注：`sharp`、`swift`、`crit_rate`、`crit_dmg`、`heavy_head`、`fast_load`、`steady_rest`、`lethal_aim`、`xp_badge`。其他英雄卡默认战斗构筑类，全局卡默认辅助类。技能伤害／冷却／范围、附带元素和大招后攻速等属于对应战斗能力，保留提高后的权重。

这些是权重倍率，不是固定出现概率；实际概率取决于当前上阵、已解锁能力、已选卡及剩余可选卡。原卡牌效果、稀有度权重和叠层规则保持。
