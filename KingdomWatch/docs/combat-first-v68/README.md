# 战斗改善第一版 · v68

本版优先解决「半局还在解锁能力、数值卡挤占构筑、敌人处理方式相同」。沿用五名英雄和现有怪物的完整美术、动作、音效与已认可特效，没有新增游戏图片、音频或视频。[正式体验地址](https://kingdom-watch.pages.dev/?v=combat-first-v68-1792597084)，[部署快照](https://cb18a231.kingdom-watch.pages.dev)。

## 战局节奏

- 五名英雄上阵即拥有基础技能与大招入口。技能自动施放；大招需要充能后手动施放。
- 初始大招能量按站位为25%、22.5%、20%、17.5%，避免整队同一时刻提示就绪。基础技能初始冷却错开0～2.4秒。
- 无击杀、无充能装备/卡时，从零充满的战斗秒数：弓80、弩86、火94、雷88、冰100。暂停、选卡、教学暂停不推进；倍速跟随战斗模拟。
- 每次有效击杀，将怪物原有能量的55%平均发给上阵英雄，各自再应用击杀充能效率。燃烧、爆破击杀也可共享；GM击杀与无奖励衍生物不发能量。满能量英雄的份额不再转移给其他英雄。
- 升级经验由 `50 × 1.35^(L−1)` 改为 `50 × 1.28^(L−1)`；每次局内升级额外给全队攻击与技能伤害项各2.5%基础成长。原有每2战斗秒发放的少量时间经验保留。

## 构筑与选卡

有效机制卡充足时，优先提供两个机制机会：一张衔接已投入英雄，一张尽量属于另一名英雄；其余位置在合法卡内抽取，纯数值卡最多一张。刷新共用规则。机制卡学满后可能少于三张；所有可用卡学满后继续战斗，避免弹出空选择。

| 新卡 | 实际效果 | 现有图标 |
| --- | --- | --- |
| 穿林箭 | 弓手普攻额外贯穿1个目标，最多2层，可配合连射/齐射 | 狙击贯穿 |
| 余烬爆破 | 被火法点燃的敌人死亡时，半径100造成火法60%攻击力的法术伤害；爆破击杀不再次引爆 | 火法灼烧 |
| 冰裂印记 | 冰系普攻/技能/大招命中后，给存活目标施加3秒、15%的全队易伤；Boss也可生效 | 冰法碎冰 |

旧技能/大招解锁卡移出当前池，原前置ID仅在本局内预置，不写入存档。保留原叠层上限、装备/突破与卡片效果；弓手机制卡原有攻击代价不变。前三场教学推荐改为机制强化，首次选卡后仍可得到一次对应英雄的教学满充能；不重复领取原有存档奖励。

## 三类共用怪物职责

| 现有怪物 | 机制 | 对策与识别 |
| --- | --- | --- |
| 大哥布林精英 | 40%物抗；累计原始物理命中达到最大生命28%后永久破甲，额外受到3秒15%易伤 | 头顶盾形小标，受击火星、破甲碎片与文字；法术绕过物抗，或物理集中破甲 |
| 狼骑兵 | 每6.5秒尝试冲锋；蓄势0.55秒、冲锋2秒、移速×1.8；冲锋抵达防线后首次攻击×1.5 | 箭头蓄势与速度线；冰封/眩晕取消本轮冲锋，减速延缓推进 |
| 哥布林萨满 | 行进中每6秒治疗180范围内最多3名受伤友军，优先生命比例最低者；不治疗自己或满血单位 | 绿色十字与实际治疗连线；控制延后施法，范围大招覆盖后排 |

物理来源为弓/弩的直接伤害，火/雷/冰/燃烧/余烬爆破为法术伤害。物抗只减物理伤害；已有章节物抗单位也复用破甲逻辑，默认阈值为最大生命30%。配置支持独立法抗，但本版没有批量新增法抗单位。原章节护盾等通用减伤仍保留。

机制写在同一套 `MonsterTraits` 中，由怪物配置启用；新怪物可复用配置，无需单独制作动画或反馈素材。图鉴与首遇波次提示同步更新；保留现有波次、怪物血量、基础伤害与奖励。原有章节特殊机制继续沿用。

## 共用反馈与边界

新增反馈复用一个Graphics节点和40个数据对象，低优先级速度线/护甲火星预留8个空位给其他反馈。0.35战斗秒内击杀5个有效敌人时，局部碎屑和短暂顿帧强调清群，冷却0.9秒；沿用原有顿帧总冷却，不叠加无限慢动作。

余烬爆破复用已有火焰爆炸，队列最多32个、每模拟步最多处理8个，不递归引爆、不新增计时器。弹体、雷冰直伤与爆破统计使用实际扣血量，处理抗性、易伤、过量伤害与复活时不再按未减伤的弹体数值计入。

本版没有改动英雄图像、序列帧、冰系v10素材、角色尺寸、原有UI布局、存档结构或主线结算。战斗暂停、选卡冻结、复活、普通关卡与无尽模式继续使用原生命周期。
