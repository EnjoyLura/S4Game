## 掉落和拾取

- 使用现有背包装备插画及品质色，真实死亡身体位置弹出，约480ms抛物线、240ms落地轻跳，轻光柱/品质落地圈/8条短碎光；固定86px点击区，不随图标跳动。
- 点击立即锁定并将同一UID存进装备仓库，再播放480ms曲线飞向右上小背包及软确认音。新装备不自动穿戴或替换现有槽位。
- 30个战斗秒后自动按同一路径收取。暂停、选卡、后台不累计，倍速随战斗时钟，最后5秒显示倒计时。减少动态时缩短运动并去弹跳。
- 胜利、失败、主动离场统一收回剩余装备。失败和复活均保留已存装备，重复点击/自动收取/结算不重复发奖。切场失败装备也已安全保存。
- 同屏最多32件，极端溢出先收回最老装备，不丢弃。普通击杀没有额外节点；只为真实掉落分配图标和局部Graphics。只复用现有已授权音频采样，未新增媒体、依赖或生成任务。

## 通关奖励和预览

关卡掉落和星级宝箱分为两页签，奖励区390–460设计单位；此布局调整取代旧316–420奖励区约束。各难度基础金币、固定强化材料和装备池同源于 `LevelDifficulty.ts`。预览明确区分通关必得材料、击杀装备掉率、成功掉落后装备池占比，说明30秒自动拾取规则。后续关卡仍保留锁定。

以关卡序号s=0/1/2计：普通通关强化石2+s；精英强化石4+2s、精铁锭1+s；地狱强化石6+3s、精铁锭2+s、魔法尘1+s。只在真实胜利时发一次。失败不发通关材料，已有掉落装备保留。结算展示材料和装备数量，点击战利品可查看聚合清单；广告只加倍金币。

星级宝箱按关卡和难度独立配置；保留原星级键与最高已领取档位，不重置存档。修复先领高档导致低档丢失的问题：高档领取会合计发放尚未领取的较低档。旧存档已标记领取的档位不追补、不重复发。
