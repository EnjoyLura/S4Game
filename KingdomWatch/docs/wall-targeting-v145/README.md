# 防线附近技能选敌修复 v145

用户反馈：怪物开始攻击防线后，技能和大招无法锁定、无法释放。

根因是 `densestBodyArea` 把特效落点下界同时用于过滤敌人。雷枪、魔法弓、镰刀的落点下界为防线 +50，剑客为 +60；近战怪物停在防线附近，地面投影还可能低于防线，因此被整个排除，选点返回 null。施法入口随即退出，导致技能不进入冷却、大招不消耗能量也不释放。

修复将两种约束分开：允许位于下界以下、真实圆形伤害范围仍能覆盖的目标参与选点；候选中心钳制到原落点下界，再按真实目标坐标统计覆盖数量。不会把敌人坐标钳制后虚算命中。原施法距离、上界、左右界、死怪排除和无目标不施放保持。

共享选点覆盖雷枪、魔法弓、镰刀、剑客及风系初始区域。已有龙卷追踪保留前向候选过滤，避免这次扩展使它追踪身后敌人。风系和剑客使用现成的存活/有效/可见节点筛选，隐藏或失效节点不参与选点。

本次不改伤害、冷却、能量需求、特效资源、弹道和雷枪位于怪物上方的层级。
