# 用户 AI 视频音轨提取 r1

源视频由用户提供，原文件保持，项目内保存一份完整副本和 SHA256。视频标记时长约8.06秒，AAC解码音轨约8.081秒（含编码补齐）。

按用户给出的时间分别切出三个2秒片段：0–2秒陨石、2–4秒雷电、4–6秒冰雨冰晶。标签仅对应用户提示词的标注，未进行音色听辨。保留44.1kHz立体声及原始速度和电平，导出24位PCM WAV；未加淡入淡出、均衡、降噪、响度调整或叠层。全部片段精确88200帧，解码样本与完整原音轨对应区间差异小于24位量化误差范围。另存完整WAV和不重编码AAC音轨，6秒后的尾声均保留在完整音轨中。

提取脚本 extract.py 与记录 extraction.json 可复查。本次只制作本地音轨，尚未将本次用户视频素材接入或发布到正式游戏；原v27运行资源保持。没有运行游戏、浏览器或播放音频。


后续更新：用户最终确定分界为2.3/4.3/6秒，并授权接入大招，已在[试用版v28](../audio-ai-ultimates-v28/README.md)发布。上文是初次提取时的历史记录。
