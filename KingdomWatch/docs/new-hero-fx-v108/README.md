## 重炮与导弹轰炸

普攻与技能继续使用重炮弹。落地爆炸改为短促接触亮点、连贯的橙金火团、贴地尘环、低透明度焦痕、延后上升的烟团，以及有抛物线高度和地面影子的碎片。地面效果放入GroundFxLayer，火团与碎片放入FxLayer，怪物和飘字仍清楚。二段爆破在原来0.35秒后的真实结算点触发独立较小爆炸。

大招正式名为“导弹轰炸”。原批次按左右交替的斜向入射点从上方俯冲，导弹具有钢铁弹体、黄铜锥头与箍环、尾翼、双层尾焰和沿实际飞行位置保留的烟迹。每枚发射后出现低亮度金色落点标记，只有该枚实际着地才消失；没有附加地面持续伤害。落地仍共用原中心全额/周围70%伤害路径与音效、命中处理。

基础6枚、培养/饱和轰炸卡增加枚数、每枚伤害/半径、75充能、0.6秒准备和0.26秒错峰均保留；斜向起点会让个别飞行时间略有差别。不改变普攻/技能数值、破甲、击退、卡片权重与上限或原怪群落点选择。资料与战斗技能Tips、培养里程碑、饱和轰炸文案同步，不改卡片ID、存档或价格。

## 生命汲取

光束从法杖晶体位置出发，并跟随完整人物镜像。以酒红轮廓、玫红光带和细浅色光芯构成柔和弯曲的束，增加缠绕的副丝、向施法者移动的亮点、敌人接触处开放符环以及施法端汇聚环。大招的符环与回流光滴更明显，主副束有粗细区别。

较大的回流光滴与短接触亮点只在实际扣血大于0时生成，包含致死一跳；同一出生实例被多通道在同一步命中合并显示一次，伤害仍独立。防线实际回复大于0才出现小型汇聚亮圈，满血不伪造回血提示。持续光束装饰与实际伤害回流分开，不改变0.25秒结算、持续锁定到死亡/离场、增伤、分流、法抗削减或回血上限。
