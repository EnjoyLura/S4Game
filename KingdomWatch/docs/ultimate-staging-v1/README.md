# 五位英雄大招演出 v1

用户要求延长每位英雄的大招演出，增强分量，并在方案后确认继续实施。本轮沿用现有人物、冰系素材、蓝色重弩与紫色落雷材质，以程序图形和真实释放队列完成蓄力、爆发、命中及余韵。

| 英雄 | 基准演出时间（战斗时钟） | 实际实施 |
| --- | --- | --- |
| 弓箭手 | 3.4 秒起 | 0.55 秒蓄风；每排间隔 0.52 秒，每轮间隔 1.35 秒；追加轮次与第三排延长时长，真实出箭时才发声及触发风压。 |
| 重弩手 | 3 秒 | 1.1 秒蓝色锁定，扫描、收拢、短暂持稳后发射；额外枪线共用最终实际目标数组；延长发射压缩波、命中光及细蓝余迹。 |
| 雷法师 | 4.5 秒 | 0.65 秒蓄电；15 道雷分三组，每组 5 道，组内逐步提速；最后一组仅提高视觉能量；保留已修正的完整地圈与雷柱脚点。 |
| 火法师 | 5 秒起 | 0.7 秒聚火；每 0.48 秒一颗，5/7 颗沿原怪群覆盖算法分散，预测包含新延迟；固定预警点、实际地面到达结算，末段余烬。升级或长屏按最后一颗落地加 0.8 秒估时。 |
| 冰法师 | 4.2 秒 | 0.5 秒凝冰，在首批接地阶段结算原全场一次伤害；固定 128 颗随机全场冰雨跨 2.8 秒出场，接地碎冰及冷色余光收尾。 |

这些是基准时长；飞行、顿帧、倍速及追加轮数会改变实际屏幕时间。整个世界共用模拟时钟，蓄力阶段限制倍速以至少保留约半秒可读时间。暂停冻结；HUD不随世界轻震移动。暗场只在背景层，透明度取多个大招的最大值、上限约17%，不叠加发黑，不以全屏白闪制造力度。局部装饰事件上限18，冲击最多3设计像素、0.14秒，0.6秒冷却。

音频沿用已接入的授权采样。蓄力是低音量、低通、淡入淡出的采样短层；释放声跟实际发射；冰雨后段的接地声限频，峰值短压低BGM，暂停/三选一/结算清理战斗声及压低状态。没有生成图片、视频或新合成蜂鸣音。

大招基础倍率、箭数、15道雷、5/7颗陨石、128颗视觉冰棱、伤害范围与双基础伤害公式保持。**伤害发生时间确有调整**：弓/弩与火按新时序出手、落地，雷击分组拉长、眩晕随每次真实命中，冰法一次全场伤害延至0.5秒。蓄力阶段暂缓新普攻/技能出手；既有飞行弹继续模拟。重弩25秒自动大招冷却持续倒计时，到期若自身大招尚未结束则等待，不因加长演出累加冷却。

三选一继续等待大招及原2秒缓冲；排队释放、真实在途大招弹、演出余韵共同保护，不提前截断。最终清怪时延后胜利结算，等真实弹道和余韵结束；失败仍即时处理。自动重弩也发起同一演出。退出销毁订阅，清理共享绘图与世界偏移。

修改集中在 `Hero.ts`、`BattleDirector.ts`、`Projectile.ts`、`UltimateTiming.ts`、`UltimatePresentation.ts`、三类既有大招VFX与重弩材质、`ImpactFX.ts`、`GameAudio.ts`、`Sfx.ts`、事件常量和重弩说明。`before/`保存本轮开始时的局部基线；`implement.py`与`integrate.py`是已执行的一次性迁移记录，后续源代码另有收尾修改，请勿重复执行。
