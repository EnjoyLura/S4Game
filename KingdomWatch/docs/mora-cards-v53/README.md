## 伤害与控制

大招由一次全场伤害改为三次：0.5 / 1.7 / 2.9秒，间隔1.2秒。原总基础伤害均分三份，不将总伤害直接乘三；碎冰逐段按命中前的目标状态结算。每段重新读取存活怪物，期间新出现的怪物可被后续段命中。保留原4.2秒演出、256颗连续全场随机冰雨、原素材与音效，不将整场冰雨重播三次。

速冻之心原实现需要70级突破才生效，而且发射时就冰冻目标；现在改为弹体实际命中判定，无突破0→15%→30%，有突破15%→30%→45%。不命中不触发，Boss仍免疫冰封。

寒冬延续覆盖普通减速2→4秒、领域解冻后减速2→4秒、大招减速4→6秒（大招10级6→8秒）。冰封延长仅作用领域，保留80级突破+0.4秒和技能15级+0.3秒，叠满合计4.2秒；不增加普通冰冻或绝对零度的单次冰封时长。已有冰封受新的冰封时长取高刷新，不缩短、不直接相加。

碎冰与既有普攻15级对减速+25%分别计算；既有里程碑仍只对普攻/减速生效。技能修复原来仅显示暴击但未乘暴伤的问题，技能及大招伤害统计按实际扣血并封顶剩余生命。
