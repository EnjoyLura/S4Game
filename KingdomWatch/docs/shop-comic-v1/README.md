# 商店 · 清爽漫画奇幻 v1

用户选定的方向：清晰深色轮廓、少量明确明暗、大块面材质和克制的细节。沿用商店大图 → 图标文字横排页签 → 三列商品的游戏布局。

## 美术制作

- 使用内置 imagegen，以同一张已选定的样张约束全部插画。每件商品独立生成，英雄额外参考原头像保留身份。
- 共 20 张生产插画：1 张商店场景、2 个货币、10 件商品、4 个英雄、3 个导航图标。原始输出保存在 `sources/`。
- 实际使用的图标在 `assets/resources/ux/shop_comic_v1/`；商店大图在 `assets/resources/scenes/bg_shop_comic_v1.jpg`。
- 物品统一为 256px 透明画布，英雄为 384px。统一主体占比，保留比例和抗锯齿，只清理生成器产生的极低透明度边缘杂点。
- 图标旁的 48px 样张见 `asset-contact-sheet.jpg`。不使用生成图中的文字、数量、价格或整页布局。
- `generation.json` 保存全部实际提示词、参考图路径和生成结果路径；生成工具为内置 imagegen。

## 组件规则

`ComicUI.ts` 统一绘制按钮、页签、资源栏、商品卡、购买弹窗和提示消息的基础形状。只保留单层深炭色轮廓和窄顶部高光，去掉偏移底板、第二层描边及底部阴影条，避免组件下沿出现叠片感。按钮按下时仅将同一个面板降低 2 个设计像素，禁用态使用同一轮廓的灰绿配色。

商品卡使用米白大底和少量品质底色。去除旧金色放射纹、暗色方形图标座和繁复花边。标题、价格与说明由游戏字体渲染。商品的锁定、已拥有、数量、阶级、价格和原有购买规则继续保留。

英雄招募卡和购买弹窗使用 `comicPortrait` 正圆裁切：圆形底色、96 段圆形遮罩和统一的半身图比例，肩部填满圆框下沿。图片本身保留比例，不压成椭圆，也不改变原插画。

资源栏和底部导航是五个主界面共用的组件，因此同步使用这套美术。资源栏靠右排列，单项宽度从 254 缩短为 218 个设计像素，保留刘海避让、货币图标紧邻数量与两个资源加号。其他四页内容仍保留现有页面布局。

商店标题和副标题锚定场景左侧方木牌的位置，跟随大图的等比裁切适配不同手机尺寸。商品面板底下增加全宽米色纯色背板，从页签下沿铺到底部导航上沿，填满左右缝隙和切角处。

## 验证与交付

- 引擎声明下的 TypeScript 检查。
- Creator 3.8.8 web-mobile 构建和 `tools/patch-web-dpr.py`。
- `check_shop.cjs` 在独立测试存档中检查四分类、插画加载、武器自动穿戴、材料购买与取消、英雄解锁与防重复购买、关卡锁定、余额不足、五页共用钱包、加号弹窗和两种手机尺寸；不启动战斗、不触碰用户存档。
- 实际页面截图保存在本目录 `shop-*.png`；核验记录见 `ui-validation.json` 和 `deployment-validation.json`。
- 发布到既有 Cloudflare Pages 的 main 分支；线上版本由入口脚本和新素材的 SHA-256 对照核验。
