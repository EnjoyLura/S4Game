# 赤狱绞杀 v144

按用户选择使用赤红／暗红与少量亮橙锋线。参考用户提供的旋转斩图片、镰刃图片和红黑多向斩 GIF；不复制角色或背景。用户随后明确取消交叉蓄势，节奏改为“区域升起 → 多方向高速切割 → 最后一击收束”。

## 游戏变化

- 普攻：赤红新月镰刃、侵蚀薄尾与细碎拖丝；保留原速度、弧形碰撞与穿透逻辑。
- 技能：完整长柄钩镰投出后每秒旋转 2.5 圈，旋转残影，停留四秒后回收；原伤害与十次命中时钟不变。
- 大招“赤狱绞杀”：锁定敌群的半径 320 区域（受范围加成），区域先升起，0.62 秒开始每 0.24 秒切割，八次普通切割后第九次双倍终结，3.16 秒结束。区域内每次结算圆形范围伤害，刀痕是视觉表现；进入/离开区域按每次结算时位置判断。替代旧三道全屏飞行波，范围形状确实改变。
- 1—20 级总基础倍率与旧三波保持一致：8 × 0.81 + 1.62 = 8.1，等级成长与既有加成继续生效。最后一击使用现有接触震动和音效。
- 按最新追加指示，雷枪飞行、插地、回收、枪雨、雷暴、地电与备用绘制全部改到怪物上方；蓄力和命中余光一致。雷枪 v143 素材、轨迹、范围、伤害保持。镰刀区域与旋转技能仍位于怪物下方，普通飞行镰刃位于弹道层。

## 制作与复现

`build_scythe.py` 生成原创程序化 Blender 几何、动态材质及逐帧姿态；`scythe-elements.blend` 保存可编辑几何和代表帧，完整动画通过脚本复现（不是已烘焙的时间轴）。使用 Blender 5.2.3 LTS EEVEE、双倍分辨率抗锯齿渲染，`pack_layers.py` 生成直通 RGBA 图集与固定锚点清单。

三张正式图集：blade 32 帧／32fps，spin 32 帧／80fps，slash 18 帧／30fps。保留两像素透明边与图集间隔；末尾切割逐帧侵蚀并归零。装备时预热，共享纹理，固定精灵池，模拟时钟驱动，素材未就绪时锁定本次施法备用绘制，不在半途跳换。

参考文件位于用户临时目录：`codex-clipboard-8503b7cf-a80f-46be-b376-87980308b5e3.png`、`codex-clipboard-cf1ee7c1-78a5-4dc4-aea9-746d57fef08d.png`、`codex-clipboard-cf64f7fc-4a20-440c-bca7-de42c1ff066b.gif`；动图时长与取帧信息见 `reference-info.json`。参考原图未当成正式资源。
