# 升级页整套美术落地 v12

依据 [四页与四类弹窗效果稿](../upgrade-art-concept-v12/README.md)，复用现有插画、ComicUI 原单层按钮和 DetailDialog 通用布局。效果图中的示例数据不写入游戏。

| 界面 | 落地内容 |
| --- | --- |
| 等级培养 | 紧凑五圆头像、连体分类；成长面板浅纸金框、内收深蓝标题；整组近白底、当前/下一级/增量对齐；战力与突破区 |
| 武器培养 | 保留完整武器与浮动展示、名称和继承说明；统一强化面板与突破卡 |
| 技能培养 | 三张切角选择卡和圆形插画；浅金选中；倍率预览白底、解锁说明及技能突破卡 |
| 装备培养 | 四张装备卡；品质方板填满图标槽、无品质角标；细金选中框及勾标；装备强化预览 |
| 属性总览 | 直接沿用已有的通用详情背板、英雄展示、近白属性分组、关闭按钮及底部留白 |
| 突破详情 | 替换旧简易弹窗；通用纸面与深蓝标题、对应图标和名称、突破效果白底、真实解锁条件和状态 |
| 武器培养弹窗 | 完整品质槽、真实等级与属性比较、绿色增量、材料分组、继承说明、绿色强化与底部留白 |
| 装备强化弹窗 | 同一布局；主属性比较、材料需要/持有、递增说明；旧 equipModal 入口也使用此弹窗 |

培养操作与导航保留原单层造型；不照搬效果稿中可能偏厚的按钮边框。新增纸面、细卡框、分割线和分组均为本地原生绘制，没有新增或改写运行图片。页面操作区距导航约32单位；强化弹窗按钮下方约30单位。

真实数值、费用、材料聚合扣除、上限、英雄/武器长按升级、成长反馈、每英雄/类别滚动记忆、突破横向滑动和战局技能三选一解锁保持。英雄页除共用强化弹窗外保持，其他页面及底部导航无改动。

按现有约定，只审阅源码、静态类型、本地生产构建与发布回执；不运行测试、模拟、游戏、浏览器或线上验收。实际画面与交互待用户人工查看。全项目静态类型仍有此前九项 ButtonFeedback 及其引用诊断，修改文件无诊断。
