## 处理与选段

先在源分辨率处理洋红底：从空白边缘估计视频编码后的底色，色差提取透明度，反解混合边缘，并仅对半透明边缘去洋红串色。之后等比缩至360×540分析，避免先缩放造成更多底色混合。此次冰法原片不带外扩法杖辉光，不使用上一版能量提取或实体保护遮罩。

比较姿态、前后相邻三帧和运动方向；弓箭手对左右披风、上身和脚部分别评分，冰法对法杖、头部、衣摆和脚部分别评分，避免稳定身体区域稀释披风误差。候选端点对照已人工静态检查，数据只用于筛选，不等同用户认可循环效果。

- 弓箭手：0起第6–54帧，49格，1.633333秒。
- 冰法师：0起第6–57帧，52格，1.733333秒。

均连续正向、30fps原速，无倒放、额外停帧、插帧、混合过渡或逐帧位置修正。源片衣摆、发丝和姿态仍可能有轻微首尾差异，不声称绝对无缝。

每位统一352×576画布和脚底，同一联合裁剪框、缩放与偏移贯穿整段，透明边距至少13px。弓图集3168×3456、冰图集3520×3456，均低于4096。
