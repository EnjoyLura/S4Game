# 三种怪物美术风格 · 待审对照

按用户纠正后的需求，固定同一组四怪，比较三种画风。各图的排列均为：左上双足散兵、右上四足猎兽、左下飞行秃鹫、右下漂浮荒灵。

| B 复古手绘 | 弱化黑线、哑光水粉、干笔触与大块明暗 | [原图](B-painted-fantasy.png) | [B](prompts/B.txt) |

[打开三图比较页](index.html)

全部使用内置 `image_gen`。A 为新建的基础设计，B、C 以 A 作为造型和构图参考重绘画风。所有生成原图按原字节保存，提示词与来源散列记录于 `art-record.json`。均为待用户选择的探索稿，尚未批准为统一美术标准。

生成对照可能存在局部造型漂移，比较页不表示三种画风的像素级等形。完整图鉴是风格预览，不能直接作为拆分完成的动画母版。
