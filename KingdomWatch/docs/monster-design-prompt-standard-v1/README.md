根据本聊天的设计反馈整理，用于后续统一怪物美术。统一画法、材质概括、细节密度、视觉主次和机位；种族、生理结构、性格与兵种身份分别设计。

可复制的完整模板：[master-prompt-zh.txt](master-prompt-zh.txt)。填写示例和机位参数：[design-variables.md](design-variables.md)。

## 使用方法

1. 每次使用同一张画法参考，再附对应种族的母型参考，写明各自用途。两种用途可以由同一张图承担。
2. 填写模板中的所有【变量】，每只怪物先确定体态、性格和一个主要识别点。
3. 同类体态整批固定机位、站姿规则、尺度与背景；四足按用户最新要求使用正面微俯视、露出一点背部，双足机位不因此自动改变。
4. 先校准一个单体，再从同一物种派生兵种；四足、飞行和其他物种单独建立母型。
5. 修改时以最新单体为编辑目标，只要求本次变化，并列出脸、体态或其他需要保留的部分。

## 当前反馈的优先顺序

- 用户要求狼看得到一点背，四足怪物都用微微俯视角；保持头脸正向，不能为了露背转成侧面，也不要仰头看镜头。详见四足固定机位模块。

- 后续用户明确否定 v13 投手：服装和长相太像人。仅写蓝皮、黄眼、兽耳及破旧并不能满足造型要求；先画清吻部、颌部、头躯关系与非人类体态，再决定穿戴方式。蓝皮兽族装备优先从作战和原始材料出发，避免自然滑回人类头巾、套头衫、短裤和标准腰带的组合。

- 用户喜欢原狼骑参考中骑手的非人类脸和动物骨盔；脸型、体块先成立。
- 允许一点筋肉感，避免健美人形。此前“完全去掉肌肉”的约束已被修正。
- 骨盔要克制，面部保持可见；头部装饰按兵种选用，不能全员复制骨盔。
- 服装适度覆盖，保留局部皮肤和身体轮廓；此前“把全身包住”的做法已被否定。
- 服装应有大块完整结构、不对称穿着和明显破损。衣服碎，是层叠细碎结构过多；衣服破，是同一件旧衣发生缺损和磨穿，两者不等同。
- 红脖巾应歪系、有不同长度和松紧，不能画成整齐对称的圆披肩；红脖巾也不是全怪通用制服。
- 同族有相同生理识别特征，同时用脸型、体态、衣装剪影和战斗结构建立个体区别。
