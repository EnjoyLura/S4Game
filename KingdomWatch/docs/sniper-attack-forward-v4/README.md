# 重弩手攻击 v4 · 比例与残留火星修正

后续按用户要求 [缩小 10%](../sniper-size90-volt-art-v1/README.md)，本目录及正式攻击 manifest 的当前显示高度为 153，与待机 v2 同步；原图集、帧顺序、脚底和比例校准保留。

用户随后指出透明度过渡造成切换黑闪，当前正式播放器和本目录预览已移除该过渡，恢复单图全不透明直接切换。详见 [切换黑闪修正](../sniper-transition-fix-v1/README.md)；下方发布及 80ms 过渡描述为 v4 初版历史记录。

已构建发布：[正式游戏](https://kingdom-watch.pages.dev/?v=sniper-attack-forward-v4-1791903111) · [修正版攻击预览](https://kingdom-watch.pages.dev/previews/sniper-attack-forward-v4/?v=1791903111)。部署 `https://406d5237.kingdom-watch.pages.dev`；Cocos web-mobile 成功退出码 36、11067ms，DPR 完成，Wrangler main 上传 14 文件、1006 文件缓存。详情见 `release.json`。

用户指出 v3 的攻击与待机切换显得人物一大一小，并提供了残留火星截图。v3 仅匹配头顶到脚底高度，没有校正 AI 视频中的人物横向比例；攻击披风更展开，也会加重切换时的宽度变化。第 13 源帧还带飞散火星，之前被错误地当成干净发射帧。

本版沿用同一 H3 原视频，不新增视频生成任务。攻击素材按当前待机首帧的头顶到脚底高度、脚底位置和双靴站姿宽度进行一次固定整帧比例校准；所有攻击帧共用该校准，不对各帧单独缩放、不拆分身体。攻击与待机统一为 512×512 格子、脚底 `(256,496)`，正式显示高度 170、节点脚底 `(0,-76)`。

源帧 8–13 全部剪除，保留 6、7、14–55 共 44 张完整人物帧，序列索引 2 对齐实际出箭。原视频保留为制作来源，去闪光成片、帧选择和校准参数在本目录。

正式播放器与预览在待机／攻击切换时采用 80 毫秒整帧透明度过渡，缓和披风展开差异；上一动作只保留静止过渡帧，攻击时不推进待机。正式过渡使用战斗模拟时钟，暂停时冻结。当前待机、原箭矢和直接左右镜像保持既有行为。

按用户要求只制作、接入、构建与发布，效果由用户人工查看，不执行测试、浏览器、游戏或线上验收。弓箭手沿用现有图片、动作和高度 185.64。
