# 大招演出与界面完整交接 v3

本轮合并用户连续四项要求：雷法师大招参考紫色落雷重做；重弩手大招加强并统一蓝色；五个主页面切换白闪；编队关闭时短暂空白。

雷法师大招由专用程序材质绘制细白电芯、紫色柔光、多尺度不规则雷路和三条分叉，85ms沿原通道回击，310ms收净。地面与雷柱共用目标脚点，怪物下方有短促紫光、断续扩散环和24段分叉交联电裂纹，580ms内收净。12组池化事件，邻近反复落雷按能量减少辉光叠白。原15道落雷的伤害、时序、范围和控制效果保持。具体制作说明见[落雷说明](../volt-ultimate-bloom-v2/README.md)。

重弩手大招保留原0.5秒锁定：蓝色瞄准轴、沿轴汇聚光点、转动收拢的四段准星；实际发弹时有蓝色压缩气浪与短促冷光。贯穿弩矢保留实物箭体，增加最长245像素的渐细蓝色尾迹、侧流线、方向性命中闪光。12组弹道与24组出手/命中池，程序材质首次未就绪时使用简化线条回退。死亡准星卡的运行时头顶标记也改为蓝色，文案同步；受伤提高30%、持续5秒保持。原卡面文件保持，未重新生成图片。

五页与页内刷新不再用整层透明度过渡。旧页面保留完整背景和内容，新页面在下方以正常透明度构建；等图片、嵌套刷新就绪且经过绘制，再交接层级。切页只保留8像素/160ms微位移，原页面填住边缘；减少动态效果模式直接完整替换。快速连续导航替换待交接内容，并取消过期绘制回调。图片加载失败仍使用现有程序回退。

编队点击完成后保持整个编队页完整可见并拦截重复操作，同时刷新下方关卡页；等待关卡页完成嵌套内容交接与绘制后，再一次性移除编队页。不会先把头像和文字淡到透明，再露出浅色底板。此处理取代旧版编队关闭后才刷新关卡的顺序。

全部战斗演出使用模拟dt，遵循暂停、倍速和顿帧；退出释放材质、节点和纹理。英雄序列、双基础伤害、卡牌数值、音效及存档规则保持。
