# 重弩手攻击视频去枪焰

已构建并发布到 [正式游戏](https://kingdom-watch.pages.dev/?v=sniper-attack-noflash-1791870716)，部署快照为 `https://d20fab7e.kingdom-watch.pages.dev`。Cocos web-mobile 构建成功（退出码 36），DPR 补丁和 Wrangler main 发布完成。

用户提供 `C:/Users/user/Downloads/弓箭手姿势描述 (3).mp4`，要求去掉枪焰。

- 原视频备份：`source.mp4`。
- 处理后视频：`sniper-attack-no-flash.mp4`。
- 原尺寸 1280×720，24fps，97 帧，视频时长约 4.04 秒。
- 仅处理第 52、53、54 帧（编号从 0 开始）人物外的枪焰区域，使用原黑色背景填充。第 52 帧沿重弩上缘避开武器，第 53、54 帧处理已离开武器的火光。
- 保留原画幅、原帧顺序、角色动作、音轨与水印。没有重生人物、跳帧或改写攻击姿态。
- `remove_flash.py` 是可重跑的处理脚本，`flash-mask-*.png` 是原坐标蒙版，`processing.json` 记录来源和改动。

用户确认去枪焰视频后，明确要求接入游戏。本次正式战斗读取 `assets/resources/ux/sniper_attack_v1/` 的完整人物透明帧。

- 原视频第 48–96 帧共 49 帧按顺序打包，去掉开场持弩等待，第 52 帧是出手帧（图集索引 4）。
- 图集格子 512×576，7 列 7 行，3584×4032；固定源脚底 `[680.5,636]`、裁剪与比例，披风完整保留，不逐帧居中或变形。
- 攻击沿用待机 `displayHeight=170` 与 `readyHeightPx=426.2915`，两套动作节点脚底均为 `(0,-76)`。仅换图集格子与锚点，不改变实际站位。
- 出手前使用准备帧，普攻、技能连狙和大招的实际发弹回调触发射击、后坐和回位。收势按攻速缩短；快速重叠发弹不重复重启完整身体动作。
- 攻击和收势期间停止待机；攻击范围内没有存活敌人、没有待发攻击且收势结束后恢复原四秒待机。左右朝向继续直接镜像，暂停沿用模拟时钟。
- 原视频枪焰已移除；正式游戏同时移除重弩普攻和大招原先叠加的弩口粒子闪光。弹道、伤害、攻速、技能及音效逻辑保留。
- `build_attack.py` 可复现固定取景、角色安全抠底与弩空隙抠底，`attack-matte.json` 记录各帧额外抠底区域。
