# 充能修复与交互动画 v2

本次包含用户连续提出的四项改动；构建和源代码检查不代替用户人工体验。

## 大招 99% 根因

上一版 Cocos 构建把 `super.ultimateRemaining` 降低为 `HeroBase.prototype.ultimateRemaining`。父 getter 因而在原型上读取只存在于实例的 `ultimateT`，得到 undefined；Math.max 返回 NaN，`<= 0` 永远不成立。受影响的是弓、弩、火、雷；冰使用父类原 getter。

四个覆写直接读取受保护的实例计时器，仍同时检查各自真实大招队列。HUD 将“已满但上一招尚在演出”显示为“施放中”。伤害、需求能量、回能和演出时长不改。

`charge-bug-before.txt` 保存旧构建关键代码；新版 main/index.js 已人工核对四个直接实例字段读取，不再有错误的 prototype getter。

## 原创三选一节奏

仅从用户录屏提取帧观察出现与选择节奏，未启动游戏。保留本项目纸纹、图标和布局，新增 PickMotion 统一时钟：卡片从下方 22px 轻抬，55ms 错峰，440ms 收稳；选择后轻抬 14px、最多 1.028 倍等比收稳，原创角线与八个小光点提示。

其余卡片保持不透明纸面并覆暗，不再透出战场。刷新等待美术，逐列交接旧卡。入场、选择、刷新等待期间拦截重复输入；回调消费一次，页面版本变化丢弃旧回调。减少动态效果和后台恢复有独立处理。

## 余额不足

商品详情购买前读取当前存档余额，金币和钻石均显示精确差额。价格区域轻摆、余额文字转红、同语义提醒音和通知；对话框保持打开。失败不调用购买扣款，成功仍走 shopBuy；确认按钮不会先播放成功声。

## 开战旗帜过场

开始战斗不改文案或 busy 皮肤。原生 Cocos 持久 Canvas，独立摄像机/图层；深蓝双旗、细金边、暗织纹、原创盾形徽记，全程序绘制。

0.34 秒合拢期间并行预载；完全遮挡后才切场景。BattleDirector 构造完整场景、已追踪背景/界面美术准备并完成一帧绘制后展开，展开约 0.48 秒；常规最短全程约 0.96 秒。开战倒计时从过场结束后开始。失败恢复原页；单项图片请求超过八秒时允许既有程序兜底显示。后台冻结、窗口适配、减少动态效果、重复输入与销毁清理已做源代码检查。
