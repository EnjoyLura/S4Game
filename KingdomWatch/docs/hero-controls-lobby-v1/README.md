# 英雄页控件与入口布局

按用户 2026-10-15 截图反馈调整英雄页：左右切换的圆石素材与主界面风格不搭，属性／故事位置奇怪，背包三分类的图标文字没有整体居中。

- 左右切换复用 `ComicUI.comicButton` 的深色切角面、细轮廓、窄高光和按下反馈，箭头为原生 Graphics 金色几何。按钮 64×64，保持原切换位置及已拥有英雄循环逻辑。
- 属性／故事由装备栏底部移到角色战力正下方，两枚 148×50 紧凑按钮，图标 30、文字 22，图文整体居中。增加 64 高的角色操作行，原角色图片、显示大小、名字、战力、站台脚底和装备槽的绝对位置保持；背景脚底锚点同步增加这 64 高度。
- 已穿戴整栏根据武器与四个装备槽的实际底边收短，最后一行下方保留 16 留白，移除旧操作钮造成的大块空区。
- 武器／装备／材料页签统一为 30 图标 + 10 间距 + 44 文字框的居中组合，图标中心 -27，文字中心 +20。选中金色／未选深色、页签尺寸与触控范围保持。

本次用户指示取代 `hero-comic-v3` 的圆石切换按钮以及属性／故事 126×86、位于装备栏底部的旧要求。原英雄和物品插画继续复用，没有调用图片或视频生成。背包滚动、分类、换装与弹窗数据回调保持。

按用户既有要求只进行 Cocos Creator 3.8.8 web-mobile 构建、DPR 补丁和 Pages main 发布；不运行测试、游戏、浏览器或线上视觉验收。效果由用户人工查看，构建和发布不等于视觉认可。

构建、发布脚本与收据保存在此目录。之前的预览与音频鸣谢随新版本继续发布。
