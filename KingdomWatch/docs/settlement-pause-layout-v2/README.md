# 结算、暂停、前哨城门与战斗界面反馈 v2

2026-10-16。回应用户同轮反馈：结算背板不搭、失败操作与重试流程；暂停设置组件过近和文字重叠；上一版城门装饰和材质不合游戏风格；三选一偶发延迟约半秒；索敌范围显示不明显。

## 结算与重试

胜利/失败奖励区统一复用主界面的 `ComicUI` 米色纸张、浅色奖励卡、单层深色轮廓和小切角。文字和数字改为深色，统计说明改为棕灰色；原皇冠标题、货币和经验图标、页签保留。正式结算不再加载旧金属大背板和金属奖励卡。

失败页移除“返回”和全宽广告行，仅保留底部并排两个按钮：左侧原返回位置为绿色“▶ 看广告复活”，右侧金色“↻ 再来一次”。说明区展示恢复 30% 耐久及返回本关的行为。广告中锁定两个操作；未完成广告留在结算页并提示重试，成功继续原战局。

“再来一次”调用回主界面的受保护导航，明确选择关卡页。通过 `flow.levelReturn` 一次性传递实际战斗关卡与难度，关卡页消费后恢复选择并让该关卡停靠点可见；不调用进入战斗。之后玩家自行点击“开始战斗”。普通主界面切换保留会话选择记忆。导航失败回滚完整 flow 并释放离场锁。暂停退出、胜利返回也定位实际战斗关卡；胜利“下一关”的原直进流程保留。

## 暂停布局

原倍速行底部为顶基 778，页签从 780 开始，仅有 2px 间隔；鸣谢链接顶基 806，落在页签 780–838 内。本轮用一个 750×680 的居中内容根替换散落的屏幕顶基坐标，短屏按安全可用高度等比缩小，留出上下合计 48px。

- 标题到首行间隔 32px。
- 设置行高 60px、行间隔 16px。
- 最后一行到鸣谢链接间隔 22px。
- 鸣谢链接独立占 44px 高度，与页签间隔 19px。
- 页签高 58px，与退出/继续按钮间隔 28px；两按钮横向相隔 50px。

奖励和最多四人伤害统计使用同一内容区，头像、姓名、数值、百分比、条形图分开。音乐/音效即时保存、倍速解锁、未开放振动、鸣谢地址及暂停逻辑保持。

## 三选一响应

源码发现 `showPick` 会将标题、卡和操作区全部隐藏，等待三张卡的所有图片加载后才统一显示。当前纸卡、标题和实际使用的漫画头像不在旧预载清单里，冷缓存可以延长这段空等。此为源码发现，未进行运行时耗时测量，不能将其当作半秒延迟的唯一原因。

新增 `PickArt.ts` 共享实际卡图映射，按上阵英雄预载三个共用纸卡资源、对应漫画头像及可抽取卡池图标。关卡页先完成首屏美术，再以两个请求并行、每批让出 16ms 的方式后台预载；战斗初始化补一次，覆盖直接进入下一关。使用已有 `uxFrame` 缓存和请求去重，不额外创建隐藏 UI 或在卡池抽取时消耗随机数，也不延长入场遮挡等待。

初次触发先立即显示可读标题及打开提示音，完整卡面仍待实际美术就绪后再展示，避免闪出空卡。首次展卡总时长 440ms → 320ms，错峰间隔 55ms → 35ms，单卡落稳 290ms → 240ms；原 480ms 选卡、520ms 刷新表现保留。击杀获得经验仅入队，在战斗子步结束后打开界面，避免在命中/死亡回调里创建弹窗。大招演出和既有 2 秒缓冲、卡权重与效果保持。实际流畅度仍需用户人工确认。

本地构建产物审阅发现 Cocos loose spread 将 `Set` 展开转换成单项数组，已改为显式 `Array.from(new Set(...))` 并重新构建；最终产物保留正确转换。该修复仅针对本轮新预载代码，错误版本未发布。

## 索敌范围

普攻圈改为亮金色，技能圈改为浅蓝色。内部填充 5% → 10%；边界使用 17px/14% 的轻外沿、8px/78% 的深色衬线、4.5px 的实色线及 1.25px 的浅色细芯，使黄土地和亮色技能背景上都能读清范围。仅打开原属性 tips 时绘制，不增加常驻逐帧绘制或新贴图。原圆心 `HERO_Y + 30` 改为实际距离判定的 `HERO_Y`，半径仍来自当前英雄的实时普攻/技能索敌属性。关闭手势、属性 tips 版式、全场范围和大招原规则保持。
