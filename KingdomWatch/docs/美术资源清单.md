# 美术资源清单（美术阶段 v1 · 2026-10-03）

> 代码现状：所有 UI/角色先有程序绘制兜底，美术图放入 `assets/resources/` 后**同名自动接管**，加载失败保持程序版——因此可逐张替换、不阻塞开发。

## 0. 落图规范

| 项 | 约定 |
|---|---|
| UI 资源路径 | `assets/resources/ux/<id>.png`（id = 代码引用名，见下表） |
| 整幅场景路径 | `assets/resources/scenes/<id>.png`（如 `scene_1_1`） |
| 格式 | PNG 透明底；整幅场景可 JPG |
| 九宫格板件 | 尺寸/边距表在 `Ux.ts` 的 `SLICE` 表（canon 尺寸合成，换分辨率自动适配；出图请按表中 canon 尺寸） |
| 风格基调 | **扁平无框**（用户多轮确认）：板件=纯色/半透明色块或羊皮纸色块，**不加**铆钉、绶带、藤蔓类装饰边框；角色/图标可带体积感 |
| 命名 | 全小写下划线，按下表 id 一字不差 |
