2026-10-22。本版集中处理穿透、初始充能、大招能量门槛、胜利延迟，以及升级选卡与大招点击同时发生的卡死。[正式游戏](https://kingdom-watch.pages.dev/?v=combat-feedback-fix-v70-1792599730) · [部署快照](https://4b580815.kingdom-watch.pages.dev)。构建及线上文件身份见 `release.json`。

## 选卡与大招的时序修复

根因是 `tryCastUlt` 将“当前非战斗操作状态”也返回为 `charging`。强化卡刚打开、战斗进入 `pick` 状态时，残留的大招触摸松开会被 HUD 当作“充能不足”打开大招说明；说明使用共用面板容器，销毁了强化卡，战斗却仍停在 `pick`，因此无法继续。

现在分开返回 `blocked` 与 `charging`。升级选卡、暂停、教学、新怪介绍、GM或胜败期间的残留大招点击直接忽略，不打开说明、不播放释放反馈、不消耗能量；大招按钮在按下和松开时均重新检查当前状态。普攻、技能说明与伤害统计入口也受相同状态保护，防止替换正在使用的强化卡。正常战斗中充能不足时仍可查看说明。

若大招先成功启动，升级机会仍保存在原队列，等待大招及原收尾锁结束后弹出，不取消升级、不重抽卡、不强制结束演出。`openPick` 也检查实际大招/弹道状态。教学引导仍先恢复 `running` 再调用释放入口。

## 穿透与充能

重弩手「贯颅弩矢」原先仅增加技能的 `skillPierce`，普通弩箭读取的 `pierce` 保持为0。现每层同时给普攻和技能各增加1个额外穿透目标，卡面和普攻属性说明同步更新。原紫卡、3层上限、归属、ID、图标与抽取前置保持；每种弹道独立读取自己的字段，不重复叠算。普通弩箭沿实际直线穿过相交敌人，大招无限贯穿保持。

所有英雄新战斗从0能量开始，移除原17.5%～25%初始赠送与至少10%的隐藏下限。按站位错开技能首次施放的设置保持。五名英雄基础大招需求分别为弓箭手45、重弩手55、冰法60、雷法65、火法70；自然回能统一为每战斗秒0.6点实际能量，避免按需求同步换算百分比而抵消门槛差异。

全队分享击杀能量的怪物能量值、55%系数、按上阵人数均分、装备效率及充能上限判定均保持。快速充能卡和培养倍率沿原公式计算，属性说明显示当前能量/实际需求/百分比。教学选卡后指定英雄的一次充满保持；未施放已满大招或集中获得足够能量时仍可能同时就绪。

## 胜利弹窗延迟

主线确认最后一个怪物被击杀后开始计时，至少1个真实秒后才播放胜利弹窗及其原动画和声音。计时不被1.5倍速或命中顿帧缩短；与最终大招的收尾等待并行，若演出超过1秒，仍先等待完整收尾。胜利确定后停止战斗伤害与回能，继续怪物死亡、粒子、命中特效和飘字收尾；原金币/钻石/星级/解锁只结算一次。场景销毁或战败清除待显示内容，无尽的3秒层间流程保持。
