## 地图与操作

前哨、深林、兽穴各一张原创路线地图，各有十关；通过章节标题两侧箭头切换。前哨以田野、石桥、哨塔和蓝顶堡垒为地标；深林改为古树、迷雾、遗迹与祭地；兽穴改为岩壁、洞口、战鼓营地与巢穴核心。沿用本游戏漫画奇幻风、清楚轮廓和大色块，不复制参考游戏的地形、图标或界面构图。

已通关节点用蓝旗和实际星级；当前选中用金旗、局部呼吸环和关卡名字签；未解锁用灰旗和锁。第十关依附章末大型地标，突出章节终点。效果稿呈现整章概览，落地时以点击面积和可读性优先，地图支持上下拖动，不强迫十个小节点塞进一屏。首次打开定位当前进度，之后保留章节和地图位置。

点击可选节点直接打开出战面板，底部“出战准备”是同一入口。关闭面板回到刚才地图位置；切换章节先收起面板，避免选中关卡与章节不一致。地图只做轻微减弱，面板展开和定位采用短时平滑移动，避免大幅缩放和反复闪遮罩。

## 功能与层级

星级宝箱继续排在掉落之前，三档条件和奖励直接摆在纸面上；可领取时保留一键领取当前关卡、当前难度全部已达成未领宝箱及实际到账弹窗。效果稿展示当前关卡尚未获得星级，因此三档均为未达成。

普通／精英／地狱仍为10／12／15波。普通不展示装备掉落，精英和地狱展示实际装备池、概率与详情入口；点击单个掉落图标也能进入详情。编队沿用现有出战英雄和编辑入口，不新增另一套阵容系统。

主页面让地图和选中节点承担视觉重点；资源、章节、当前关卡摘要为辅助。奖励与养成信息集中到出战面板，减少常驻分区和重复边框。面板短屏时内容滚动，标题关闭、开始战斗及底部导航保持可操作；避免奖励区挤压按钮。

## 后续实现建议

将现有关卡页分为固定资源／章节层、可拖动地图层、独立关卡节点层、底部摘要与出战面板层。地图底图不烘焙文字、星级、锁和节点；关卡坐标独立配置，节点状态读取现有 Campaign 与 GameData。背景只负责地形和地标，可按章节延迟加载，避免一次下载三章大图。

保留原关卡编号、解锁顺序、三档独立星级、已领奖记录、奖励事务与退出定位，不重置存档、不重复发奖。两张概念稿不代表已制作三章最终地图，也不代表已完成运行效果验收。
