## Recommended selection process

1. Start with two source-level auditions: WOW Sound Fantasy UI (Cute/Light) and BOOM Casual UI.
2. Confirm which overall sound direction fits before selecting dozens of files or buying a large bundle.
3. From the preferred permitted library, shortlist only three event types: D01 upgrade celebration, D02 repeated upgrade tick, D03 numerical landing. Compare these as one coherent sequence against the current game baseline.
4. Preserve context: repeated ticks must leave space for the final accent; the main upgrade cue should not restart on each tick. Judge with the actual animation and background mix after licensed files become available.
5. Keep C01/C03/C04/D04/D05 on v21 unless the user changes those choices. No growth-r1 option is approved.
