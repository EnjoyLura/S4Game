# 《王国守望》五主界面需求清单（已对齐）

参考基准：《向僵尸开炮》五张主界面截图（商城/角色/战斗/核心/基地），布局结构对齐，美术保留本作奇幻手绘风（金框羊皮纸）。
纯单机：无内购、无广告变现位、无抽卡、无体力。顶栏维持 金币+钻石 双货币（不加头像/体力）。
底部导航五页签保持：商店 / 英雄 / 关卡 / 升级 / 基地（左→右）。

---

## ① 商店（参考：商城页）

- **纯购买制**：不做宝箱/招募/充值页签。
- **四页签**：武器(钻石) / 英雄(钻石) / 装备(金币) / 材料(金币)。
- **固定货架 12 件**（首批）：武器 2 + 英雄 2（占位"敬请期待"）+ 装备 4 + 材料 4。
- 商品随**关卡章节阶段性解锁**：未解锁商品灰化 + 显示解锁条件（如"通关 1-5 解锁"）；不限购、不刷新。
- 购买流程：点商品 → 确认弹窗（价格/持有数/属性预览）→ 扣货币 → 入背包（英雄为解锁）。
- 掉落与购买共用同一物品定义（物品表唯一）。

## ② 英雄（参考：角色页，大图环绕式）

- **单英雄大立绘居中** + 左右箭头切换已拥有英雄；未拥有英雄显示剪影 + "前往商店解锁"引导。
- **六装备槽环绕立绘**：槽1 武器1、槽2 武器2、槽3 头盔、槽4 饰品、槽5 手套、槽6 衣服。
  - 每槽显示：图标 + 品质边框色(白/绿/蓝/紫) + 阶级角标(1阶/2阶…) + 等级。
  - 点槽位 → 背包选择弹窗（只列该槽位类型）→ 穿戴（原装备回背包）。
- **战力值**：立绘下方火焰徽章样式大数字；点英雄头像/名字 → 属性+背景故事弹窗
  （战力/攻击/攻速/技能预览/定位说明/背景故事文案）。
- **下方"我的背包"**：网格 + 页签（全部 / 装备 / 材料）；物品格显示数量角标；点物品弹详情。

## ③ 关卡（参考：战斗页，单关大图式）

- 顶部：章节名 + 关卡名（如"1. 腐朽森林 — 1-1 前哨"）。
- **当前关场景大图**居中 + 左右箭头切换关卡（范围：已解锁关卡；已通关可无限回刷）。
- **三档通关宝箱**（映射现有 1~3 星，按通关时防线血量比例）：
  - 成功通关(1星) / 50%血量通关(2星) / 完美通关(3星)；
  - 每档**首次达标可领一次性奖励**，金币→钻石递增；已领显示"已领取"，未达标灰化+条件文字。
- 底部大按钮 **"开始战斗"** → 直接进入战斗。

## ④ 升级（按英雄养成，参考：核心页）

- 顶部**英雄切换栏**（头像横排）→ 中部英雄大图 + 战力 + 等级。
- **四页签模块**：
  1. **等级**：金币升级（上限30级），每级 +8% 攻击、+5% 技能伤害。
  2. **武器**：该英雄武器1/武器2 强化（材料+金币，上限20级），每级 +6% 攻击。
  3. **技能**：普攻 / 技能 / 大招 三行独立等级（金币，上限10级），每级 +10% 对应伤害。
  4. **装备**：已穿戴六槽装备逐件强化（材料+金币，每件上限20级），每级 +4% 主属性。
- 所有加成实时汇入战力显示。

## ⑤ 基地（参考：基地页，等距场景）

- **一张奇幻风等距基地场景图**；主城 + 研究院 两个建筑可点，其余建筑灰化锁定占位（后续版本）。
- **主城**：等级面板 + 金币升级（上限10级）；
  效果：每级 +100 防线基础耐久（基础1000），每 3 级 +200 阶段性盾量（战斗内盾条已支持）。
- **研究院（怪物图鉴）**：怪物网格（已解锁亮/未解锁剪影）→ 点开词条：名称/描述/弱点。
  解锁方式：**战斗内首次遇到新怪**弹"📚 新怪物图鉴已解锁"提示，自动解锁词条。

## 经济与产出闭环

- 装备/材料获取：**商店购买为主**；精英怪/Boss 击杀掉落 + 通关结算低概率掉落；
  **每关掉落表可配置**（配置文件按关卡定义物品与概率）。
- 货币分配：英雄/武器 → 钻石；装备/材料 → 金币。
- 钻石来源：星箱(2/3星档)、后续成就等；金币来源：通关结算、星箱、主城? （实施时校准）。

## 数值默认值（实施时校准）

| 项 | 规则 |
|---|---|
| 英雄升级 | 金币 = 100 × Lv^1.35（取整到10），上限30 |
| 武器强化 | 金币 = 150 × Lv^1.4 + 材料，上限20 |
| 技能升级 | 金币 = 200 × Lv^1.5，上限10 |
| 装备强化 | 金币 = 120 × Lv^1.4 + 材料，上限20 |
| 装备售价 | 白100金 / 绿400金 / 蓝1500金 / 紫5000金；阶级每+1 售价×3、属性×1.8 |
| 商店定价 | 武器 800/1200 钻；英雄 3000/6800 钻（占位）；装备 300~2400 金；材料 50~200 金 |
| 主城升级 | 金币 = 500 × Lv^1.6，上限10 |
| 星箱奖励 | 1星=200金；2星=60钻；3星=150钻（每关一次性） |
| 战力公式 | 攻击×(1+攻速加成) + 技能伤害×0.5 + 装备加成汇总（实施时定稿） |
