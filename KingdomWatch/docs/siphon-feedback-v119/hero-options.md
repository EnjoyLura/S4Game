# 新英雄备选（设计草案，未接入）

当前阵容已有箭矢/连狙、火雷冰法、重炮、汲取持续光束。优先补充聚怪、辅助防御、毒蚀与弹跳等新玩法。以下均保持英雄在防线上作战，近战职业通过飞刃/剑气等作用于战场，不默认新增英雄出城寻路。

|编号|英雄|普攻|技能|大招|特色/工作量|
|---|---|---|---|---|---|
|H1|风刃术士|穿行后回旋的风刃|牵引一小群敌人聚拢，首领只减速|移动龙卷风持续卷击|聚怪配合炮手/火法；中|
|H2|圣盾祭司|光弹，累积圣印|给防线一层有上限的护盾|展开圣域，短时减伤并脉冲惩戒|保护防线，提升容错；低至中|
|H3|炼金毒师|毒瓶叠加有上限的毒蚀|腐蚀雾削弱护甲，地面持续伤害|引爆范围内毒蚀，保留部分毒量|持续铺毒与主动引爆；中|
|H4|链刃舞者|链刃在敌人间弹跳|回收链刃，再沿路径切割|多把巨型回旋刃交错穿场|弹跳/回程构筑，物理清群；中|
|H5|符文剑士|远程剑气，命中积累剑印|消耗剑印召唤追击飞剑|剑阵依次落剑，末段汇聚斩击|先标记后爆发，适合精英；中|
|H6|沙漏术士|时间弹，对同一目标叠时滞|短暂停住一片区域，首领仅减速|记录期间承受的部分伤害，结束统一回响|伤害放大与爆发窗口；中|
|H7|猎魔枪手|双枪快速交替射击|扇形散射，近处命中更多弹丸|短时过热扫射，结束强力贯穿弹|贴近防线越危险输出越高；中|
|H8|星界术士|星弹命中留下星痕|连接星痕，沿连线造成伤害|在敌群间织成星网，交点爆发|用敌人位置组成攻击几何；中至高|
|H9|驯鹰猎人|投矛，战鹰追加啄击|指定目标俯冲，优先飞行怪|鹰群交错掠场|物理对空与重点猎杀；较高，需战鹰动作|
|H10|地脉守卫|地刺贯穿一条地面路径|石墙短时阻挡指定区域敌人|地裂逐段推进，震退地面怪|专注地面控场；高，需阻挡规则|
|H11|诅咒女巫|咒弹施加厄印|转移并复制厄印，降低治疗|引爆厄印；普通怪残血处决，精英/首领改固定伤害|反治疗与收割；中|
|H12|机关猎手|射出倒钩弩矢|布置触发式地雷或捕兽夹|沿防线前方布置联动陷阱阵|提前布阵，守住突破口；中至高|

建议先选H1风刃术士与H2圣盾祭司：一位负责聚怪，配合现有范围输出；一位负责保护防线，增加输出之外的选人取舍。偏纯输出则选H3炼金毒师或H4链刃舞者。

对空原则继续按形式：飞刃、光弹、飞剑、子弹、星弹、鹰群可对空；地刺、地雷、石墙、地面毒雾仅地面。毒瓶直击和咒印可对空，附着状态可继续结算。具体倍率/上限/强化卡在用户选定后再设计，不抢先加入实现。

制作量表示战斗机制的相对工作量。所有新英雄仍需正式人物/头像/能力图标；召唤战鹰还需动作资源。多数光线、剑气、毒雾、龙卷风和标记可以用现有渲染设施加代码实现，不承诺完全零美术制作。
