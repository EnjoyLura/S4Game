# 敌人死亡表现

> 用户已否定本版整张角色倾倒的视觉表现，明确要求怪物死亡时不要倒地。现行方案见 [原地爆散死亡 v2](../enemy-death-burst-v2/README.md)。本页保留历史制作记录，构建成功不代表用户认可倒地表现。

将原有“角色转 16 度，0.18 秒淡出”的死亡改为战斗时钟控制的完整收尾：致命冲击、脚底支点失衡倒地、轻微触地收稳、短暂残骸与轮廓侵蚀消散。普通敌人约 0.74–0.89 秒，精英约 1 秒，Boss 钩子约 1.15 秒。最后一击传入真实弹道角度；爆炸范围命中传入从爆心指向目标的方向。水平分量决定倾倒方向，正面垂直命中的左右失衡有稳定变化，位移受到限制；重击与精英使用不同冲量、重量和节奏。

沿用击中瞬间的完整角色帧并停住步态／攻击混合层，不拼接肢体，不生成新的角色死亡序列帧。脚底支点、接触阴影、触地扬尘与碎屑共享同一套死亡时序。保持完整帧的比例，整体现有姿态随支点倾倒；当前版本不是新绘制的逐怪种肢体死亡动作。

四类收尾使用同一个轮廓材质及原生 Graphics：

- 物理：保留暗下来的身体轮廓，地面短尘与少量尘屑。
- 火系／灼烧：逐渐焦化，橙色侵蚀边缘与缓慢升起的余烬。
- 冰系／冻结目标：冷色轮廓、旋转切面碎冰与细小寒尘。
- 雷系：短促残余电弧、暗紫轮廓与少量电屑。

轮廓侵蚀按当前图集帧的实际 UV 和显示像素固定，保持透明边界，尾部完全退净；材质未就绪时保持相同倒地过程，以渐隐兜底。没有白色整人闪光或全屏闪光。余烬出生位置由出生时刻姿态计算，不跟随之后的身体移动；粒子寿命限制在完整尾段内。沿用现有致命命中、击杀采样和重击顿帧规则，未新增音频或付费媒体。

`Monster` 在致命命中时立即死亡并发出原击杀事件，奖励、经验、充能与伤害结算保持原流程。`MonsterManager` 将尸体从活怪列表移入独立演出列表，不参与碰撞、索敌、群体分离、波次清场或活怪数量限制。演出上限 64，超限优先回收最旧尸体；结束后复用原怪物对象及材质。阴影与空中碎屑共用绘制层，尸体保留地面纵深排序。每只怪物存活期间预备可复用材质，避免群杀同时创建所有材质。

死亡演出只推进模拟时钟，跟随倍速与已有重击顿帧；暂停、三选一冻结。胜利或失败后只完成已有尸体演出，不恢复怪物行动或伤害。复用时清理死亡材质、支点、透明度、颜色和状态；退出场景时销毁脱离场景的池内节点及各自材质。

功能代码：新增 `MonsterDeath.ts`、`mob-death.effect`；调整 `Monster.ts`、`BattleSprite.ts`、`Projectile.ts` 和 `BattleDirector.ts`。未变更英雄动作、已认可的冰系技能／大招、数值配置或音效素材。

依用户约定仅源码调整、Cocos 构建、DPR 补丁和发布，不运行测试、游戏、浏览器或线上验收。当前观感与手感待用户人工确认。
