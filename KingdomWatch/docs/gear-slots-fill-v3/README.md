# 装备槽铺满与品质角标移除 v3

用户要求去掉普通、优秀等左上品质标签，品质背板铺满装备槽，武器同样大小。

- 删除所有共享品质角标，覆盖英雄穿戴、背包、对比详情、商店、商品详情和已收战利品。详情中的品质说明文字仍保留。
- 已穿戴四槽使用完整方形品质底板，取消小底板外围的浅色套槽。武器左半方形与四槽共用同一个sq尺寸，图标居中，名称与培养等级保留在右半。
- 武器行高度同步方槽尺寸；装备组围绕原中心排布，顶部44、行间14、底边14，无交叠。空槽占位、等级与数量角标保持。
- 背包与装备详情中的品质背板铺满方槽。商店商品图158方槽、详情124方槽同样铺满。

仅四个UI脚本改动，未新增运行时美术，没有数值、逻辑或存档变更。保留此前新制的难度、宝箱、领取按钮与准备抽屉布局。

仅源码与本地构建产物审阅；类型诊断与上一版相同，改动模块无新诊断。按约定不运行测试、模拟、游戏、浏览器或线上视觉验收，由用户人工确认效果。
