## 页面结构

采用竖屏独立二级页面。顶部约8–10%放返回、无尽挑战标题和「章节目录」；地图占主要空间（约65–75%）；底部约20–25%固定显示所选挑战的信息和「开始挑战」。实际按安全区域及短屏自适应，不固定死比例。

- [完整界面效果图](endless-world-map-ux-v61.png)
- [无文字临时地图底图](world-map-placeholder-v61.png)

不再以三个页签决定章节数量。地图占满页面中部，保持连续地形与探索感；信息栏是页面的一部分，没有弹窗遮罩或关闭叉号。入口不收费，顶部不必重复展示金币、钻石等与此次选择无关的信息。

## 地图怎样对应玩法

**一面旗帜代表一个章节的无尽模式**，不代表某一个普通关卡，也不代表无尽挑战的某一层。同一地貌可容纳多个后续章节，地图区域数不约束章节总数。

| 地图状态 | 标记 | 点选后的底部信息 |
| --- | --- | --- |
| 已解锁 | 蓝旗，章编号 | 章节名、最高已通层、累计怪物范围、开始挑战 |
| 当前选中 | 金色轮廓或光环 | 相同信息，明确显示所选章节 |
| 尚未解锁 | 灰色锁标记，章编号 | 通关N-10解锁、前往主线 |
| 尚未确定或未上线地区 | 薄雾覆盖或未知地貌 | 待开放，不提供可进入的挑战 |

章节1解锁条件为普通1-10通关；章节N为普通N-10通关；怪物范围为第1至N章实际使用过的怪物并集。最高纪录显示「最高已通15层」，不写含糊的「第15层」。开战仍从第1层开始，不将纪录当作续关。

本轮底图包含前线草原、深林、石山洞穴、沼泽、峡谷沙地、雪岭、火山、海岸及遗迹等临时地貌。这些只是扩展布局的示例，不代表已确定的章节、顺序、名称或新增怪物配置。

## 浏览与快速定位

- 单指拖动，双指缩放。近景可读章节名与地标；远景只保留重要地貌和章编号，防止文字挤成一团。允许双向探索，不强制玩家沿固定长条不断上滑。
- 同屏只展开选中节点的完整信息。其他节点保持简洁；小屏、远景时隐藏重复的章节名字和纪录，不隐藏关键锁定状态。
- 「章节目录」打开可滚动的编号/名称列表，支持「已解锁」筛选；章节很多时增加搜索。点某章后关闭目录并将地图平滑定位过去。
- 地图边缘提供小型「定位」按钮，回到最后所选或最高已解锁挑战；缩放按钮可与双指手势并存。
- 首次进入默认定位最高已解锁挑战。之后保留最后选择、缩放和浏览位置；从战斗返回不强行重置到世界起点。
- 拖动超过手势阈值即取消本次点击。点旗帜只选择章节，玩家再点底部「开始挑战」才进入战斗；避免拖动时误开战。
- 新章节解锁可以轻微亮旗并在目录显示提示，避免常驻强光、多个呼吸标记和大面积红点抢地图视觉。

## 底部固定信息栏

解锁示例：

> 第2章 · 深林挑战  
> 最高已通15层  
> 怪物范围：第1～2章  
> [开始挑战]

尚未解锁示例：

> 第4章 · 临时地区名  
> 通关4-10解锁  
> [前往主线]

未上线地区不承诺解锁条件，显示「待开放」。按钮与底部手势区域留足空间。不同长度的章节名可换行，但主要按钮保持可见。地图上的底部节点也能拖到信息栏上方，避免被固定栏遮住。

## 正式接入时的资源结构

以下是制作建议，不是本轮已实现的代码：

1. 地图底图不烘焙章名、旗帜、锁、线路进度、纪录和按钮。当前无文字底图可以直接替换为正式美术。
2. 每章使用稳定ID和独立地图坐标；章节数据关联解锁规则、怪池、纪录键。更换美术时主要调整底图和节点坐标，不更改已有存档中的章节ID。
3. 未来按相邻地区拼接地图块，只加载可见和相邻区域。不要把所有远期章节压在一张极大纹理里，也不要因为手机最大纹理尺寸而缩糊整张地图。
4. 节点、名称与按钮由Cocos UI渲染；底图缩放与文字层独立，控制文字最小显示大小和点击范围。贴图清晰度仍需按目标机型做人工验收。
5. 目录的数据与地图节点同源，可持续加入第4、10、50章。地图局部扩建时仍能通过目录定位全部章节。
