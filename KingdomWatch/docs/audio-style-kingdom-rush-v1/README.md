## 本项目的声音目标

有材质感的欧美卡通奇幻，动作清楚、短促有力，关键事件有表演性，整体保留幽默与角色性格。战斗底层和操作结果各有强弱，给重要声音留下空间。

| 类别 | 希望听到的特征 | 首轮建议长度 | 构成与密度 |
|---|---|---|---|
| 弓箭普攻 | 干净弓弦、轻掠空气，能辨认出武器 | 0.12–0.3秒 | 单次以一个清楚动作声为主；用连续射击片段检查耐听性 |
| 重弩 | 更低、更结实的弦与机械弹射感 | 0.18–0.4秒 | 强于弓箭，保留木/金属机关特征 |
| 普通法术 | 火焰的扑燃、电击的脆裂、冰晶的碎裂，各自能辨认 | 0.2–0.55秒 | 一个明确起音，接短材质尾声；高频部分控制刺耳感 |
| 技能/大招 | 有可感知的体积和撞击，元素身份明确 | 0.5–1.4秒 | 一个主冲击，按画面需要增加短准备/尾声；场内小声部让位 |
| 普通升级 | 短上扬、扎实落定，让数值增长被感知 | 0.45–0.85秒 | 一段完整反馈；长按集中一次，数字落点不另加声音 |
| 阶段突破 | 比普通升级更强的完成感 | 0.8–1.5秒 | 普通成长声让位，突出突破这一次结果 |
| 领奖/购买/招募 | 轻巧开揭、金币或物品材质、短庆祝 | 0.5–1秒 | 先共用一个核心音色，不因页面不同而拆成多个旋律 |
| 胜利 | 短号角/铜管动机、明确终止，带轻快凯旋感 | 1.2–2.2秒 | 结算主音一次；奖励数字与星星保持视觉表现 |
| 失败 | 短下行、略带幽默，收尾干净 | 0.7–1.4秒 | 声部稀少，快速把操作空间交给重试/复活 |
| 界面操作 | 简洁、轻、触觉明确 | 0.05–0.15秒 | 继续统一点击，页签/开关弹窗不额外叠声音 |
| 角色短语 | 简短、有性格，配合英雄关键动作 | 后续单独定义 | 可作为身份层后续探索；当前不增加配音任务、费用或触发 |

这些长度是样本筛选起点，不是机械裁剪要求。声音的完整起音、主体和自然收尾优先于刚性时长。

## 下一轮只做三个代表场景

1. 弓箭连续三次：确认武器材质、瞬态、连续听感和声音间的空隙。
2. 寒冰法术一次：确认元素身份、冲击和短尾声，兼顾中小音量的可辨识性。
3. 普通英雄升级一次：确认上扬与落定是否能支撑数值变化，控制庆祝声的长度。

同一场景只提供少量明确不同的候选，用相同游戏画面和接近的播放电平比较。免费可商用素材需要逐项核对许可、作者与来源。参考作品用于明确目标，成品采用授权素材或原创制作，不提取参考游戏音源接入项目。

用户确认代表声音后，再扩展五英雄、领奖与胜败。既有R01–R07试听页仍是待确认的历史候选，不因本次方向说明而自动获得认可。用户要求减少音效的v23策略继续作为触发数量和叠音控制的起点，后续如需增加/恢复事件应有具体体验理由，不以填满61项为目标。
