# 弓箭手 Cocos 原生分层动画方案

用户因费用放弃 Spine。保留自然待机、攻击和按攻击方向转身的目标，使用项目已有 Cocos Creator 3.8.8 和独立 PNG 部件，无额外动画软件授权或 Spine 运行时。

## 素材

以当前立绘及待确认的战斗候选保持人物身份。按头、躯干、左右上臂／前臂／手、腿靴、斗篷、箭筒、弓与搭箭准备独立部件，补齐关节重叠和被遮挡区域。正上、左上、右上分别校准方向与遮挡顺序，始终保持左手持弓、右手拉弦。部件拆分质量影响动作上限，不能只把整个人物平面旋转当作转身。

## 动画

用 Cocos 节点的父子关系表示骨骼，用可复现的连续时间曲线驱动局部位置和旋转。关节位置和绘制顺序由素材清单记录。弓弦可用连接弓尖与持弦手的动态线段表现，搭箭跟随持弦点与握弓点，防止结构脱节。

- 待机：轻微肩胸呼吸、头部和斗篷的滞后运动，站位稳定。
- 攻击：准备、拉弦、放弦、回位；按实际发射回调同步释放，不改变战斗数值和连射规则。
- 转向：根据实际攻击方向选择对应部件与绘制顺序，设置角度缓冲；较大角度变化采用短转身动作，保持防线根节点及地面原点稳定。
- 连射：延续举弓和拉弦动作，避免每发硬重置到待机。
- 暂停：使用战斗动作时钟，不在暂停时继续播放。

小幅度衣摆用独立部件与柔和曲线即可。复杂的连续透视转身、明显布料形变需要更多绘制与调校，先以弓箭手样板验证，不预先承诺与成熟 Spine 制作流程相同的效果。

## 制作与验收

用户已确认形象并授权执行；三方向分层待机／攻击已制作并接入，见 [原生动画实现](../archer-native-v1/README.md)。其他英雄仍保留现有动作。本方案的待确认与视频资料属于前期记录，不再作为弓箭手接入的等待条件。
