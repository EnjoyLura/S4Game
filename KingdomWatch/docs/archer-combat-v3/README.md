## 朝向与动作设计

| 项目 | 接入目标 |
| --- | --- |
| 朝向 | 正上、左上、右上，按实际攻击方向选择，保持左右手与箭筒的解剖侧一致 |
| 转向 | 加入角度缓冲，跨方向时短暂原地转身；允许自然的足部转轴动作，但防线站位和地面锚点稳定 |
| 待机 | 约两秒的轻呼吸周期，肩胸、发梢与衣摆少量跟随；持弓稳定，首尾姿态可循环 |
| 攻击 | 预拉弦、拉弓蓄力、放弦、手臂回位；衣摆滞后，人物不整块弹跳或缩放 |
| 释放同步 | 放箭的关键帧对应实际箭矢发射；连射、强化箭和箭雨需要各自同步，不让画面与弹道脱节 |
| 连射 | 保持举弓姿态连续拉弦，不每发硬切回待机再重启整段动作 |
| 无目标 | 短暂保留最近朝向后自然回到警戒，不在目标丢失时立即弹回正上方 |

每个朝向需独立的待机与攻击素材，共六套。形象确认后，以对应朝向的同一准备姿态分别生成动作；不把一张多格原画当作连续动画，也不通过水平镜像让弓换手。下附 [待机提示词](prompts/archer-idle.txt) 与 [攻击提示词](prompts/archer-attack.txt)，供用户制作视频时使用，未执行生成。

沿用已有视频工作流：固定画幅与镜头、完整武器留白、仅人物动作、无背景与箭矢特效。接入前将每个角色所有方向和动作采用同一联合裁切、缩放与地面原点，再检查武器稳定、脚底、首尾回位和游戏显示尺寸。
