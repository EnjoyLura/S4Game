# 战斗退出修复、击杀反馈与出手气流位置 v3

本轮合并处理用户连续提出的三项要求。仅做源码审阅、离线音频素材制作、Cocos 构建、DPR 修补和发布；遵守项目约定，不运行测试、模拟、游戏、浏览器或线上视觉/听觉验收。实际手感由用户人工确认。

## 出手气流

弓箭手气流沿实际发射方向前移 36 个设计像素，重弩同类气流前移 42 像素，避开头部。程序材质与 Graphics 兜底共用调整后的视觉原点；弓箭大招的弓弦气流与其兜底同步前移。原气流大小、亮度、节奏，人物素材和动作、箭弹真实起点、弹道及判定均保持。

## 击杀声音与死亡动作

新增 15 个短击杀音频：物理、厚重、火、雷、冰各 3 个变体，约 147–258ms，44.1kHz 单声道 PCM16，共约 260KB。由项目已保存的授权采样制作，短身体冲击、破裂与元素余响分层，带限、削共振、塑形衰减；厚重物理层仅含低音量的短怪物尾声，不堆叠长惨叫、不使用合成蜂鸣。来源、修改参数和哈希见 [音频清单](audio-assets.json)，可通过 [制作脚本](prepare_death_audio.py) 重建，游戏内署名页同步补充。

声音在致死命中时触发，替换原低音量、与普通命中共享预算的 `kill` 声。独立死亡声音组，优先级 2、最多 2 个声部、同组 75ms 最小间隔，避免群杀堆声。保留原混音、压限、音量开关和后台处理；暂停、三选一、离场会收掉声音，不排队补播；最后一击的短尾音可在结算上自然结束，不因每次击杀压低 BGM。

原怪物帧仍在原地形成 6 块曲边碎散：20/30ms 致命停留后快速分离，先保留碎片可读性，再淡出；普通/精英/Boss 身体阶段仍为 190/220/240ms。8/10 个碎屑及 6 根局部短促尖光增加击破节奏，火余烬、冰屑和雷弧继续分元素收尾，物理碎屑改中性棕金。不倒地、不整人飞走、不留绿色地面残迹，不增加每杀震屏或全屏白闪。池化、64 个死亡演出上限、战斗时钟和暂停保持；奖励、伤害、充能、碰撞和索敌立即结算逻辑不变。

## 退出与重试

源码确认 Cocos 先销毁场景子树，后调用父组件 `onDestroy`。旧怪物管理器在此时访问已销毁 Graphics 的 `node.isValid`，其 `node` 已为 null，导致截图中的空引用，同时让后续事件解绑中断。

现在先解绑战斗总线，怪物管理器仅销毁自己持有的脱离场景的对象池节点，使用严格有效性与幂等保护；在场怪物、标记、地面和飞行特效继续交给所属场景统一销毁。删除几个特效回调中重复销毁场景子节点的操作，注销深度排序回调，修正三选一旧面板清理对已销毁组件的访问。

退出、下一关、重试共用一次导航保护，离场立即停战斗步进和战斗声，加载失败还原流程并提示，失效广告回调不再碰旧界面。“再来一次”重新进入当前关卡与难度，返回仍回主界面。
