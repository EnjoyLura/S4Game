# 重弩手朝前平举弩攻击 v3

用户随后指出本版攻击与待机大小切换不自然，并截图指出残留火星，第 13 源帧被误当成干净发射帧。本版保留历史，当前正式资源已由 [比例与火星修正 v4](../sniper-attack-forward-v4/README.md) 替代。下方为 v3 当时的制作与发布记录，不代表用户认可效果。

已构建并发布：[正式游戏](https://kingdom-watch.pages.dev/?v=sniper-attack-forward-v3-1791900246) · [攻击与镜像预览](https://kingdom-watch.pages.dev/previews/sniper-attack-forward-v3/?v=1791900246)。部署 `https://3c30f3b9.kingdom-watch.pages.dev`；Cocos web-mobile 成功退出码 36，DPR 补丁完成。发布调用中断后仍在后台完成，继续时从 Wrangler 日志确认部署成功，16 文件上传、984 文件缓存，没有重复提交。详情见 `release.json`。

用户要求完成当前重弩手攻击序列。本版与正式 `sniper_idle_forward_v2` 共用同一红底母版，攻击采用双臂短促受力、肩背轻震及回位，弩保持原形，箭矢由游戏独立生成。项目 MiniMax H3 请求两秒，提示词、任务与原始视频保存在本目录。

制作发射帧时发现首轮出现枪械形状和枪焰，第二轮把弩弦动作画成拉弓，两份原片只保留历史，不接入游戏。因此本版约束弩为刚体，只生成连贯的手臂、肩背反应与完整披风跟随。此前待机 v1 射击段也没有复用。

采用完整人物帧、统一裁剪、固定脚底和比例；画内人物高度与当前待机对齐，高度 170。正式出箭回调对齐攻击受力帧，攻击／收势时停播待机，快速连射不重复重启动作，左右直接镜像。攻击为单向一次播放。

H3 本轮实际返回 768×1344、24fps、56 帧、约 2.33 秒原片，发射瞬间仍有闪光。素材制作保留 6–55 帧中的完整人物帧，剪除含闪光的 8–12 帧，以第 13 源帧作为出箭时的第一张干净受力帧；不修补、拼接身体或武器。共 45 帧，发射索引 2，清洁动作时长 1.875 秒。原片 `source.mp4` 和去闪光成片 `attack-clean.mp4` 均保留，逐帧选择见 `frame-selection.json`。

图集为 4096×3456，格子 512×576；与当前待机共用画内基准高度 467.5133 和显示高度 170。攻击格内脚底为 `(256,560)`，运行节点脚底 `(0,-76)` 保持一致。资源 `sniper_attack_forward_v3` 的 JSON 记录原视频、完整帧索引、单向时序及发射／准备／回位节点。
