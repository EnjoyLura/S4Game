# 重弩手朝前平举弩 v2 正式接入

后续已完成并发布 [同一母版的攻击 v3](../sniper-attack-forward-v3/README.md)：45 张完整人物帧接入正式出箭、收势和回位，替代本记录中的临时静态交战表现。[打开当前游戏](https://kingdom-watch.pages.dev/?v=sniper-attack-forward-v3-1791900246)。下方内容为本轮待机接入的历史记录。

已构建发布：[打开正式游戏](https://kingdom-watch.pages.dev/?v=sniper-forward-live-v2-1791897572)。部署 `https://3a692b8f.kingdom-watch.pages.dev`；Cocos web-mobile 成功退出码 36，DPR 补丁完成，Wrangler main 首次遇到连接错误后用同一发布包重试成功（2 文件上传、978 缓存）。详情见 `release.json`。

用户在新待机预览后要求“继续”。本轮按继续推进正式战斗接入处理，不将该指示记录为已经通过全部视觉验收。

`SniperIdleAnimation` 改为读取 `sniper_idle_forward_v2`，使用已经发布的 56 张完整人物帧及 110 项四秒逐帧往返时序。显示高度 170，脚底节点仍为 `(0,-76)`；左右跟随目标及实际发弹方向直接镜像。弓箭手现有图片、待机、攻击和高度 185.64 保留。

范围内没有敌人、没有待发连狙或大招锁定且攻击／收势结束后播放待机；倒计时继续播放待机。进入攻击范围、待发或正在发弹时，固定同一新形象的当前持弩帧并冻结待机相位，空闲后从原相位继续。暂停等状态仍使用战斗模拟时钟。

现有 `sniper_attack_v1` 与新母版的形象不一致，本轮保留旧资产历史，正式播放器不加载该图集，以免交战时切回旧形象。新攻击序列尚未制作，因此本轮攻击表现为新持弩姿态加原有箭矢。普攻、连狙、技能、大招、弹道、伤害、射速及声音沿用原逻辑。

仅完成接入、Cocos web-mobile 构建、DPR 补丁及 Wrangler main 发布。按用户要求不运行测试、游戏、浏览器或线上验收，效果由用户人工查看。发布记录见 `release.json`。
