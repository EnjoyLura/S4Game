# 地面破坏加强与吸取动态遮罩修正 v110

用户反馈：爆炸地面破坏不够；吸取静态可接受，动态有拼接/方块感，像黑色半透明遮罩移动。本次只改hero-impact-flow.effect、AdvancedHeroVFX.ts、HeroFxShader.ts三份运行资源，不改变伤害/充能/抗性/卡片/索敌/回血/声音/导弹数量或关卡。

## 吸取根因与处理

旧版吸取和烟雾共用SRC_ALPHA/ONE_MINUS_SRC_ALPHA混合，宽雾层RGB接近黑色，透明度和宽度又受二维格点噪声影响。移动或长度变化时可压暗一片背景并出现噪声块。载体高度固定偏窄，旧边缘羽化以UV百分比计算，也会随长度改变物理宽度。

新增第二个ONE/ONE混合technique，只供生命吸取池使用；Sprite的实际混合因子同步设置，原火焰/烟/地面继续普通混合。吸取输出按覆盖率预乘的正值发光颜色，去除黑底、宽黑雾和二维格点噪声。三股流丝改为按物理距离连续变化的解析曲线，能量向施法者方向流动；端点仍有旋流。加宽载体到普通120/大招144，并把边缘羽化改为固定8物理单位，避免光束伸缩时边缘比例变化。

实际扣血精华的方形线段拖光改为两端收尖的曲线光滴，淡化外晕、提高粒子亮度，保留真实扣血/回血触发；主副束、掌心定位、锁定至死亡与0.25秒结算保持。

## 爆炸地面

加深不规则焦坑、明暗坑沿、尘浪与短暂热裂纹；补7条曲折主裂缝/4条分叉、7块脚底固定的隆起土块和切面。几何/形态由落点及事件种子决定，出生计算并复用，不消耗战斗随机数，不随烟雾旋转或漂移。

地面与空中寿命拆开：普攻/技能焦痕2.4秒，大招3.2秒，二段1.65秒，最后0.8秒淡出。原空中火焰/烟/飞溅碎片时序不延长，超过原空中期限就不再绘制其quad/碎片。地面痕迹仍在怪物下方、仍16槽，随战斗暂停，不新增持续伤害、实际地形、碰撞或结算等待。
