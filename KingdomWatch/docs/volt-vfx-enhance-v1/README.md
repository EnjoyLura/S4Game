# 雷法师特效增强 v1

普攻：原小电球改为沿实际弹道朝向的电光弹头；逐距离增长、最长166px的渐细离子拖尾，细白电芯、蓝紫光晕、两侧游离短电弧，出手放电和命中分叉同步接入。

技能：替换原五段折线和笔直白线，以同一条锯齿路径叠加紫色外晕、蓝色电流、细白电芯，附着分叉、逐跳错开的余电脉冲与施法点放电。各跳仍在原时刻立即结算伤害，不引入施法延迟或额外命中。

大招：保留15道天雷及原目标、范围、节奏，雷柱加强分叉、两次纯视觉复亮、局部触点亮核与向外放电；脚底独立地面层绘制扁平断弧和电裂纹，约0.33秒内消散，避免整屏白闪和持续地面残迹。

`VoltVFX.ts` 使用三个共享 Graphics 节点、96个池化事件，密集命中预留24个技能／大招位置；电弧临时顶点复用，不逐命中创建节点或Tween。特效噪声独立于战斗随机数，统一用战斗模拟dt，暂停／三选一冻结，随倍速和顿帧推进。普攻不再叠加旧通用雷系发射／飞行装饰，避免重复发亮。

保留双基础伤害公式、普攻攻速、技能大招系数／次数／范围／感电／眩晕、英雄动作素材、其他英雄特效及音频。不新增生成式图片或视频。按用户约定仅构建、DPR补丁和发布，不运行测试、模拟、游戏、浏览器或线上视觉验收，效果由用户人工体验。
