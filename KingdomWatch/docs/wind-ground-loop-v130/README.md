# 风场接地、轴线与循环 v130

用户反馈龙卷左右倾斜、风眼像悬浮在怪物身上、循环分成两段，并要求再加速。相对v129，本轮仅改变WindVideoVFX表现类与两张现有序列图集及对应清单/尺寸meta。玩法、风刃、忍者、Shader、预热入口均保持。

## 原因与改动

龙卷节点原本没有旋转动画，倾斜来自源视频上部风口左右偏移。离线测量顶部45..125行alpha质量中心，五帧滤波后围绕固定地面行作随高度增加的水平剪切，脚点和底尘保持；左右各补16透明像素防修正后裁切。上部中心横移范围由27.48px收至4.92px，削弱81.1%。旋转气流自身仍有不对称轮廓，不能称每片叶子或每条风带都垂直。画格320→352宽、显示3r→3.3r用于抵消新透明留边，主体实际尺寸/高度保持v129。槽节点始终不随目标方向旋转。

风眼之前与龙卷共处怪物上方的表现层，近乎正对镜头的厚圆盘挡住怪物。现在使用独立WindEyeGroundVFX子根，挂在已有GroundFxLayer，顺序早于MobLayer；风眼Sprite每次按种类归到地面根，龙卷仍在原上层。原图纵向仅投影为58%（最终图框高宽比约0.338），位置由hitY中心下移18单位，贴向怪物脚下。只压缩风眼的地面透视，不压矮龙卷。

旧片60帧后追加6张静止两端之间的光流补帧，播放仍像回接一个不同片段。新版对原片最后12张与最前12张逐对做双向Farneback光流对齐、预乘RGBA移动重叠，权重smoothstep；直接段源12..47后接合成尾48..59/头0..11，最后接源12天然相邻。原60张全部参与，没有倒放、停帧或删成静止段；结果48格，含12格合成重叠，非60原帧原样循环，也不冒称原生无缝。接缝处叶片/细风纹可能略微软化。

两者源帧率仍30，播放倍率均2：龙卷由1.5→2，风眼由1→2，最终60fps、48格0.8秒循环。所有视觉继续只读取area.age，不改变大招基础5秒、技能基础4秒、伤害tick、移动速度或牵引/养成规则。源端重叠缩短循环长度，速度参数与循环长度都记录，不将加速误写成伤害提升。

## 制作与验证

`prepare.py`从local归档源视频读帧，校验v129源SHA，复用已修的绿色/亮芯/灰尘分离抠图，不对已抠素材二次抠图。新两图集仍普通straight-alpha，无损导出；尺寸2816×2160和3072×1344，解码RGBA总约38.95MiB，较v129下降约16.31MiB。源MP4和旧试稿本地归档，不进运行包。`art-manifest-*.json`记录剪切中心/脚点、全部原片帧贡献、合成权重、全循环相邻误差、媒体哈希。末→首误差与常规相邻帧同量级仅作检查，不代表动态观感获认可。

`verify.cjs`隔离表现类验证地面层先于怪物、场景从任意顺序销毁、迟到与失败回退、8槽复用、预热不重复、600时间索引/暂停与比例。360次忍者及程序回退绘图与v129相同，所有战斗代码和配置原字节保持；源类型9条旧诊断无新增。未启动游戏、浏览器、真实战斗、战斗模拟、音频或WASM，手机动态与性能仍待用户。

离屏图像合成：[技能风眼](eye-preview.webp)、[大招龙卷](tornado-preview.webp)。风眼预览中怪物在风眼上层，显示目标遮挡；不是实际游戏截图或性能验收。

本地实现81799033，接缝权重细化5d5461c7。最终Creator17666ms、退出36，生产运行包1609文件208401908字节（208.40MB），版本12c04809da92ab9c，比v129减少2560790字节。516份其他native原字节保持，仅替换两张风场图集；新图集无损导出逐像素相同，48格边界透明检查通过。全部文件SHA/子路径/解码与WASM头静态验证、15份JS+5段内联仅语法检查通过，详见package-static-verification.json、export-report.json与build-record.json。
