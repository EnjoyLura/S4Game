# 弓箭手循环接头微调 v103

用户反馈v102弓箭手首尾有一两帧的小幅跳动。本轮只处理弓箭手，冰法师及其他角色保持。旧v102图集、帧序和制作记录原字节保留。

## 原因与处理

重新比较实际“末帧→首帧”的位置增量、前后速度与分区误差。原第54帧→第6帧在头部、披风和脚部的差异约为常规相邻帧的2–3倍。只调整截取点，第55帧→第6帧虽然略好，但无法消掉源片的姿态偏差，因此本轮不再只靠换窗口。

保留v102全部49格像素不变，沿原时间方向补上源视频第55帧，再对第55帧→第6帧添加2格运动补偿过渡。双向Farneback光流先把两幅轮廓向中间位置对齐，再在预乘Alpha空间混合颜色，避免简单淡化产生两套错位轮廓；透明像素RGB清零。没有使用生成模型、倒放、额外停顿或移动主体画布。过渡帧属于确定性插值，不能再把整套资源描述成“全部为原片原帧”。

最终50格原片＋2格过渡，共52格/1.733333秒；每格仍1/30秒，原49格速度和图像保持，循环较原版增加0.1秒。原固定352×576画布、裁剪、缩放和偏移沿用；新图集3520×3456，透明边距至少14px。

旧直接接缝平均差0.006142；新接头各步约0.00165–0.00204，普通第一步约0.00239。此数值支持跳变已减小，不等于动效已获用户认可。静态放大脸部/披风对照未见明显双轮廓；运动补偿仍可能产生少量局部软化，需用户检查真实播放。
