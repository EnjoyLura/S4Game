# 界面交互与轻动效

2026-10-15，按用户要求统一游戏的点击声音、屏幕触点反馈、页面切换和弹窗开合。延续主界面既有美术、布局和按钮反馈，不新增付费媒体或图像生成。

## 触点与声音

- Canvas最上层使用原生Graphics绘制暖金细环、瞬时亮点与四枚小光屑；按下显示轻接触，正常松开在约0.38秒内扩散消失。没有全屏闪光、大爆炸或图片贴片。
- DOM捕获仅观察GameCanvas手势，不阻止Cocos输入。鼠标／触摸／多点触控共用8槽池；拖动超过8个CSS像素或取消时撤销释放特效。按实际Canvas矩形及当前可视区映射，忽略画布外操作。
- 没有触点时关闭组件update，切后台清空，换场景解除DOM监听；特效节点没有输入监听或拦截组件。
- ButtonFeedback覆盖现有按钮、页签、卡片、物品、英雄及战斗入口。保留按下与高光，回位改为cubicOut，避免过冲。点击、选择、弹窗打开／关闭、开关、确认采用不同的采样音量和音高；全部复用已有授权UI采样。
- 同一操作在微任务内合并为一个有语义的提示音，音频UI总线另有35ms限流。悬停、滚动、禁用和取消不播放成功点击音。音乐／音效设置继续生效，保留上一轮捕获解锁与预加载修复。

## 界面与弹窗

- 五页主导航切换用200ms淡入及按导航方向18设计像素的位移，旧页120ms淡出再销毁，背景独立交接淡化。原导航、资源栏与背景布局保持。页内类别、背包、培养、关卡和数据刷新采用120ms、从94%不透明度回到原值的轻过渡。
- 通用纸面弹窗、属性／故事、装备详情、购买、培养详情等用180ms、97.5%到原比例、9像素回正的cubicOut；遮罩独立淡入。关闭120ms淡出，期间有透明输入拦截层，防止重复操作或点穿。
- 编队、GM、暂停、结算、伤害统计及技能Tips同步接入。暂停／结算页签重建仅轻淡入，不重复播放整套打开动画和提示音；三选一保留原卡片错峰入场与选择动画，保留升级／胜负专属提示。
- 购买、穿戴、替换、出售、强化及编队确认继续使用原数据操作，先执行原动作，随后在关闭过渡结束后刷新页面。战斗恢复仍即时执行，关闭画面独立退场。
- 动画组件拥有并清理自己的Tween，旧面板退场内容单独移出，避免晚到的回调删除新面板。三选一选择补齐版本号校验，切页或关闭后不执行过期选择回调。
- 轻提示同时只留一条，出现与消失有轻动效；计时及Tween随节点销毁清理，提示消失不阻挡输入。
- 跟随系统“减少动态效果”设置：页面／弹窗仅保留短淡入，触点不散发光屑。

新增脚本：`UIAudio.ts`、`UIMotion.ts`、`TouchFeedback.ts`。没有改变英雄动作、战斗数值、技能、发射特效、存档及经济规则。
