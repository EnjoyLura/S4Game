# 编队动态行数与英雄栏导航 v107

用户要求出战编队的英雄选择区按英雄数量动态增加行数，并指出英雄页顶部横向栏不容易让玩家发现可滑动。两类选择器分别处理。

## 编队

SquadPanel改为每行最多5位的网格，当前7位自动排成两行（5+2）。继续使用原126×206卡片、头像/锁定/上阵状态；面板高度、标题位置、下方说明按实际行数计算，增加到11位时自然变三行，不缩小卡片。正常高度显示完整内容，短屏或后续英雄较多时正文纵向滚动，顶部标题/返回和底部完成按钮固定可用。复用pageScroll，取消横向滚动、旧偏移与“左右滑动”提示；最大上阵数、阵容保存、下阵确认和引导规则保持。

## 英雄页与升级页

共用HeroRosterRail在确实溢出时显示可点击的左右箭头与细位置指示；箭头有独立边槽，不覆盖头像。可视区保留部分下一位头像，提示后面还有内容，原手势拖动保留。到边界时对应箭头隐藏，无溢出时不增加控件。点击箭头滚动一段，遵守减少动态效果设置。

每次重建都检查当前选中英雄是否可见。滚动恢复移至BEFORE_DRAW，在调用方建立所有头像和ScrollView更新边界后再应用，避免选中重炮/生命法师而栏内仍只见前五位。销毁时清理尚未执行的回调，不影响原头像或待机比例。

只改两个UI脚本，不增加美术、字体或音效，不改变战斗或存档。按用户长期约定本地提交并部署GitHub Pages；源码不推送、CF不动。验证仅编译、构建、静态资源/包/HTTP检查，不启动游戏、浏览器、战斗、音频或WASM；手机交互与视觉效果待用户确认。
