# 英雄详情共用布局 v6

按用户三张截图修正英雄弹窗和背包栏。英雄弹窗与商品详情共用实际的 `DetailDialog`，而非各自仿画。

- 同一纸面金框、内收深蓝标题和原单层关闭按钮。
- 同一168方形展示区、名称/等级/职业信息、金色分隔、分组标题及整块近白属性底。
- 装备、属性、故事、材料、出售确认与强化采用统一的内容流和固定操作区。按实际内容分配高度，避免大块空白；短屏仅信息区可滚动。
- 双栏装备对比共用同一组件的窄卡布局，两侧取相同高度。装备仍点空白关闭，不额外加关闭X。
- 按钮保留原单层样式，底边留约30单位。
- 背包采用连续纸面，去掉贴屏的切角外框；分类使用完整圆角深蓝底和一个内收选中面，移除每格重复绘制的切角底牌。

商品数据预览/购买函数、穿戴/卸下/出售/强化事务、角色场景与装备槽、背包过滤和滚动记忆保持。其余已有脚本散列对照保留；未改配置、数值或存档。

仅进行源码对照、静态类型诊断和本地构建文件检查。不运行测试、模拟、游戏、浏览器或线上验收，不额外Git提交。静态类型全项目仍有此前十项主诊断，改动模块无诊断。实际美术与交互由用户人工确认。

构建使用 Creator 3.8.8 web-mobile production/MD5，继续DPR和发布缓存处理。`publish.ps1` 继承上一版预览文件并用Wrangler发布main；`release.py` 只读取源码、构建文件和发布回执。
