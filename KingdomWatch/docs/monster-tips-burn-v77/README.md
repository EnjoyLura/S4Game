# 怪物点击、左侧介绍与灼烧时序 v77

用户手机试玩反馈：怪物难以点中，说明应参考《王国保卫战》，固定在左边竖向、内容简短；原灼烧动画速度合适，只需要对齐出现和扣血时机。本版针对这两项修正 v76。

## 点击与说明栏

- 按下时记录目标与当时的出生编号，抬起时打开；怪物在手指按住期间移动、被击败或回收，都不会让该次选择丢失或错误切到复用对象。
- 扩大身体点击宽度，并对身体边缘增加 26 设计单位的容错，优先选择直接触到的身体，其次选择最近的边缘。手指移动容差从 14 提高到 34 设计单位；明显拖动仍不当作点击，多指不覆盖当前这次选择。
- 透明点击层移到角色和特效上方，保持在装备掉落、飘字和 HUD 下方；掉落图标、大招、暂停、统计与 GM 仍使用原有点击入口。
- 原随怪移动的 380×300 面板改为固定左侧的 148×334 窄竖栏，左内缩 12，放在左列操作按钮下方、防线 HUD 上方。复用现有半透明背板、文字、血条和按钮，无新增美术。
- 内容只保留名称、类别、生命、物抗/法抗、两行简短介绍与最多两个关键状态；不显示完整机制长段、读条秒数或状态数值清单。破甲/破盾仍会更新。
- 正常战斗中，选中的怪物被击败后保留介绍并显示「已击败」，便于阅读。点击空地、再次点击同一目标或点关闭收起；选卡、暂停、结算等阻止战斗操作的状态仍自动关闭。查看不暂停战斗。

## 灼烧保留原速度，只对齐触发

v76 将完整动画映射到半秒伤害周期，缩短了实际逐帧时长。这不符合用户希望保留原节奏的要求。本版恢复原 12 格逐帧时长：

`0.04, 0.04, 0.04, 0.04, 0.05, 0.05, 0.05, 0.05, 0.065, 0.065, 0.065, 0.065` 秒，总计 **0.62 个战斗秒**。

每次实际灼烧扣血才启动一次完整火焰，不再先显示静止余焰后等扣血，也不独立空转循环。现有伤害仍每 0.5 个战斗秒结算、每次为 DPS×0.5；动画逐帧只加实际战斗 dt，不再将 0.62 秒压成 0.5 秒。前一段最后 0.12 秒的余焰可与下一次起火短暂并存，最多两段附着动画，复用节点，不截断正在播放的收尾。

灼烧刷新不会重播或打断已有动画；事件编号在同一怪物生命内递增，避免状态重新施加时误播旧事件，怪物回收后按新的出生编号重新绑定。最后一跳扣血之后，即使灼烧状态刚到期，存活怪物上的这一段余焰仍自然播完；怪物死亡时清理附着。移除 v76 另加的橙色小火光，避免重复闪动。

原火焰素材、命中动画、陨石和全部美术/音频字节保持。没有改灼烧伤害量、间隔、持续时间、抗性结算、关卡数值或英雄强化。两秒胜利收尾和物品详情点击保持。
