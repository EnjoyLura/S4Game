# 成功／失败结算漫画美术与布局

2026-10-15 用户提供当前结算截图与其他游戏参考，要求成功、失败也使用美术资源，并适当优化布局。本次明确允许调整这两个结算页面的布局，替代此前限定只换肤的约束。暂停、伤害 tips、三选一保持原布局。

## 美术资源

使用内置 imagegen 生成一张真实透明组件图集，原始输出复制到 `source-atlas.png`，完整实际提示词为 `image-prompt.txt`。风格沿用项目清爽漫画奇幻参考，用户胜利／失败参考分别保存为 `reference-win.png` / `reference-lose.png`，现状截图为 `before-win.png` / `before-lose.png`。

`prepare_assets.py` 按独立 alpha 连通组件提取 8 张原像素 PNG，保留抗锯齿边缘，不重画、不重新采样：金色皇冠号角横幅、蓝灰破损皇冠横幅、暖色／冷色内容底板、青色／灰色按钮、两种奖励卡底板。资源位于 `assets/resources/ux/settlement_comic_v1/`，准确尺寸、来源与 SHA256 在 `assets.json`。按钮、内容底板、奖励卡采用九宫格渲染，横幅按比例显示。文字均由引擎渲染，不烘焙在图内。金／绿导航按钮和连体页签复用暂停美术。

## 布局与行为

`SettlementPanelSkin.ts` 提供居中的结算布局，顶部皇冠标题，随后星级、关卡名和耐久信息，中部固定内容底板与奖励／统计页签，下方广告操作，再下方左右导航。内容聚拢，缩短旧版大块空白；较矮屏幕按可用高度统一缩放，底部操作留白。

成功为金棕主题，保留实际星级与剩余耐久，返回居左、下一关居右；双倍明确为双倍金币，成功领取后展示实际双倍金币，经验保持原奖励。失败为蓝灰主题，保底奖励及复活说明与操作集中，返回居左、再来一次居右；所有按钮沿用原回调，不重写奖励、重试或复活结算。

统计显示最多五位上阵英雄，最高输出标 MVP，真实伤害数值与团队占比保留，橙色条按最高输出比较。广告操作期间按钮禁点，异步回调保留当前页签，复活成功由原回调关闭结算并继续战局。

同轮收到火法师待机视频后，将新待机和已有新攻击配对接入，详见 `../pyro-idle-user-v1/README.md`。其他英雄媒体、战斗数值、暂停美术与生命／护盾显示保持。
