# 弩空隙抠底与循环修正

用户指出弩中间黑色闪烁。原版从画面边缘抠黑，弩弦围住的空隙在一些帧中与外部背景连通、另一些帧封闭，因此产生透明与黑块的跳变。本次在两个实际空隙内补充抠底种子，以重弩局部图像匹配确定种子的轻微平移，只移除原视频背景，人物和武器像素仍在原位置。不冻结身体，不拼接披风，不重新生成视频。

参数在 `apertures.json`；参考为原视频第 4 帧；每帧种子位置在 `processing.json`。人物原有深色衣服和描边仍由边缘抠底保护，不全局清除所有黑色。修正前图集、帧数据、GIF 和发布记录保存在 `before/`。

用户随后指出首尾帧差异导致硬跳。新版用完整 56 帧前进，再沿相邻帧返回，共 110 个播放项，循环 4 秒。每帧时长按余弦运动曲线设置，使两个回转端逐渐减速，回绕从源帧 1 回到源帧 0，不再从末帧直接跳到首帧。不存在跳帧、插画扭曲或两张人物交叉淡化。原始两秒生成请求和约 2.33 秒源视频保持原样。

`animation.frameDurations` 保存每个播放项的秒数，网页预览、逐帧滑杆、镜像 GIF 与场景 GIF 使用同一时序。图集仍为 56 格、384×576；播放顺序及停留时间已调整，未来游戏接入须读取逐帧时长。当前只发布独立预览，仍由用户人工验收，不运行浏览器或线上效果验证。
