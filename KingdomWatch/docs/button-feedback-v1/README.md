# 全局按钮交互反馈

2026-10-15，按用户“检查所有按钮，增加按钮反馈，体验要好”的要求，对源码中的所有触控入口进行了归类。按钮、页签、可选卡片及图标接入统一反馈组件；空白关闭区、遮罩拦截、滚动与尺寸监听保留各自语义。

## 统一手感

- 按下用 65ms 收缩至 96.5%、下沉 1.5，叠加低透明暖白高光；主导航及较大卡片适度减小缩放幅度。
- 松开立即执行真实回调，视觉用 120ms 回位及 180ms 高光消退，不等待动画结束才响应。三选一卡与大招入口保留自身动画，只加高光避免动画互相争抢。
- 鼠标悬停低亮提示；有效点击播放现有已授权采样音效，取消和禁用不播放。
- 同一触点配对，移出或拖动超过12设计单位取消；路线拖动沿用7单位限制，ScrollView继续接收拖动捕获。
- 松开恢复原几何后再做引擎屏幕坐标命中检测。共用按钮触控尺寸至少44，图形尺寸不变。
- 140ms跨节点点击间隔阻挡快速连点及弹窗切换后的误穿透；节点禁用、销毁、应用切后台时清理按压状态。嵌套子按钮独占手势，不吞掉ScrollView所需的开始事件。
- 自定义图标与文字在首次按下时归入按钮面，跟随同一反馈，根触控框保持固定。无闲置逐帧update或全局按钮扫描。
