# 横幅领奖弹窗与渐隐双线通知 v14

按用户提供的常见游戏领奖参考，重新实现 `RewardPopup`；通知样式取代 v13 的底部圆角条。

- 领奖界面：全屏暗色遮罩、横贯屏幕的深蓝灰半透明展示带、上下细金线；顶部金色翼饰与圆章承托“恭喜获得”。原金币/钻石以方形蓝底展示，实际到账数量放在图标右下；单项居中，多项并排，名称在下。
- 交互：保留关卡/难度及本次领取宝箱数量；点击任意位置收下，取消旧纸板、关闭X和大确认按钮。动画只展示回执，奖励仍在打开前保存；关闭不会再次发奖。
- 动画与声音：原卡片错峰轻弹、数字变化和局部金色碎光保留；首次绘制时只触发一次领奖提示音，取消原来的额外延后确认声。新增独立 `reward` 音效语义，复用现有上扬旋律 `audio/v1/levelup.wav`，播放速率1.12、cue增益0.94；不新增或修改音频文件。音效开关、手势解锁、后台静音和原混音继续生效。
- 通知：停留在屏幕中上部（通常距屏顶约38%），深色背景两侧平滑渐隐，上下各两根细金线也同步渐隐，无矩形外框。380ms从物理屏幕下方滑入，停留约1.8–2.3秒，320ms向上36单位并淡出；长消息额外延长。保留真实成长文本、同对象连升合并、单条替换、后台清理和减少动态效果支持，不拦截输入。

仅改 `RewardPopup.ts`、`UINotice.ts`、`UIAudio.ts`、`AudioCatalog.ts`。关卡领取入口、一次性奖励记录、到账数值、存档、基地美术及其余原脚本保持；无新运行图片、音频或 Git 提交。

源码及本地构建产物静态审阅，类型结果仍为原九项诊断，改动模块无诊断。按已有约定未运行测试、模拟、游戏、浏览器、试听或线上验收；实际观感与听感由用户人工确认。`before/` 与 `source-baseline.json` 保存本轮之前的111份原脚本散列，`release.py` 只读取本地源码、构建文件和发布回执。
