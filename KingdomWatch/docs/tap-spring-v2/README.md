# 全画面点击与弹性按钮 v2

用户要求：点击空白非组件画面也出现反馈／特效；按钮按下不能变白，应有正常游戏的弹性反馈。此要求取代 ui-experience-v1 中按钮按下／松手的浅色覆盖和无弹性回位。

- TouchFeedback 从 onLoad 注册 DOM 捕获和 Cocos 全局触摸入口，覆盖大厅、战场及弹窗的非组件区域；DOM／引擎坐标去重，鼠标、触摸与多指沿用 8 槽池。没有添加全屏输入拦截节点，不消费游戏输入。
- 按下即时出现接触环，松手用 0.4 秒金色扩散细环、中心亮点和 6 枚短光屑；细暗边提升浅色纸面与明亮战场的可见性。拖动超过 8 CSS 像素取消（引擎回退 10 UI 像素），滑动／取消不出现松手光效；后台／失焦清空，换场景解除监听，空闲停止 update。减少动态效果模式只保留短小光环。
- ButtonFeedback 完全移除白色 Graphics 覆盖层与高光 Tween，UIKit 旧按钮不再切换按下图片。按钮保持本来色彩，整个图文一起 70ms 下压，默认 94% 比例、下沉 2 设计像素；松手 100ms 回弹至 102.2%，再 130ms 收稳。快速点击也保留可见下压，桌面悬停为 101.2% 微抬，不进行泛白。
- 页签采用较小的 96–97% 压缩；三选一卡片按下轻压，松手衔接原选择弹跳，不叠两套动画。大招图标用中心支点包裹完整图、充能、文字与能量，整体弹性反馈，不仅移动透明命中圈。
- 真实命中检查使用复原后的视觉与触控区域，保留滑出／拖动取消、140ms 激活保护、禁用／忙碌状态、语义点击音效及异步操作。减少动态效果时使用 98% 微压与 100ms 复位。所有运动只停止自己持有的 Tween，后台及销毁清理。

保留上一轮 48 条战斗音效、混音、BGM、页面／弹窗动画、布局和战斗规则，无新图片、视频或付费调用。依长期要求只构建发布，不运行测试、游戏、浏览器或线上效果验收；实际视觉和手感由用户体验。
