# 页面与英雄刷新白闪修复

本次针对切换主界面、切换英雄、升级英雄等操作出现轻微白闪的反馈。

源码中的共同原因是：页内刷新主动将整页透明度降为94%，多层刷新会叠加；切页时新旧页独立淡入淡出，背景也独立过渡，浅色纸底会露出；先销毁旧内容再异步填入人物和场景图，会出现素材未就绪的中间状态。

修正：

- 刷新取消整页透明度脉冲；英雄、背包、培养、关卡、商店统一保留旧画面，等新画面的普通美术与图集加载完成，再一次替换。
- 页面切换保留完整旧页，背景随页面一起过渡；只让新页淡入，原画面在其下保持原亮度，结束后再回收。
- 新请求替换尚未展示的候选页，版本标识拦截过期回调；退出页面时清理保留节点与动画。加载失败使用既有程序绘制兜底。
- 忽略重复选择当前英雄；保留弹性按钮、点击反馈、音效及弹窗微动画。
