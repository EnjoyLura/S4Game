# 音效替换清单

你负责选定喜欢的声音，我按编号替换、接入和混音。以本清单编号为后续沟通依据。

- 这是61个用途条目，包含可共用和待补接的用途；不是要求找61条不同录音，也不是要求找齐此前83个音频文件。
- 每项先选1条即可；高频普攻/命中如果找到2–3条同风格变体，可以一并提供。
- 可以直接发音频文件或音效详情页链接，注明编号。例：`C05 胜利，这条用整段`；`F01 弓箭手普攻，取0.1–0.4秒`。
- 你选定素材的音色和旋律由你决定；我处理转换、裁切、响度、触发和防叠音。较大幅度的音色/旋律变化先提出具体方案。
- 可以分批提供；未提供的用途继续沿用当前声音。建议先找C05/C06/C01/D01/B04，随后找普攻和命中。
- 推荐时长只是便于筛选：点击0.05–0.2秒，普攻/普通命中0.1–0.4秒，技能/大招0.4–2秒，领奖/升级0.5–2秒，胜败1.5–5秒；更长也可以交来裁切。
