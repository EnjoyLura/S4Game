# 商店商品详情

商店四类商品的图标均可点击，沿用已有弹性反馈、打开音效与纸质弹窗。价格按钮进入同一份详情；点击图标只查看，购买需点击弹窗内的“购买”。已拥有、未解锁及新英雄占位也可查看，状态会限制购买。

- 武器／装备：介绍、品质、部位、阶级、Lv.1、实际属性和持有数（含已穿戴）。属性复用 `equipStat`，包含阶级系数，百分比复用 `statFmt`。
- 英雄：定位、背景、初始攻击／攻速、技能与大招名称，说明购买解锁与每局强化卡学习规则。
- 材料：配置中的用途说明、当前持有数、每次获得数量与背包位置。
- 底部：获得数量／购买状态、货币图标、价格、余额、关闭和购买。资料区域可纵向滚动，底部操作固定。

购买沿用 `shopBuy`，实际操作时重新检查关卡条件；已拥有英雄、未解锁、尚未开放商品的详情购买按钮禁用。余额不足仍保留点击后的明确提示，成功后提示并刷新主界面与货币栏。

功能代码仅修改 `assets/scripts/ui/pages/ShopPage.ts`。依用户约定仅源码调整、Cocos 构建、DPR 补丁和发布，不运行测试、游戏、浏览器或线上验收，实际体验由用户人工确认。
