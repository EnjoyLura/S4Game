# 必备武器与共用培养 v1

每位英雄保持一件武器，可直接替换，不可卸下。初始配置：艾拉狩猎木弓，凯尔制式轻弩，焰辉学徒魔法书，沃尔与莫拉各自持有学徒法杖实例。旧档保留兼容且独占的已穿戴武器，缺失、失效、重复占用或职业不符的槽位补发初始武器；原装备留在仓库。初始武器不可出售，替换后保留备用。

武器培养仍按每位英雄独立保存，沿用原有 `weaponLv`，上限90、成本保持，换装继承该英雄培养等级，不转移其他英雄的培养。旧档当前武器的独立装备强化等级若更高，首次迁移将其提升至该英雄武器培养等级；不叠加等级。非武器装备仍独立强化至20级。

八件新美术由内置 image_gen 分别生成：四件白色初始武器、四件绿色进阶武器，原图完整复制，保留透明，无像素编辑。`generation.json` 保存实际提示词和来源，`imagegen-assets.json` 保存尺寸、透明范围和摘要；资源在 `assets/resources/ux/weapons_v1/`。已有猎风长弓ID及基础词条沿用，配新绿色弓插画；已有紫色鹰眼重弩保持原图与词条。

武器词条沿用每级4%成长，英雄基础乘区沿用每级6%培养成长；通用每10级8%突破改由当前武器专属表分别作用攻击和技能伤害。每30级额外词条并入装备聚合，攻速由面板统一计算，暴击/暴伤/充能由战斗现有装备入口各应用一次。换装后按当前武器重算已达到的突破。

弓限弓手、弩限重弩手，火雷冰法师可用书或杖。穿戴操作验证库存、槽位、职业与其他英雄占用，无法抢走另一英雄当前武器。英雄装备弹窗改更换武器 / 武器培养，比较面板禁用卸下，强化入口共用武器升级；非武器卸下保持。背包、插槽、对比、升级页、突破卡和成功通知读取当前真实武器及培养等级。

四件绿色武器可在商店购买（各800钻石，沿用现有绿色弓定价）；精英/地狱装备池将原绿色弓权重均分四类，总装备掉率和绿色武器总占比保持。初始武器不进入售卖或随机掉落。扩大的掉落目录和结算清单使用局部滚动，防止溢出弹窗。
