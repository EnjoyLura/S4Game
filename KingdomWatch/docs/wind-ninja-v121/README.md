# 风眼、龙卷与能量旋刃 v121

根据用户提供的旋流、龙卷和圆弧刀刃参考，完成风法师三种攻击及忍者大招的视觉重做。

- 风法师普攻：圆弧能量刀刃，中段饱满、两端收尖，前缘亮芯、后方短流光。弧面正中沿实际预判弹道朝向敌人；转向用 `atan2(vy,vx)`，不再固定水平“小伞”造型。
- 风眼：青蓝旋流、宽窄交错的螺旋光带与成组细流纹，域扭曲噪声随战斗时间向内流动，叠加卷入的叶片。删除完整圆形范围边线。
- 移动龙卷：更厚实的渐宽风体、前后斜卷气流、柔边雾气、顶部卷动与底部卷尘。流纹沿风体上升，细节不再由几个平涂椭圆圈拼成。
- 忍者大招：青蓝主色四瓣弯曲能量旋刃，白青亮芯、蓝色辉光、旋转残影与少量能量碎屑；大招不绘制金属面、铆钉或中心金属孔。普通手里剑及命中留标仍沿用金属造型。

实现复用 `HeroFxShader` 的固定池与两像素白色载体，新增唯一共享程序 `assets/resources/fx/wind-ninja-flow.effect`。4个模式使用实际战斗年龄，暂停时冻结；风场池每英雄8个、风刃池上限沿用80个，风刃池仅编队包含风英雄时在战前创建。预热纳入已有出战资源屏障，失败可用定向几何后备，不显示白色载体；每个事件固定渲染路径，避免异步完成时中途变形。旧炮手和生命法师仍使用原效果、技术索引与混合方式；缓存按效果路径独立并合并重复请求。

风体使用预乘色覆盖与发光混合，实际形状的覆盖alpha不超过0.35；忍者大招和风刃为alpha0的纯能量发光，混合 `ONE / ONE_MINUS_SRC_ALPHA` 下仍保留原背景。所有载体边缘归零，不引入黑色方板。两级噪声、固定最大4次循环，无纹理采样或体积光线步进；未新增图片、音频、视频或序列帧。两位英雄的伤害、命中、范围、持续时间、移动聚怪、对空和标记回收机制沿用v120。
