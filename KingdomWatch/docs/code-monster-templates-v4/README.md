## 改动原理

参考用户提供的 `D:/AI/S5Game/docs/artifacts/eagle-flight-v1/bake_eagle_flight.py` 与制作指南；方法来源及代码散列保存在 `sources.json`。老鹰采用该案例的翅根、径向角度过渡及外翼延迟思路；双足、四足在同一原则上改为连续网格，不依靠拆开的肢体去遮住断口。

1. **UV 始终采样同一张原画。** 变形的是三角网格，角色的脸、纹样和配色来自同一幅图。
2. **关节有一片固定区域。** 翅根半径以内保持与身体相同的运动，外侧的旋转角逐渐增加；不只钉住一个点。老鹰根部固定半径 35 原图像素，蝙蝠 42 像素。
3. **双足、四足使用一张连续网格。** 肩、髋、膝周围的蒙版只选择变形影响，不切断图像。关节之后使用角度场和步伐位移；后续关节跟随前面的变形。轮廓附近的局部场用 10 小步积分，避免一次大幅变换把网格折回去。
4. **飞行使用身体与双翼三层。** 根部有纹理重叠，身体覆盖连接处，各层共享完全相同的身体起伏。蝙蝠额外保护耳朵和头部邻域，翼的场分 16 小步积分，避免耳朵切口随翅膀拉开。
5. **动作由周期函数驱动。** 左右腿错相，前后腿错相，翼尖延迟；每周期均匀取 32 帧，不重复最后一张首帧，不进行首尾交叉淡化。
6. **离线烘焙。** 以 2 倍分辨率进行三角形反向采样，预乘透明度下合成和缩小，再输出直通 RGBA，减少边缘污染。游戏将来只需播放图片，不执行这些网格计算。

这仍是单图二维动画：看不见的背面不会凭空出现，原画严重遮挡的腿也不能自动变成完整三维步态。每只新怪仍要校准关节、影响区域、遮挡与动作幅度。不能把本轮五只的离线检查当成所有原画都能直接批量通过。

## 文件

- `biped-new.gif`、`quadruped-new.gif`、`flight-new.gif`：本轮分组预览，米色底。
- 各怪目录 `preview.gif`：单只预览；`preview.apng`：透明循环动画。
- `frames/`：每只 32 张、512×512 透明 PNG。
- `atlas-512.png/json`：8×4、4096×2048 母版图集与元数据。
- `atlas-256.png/json`：8×4、2048×1024 游戏尺寸候选图集与元数据。
- `old-new.gif`：同取景、同周期旧左新右；`contact.jpg`：八关键姿势；`joint-details.jpg`：连接区放大。
- `inputs/`：原有透明图的逐字节副本；`legacy/`：从旧 640 格图集统一缩小到 512 格的参考。
- `engine.py`：连续角度场、网格、预乘透明度采样与烘焙。
- `prepare.py`：从原项目归档来源并写出 `rigs.json`，需要原项目历史文件。独立方法包已有输入和配置，通常不必执行。
- `bake.py`：生成资源与预览；`validate.py`：离线资源检查。
- `validation.json`：各怪完整周期的检查记录；`validation-summary.json`、`asset-sha256.json`：汇总与资源散列。
- `five-monsters-pinned-mesh-v4.zip`：全部资源和源码，不含 Python 缓存与草稿。

图集各格统一缩放和锚点，不逐帧自动裁剪。元数据的 `pivot_top_left_normalized` 以左上角为原点；接入底部原点的引擎时使用 `(x,1-y)`。飞行锚点为身体参考点，行走锚点为固定地面参考；不能按每帧包围盒重算脚底。

## 重现

Python 3.14、Pillow 12.3、NumPy 2.5；没有网络、AI 模型、Cocos 或浏览器依赖。预览文字使用 Windows 微软雅黑 `C:/Windows/Fonts/msyh.ttc`，其他系统可调整 `bake.py` 的 `font()`。

```powershell
python bake.py --draft             # 先看四关键姿势
python bake.py --draft --only bat  # 单独调整一只
python bake.py                    # 烘焙五只并制作预览
python validate.py                # 检查透明帧、图集、时长、周期与来源
python bake.py --package-only     # 包含最新检查记录重新打包
```

离线检查包括：每只 129 个相位的网格方向和范围、周期位置与速度、两类飞行固定区域相对运动、每张输出中外翼与身体的透明度连通、160 张透明帧与两个尺寸图集逐格一致、GIF/APNG 时长、原素材与旧代码散列保持。只检查图片和数学结果，没有运行游戏、浏览器、战斗、音频或实机性能验收。正面积和像素连通只证明相应条件，不等同于美术和自然度获得认可。
