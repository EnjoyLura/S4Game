# 基地页：清爽漫画奇幻 v1

基地的庭院、主城建设、研究院图鉴和详情改为已认可的漫画风格。完整插画让三座建筑共享地面、透视与光照；冷蓝远景、绿色树林和暖石庭院形成层次。明确的深色轮廓、大色块和克制的材质细节用于减少生成感。

- 主城、研究院、工坊直接作为入口。建筑和名称一起响应点击，主城显示真实等级与可升级提示，研究院显示真实解锁进度及可领取数量，工坊保留未开放状态。
- 全宽米色建设栏固定在导航上方：漫画心形、盾牌、锤子和城堡插画复用统一组件；等级、耐久、护盾、费用都由代码显示。点击升级先打开预览，确认后调用 `upKeep()`。
- 主城建设弹窗对比当前／下一等级，并展示增量、持有金币和实际费用。金币不足、等级上限沿用原有规则，不改变成长公式。
- 怪物图鉴保留六种实际战斗怪物插画、发现条件、特征、描述、弱点与每种一次的 20 钻石首览奖励。未发现项使用锁定图形，不提前展示怪物；领取后资源栏、研究院通知和列表同时更新。
- 列表和详情使用 ComicUI 单层背板与按钮，避免重复底板和底部叠影。详情关闭回到原列表，保留滚动位置，不叠加遮罩。
- 短屏只滚动中间营地，插画和点击区域使用相同变换；资源栏、标题、建设栏和导航保持固定。营地与图鉴滚动条提示隐藏内容，偏移在本次页面会话内保留。

## 制作与素材

使用 imagegen 技能的**内置 `image_gen.imagegen` 工具**生成完整庭院和透明心形，以已认可的商店场景、风格参考和城堡导航插画约束画风。庭院另做一次定向编辑：缩小前景建筑、移入安全边距，保留连续地面和光照。实际提示词、参考图、编辑约束和源图路径全部保存在 [generation.json](generation.json)，原图保存在 `sources/`。

场景构图固定，建筑基础坐标由最终图校准：主城 (0.5, 0.469)、研究院 (0.27, 0.715)、工坊 (0.73, 0.747)。后续替换场景图必须重新校准，不能只按生图提示词中的期望位置设点击区。
