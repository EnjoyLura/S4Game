- 枪身从细线改为有厚度、收尖的发光主体，增加三股贴身游动电流与少量短弧；普攻显示尺寸 9→12，大招 35→40。不恢复密集长树杈。
- 移除规则的放射地纹和完整亮圈。地面采用局部焦痕、独立渐隐/渐现的爬行分叉、电雾；脉冲波由不同长度的破碎波前和局部电弧组成。
- 巨枪落地仍有原有范围伤害和持续脉冲，视觉加强闪爆、电火花、烟尘与飞散碎屑。入地裁切、前景土唇、飞行与驻地的电流相位连续保留。
- 普攻和巨枪改用宽缓的投掷投影曲线，位置、朝向、到达时间共用解析曲线，末端保持斜向入土。近竖直方向分开横向与纵向转折点，极近目标缩小弧线，避免最高点急转或末段突然折头。枪雨继续向下加速落地。

这里的常规投掷是二维地图上的美术投影曲线，不能将地图纵深直接等同真实高度；没有把此实现宣称为恒定重力物理模拟。伤害倍率、伤害范围、持续时间、枪雨数量未调整；实际投掷时间与画面共用曲线方案。
