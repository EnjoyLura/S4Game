# 等级与武器突破左右滑动 v1

英雄等级突破及武器突破直接复用技能突破的 `milestoneShelf` 滑动模式及 `MilestoneSwipe`，去掉左右箭头。卡片随手指拖动，松手吸附到档位，边缘阻尼和200ms缓出沿用技能突破；切档沿用选择音效。区分横向拖动和页面纵向滚动，拖动取消卡片点击，点按仍打开突破详情。

各英雄、等级和武器分类独立记忆已浏览位置；升级刷新不重置该位置，首次显示仍定位到下一待解锁档位。突破等级、效果、已解锁和下一阶段高亮均保持，技能继续使用原滑动交互。

仅修改 `TrainingLobby.ts` 的共用突破栏调用参数。`before/`保存修改前源文件及复用的滑动组件。按项目要求只审阅源码、构建、DPR补丁并发布，不运行测试、模拟、游戏或浏览器；实际手势和视觉由用户人工确认。
