# 雷枪轨迹、流动电芯与大范围雷暴 v143

2026-10-28，修复用户指出的正前投掷突然侧拐、黑色实体枪尖、静态实心枪身与爆炸过小；按追加要求，所有雷枪视觉放到怪物下面。随后用户明确评价：“这版特效还算比较满意的了可以作为标杆特效”。v143 因此成为已获用户认可的雷电/能量武器与落地爆发质量基线；这项认可不等于全部设备与全部技能组合的性能验收。

## 修改

普通/巨枪移除 v141–v142 的三次曲线和人为侧弯控制点，改为固定横向速度、固定向下加速度的投掷平面抛物线。位置和速度使用同一个解析式，发射速度由落点/飞行时间解出；伤害仍在同一条弹道到达目标时结算。竖直投掷保持同一 X，斜向投掷的 X 单调前进。枪身沿瞬时速度，低投影速度附近缩短长度，避免正竖直顶点的 atan2 奇点让整柄枪瞬间翻向侧面；这是二维显示处理，不宣称完整三维刚体空气动力仿真。落地沿末速度方向入土，继承长度投影与动画相位。

Blender 枪体删去全部实心网格、金属针尖和静态主芯，改为 32 股持续变形、粗细脉动的电流组成内部轮廓，尖端也是电流汇聚；保留外层缠绕电丝。中心电流采用 2 秒循环关键帧，不靠整柄平移或旋转假装内部流动。

落地雷暴横向形体扩大 2.15 倍，爆发实例按伤害半径 1.2 倍绘制；图集单帧从 384 提升到 512，重新固定取景留出边缘。地电和游离波取消原相机对地图纵向的压缩，与实际圆形伤害计算对应，游离波额外向外延伸 18%。爆发单独校准纵向覆盖。参数不扩大真实伤害或改变伤害数值。

`GroundFxLayer` 位于 `MobLayer` 下面。飞行专属根节点、材质备用渲染、Graphics 备用渲染、插地/回收、枪雨、地电、爆发、连锁电弧及雷枪通用蓄力均在该层。飞行独立根节点跟随弹道层销毁，地面/插地根节点跟随英雄销毁。其他英雄的图层不变。

- `verify_cosmetics.cjs`：隔离执行实际视觉类、实际飞行层初始化方法，确认所有雷枪 Sprite 和备用渲染层低于怪物，节点复用、场景销毁、结束清理正常。属性数值配置与 v142 原字节一致；英雄逻辑只传递落地视觉长度。
- `measure_coverage.py`：从实际渲染调用和正式纹理读取像素，在 72 个角向分段测量亮区外缘。接触后 0.25–0.40 秒，雷暴在全部方向越过 250 的真实伤害半径；0.30 秒最短外缘为半径的 1.058 倍，中位 1.46 倍。测量的是不规则亮区外缘，不表示每个像素都被不透明特效填满。48 帧核心区域均存在运动变化。

- `contact-sheet.jpg`、`ultimate-placement.mp4`：真实绘制调用的静态场景离屏合成。`damage-coverage.jpg` 的青色虚线只是实际伤害边界检查标注，不出现在游戏里。

## 标杆确认与制作复盘

本次最终成立的是一整套相互配合的表现：可辨认的雷枪轮廓、内部流动电芯、外层不规则电丝、连续投掷和贯地、短促雷暴、覆盖伤害区的地电与外缘游离波，以及怪物对特效的正确遮挡。后续以这些质量要求为参照；冰、火、风等元素仍应保留各自运动和材质特点。

### 从反馈得到的关键经验

| 早期问题 | v143 的有效处理 | 后续制作规则 |
| --- | --- | --- |
| 枪像螺旋棍子、规律重复的装饰模型 | 保持长尖轮廓，电丝长短、粗细、弯曲和分支各不相同 | 先看轮廓，再做细节；随机要服务主体识别，避免机械重复和均匀放射 |
| 黑色针尖、静态实心内芯像带电金属武器 | 枪尖与内部均由持续变形、脉动的电流构成，外层再叠缠绕电丝 | 能量武器的主体材质本身必须运动；只加 Bloom、闪烁或外围粒子不能替代内部运动 |
| 正前抛出却突然侧拐 | 移除人为侧弯，位置和朝向共用解析速度，顶点处理短投影，触地继承末切线 | 弹道、朝向、接触点和爆发触发共用运动数据；竖直、极近和左右目标单独检查，不能只看一个好看的斜角 |
| 插地像轻轻停住，缺少爆发力 | 末段加速、约85ms轴向贯入、微小回稳、接触瞬间雷暴、随后外扩电流 | 力度来自触地前后速度与能量释放的节奏：飞行→接触→爆发→扩散→余电；单纯增亮或加粒子不够 |
| 图集很大，游戏内爆炸却只覆盖中心 | 按有效亮区和接触锚点缩放，校准地图圆形范围与烘焙透视，单独扩大爆发主体 | 整格尺寸不等于有效特效范围；叠真实伤害边界检查峰值及传播过程，雷枪可有视觉外溢，但不因此扩大伤害 |
| 规则圆圈生硬，电丝覆盖不够 | 分叉主路、持续地电、断裂游离外缘分层，错峰传播、侵蚀和消散 | 圈可以有大致外扩趋势，不能变成整齐闭合的亮环；密度通过多尺度、不同寿命组成 |
| 雷枪/爆发盖住怪物，空间关系不成立 | 用户指定的所有雷枪视觉及备用渲染都放在怪物层下面 | 图层属于特效设计的一部分；用怪物穿过/遮挡特效的场景检查，新增图集和失败回退路径都必须一致 |

### 工具分工与可重复流程

1. 先列清主体材料、起手/飞行/接触/爆发/余波、真实伤害范围、屏幕显示尺寸和遮挡规则。参考视频分别借鉴轮廓、时间节奏和电弧结构；配色按用户要求确定。
2. 用 Blender 制作可编辑的几何、内部材质运动和分层动画。本次通过脚本与后台渲染完成；质量提升来自这些具体设计和迭代，并不依赖安装 Blender MCP。
3. 枪体、爆发、地电、外扩波分离导出，固定画布、固定针尖/地面锚点。主体能够按弹道旋转，地面层能够按伤害半径缩放，各层独立调节时序，避免把完整镜头直接当成一次攻击。
4. 辉光只烘焙一次，保留正确直通 RGBA 与标准透明混合、帧格留白和透明收尾；按高对比背景检查黑边、过曝、裁边和细电丝丢失。保留源文件与生成脚本。
5. 游戏代码负责模拟时钟、弹道、接触回调、缩放、分层和池化；图集负责具体光电纹理。普攻、枪雨和大招共用材质语言，但区分尺寸、同屏密度、爆发层数与节奏。
6. 在实际游戏尺寸的静态战场中，用正式渲染代码输出状态再合成。同时看单帧轮廓和连续播放，加入怪物遮挡、正前投掷、极近落点、多个实例与真实范围标注；独立黑底预览只能说明素材质量。
7. 将反馈对应到明确层次：轮廓问题修造型，内部不活修电芯，侧拐修弹道，爆发弱修时序/有效范围，遮挡错误修层级。每轮保留已认可的部分，避免整套无目标重做。
8. 做针对性几何、像素、生命周期与构建检查，再由用户判断整体观感。v141 的大量几何采样曾通过，但其人为侧弯仍被用户否定，说明“连续、无 NaN”不足以证明运动正确。v143 增加恒重力、横向不绕行、真实范围覆盖等针对反馈的断言；数值检查仍不能替代视觉认可。

### 复用边界

雷枪的 32 股电芯、85ms 贯入、2.15 倍雷暴形体、1.2 倍绘制半径和 18% 外缘延伸均为本次校准值，不是所有特效的默认参数。伤害范围覆盖应按各招式真实判定验证；层级服从招式空间关系和用户要求。后续优先复用已认可源文件、图集管线和质量检查，不为统一风格破坏已认可的冰系等其他特效。此次仅记录认可与经验，保留线上 v143 运行内容。
