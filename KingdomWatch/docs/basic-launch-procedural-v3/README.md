# 程序发射特效与盾量显示修正

用户否定上一轮发射贴图的视觉效果，本版停止加载四张 `basic_launch_v2_*` 发射图，改为自定义 Shader 实时绘制。旧资源和发布记录只留作历史，不再作为认可基线。该改动不涉及英雄动画素材、弹体美术或已接入的飞行拖尾。

- 弓箭／重弩：短促、空心的横向风压，细白光芯和两侧收尖的气流；重弩稍强。
- 火法：小范围向前的橙色热脉冲、浅黄光芯及少量余烬。
- 雷法：短分叉电弧、紫色柔边及白色细芯。
- 冰法：短霜气脉冲和小晶片。

所有发射形状、柔边、粒子运动和衰减均由程序计算；片元 Shader 不采样图片。运行时创建的 2×2 白色纹理仅用于 Cocos Sprite 的四顶点载体，不包含发射图案。动态材质实例复用固定 36 槽对象池，效果方向沿实际弹道，年龄来自战斗模拟时间。资源载入前沿用原生 Graphics 绘制回退，无逐发资源下载或 AI 调用。

发射时长分别为弓箭 0.24 秒、重弩 0.28 秒、火 0.25 秒、雷 0.22 秒、冰 0.28 秒。缩小出弹点周围的占用，取消上一版整张图案的放大。飞行拖尾、伤害、攻速、碰撞、索敌、技能和大招保持原逻辑。

同轮修正防线显示：生命仍在上、盾值仍在下、数字仍右对齐。移除固定宽度文字框，心形／盾形图标根据实际文字宽度贴到数字左侧；字体异步载入、位数变化时自动重新定位。蓝色外盾保持右端固定，受损从左向右消退，零盾不画外框，数值 0 仍显示。盾量长度继续使用盾值／最大耐久计算，绿色生命条保持不变。

按用户持续要求，只改动、构建 web-mobile、DPR 补丁及发布；不运行测试、游戏、浏览器或线上视觉验收。效果由用户人工查看，编译／发布成功不代表用户视觉认可。
