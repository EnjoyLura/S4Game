# 风与忍者纯代码特效 v123

用户明确要求按三张动态参考制作纯特效代码，风场不使用生成图片、贴图或序列帧。v122的两张风场图集、专用采样效果和WindVolumeVFX已从活动工程移出，保留本地 `local/art-archive/wind-code-v123/retired/` 与Git历史。常规人物、头像、图标与场景美术不属于本次风场素材，继续沿用。

## 造型与动态

- **风眼**：参考第二张GIF的低矮倾斜旋流。六股不同长度、半径和速度的青色宽风面卷吸，带软肩、细流纹和白青球核。由数学曲线、距离场与一个两级噪声场直接生成。
- **龙卷**：参考第一张GIF的绿色宽螺旋风带。解析求取正反锥面，按深度分前后明暗，宽风面绕转、亮流上升，边缘噪声侵蚀与柔化，底部有程序尘旋与叶片。无需图像采样或体积光线步进。
- **忍者大招**：参考第三张GIF的投掷、旋转风盘与到达后的压力展开。前摇0.45秒内增加纯表现的飞行旋刃，从真实施法手部到原密集区落点；到达后仍为原4秒持续伤害区域。四个尖角刀刃随倾斜风盘高速旋转，外围多层切风尾迹、压力罩和小球核。只有表现增加了投掷，原命中、伤害、目标、范围、持续时间及充能不变。
- **风刃普攻**：沿用v122的圆弧刀刃与瞄准方向；`windCrescent`函数逐字保护。

所有图形由原有 `HeroFxShader` 和Graphics池生成。Shader不声明图片sampler，不读取图片或帧图集；2×2纯白内存载体仅提供四边形UV。每英雄8个区域、最多2个前摇飞行事件，统一12个Shader绘制槽；开始/结束复用并隐藏槽位，战斗暂停时年龄不前进。效果保持在伤害文字下方；Shader未就绪时可用程序几何后备，单次事件固定绘制路径。

## 检查与预览

- `check_code.cjs` / `code-check.json`：16组静态和隔离实际绘图检查；337份旧文件与35个英雄方法受保护，允许的英雄改动仅为等价手部定位封装、效果构造参数清理、前摇表现调用。覆盖纯代码约束、图片路径移除、池上限、事件过期、图形有限值与风刃原函数。
- `audit_types.cjs` / `typecheck-comparison.json`：9项既有UI诊断，无新增；基线解析时也提供已删除的旧模块，避免把缺文件误算成原诊断。
- `make_preview.cjs`：只运行真实VFX绘图类，使用惰性节点/材质替身采集360个表现帧；无引擎和伤害模拟。可再生成的大型几何记录存本地忽略目录。
- `render_gpu.py` / `gpu-review.json`：实际片元程序离屏编译，在森林与原有怪物美术上合成270帧，含完整前摇飞行→落点旋转演示。核对五种模式的有限值、透明覆盖、零强度归零、无sampler、四向风刃。背景和怪物图片仅用于美术摆放检查，不参与特效生成。
- `energy-review.webp`、`ninja-launch.webp`、`gpu-contact-sheet.jpg`：离屏素材合成预览，不是运行游戏的录像。

不启动游戏、浏览器、实战场景、音频或WASM；手机最终观感与性能待用户试玩。当前发布会清理上一版运行文件，以移除弃用风场图集；浏览器可能仍保有自己的历史缓存，但新版本不引用它们。构建、包体验证和发布回执在交付时补充。本地提交源码，仅发布独立GitHub Pages运行仓库，不推送源码、不部署Cloudflare。
