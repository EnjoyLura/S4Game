# 苦工纯代码行走 v2：颈部与腋下接缝修复

2026-10-20。用户认可 v1 的整体动作，指出脖子与腋下有空隙。本版只修复这些接缝，原图、步幅、抬脚、换重心、摆臂、武器跟随、32 帧与 1.28 秒循环均保持。v1 独立保留。

## 交付

- `goblin-code-walk.gif`：640×640，32 帧，每帧 40ms，循环播放。
- `goblin-code-walk-frames.zip`：32 张透明 PNG、5120×2560 的 8×4 图集、帧时序与矩形 JSON。
- `seams-before-after.jpg`：第 0/8/16/24 帧上半身放大对照，左为 v1、右为 v2。
- `animate.py`：完整源码，Python + Pillow + NumPy；仍使用同一张旧静态图，没有新图片或视频生成。

原脚本按切口互补分割，部件相对转动时会露出底色。v2 在颈部、两侧肩根与腋下增加连续纹理底片：沿切口取原图纹理，使用共享顶点的 16px 三角网格，在头部/躯干、上臂/躯干两个变换间平滑过渡。底片画在原有部件下，避开透明外轮廓；现有脸部、衣服和武器仍由原部件绘制。

已查看修复后的整体静帧及四个阶段放大对比；GIF 实际帧数 32、总时长 1280ms。修订版的实际运动观感仍由用户查看。本轮仅本地动画资产制作，没有改游戏、构建或发布，没有 Git 提交。

## 后续批量方法

可复用的是步态时序、层级变换、接缝补片、透明帧与图集导出。每只怪物仍需按实际形象校准部件蒙版、关节、前后遮挡和运动幅度，不是把所有怪物套同一组像素坐标。

优先用双足、四肢分离清楚的原图批量试做；体型差异通过步幅、重心和手持物惯性区分。四足和飞行需要各自的步态模板，本轮没有制作或验证。被武器或衣物大面积遮住的关节需单独补底，不能自动承诺从单张图恢复不可见结构。

重建：在项目根目录运行 `python docs/code-monster-walk-v2/animate.py`。原图位置为 `docs/goblin-worker-reference-style-v1/goblin-worker-front-blue-v1.png`。
