# 战斗奖励面板渐隐双线 v20

暂停、胜利、失败共用 `BattleRewardPanel`：连续 alpha 的两端渐隐深蓝灰底，上下各两条渐隐金线。上层为本局实际金币、累计经验与已发放通关材料；下层只展示本局已收入背包的装备，按定义聚合数量，沿用现有品质方框和插画。超过五类可横向滑动，点装备打开原战利品清单。无装备时不创建下层标题、分割和列表，背板缩短122单位。

暂停只读取 BattleLoot.summary() 的已拾取记录，不自动拾取地面物品、不掷骰、不发放结算材料。经验口径改为本局累计，与胜败一致，避免把选卡后的经验余量当成总收获。胜败结算仍由原 collectAll/grantStageMaterials 入账；广告仍只双倍金币。原皇冠、星级、逐项数字滚动、音效、复活/重试/下一关/返回、伤害和设置页保留。

用户随后补充升级提示拥挤、背板透明度不够。本轮一起调整成长提示：主行保留真实原值→新值和完整增量；攻击/技能等次要属性改成一行两列增量，完整前后值仍在页面属性面板。普通两项属性提示从278高收至208高，增加字号层级间的留白，背景alpha从98.5%降至68%，用字描边保证可读；长按累计与连续追赶、突破提示、中部上移、原音效保持。三项以上增量自动换行，不截断。

本轮六个原脚本：Panels、SettlementPanelSkin、BattleLoot、BattleDirector、PositiveFeedback、FeedbackSurface；新增纯绘制工具 BattleRewardPanel（无注册组件）及唯一 meta。其他111个原脚本用散列审阅，不改媒体、数值或存档结构。当前用户要求授权奖励区重排，其他战斗弹窗约束继续适用。普通Toast未改。
