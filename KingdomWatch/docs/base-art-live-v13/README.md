# 基地整套美术、关卡名牌与 Toast v13

按 [基地效果稿](../base-art-concept-v13/README.md) 实装。原插画与数据继续使用现有资源，新增表现使用原生 Graphics；未启动游戏或浏览器，实际画面和交互由用户人工确认。

本轮完成：

1. 关卡名牌从相对 Y=-86 调到 -76，上移10个设计单位，缩小与星星的间隙。
2. 全局 Toast 改为78%深色半透明圆角底加浅色文字；从物理屏幕下方约24单位处在280ms内滑入，停留约1.8–2.3秒后320ms淡出。去掉图标、边条、进度线和光屑；文字自动换行，同对象连续升级仍合并真实等级与属性增量，支持减少动态效果。
3. 基地主页：营地标题与建筑细金深蓝名牌、主城金色牌、锁定工坊牌、研究院奖励红点；底部浅纸建设栏、顶部分割和整组浅白属性。
4. 主城建设：通用商品详情纸面、内收深蓝标题、原关闭X；主城展示、当前与下级耐久/护盾对比、真实增量、建设消耗/持有分列及不足红字；固定底部操作。
5. 研究院图鉴：真实发现进度、奖励概览、两列六张浅白细框卡、浅圆原怪物插画、剪影/锁/问号、待领红点与已领勾标；短屏可滚动并保留列表位置。
6. 普通怪物和BOSS详情：复用相同通用弹窗；原怪物、真实名称与标签，行动特征/描述/弱点三组浅白底，奖励说明和原绿色/灰绿按钮；按钮下留30单位纸面。

连续庭院、建筑点击锚点与滚动同步、底部固定建设区、资源栏和原导航选中保持。升级仍调用 `growthAction` 包裹 `upKeep`；图鉴仍用 `codexUnlocked` / `codexClaimed` / `claimCodexReward`，每种一次20钻石；数据公式、上限、存档与返回时单遮罩会话保持。

仅修改原 `CampaignRoute.ts` / `UINotice.ts` / `BasePage.ts`，新增 `BaseChrome.ts`。静态类型审阅仍为原九项诊断，本轮模块无诊断；构建与发布记录见本目录。没有运行测试、模拟、游戏、浏览器、试听或线上验收，也没有 Git 提交。

`before/` 与 `source-baseline.json` 保留改动前源码及110份原脚本散列；`release.py` 只读取源码、构建文件与发布回执，不执行游戏。
