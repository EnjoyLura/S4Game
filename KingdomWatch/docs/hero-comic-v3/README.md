# 英雄页 · 清爽漫画奇幻 v3

2026-10-11。根据用户对 v2 的反馈调整：恢复结构性背板，场景改用商店同款冷暖和前后层次，重做切换和战力资源，放大手机上的属性、故事入口。

## 恢复与保留

英雄选择恢复 126×114 的方形切角卡，选中金色、未选米色，卡内头像保持正圆裁切。武器、装备、材料分类恢复深色未选、金色选中的切角页签。装备整栏恢复米色背板，武器与四个穿戴槽也恢复实色小底板，文字使用深色以保证对比度。

保留用户已要求的页面标题移除、名称无底牌、上半部独立背景、下半部全宽纯色背包、空分类只显示居中说明，不再绘制空物品槽。

新展示背景直接参照 [已批准的商店场景](../../assets/resources/scenes/bg_shop_comic_v1.jpg)：暖木梁和墙板、中景砂岩、蓝旗、冷色窗外天空与城堡、前景地砖及低圆石台。避免单一灰绿空墙。角色立绘未替换；石台顶面中心 `(u=.326,v=.815)` 与脚底对齐，缩放与裁切仍由运行时补偿。

切换资源改为完整圆石质按钮与金色直角箭头；战力资源改为深色金边盾牌底板，数字由代码绘制。属性和故事按钮增加深色底板，由 116×50 放大到 126×86，图标 34→46，文字 20→26。

## 资源与提示词

使用内置 Imagegen：一张新场景、一个左切换按钮（右侧在运行时镜像）、一个战力底板。场景另做一次仅缩小站台的编辑。图标延续 [商店风格参考](../shop-comic-v1/style-reference.png)。整理仅做透明边距裁切、同比缩放和 Creator 元数据导入，不进行图形变形或补绘。

- [generation.json](generation.json)：实际完整提示词、参考、原图路径和场景编辑记录。
- [sources](sources/)：生成原图工作副本，默认生成目录原文件保留。
- [assets.json](assets.json)：三张生产文件及对应原图；合计 547,127 字节。
- [asset-contact-sheet.jpg](asset-contact-sheet.jpg)：新按钮和战力底板合成预览。
- [hero-main.png](hero-main.png)、[hero-small.png](hero-small.png)、[hero-empty-equip.png](hero-empty-equip.png)：实际页面预览。

生产背景位于 `assets/resources/scenes/bg_heroes_comic_v3.jpg`，两个透明控件位于 `assets/resources/ux/hero_comic_v3/`。五名立绘、卡内头像、物品、背包/属性/故事/强化图标继续复用同风格素材。

## 验证

只验证主界面并使用隔离存档，不进入真实战斗。检查恢复后的卡片、分类颜色、装备背板、加大入口、站台脚底对齐、五英雄选择与左右切换、背包滚动与已穿戴过滤、属性/故事/换装/强化/出售/分解功能、资源不足和满级保护、三种纯文字空背包及两种手机尺寸。商店使用原检查脚本回归。

通过 TypeScript、Creator 3.8.8 web-mobile 构建及 DPR 补丁后发布 Pages main；`verify_release.py` 核验线上入口、主脚本、资源配置、DPR 引擎及 37 张新旧漫画生产素材。结果保存到 `ui-validation.json` 与 `deployment-validation.json`。
