# 商店按钮还原与词条简化 v4

按用户本轮截图调整`ShopPage.ts`和`LobbyChrome.ts`；工作中追加的`MainUI.ts`底部导航选中态还原，以及BGM和音效各提高1 dB也包含在本次发布。

- 商品详情右上关闭恢复`comicDialog`自带的44×44深蓝单层按钮；底部关闭与购买恢复原`comicButton`样式、248×58尺寸和24字号。移除这三处新增的多层斜面绘制。
- 商店四个分类页签恢复原有的单层深色/金色面，不再绘制多层选中斜面，分类图标、文字、选中与切换逻辑保持。
- 弹窗两条横向分割线改为不透明金棕色、1.8粗线，保留中心菱形。共用导航和分类条的分隔适度加深，外围透明度由0.075调至0.22。
- 底部导航选中态恢复上一轮改版前的126×104圆角纯金色底和原图标配色，移除多层金边斜面，保留分割线。
- 初始属性、武器特性、持有情况的单行底板及浅色分组垫底全部移除，词条直接在纸面排字。保留原行距、分组标题与绿色加成数字。

暖纸主框、深蓝标题栏、商品展示、商品卡片、方形品质槽、商店价格按钮和固定购买区沿用上一版。预览数据和购买处理函数保持相同；其他原脚本的散列保持，不修改数值、奖励、存档或解锁规则，不新增运行素材，不额外Git提交。

`GameAudio.ts`的共享增益在上一版√2基础上额外乘以`10^(1/20)`，即约1.122018倍，使营地BGM、战斗BGM、界面和战斗音效相对当前版本各提高1 dB。初始化与设置刷新继续共用同一常量，静音、曲目、原始音频、淡入淡出、暂停压低、重要音效避让、声部预算和输出压缩器保持。不运行试听，实际听感由用户确认。

`before/`及`source-baseline.json`记录本轮前源文件与脚本散列。`release.py inspect`只读取源码、类型日志与本地编译产物，不执行游戏代码。项目此前十项主类型诊断仍在，本轮改动模块无新增诊断。
