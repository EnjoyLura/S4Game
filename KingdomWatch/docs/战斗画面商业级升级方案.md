版本：2026-10-07。方向已经用户确认：保留魔幻题材，以《王国保卫战》的手绘质感、清晰轮廓和战斗可读性为视觉目标，使用原创角色与素材。

## 2. 截图诊断与视觉原则

《向僵尸开炮》的截图适合参考竖屏防线玩法与战场信息密度。单张静态图只能评价布局、颜色、素材和遮挡，无法据此判断它的实际帧率、动画或声音质量。当前项目的问题由代码和运行画面单独确认。

截图里的主要视觉负担：顶栏与横幅占用战场；侧边按钮与战场相互挤压；伤害数字在防线前重叠；人物与地面缺少明确接触关系；大面积技能色块覆盖敌人。对应的解决顺序是先确立焦点和角色轮廓，再补动作与事件节奏，最后精修材质和环境。

视觉风格约束：

- 手绘厚涂与简化卡通体块：远看先认轮廓、职业与动作，近看再读材质细节。小怪弱化纹理频率，大怪保留大块护甲和武器。
- 主光统一从左上落下；阴影低饱和暖褐；边缘少量冷色高光。场景整体明度低于英雄/重要目标，发光只留给关键反馈。
- 背景中央约 65% 宽度保持低对比行军区，装饰集中在两侧。草叶、碎石、箭矢与旗帜避免堆在角色头部。
- 木材、岩石、皮革、羊皮纸作为基础材质。沿用简洁无装饰外框的 UI 方向，避免整屏金边、厚背板与每个小按钮都发光。
- 敌人朝屏幕下方；防线英雄背身朝上。视觉动画动美术子节点，碰撞/索敌原点保持稳定。

建议色板：森林 #556237 / 土路 #AF8A4B / 深墨 #30261B / 羊皮纸 #E9DFC2 / 金 #EFC666 / 经验青 #6CBCC6。元素：弓金绿、弩冰蓝、火橙、雷紫、冰青白。危险预告使用红橙，治疗用柔和绿，避免和冰控制的青蓝混淆。

## 3. 战斗 UI 与场景层次

工程设计宽度是 750，实际高度随竖屏比例变化。顶栏相对安全区定位，防线继续贴物理底边。本轮顶栏暂停/波次起始位置从距顶 105 收到 24，经验条从 184 收到 100；这样可把更多空间还给怪群。

| 层级 | 信息 | 布局/表现要求 |
|---|---|---|
| 常驻第一层 | 关卡、波次、耐久、大招可用性 | 一眼可读；深浅对比稳定；不靠颜色一种方式表达状态 |
| 常驻第二层 | 时间、经验、技能冷却、倍速 | 字号低于关卡与波次；冷却只显示必要倒计时 |
| 短时提示 | 增援、新敌人、技能就绪 | 先后排队，1–2 秒内退出；避免同时间多个横幅叠加 |
| 调试 | FPS、GM | FPS 用 ?perf=1 或 ?gm=1 显示；GM 保留原有 debug/?gm=1 入口，发行时关闭 debug |

大招保留右侧单列，便于拇指点击；英雄脚下的普攻/技能图标保持现有位置。后续针对四英雄小屏测试命中区域是否互相压迫，必要时减小视觉图标、保留较大的透明点击区。大招就绪仅强化该按钮，其他按钮保持静态。

当前渲染顺序：场景底色 → 场景贴图 → 边缘环境动效 → 防线 → 怪物阴影/怪物 → 英雄 → 弹道 → 命中特效 → 飘字 → HUD → 弹窗。下一步把技能地面印记独立到怪物下方，避免冻圈、陨石坑覆盖角色主体。

场景精修制作规格：每关一份 1152×2048 或更高的母稿，再拆远景、土路、两侧植被、前景遮挡和环境动效。以 750 宽进行真实游戏尺寸验收，确认背景细纹理不会和箭羽/伤害数字混在一起。背景超出可视区做 cover 裁切，关键地标避开上下 UI。

防线需要完整、轻损、重损三态。耐久小于 30% 时用缺口、落石和局部红色提示；修复先亮起短促暖色脉冲，再恢复。对当前已存在的防线位置和判定规则不作重写。

## 4. 英雄建模与动画制作路线

目标是立体可读的角色。推荐以 2D 分层手绘 + Spine 为主，必要时用 3D 灰模辅助统一体积与镜头，再转成与场景一致的手绘拆件。当前正交竖屏视角下，先把轮廓、动作、光照统一，可以更直接地改善效果；是否使用实时 3D，应在美术样板和手机预算验证后决定。

五位英雄的辨识符：艾拉的金发/绿披风/长弓；凯尔的深蓝披风/宽弩；焰的红发/橙色杖头；沃尔的银发/紫袍；莫拉的冰蓝长发/白毛肩/晶杖。普攻姿态变化重点在肩、肘、武器和躯干，披风负责少量跟随动势。

下一批每英雄需要：分层源文件 1 份，待机、普攻、技能、大招四套动作。拆件至少包括头发、头、身体、双上臂/前臂、武器、披风、双腿；手与武器有稳定的发射挂点。待机 2–3 秒循环，普攻约 0.35–0.65 秒，技能约 0.6–1 秒，大招约 0.8–1.4 秒。数值的发射时刻独立定义，动作要围绕实际发射事件匹配，避免动画很长却已经提前扣血。

| 单位 | 最小完整动画清单 | 动作重点 |
|---|---|---|
| 苦工/投石手 | 行走、待攻、攻击、死亡 | 双脚真实交替；武器前摇明确；投石手的松手帧对上石块出生 |
| 萨满 | 行走、施法、攻击、死亡 | 法杖与治疗脉冲挂点；治疗状态可被看懂 |
| 狼骑 | 奔跑、跃击、死亡 | 狼前后腿节奏、骑手跟随弹性，速度感来自步幅 |
| 精英 | 行走、重击蓄力、落锤、死亡 | 大块体积、较长可辨前摇、局部土尘 |
| 预留王 | 入场、行走、普攻、技能、死亡 | 单独头目血条与技能预警，不只放大普通怪 |

受击维持当前约定：只给视觉闪红，不额外击退、停步或减速。冻结/眩晕/减速仍由相应技能效果控制。角色死亡可增加视觉下沉/倾倒与短暂残影，及时清理尸体，避免防线前遮挡。

Spine 导出版本须先和项目内 3.8.8 的运行时对照，再提交最小动作样本验证。缓存模式和合批不是所有动画通用的免费优化，需要按数量、换装、混合动作与平台测试选择。[Cocos Spine 官方说明](https://docs.cocos.com/creator/3.8/manual/en/editor/components/spine.html)

## 5. 特效、打击感与爽感

每个攻击是一条能被读懂的事件链：发力/短预备 → 发射 → 有方向的飞行 → 命中亮芯 → 碎屑/余波 → 迅速退出。普通攻击短而清楚，大招有更强的形状与节奏。画面大部分时间应能看见敌人和防线。

| 攻击 | 视觉语言 | 声音/反馈 | 退出方式 |
|---|---|---|---|
| 弓普攻 | 尖锐箭头、细暖色尾迹、沿入射方向的短火花 | 每排出弓同步弦响 + 短命中音 | 命中效果约 0.12 秒消散 |
| 重弩 | 粗一些的钢蓝箭矢、瞬时亮点 | 上弩/释放的机械质感；重命中更低沉 | 拖尾快速收短 |
| 火球/陨石 | 白黄内芯、橙色外焰、少量暗烟和地面焦痕 | 低频爆点 + 短破裂声 | 火焰快退，烟/焦痕慢退 |
| 连锁闪电 | 有分叉的细紫电弧、接点亮芯 | 短电流裂响 | 先亮后断，不保留持续满屏线网 |
| 冰晶/新星 | 细长晶面、少量青白碎屑、薄地面霜纹 | 清脆晶体声 + 轻空气声 | 冰环透明衰减，霜盘低透明融化 |
| 大招 | 角色局部发力，分批落点，局部强命中；战场和镜头不震动 | 预备声 → 爆点 → 短尾音 | 冰系无闪屏，仅细冰雨、目标碎冰与一道淡波纹 |

本轮已把普通命中和重命中统一接入 ImpactFX：普通约 0.12 秒、重击约 0.22 秒、施放亮点约 0.16 秒、陨石局部爆点约 0.28 秒，最多 32 个同时存在。普通命中取消扩散圆环；箭/弩沿实际弹道方向形成穿透亮线，雷击形成短折线，冰击形成锐角碎片。命中碎屑约 0.14–0.24 秒退出，陨石保留暗色贴地尘环和短亮芯，避免大光圈铺满伤害范围。

微顿帧缩短到约 32ms，间隔至少 650ms，仅重命中、重弩暴击和精英击杀触发。普通暴击和普通击杀不再让全场频繁慢下来。按用户要求完全移除大招战场震动；力量感由出手动作、方向、命中爆点与声音产生。英雄以脚底为轴快速发力、指数收势，不滑步、不弹性拉伸；重弩大招在锁定完成后的实际发射时刻发力，并取消尚未飞到目标时的提前命中火花。

普通伤害字 27、暴击 40、灼烧 21；普通与持续伤害用白色，暴击用红色。采用厚实斜体数字与硬阴影：32–35ms 撑开，落定后保持全不透明、不横漂不上浮，最后 90–130ms 向下压缩退场；总长分别约 0.41/0.50/0.25 秒。总量 30，普通字达到 24 个时给暴击预留余量。保留 75ms 同目标同类伤害合并和空间避让，合并时补小脉冲、不续命；漫画击杀词沿用事件/概率。具体分段、动态演示与回归见 [字体与战斗飘字规范](字体与战斗飘字规范.md)。

爽感节奏建议：低强度行军段让玩家读卡片收益；中强度群战突出穿透/连锁的传播方向；重击时只突出一个爆点；清场短暂回到安静状态。用场景明度、声音留白与敌人动作承接节奏，不让所有技能同等亮、同等响。

## 6. 音频制作与混音

当前素材目录没有最终音频，本轮仍是 WebAudio 合成，但已经提供职业区分、重点事件让位与合成通道压缩。专业样本可以按下列名字放进 assets/resources/audio，服务会优先加载。样本播放还需要统一响度与实测混音，不能假定它们自动经过合成通道的压缩器。

| 资源前缀 | 建议数量 | 内容/规格 |
|---|---:|---|
| sfx_bow / sfx_crossbow | 各 3 变体 | 弦、机械、空气；0.08–0.25 秒，避免刺耳尖峰 |
| sfx_fire / sfx_thunder / sfx_frost | 各 3 变体 | 约 0.1–0.35 秒；不同频段与包络 |
| sfx_hit / sfx_crit / sfx_kill | 各 3 变体 | 普通软、暴击硬、死亡短；不使用同一声音简单加大音量 |
| sfx_pierce / sfx_crush / sfx_zap_hit / sfx_icebreak | 各 3 变体 | 重弩穿透、火焰闷击、电击裂响、冰晶破碎；快起音、中频实体感、短尾音 |
| sfx_skill / sfx_ult / sfx_snipe | 各 2–3 变体 | 前摇/爆点/尾音分层；重点事件优先 |
| sfx_wall / sfx_surge / sfx_ready / sfx_levelup / sfx_victory | 各 1–2 | 防线木石冲击、增援提示、就绪、升级、胜利 |
| amb_forest / amb_battle | 各 1 循环 | 鸟鸣/风叶低占比，战斗中不能盖住危险提示 |
| bgm_battle / bgm_boss | 各 1 循环 | 原创魔幻管弦节奏，40–90 秒无缝循环，验证音乐开关与跨关卡生命周期 |

母带交付 48kHz WAV，游戏导出兼容 H5 的压缩格式并在目标浏览器验证。短效果尽量单声道，音乐与环境可立体声。高频攻击有随机音高/变体，声音数超预算时先丢弃重复普攻，保留技能、危机和升级提示。

验收分别用手机扬声器、普通耳机、静音开关、首次触控解锁、切后台再回来测试。BGM 与环境音尚未在本轮接入。

## 7. 资源、性能与制作顺序

本轮资源：

- ux/battle_mobs_v2.png：1536×1024，6 帧；前 5 种已经在关卡使用。
- ux/battle_heroes_v2.png：1920×768，10 帧，五位英雄各两姿态。
- 两份 .frames.json 保存精确矩形，BattleSprite 用共享纹理创建精灵帧。
- 原始生图及完整提示词归档在美术/原图/批次17_战斗品质_2026-10-07。
- tools/pack-battle-art.cjs 根据透明连通区域分离角色、保留抗锯齿边缘并重排图集，避免生成网格偏移导致切坏角色。

图集约占 11.6MiB 未压缩 RGBA 纹理内存，不包含旧场景/图标和引擎缓冲；文件压缩体积与显存开销需要分别管理。怪物当前管理器上限 60，弹道上限 80，粒子 90，命中特效 32，飘字 30。低档可以先降低环境、余波和装饰粒子，保留危险预警、目标轮廓、弹道和耐久信息。

共享贴图只是合批的条件之一；渲染顺序、材质和遮罩也会打断批次。本轮将怪物接触阴影集中到单独 Graphics，避免每个角色的阴影插在精灵之间。后续按真实 Draw Call、GPU 用时和内存验证，不能只看贴图文件数量。[Cocos 2D 合批官方说明](https://docs.cocos.com/creator/3.8/manual/en/ui-system/components/engine/ui-batch.html)

制作关卡样板的顺序：

1. **第一批已实现**：角色图集、两姿态、阴影与排序、收拢 HUD、命中/飘字、大招反馈、职业音效区分。
2. **动画样板**：先把艾拉和苦工做完整动作，确认镜头、身体比例、发射点和动作事件，再推广到其他英雄/怪物；不同时铺开所有拆件。
3. **元素样板**：依次精修火、雷、冰的预告/弹体/命中/消散；每做一个都检查四英雄并发；地面痕迹与角色分层。
4. **场景与界面精修**：三个场景拆层、前景、环境循环、破损防线、危机提示，校正小屏上的图标/文本。
5. **音频最终化**：制作/选择原创声音与音乐，接入随机样本和统一混音，同时测试手机扬声器。
6. **发行验收**：目标手机的帧率、热量、内存、后台恢复、不同 DPI、完整通关流程和首屏资源加载。

每批都需要交付能运行的完整战斗片段，包含平静、群战、大招、升级、危机和清场六个状态；单张美术图与截图不能代替整段战斗验收。

## 8. 验收标准与回归入口

| 项目 | 目标 | 本轮验证边界 |
|---|---|---|
| 可读性 | 常规群战能分辨所有职业/怪种；大招期间仍能辨认敌人；数字不长期盖住防线 | 两种手机尺寸的引擎截图、各类角色加载和元素并发检查 |
| 动画 | 发射、受击、死亡事件准确；脚底不滑；攻击中武器不穿身 | 两姿态与视觉变换已接入；连续骨骼动画待制作 |
| UI | 顶部安全区正确；四英雄图标可点；不同冷却/充能状态可辨 | 手机浏览器视口测试；真机触控和刘海区域待验 |
| 性能 | 中档真机争取稳定 60fps；低档 30fps；群战不持续恶化 | 类型检查、构建、桌面浏览器回归；手机 GPU/温度未实测 |
| 音频 | 不失真、不糊成一团；危机与大招可听懂；音乐/音效开关有效 | 原有开关与合成声音路径；专业样本与最终混音待验 |
| 打击反馈 | 大招期间战场固定、无冰系闪屏；攻击动作跟随实际发射；致命命中仍有爆炸传播 | 两编队覆盖五位英雄大招；逐帧记录战场位移为 0；30fps 重击短顿后恢复；致命爆炸实测邻近目标受伤且显示局部爆点 |
| 字体 | 中文标题/正文、直立 HUD 数字与斜体伤害字形成层级；连击不堆叠 | 两视口加载五类字体；125+175 合并为 300，暴击/灼烧/其他目标独立；中英拟声词与字池复用通过 |
| 生命周期 | 暂停冻结；怪物回池重用不残留颜色/角度；切换场景后资源可复用 | tools/battle-smoke.cjs 检查加载、暂停、施放与怪物回池 |

本地构建：Creator 3.8.8 web-mobile 构建完成后运行 tools/patch-web-dpr.py，再通过本地 HTTP 服务预览。回归脚本使用独立的临时浏览器环境，不读写玩家平时的浏览器存档。
