## 进入关卡

`BattleEntry.configure` 在进入战斗方向保持当前音乐。战斗场景可以在门后初始化及预载音乐，`startMusic` 的入口和解码完成回调均检查过渡等待标记，期间不启动新战斗曲目或改变场景音乐音量。音乐关闭不受等待影响。

`BattleEntry.finish` 在关门、闭门停留、开门显露全部完成后解除等待。需要换曲时沿用 v29 的 1.6 秒交叉淡入淡出；主界面与战斗使用同一曲目时保持进度，用 1 秒渐变到战斗音量。没有用估算时长的定时器。失败后的退回动画结束和过渡节点销毁也会解除等待，减少动态模式沿用实际完成回调。

仅调整三个运行脚本：`AudioCatalog.ts`、`GameAudio.ts`、`BattleEntry.ts`。未改关门动画、门声或战斗规则。
