# 空间禁锢光柱与五岳天剑 v128

按用户本轮设计重做两英雄的能力形态；其余英雄、炮弹穿透、战斗规则和既有角色立绘保持。

空间法师「禁界光柱」：优先选择靠近防线、处于可视战场的最多6名敌人，立即以紫色光球禁锢，经过0.6秒大招准备和0.35秒聚能后，从原落点地底喷出光柱。光柱持续3秒、等间隔10次范围法伤，基础每次技能倍率48%，每柱基础半径105；重叠光柱对同一敌人每次只结算一次，目标死亡后落点仍持续冲击后来进入的敌人。首领免疫禁锢，仍承受范围伤害；可对空。10级目标数增至8，5级范围+20%，15级充能-10%，20级伤害+20%。原技能「空间放逐」仍为4目标向上瞬移；光柱期间暂缓本英雄自动传送，避免把禁锢目标移出光柱。

空间禁锢独立于冰冻/眩晕，不复用冰冻图像；阻止移动、攻击、施法和击退，已有持续伤害正常结算。出生、死亡、对象复用清零，光球核验 lifeId 后才跟随，避免套在复用后的怪物身上。控制与特效共用战斗时间，暂停/倍速沿用现有流程。

御剑师原大招剑阵移到技能「万剑归宗」：密集处12柄落剑，加消耗的剑意（最多6），最后追加终结剑。基础每剑技能倍率35%、终结140%、剑阵半径155；10级落剑+3，15级范围+15%，保留5级减冷却和20级伤害。普攻命中攒剑意规则不变。技能不发大招镜头事件。

新大招「五岳天剑」：固定四柄斜向巨剑，按左、后、右、前依次落下，最后中央垂直巨剑重击。前四剑基础每柄135%技能倍率、半径240；中央420%、半径320。落点按屏幕边界限制，使用已存在的 groundTarget 落地结算，不被途中怪物提前截住；全部可对空。5级范围+15%，10级四方剑伤+15%，15级充能-10%，20级全部伤害+20%。箭雨与天剑的时序/选点来自共享纯函数。

特效为纯代码：解析球壳、晶格流光、向上平流的光柱、底部脉冲、实体银白玉色巨剑、能量尾迹、落地震波/裂纹/飞屑。新 Shader 仅数学噪声，无图片或纹理采样；载体为既有2×2白色内存纹理，ONE/ONE混合且 alpha 始终0，不会出现黑色半透明方板。每位相关英雄战前预热16个绘制槽，最高8球+8柱；退出时释放。

UI图标通过内置 imagegen 生成，单张四宫格，保持圆形、无装饰外环，打包为512²共享图集与8个别名；不作为战斗特效纹理。正式资源 `assets/resources/ux/space_sword_v128/icons.png`，母版仅本地归档。完整提示词见 `art-prompts.json`，裁切/尺寸/UUID/SHA见 `art-manifest.json`，可重做脚本 `prepare-art.cjs`。养成里程碑、技能Tips、英雄故事和养成预览均同步，字库仅从同一已固定来源追加缺字。
