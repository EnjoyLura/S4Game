# 镰刀空间绞杀与实心卷流 v148

用户指出 v147 的裂隙立体感不足，技能中空双镰像电风扇、边界清晰、外围装饰不足。此次按“抬起倾斜、前后上下多方向凌乱切割，几十道视觉裂隙但只有九次伤害”的要求改进。维吉尔次元斩仅作为节奏与空间错切的描述参照；保留用户指定的 v144 红黑裂隙素材，不替换成 v146 的亮线方案。雷枪仍是用户认可的标杆；本版镰刀没有得到用户视觉认可。

## 最终设计

- 大招：64 道独立空间切口加 8 道终结切口，共 72 道。确定性种子控制不等间隔、位置、长度、厚度、18–64°正反俯仰、正反侧倾与任意朝向；抬升为半径的 8–68%。前后景穿插，避免所有裂隙从同一点向外放射。起刀约25毫秒，余痕快速收缩，终结前清空普通裂隙，中央主斩配合错时短斩收束。
- 精灵使用实际 `Node.setRotationFromEuler(pitch,yaw,roll)` 三轴倾斜；相伴雾丝与火星的方向按相同投影计算。原裂隙 PNG 字节不变。地面延续 v147 深暗区域；每个切口都有离散火星、暗碎屑和短暂红雾，不依赖伤害时刻生成。
- 技能：重新制作 Blender 流动暗核，中心由连续起伏的暗红卷流填满。两片短弯刃嵌入流层，内部少量热亮划痕，九片不等宽卷流、24条外甩细丝与11片散离碎屑。降低观察角度，压暗大面积主体，避免球体和空心风扇轮廓；外围另有独立移动的断续光丝与雾尾，避免只靠贴图闭合边缘。
- 仍为32帧120fps、1.8倍视觉时钟，约6.75转/秒。预热、固定池、纹理共享与模拟时钟沿用；素材分前后半幅围绕怪物，外围Shader也分前后层。
- 普攻保持 v147；伤害、真实范围、冷却、投出/停留/回收时序、英雄逻辑与雷枪均保持。`ScytheRiftVolume` 只决定表现，不读取伤害次数；实际9次结算及最后双倍不变。持续授权仅本地提交源码、发布独立 GitHub Pages 运行包。

## 制作与验证

`build_vortex.py` / `scythe-vortex.blend`：Blender 5.2.3 LTS，896²渲染、448²动画单元。`pack_layers.py` 从热亮部分产生柔光，固定锚点、透明边缘、straight RGBA，只新增 `scythe_spin_v148`；保留旧资产便于回退。

`verify.cjs` 隔离实际视觉类与英雄回调，记录650帧；200种种子/14400个姿态直接对照引擎源码中提取的两个纯数学方法，不启动引擎。最大同时存活19道（含余雾），在现有固定池容量内；绘制不逐帧创建节点。把视觉输入的 hits 从1改为999，绘制结果完全相同。实际伤害仍为9次，总倍率8.1、最后双倍；边界/越界、暂停/大步长、20级倍率与释放结束检查通过。

`render_review.py` 直接绘制实际GLSL、正式图集与记录的三轴变换，在静态战场素材上合成；9种模式63个GPU有限值/零强度透明检查。`make_previews.py` 生成动态GIF，30/40/30ms交替保留正确时长。预览见 `skill-review.gif` / `ultimate-review.gif`，完整MP4和接触表同目录。

贴防线选敌回归：288次实际施放回调、300组普通集群保持；TypeScript仍为原有9条诊断，无新增。没有启动游戏、浏览器、真实战斗、音频或WASM；离屏渲染不等于手机实战验收。构建、包体和发布回执完成后补入本目录。
