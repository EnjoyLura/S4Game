# 原地爆散死亡 v2

用户明确否定上一版整张怪物绕脚底倾倒，要求死亡时不要倒地，模仿《向僵尸开炮》。本次以用户提供的 `C:/Users/user/Downloads/Screenrecording_20261015_190858.mp4` 为直接视觉参考。读取其约 4 秒画面后，约 0.98–1.30 秒可见：站立目标直接消失为短促飞散的小碎块，脚下生成少量绿色残迹，残迹随后淡去。取帧记录见 `user-recording-frames.jpg`。这属于素材分析，未运行游戏或效果验收。

当前实现取消上一版的整人旋转、位移、倒地、触地停留、落地扬尘及长时间轮廓侵蚀。命中时冻结实际角色帧，保持原朝向与比例，约 25–35ms 后原地碎散：普通怪身体碎块在 190ms 内收净，精英 220ms、Boss 预留 240ms。地面残迹独立约 0.9–1.15 秒淡去，身体无需等它结束。精英通过碎散尺度和尾段区分，不恢复倒地动作。

碎块直接采样本游戏怪物当时的图集帧，保留皮肤、衣服与装备材质。单张扩展四边形内计算六块曲边分区、分离、独立小角度旋转、重力、等比缩小和渐退；不拆分创建六个精灵，也没有整人旋转。交接时完整角色与碎块四边形只显示其一，零时刻位置一致；透明边缘与 straight-alpha 合成保持。材质未就绪时固定使用原地快速渐退兜底，本次死亡不会中途改路径而闪回身体。

地面使用与怪物固定脚底一致的不规则绿色残迹，小范围曲边轮廓、少量深浅层次与外围液滴，快速出现后逐渐淡去。轮廓每次死亡确定一次，不逐帧变形，不生成圆环。火系收尾略焦暗并有短余烬；冰系偏冷、有少量冰屑；雷系使用 100ms 短残余电弧。所有元素沿用相同的原地碎散核心节奏，颜色装饰保持局部。

保留上一版已分离的死亡演出列表、模拟时钟、64 演出上限、节点与材质复用、暂停／三选一冻结、结算后仅完成尾段，以及退出时清理脱离场景的节点。致命命中仍立即结算伤害、金币、经验和充能；死亡对象不参与索敌、碰撞、分离或波次阻塞。音效继续沿用已有授权命中／击杀采样。本次未生成或复制其他游戏素材，也未调用付费媒体。
