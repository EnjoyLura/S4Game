# 商店卡片价格按钮还原 v5

用户指出上一版只恢复了商品详情购买按钮，商品卡片下方的价格按钮仍有多重斜面。本轮补齐所有商店分类共用`drawCard`的金币/钻石价格按钮。

恢复原`ComicUI`绿色单层切角面、单轮廓和顶部细高光，尺寸回到192×48；删除`paintLobbyFace`覆盖绘制及已无调用的绘制器和色板。按钮代码与美术改版前快照逐段比对，除保留当前商品卡的垂直位置外相同。货币图标、价格、字号、状态和打开详情的点击处理保持。

本轮仅修改`ShopPage.ts`及`LobbyChrome.ts`。商品卡、方形品质槽、商品详情、上一版还原的分类和导航选中、加深分割线、去除词条底板以及BGM/音效各增加1 dB全部保留。其他原脚本散列保持，预览与实际购买事务原函数相同；不修改数值、奖励、存档，不新增素材或Git提交。

`before/`和`source-baseline.json`记录本轮前源码。静态类型诊断与上一版相同，保留此前十项主诊断，改动模块无新增诊断。`release.py inspect`仅比对源码、类型日志和本地编译产物，不执行游戏代码。

构建流程为Cocos production/MD5、DPR补丁、production缓存准备及Wrangler main发布，记录部署和文件散列。遵循用户人工验收要求，不运行测试、模拟、游戏、浏览器或线上验收，视觉效果由用户确认。
