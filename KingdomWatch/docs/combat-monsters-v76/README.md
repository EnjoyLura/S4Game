# 怪物抗性、配合与战斗反馈 v76

本版落实用户要求的怪物优化，并处理本轮试玩追加的碎甲标记、点击查看怪物、穿透命中、火球数量和灼烧时序反馈。全部沿用现有怪物和英雄素材，新增反馈由代码绘制。

## 怪物规则

- 铠甲类以物抗为主，法师、灵体类以法抗为主，按实际怪物逐项配置，不依赖名称猜测。新配置的物抗为 25%～35%，原大哥布林 40% 物抗保留；法抗为 35%。本版没有同时配置两种常驻抗性的怪物。
- 物理伤害累计击破护甲，魔法伤害累计击破符盾。阈值默认最大生命的 30% 原始对应伤害，原有特殊破甲比例保留；破坏后该抗性不再恢复，并沿用 15%、3 秒易伤和同类取较高值规则。穿透增加命中目标数，不等于无视防御。
- 有对应抗性的防御姿态只减免该类伤害，破甲/破盾后相应姿态失效。点击说明显示的是当前有效抗性，包含姿态变化。
- 哥布林萨满基础生命 240→600，六种扩展治疗者基础生命 320→640。普通第一章指定治疗波次使用更高的手工血量：1-4 为 1800、1-5 为 2200、1-6 两波为 2400/2800。
- 治疗每轮间隔 4 秒、准备 1.2 秒，最多为附近三名非治疗伤员各回复其最大生命的 4%，单次每目标上限为施法者最大生命的 20%。不治疗自己或其他治疗者，同一受益目标有 4 秒同类支援间隔；优先支援本组前排，再处理低生命比例伤员。
- 治疗准备会短暂停步，冰封、眩晕取消本次治疗并重置治疗冷却。控制同样清除待发攻击和本次冲锋的撞线强化；减速继续只影响行进。

普通 1-4～1-6 的少数指定波次加入「前排护送治疗」：同一出生区域，前排先到、治疗在后，支援保持约 140 距离，前排死亡后解除约束。最多两组，不增加寻路或蛇形移动。四个波次各用一名重甲替换一名普通哥布林，关卡总怪数保持。1-6 末波投手与骑兵分两侧，骑兵比首名投手至少晚 6 秒、相互错开至少 3 秒。

## 看得见的状态与点击说明

破甲后头顶持续显示碎裂盾牌，破盾后显示断裂符文，位置紧贴头顶，无黑色背板。职责图标、治疗准备、治疗连线、破盾碎片、打断和灼烧小火光共用有上限的反馈池，没有新增图片、音频或视频。

点击场上的怪物可打开一张小型实时说明，显示名称、普通/精英/首领及机制标签、当前生命、物抗、法抗、破甲/破盾和灼烧/减速/冰封/眩晕等状态，以及对应的应对提示。说明不暂停战斗，随选中怪物移动和更新；再次点击、点击空地或关闭按钮收起，怪物死亡、回收或进入选卡/结算等状态时自动关闭。HUD、掉落和弹窗按钮仍在点击层上方。

## 本轮修复

- 重弩手原「普攻和技能穿透 +1」卡改为只增加技能穿透，卡片 ID、图标、前置和上限保留。
- 穿透原来仍经过普通伤害、受击闪光、音效和词条入口，但每步只找一个目标，且按怪物列表顺序命中。本版改为有限线段扫掠，按飞行先后处理同一步的所有命中，按出生编号去重；每个接触仍走原命中入口。原 8ms 相近受击声音合并策略保留，听感仍待实机确认。
- 火球 +1 卡原已写入数量，但同起点同时发射容易重叠，弹体池满时还会丢弃发射请求。本版按实际强化后数量连续发射，间隔 0.12 秒、方向轻微展开；池满时保留待发火球，成功后才出队，容量恢复时仍错开。技能详情同步改为「连续发射」。
- 灼烧动画原独立循环约 0.6 秒，扣血每 0.5 秒，存在相位偏差。本版让身上火焰跟随实际灼烧计时，每次真实扣血触发小火光；首跳前保持较弱余焰，刷新点燃不重置相位。怪物复用时按出生编号重新附着，避免继承上一只的状态动画。原序列帧字节保留，尾跳加浮点容差以避免漏掉完整的最后一次扣血。

沿用末次击杀后至少两秒真实时间的胜利收尾以及原奖励/双倍/复活/存档代码。
