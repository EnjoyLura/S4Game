# 冰霜领域 v2

## 数值

自动技能基础冰封时长由 0.8 秒改为 **1.5 秒**，基础伤害倍率由 1.5 改为 **2.0**。技能等级与突破的附加效果继续叠加，20 级倍率里程碑改为 2.0→2.3，80 级突破冰封说明更新为基础累计 1.9 秒。技能面板使用同一组配置。

普通怪与精英立即冰封、Boss 免疫冰封；解冻后减速 2 秒的规则继续保留。

## 角色状态颜色

原 Sprite 乘色无法把绿色皮肤变成明显冰蓝。新增 `fx/mob-cold.effect`，按原图明暗向冰蓝调色板混合，冰封强度 62%，减速强度 38%。保留原角色的装备轮廓、材质明暗和透明边缘，受击闪色继续叠在状态颜色之上，状态结束后恢复原材质。

两个状态共用两个材质，无逐怪、逐帧材质创建。加载期间采用更深的冷色乘色兜底，池化怪物初始化时重置材质，混合帧与主帧保持一致。
