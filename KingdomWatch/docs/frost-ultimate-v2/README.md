# 冰法师大招：从天而降与密集碎冰

本页保存上一版产物。用户后续认为出现位置、视角与密度仍不自然，最新调整见 [v3：错峰落冰与场景深度](../frost-ultimate-v3/README.md)。素材合成脚本读取当前运行时，重现当前版本请使用 v3 脚本。

2026-10-11 用户反馈：冰棱雨像短距离浮动，缺少真实落地，落冰和地面碎冰都太稀。此次调整轨迹、接地点、时序与密度，复用首版的冰晶和 H3 连续碎冰图集，没有新 AI 生成调用。

运行时：[FrostUltimateVFX.ts](../../assets/scripts/battle/FrostUltimateVFX.ts)。旧素材和处理记录见 [v1](../frost-ultimate-v1/README.md)。原普通技能 v10、伤害倍率、立即一次伤害、减速持续时间沿用。

| 项目 | v1 | v2 |
| --- | --- | --- |
| 下落起点 | 落点附近 131–198 设计单位 | 所有冰棱从可视战场上方 100–165 单位进入 |
| 下降 | 短程匀速斜移 | 接近竖直；位移进度 `0.28u + 0.72u²`，越接近地面越快 |
| 接地 | Sprite 中心定位，提前淡出 | 素材尖端 `(46,2)` 定位，接地前保持可见，接地后消耗 |
| 撞击时序 | 碎冰先出现，落冰另行播放 | 阴影固定在落点；冰棱到达才开始闪光、裂纹与碎屑 |
| 连续落冰 | 56 枚 | 128 枚；打散网格并抖动位置，减少随机空洞 |
| 怪物附近连续碎冰 | 最多 8 处 | 最多 24 处；每处 5 枚材质冰屑沿低弧线弹开、旋转、落地 |
| 其他落点 | 没有独立撞击 | 每次撞击都有 6 枚小碎冰和短裂纹，共 128 处局部接地反馈 |
| 总时长 | 2 秒 | 2 秒，末尾清空；没有全场寒潮扩散 |

AI 碎冰仍按同一纹理的互补矩形拆到怪物前后两层，避免覆盖身体。增加密度时缩小单处图集尺寸（120–164 设计单位），减少重复叠亮；局部寒气保留。

预建并复用 24 对命中 Sprite、128 枚冰棱、120 枚冰屑；局部裂纹与小碎块共用 Graphics。连续施放替换同一组槽位，不分配新节点。资源回调、销毁释放、暂停和倍速仍受战斗模拟时钟控制。

检查了起手、空中加速、尖端接地、碎裂、低弧线回落与尾部清空。两个场景 2.0 秒末帧与同一时刻无特效合成像素完全一致；实际手机帧率和最终视觉评价由用户人工体验。
