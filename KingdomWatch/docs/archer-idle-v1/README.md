## 接入

使用用户提供视频的完整举弓人物动作，视频副本保存为 `source.mp4`。提取连续待机循环段、抠黑背景并输出透明序列帧，人物区域使用统一裁切框、固定缩放和固定脚底原点。深色衣服和轮廓保留，视频人物外的标识不进入图集；不生成新视频、不重新绘制肢体。

图集位于 `assets/resources/ux/archer_idle_v1/idle.png`，56 格，1536 × 2464，约 2.74 MiB；循环时长约 3.46 秒。`idle.frames.json` 记录源帧索引、时长、裁切、缩放和脚底锚点。当前使用视频提供的举弓姿势，替代前次静态低持弓样图和被用户否定的拆分动画。

`ArcherIdleAnimation.ts` 用原生 Sprite 播放完整帧，不做肢体拼接、UV 变形、逐帧居中或角色弹性缩放。人物显示高度沿用 146 设计单位，脚底锚点相对英雄根节点为 `(0, -76)`。后续按用户要求增加 [镜像朝向与待机规则](../hero-mirror-v1/README.md)：攻击时停止待机时钟，攻击范围内无敌人且无待发攻击时继续播放；目标左右方向通过整幅人物镜像切换，脚底原点固定。范围外敌人不阻止待机。随后用户提供第二段视频，已增加 [攻击序列帧](../archer-attack-v1/README.md)，收势／取箭完成后才能恢复待机；原有射箭逻辑继续运行。

构建后 `node docs/archer-idle-v1/build_preview.cjs` 将单独待机预览与同一套序列帧复制到 `build/web-mobile/previews/archer-idle-v1/`。该预览提供放大、战场显示大小与播放／暂停。旧 `archer-native-v1` 预览不再随本次部署发布。
