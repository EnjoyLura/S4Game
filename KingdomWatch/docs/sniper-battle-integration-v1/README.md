# 正式战斗接入新重弩手，弓箭手缩小 16%

已完成 Cocos 构建、DPR 补丁与 main 发布：[打开正式游戏](https://kingdom-watch.pages.dev/?v=sniper-live-archer-84-1791868072)。部署记录见 `release.json`，效果由用户人工查看。

之前只构建发布了重弩手独立素材预览，正式战斗仍实例化旧 `battle_heroes_v2` 图集，所以游戏中的重弩手外观没有变化。用户本次明确要求更新正式游戏，并把弓箭手从当前尺寸缩小 16%。

`HeroBase.attachBattleArt('sniper')` 现在创建 `SniperIdleAnimation`，直接读取 `sniper_idle_rebuild_v4` 中已修正弩空隙的完整人物图集。56 张原帧组成四秒、110 项往返循环，播放器读取 `animation.frameDurations` 的逐帧秒数，保留预览中的端点减速节奏。全套帧共用一个脚底原点和显示比例，节点脚底继续位于 (0,-76)，不会对人物拆分或使用旧 UV 形变。

倒计时和攻击范围内没有敌人时播放新待机；范围内有敌人、正在射击、存在连狙待发或大招锁定、收势期间冻结当前完整人物新姿态。左右按目标和实际射击方向直接镜像。重弩手已有攻击动作尚未生成新的完整视频，本次战斗期间使用新形象的持弩姿态，继续沿用原弹道、伤害、射速、技能和大招逻辑。

弓箭手待机与攻击清单的 `displayHeight` 从 221 改为 185.64，即 221×0.84；两个动作等比同步缩小 16%。PNG 图集、原动画时序、固定脚底和射箭动作都保持原样。待机制作脚本同步输出 185.64，攻击制作脚本继续从待机清单读取尺寸，避免下次打包恢复旧大小。

本次将实际战斗代码和资源一同构建发布到正式 Pages 站点；独立预览的场景合成也同步显示新尺寸。生产记录见 `release.json`。按用户既有要求仅完成接入、Cocos web-mobile 构建、DPR 补丁和 Wrangler main 发布，由用户人工验证，不运行游戏、浏览器、线上或自动效果验收。
