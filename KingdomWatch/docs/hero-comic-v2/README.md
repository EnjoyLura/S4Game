2026-10-11。按用户的英雄页截图反馈修改：去掉标题、只绘制上半部场景、让英雄站稳在石台上、减少方形大背板，并补全动作图标美术和空背包状态。本文保留中间版本记录；用户后续要求恢复方形英雄卡、深色页签及装备背板，场景与动作资源重做，最新规范见 [v3](../hero-comic-v3/README.md)。

## 场景与组件

新背景为安静的公会训练室：低饱和灰绿墙面、暖砂岩圆拱、地砖及低矮圆石台。背景只覆盖资源栏、英雄选择及角色展示区域，背包使用全宽米色。背景图的石台顶面中心 `(u=.315, v=.840)` 与角色脚底坐标对齐；场景按覆盖区域同比缩放后做位置补偿，人物脚底透明边距单独补偿，避免立绘悬空。`heroPlatformAnchor` 是没有图形的定位节点，便于验证两者一致。

取消页面“英雄”标题及名称底牌。英雄选择使用正圆头像和环形高亮。切换箭头不加按钮底板，战力用火焰与布旗承托；装备栏取消整体大背板，保留五个圆角装备小槽位。属性卷轴、故事书和背包图标都是独立插画。名称和舞台文字使用浅色与克制深描边，保证背景上的对比度。

背包分类只为当前分类提供圆角高亮。实际有物品才创建物品槽，武器、装备、材料任一分类为空时，只在大背板中央显示说明，不绘制空槽位或说明小底板。已有背包滚动、分类与英雄滚动位置记忆、全英雄已穿戴过滤和各弹窗保持可用。

## 生成与生产资源

内置 Imagegen 生成一张场景与六张动作插画；全部使用已批准的 [商店风格参考](../shop-comic-v1/style-reference.png)。场景初稿另做一次构图编辑，使立台缩小、墙面留白增大并改为竖幅。新美术采用明确轮廓、两三档明暗、宽色面及克制细节；避免柔光、漂浮装饰、写实纹理和额外按钮底框。

- [generation.json](generation.json)：七张资产的完整提示词、参考、原图路径、背景编辑记录和平台定位。
- [sources](sources/)：初稿及最终原图副本；默认生成目录原文件保留。
- [assets.json](assets.json)：七张生产文件的路径、大小、尺寸和来源。
- [asset-contact-sheet.jpg](asset-contact-sheet.jpg)：六张动作图标的合成预览。
- [hero-empty-equip.png](hero-empty-equip.png)：新场景与空背包的实际页面截图。

生产文件位于 `assets/resources/scenes/bg_heroes_comic_v2.jpg` 和 `assets/resources/ux/hero_comic_v2/`。六张图标保留真实透明度；普通图标整理为 256px 方形，战力旗保留自然宽高比。生产整理只做边距裁切、同比缩放和 Creator 元数据导入，不变形。七张生产素材总计 634,808 字节；五名立绘、头像及物品图标复用之前的版本。

## 验证与发布

`check_heroes.cjs` 只检查主界面，使用隔离存档，不进入真实战斗。16 项检查涵盖标题与大背板移除、背景边界、石台与脚底定位、五名英雄及左右切换、独立背包滚动、装备过滤、换装、详情、故事、强化材料与金币扣除、缺资源与满级保护、出售/分解取消和确认、三个分类纯文字空状态、未解锁选择及两种手机屏幕。

通过 TypeScript 检查、Creator 3.8.8 web-mobile 构建、DPR 补丁及商店回归后发布 Pages main。`verify_release.py` 比对线上入口、主脚本、资源配置、DPR 引擎和 34 张新旧漫画素材的 SHA-256；结果见 `deployment-validation.json`。冰法师技能 v10、大招 128 颗错峰落冰、减速强化卡及普攻冰晶继续保留。
