# 反馈修整与领奖关闭修复 v17

用户否定旧版条纹 Toast、巨大硬边风车状光束，并报告点击空白收下奖励后 `t.includes is not a function`、界面卡死。v15/v16 的构建与发布不能视为效果或关闭交互获认可。

两段用户提供的视频仅离线抽帧参考：第一段在遮暗后短促聚光，奖励清楚落定后收尾；第二段升级成功短提示，实际属性与战力是焦点。保留自己的深蓝、暖金、英雄和物品插画，不复制外部游戏的标题、图标或版式。联系表见 reference-1/2-contact.jpg，原视频没有改动、没有加入游戏资源。

## 关闭卡死

本地 v16 生产包将 `[...new Set(icons)]` 编译成 `[].concat(new Set(icons))`。新数组仅有一个 Set，即使没有货币奖励也会进入飞币流程；对该 Set 调用 icon.includes 触发截图异常。替换为 `Array.from(new Set(...))`，输入检查字符串。关闭和到账确认各自幂等，原淡出结束后先释放调用方领取锁，再启动装饰动画；装饰创建失败清理节点并记录警告，不影响收下。奖励已由调用方保存，本弹窗及动画始终不发放、扣除货币或物品。

## 视觉改动

- 共用 FeedbackSurface：四张按需生成并缓存的白色 alpha 纹理，逐像素连续渐变、双线性过滤；背景和双线各为单张 Sprite，替代条带叠画。RGBA 合计 1,327,104 字节，没有新图片下载或材质依赖，不逐帧生成纹理。
- 成长通知：常规高度 190→142、突破 224→192，标题一行、等级和战力并排、属性一行；保留真实累计成长和连续升级合并。中部偏上停留，下方滑入、上移淡出；仅标题短暂暖光，不再抛撒大片碎屑。
- 普通通知：保留中上部位置、双线、滑入/停留/上移淡出节奏，替换有接缝的分段透明背板。
- 领奖/购买/招募：去掉粗大多层金色旗带和风车放射线，换暖金字、左右细线、柔光聚焦、少量微光。物品以 90ms 错峰、280ms 轻显，真实奖励数量从出现起完整展示；提示稍后出现，随时点击空白仍可收下。保留原领奖/购买/招募音效，首个就绪绘制帧后播放。
- 英雄培养/主城升级/胜利：同样去掉硬边光束和横向分段光柱，使用局部柔光、较细脚底光环与少量闪点，减轻人物/建筑缩放。原胜利皇冠、星级节奏、奖励、页面布局保持。

## 范围与交付限制

修改八个现有 UI 脚本，新增无 Component 的 FeedbackSurface。每个脚本最多注册一个 Component，保留 v16 拆分。核心数值、交易、领奖、存档、素材和已有音频未改。

依项目要求，仅审阅源码、TypeScript 静态诊断、组件注册 AST 与本地 Cocos 生产构建产物，不运行测试、模拟、游戏、浏览器、音效试听或线上验收。完整项目原有九项 ButtonFeedback 及调用方类型诊断仍存在，本轮文件无新增诊断。实际视觉、声音与点击收下由用户手动验收。
