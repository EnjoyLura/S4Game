# 弓手立绘、弓形与品质收敛 v2

按本轮两条要求，重做弓箭手正面全身立绘、狩猎木弓和猎风长弓；装备品质色只留在圆形背板与左上角角标。

使用内置 image_gen.imagegen，三张图均以项目原图为参考，生成透明 PNG，完整复制到版本化资源，未裁剪、重绘、缩放或处理像素。旧图保留。立绘保留角色身份与服装，改为左手握弓把、身体侧面垂直持弓，右手放松；两把武器移除穿过弓身的箭，简化弓臂、弓弦和装饰。素材生成与人工认可分开记录。

新素材由 HeroComic 与 Weapons 的共用入口引用，覆盖英雄页、升级页、故事、背包、商店和掉落详情。角色透明脚底边距按14/1546校准；原战斗图集、待机和攻击动作没有更换。

GearQuality 外框统一恢复中性米纸底和深色单轮廓，去掉品质色内边带及大面积铺色。物品名称与说明恢复普通文字颜色；圆形品质底与左上角品质角标保留，删去圆外的额外闪光装饰。穿戴、背包、详情、关卡掉落与战利品清单同步使用。原数值、价格、背包实例和存档不变，战场装备爆出/拾取的品质反馈不变。

只审阅源码、生成静态图片与本地构建产物，按项目约定不运行测试、模拟、游戏、浏览器或线上验收。完成正式 production/MD5 构建、DPR补丁与 Pages 发布后，由用户人工查看实际界面。

- `generation.json`：完整实际提示词、参考路径、透明参数与内置工具回执。
- `imagegen-assets.json`：输出来源、资源UUID、透明范围、脚底边距与原图/复制图相同SHA256。
- `*.before.txt`、`source-review.diff`：本轮开始时的源代码与增量审阅。
- `bundle-inspection.json`、`release.json`：本地包检查及正式发布回执。
