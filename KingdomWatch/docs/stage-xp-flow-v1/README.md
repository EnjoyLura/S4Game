# 关卡等级与时间经验 v1

按用户要求完成三项调整：移除 Lv 背板、经验增长不变白、每两秒获得少量关卡等级经验。

等级文字保留原居中位置、字号、数字字体和金色，直接放在 HUD 上，仅以 2px 深色字描边保证可读。经验条固定 `#6CBCC6`，取消获得经验时 350ms 的亮白切色；顶部静态高光也改为同色系青蓝。保留长度平滑逼近，升级后直接交接本级剩余经验。初始填充显式置零，避免通用进度条默认满格留在开局。

新增时间经验采用战斗计时器：每 2 个战斗秒发放 `max(1, round(本级升级需求 × 1%)) × 经验获取倍率`。最低 1 点，后期按当前需求适量增长；1% 是本轮初设平衡值，可继续调整。发放共用原 `gainXp`、正常升级/三选一队列和大招演出保护，不单独增加音效或提示。击杀经验与原 `50 × 1.35^(L−1)` 升级曲线保持。

只在战斗运行期间累计，随战斗倍速和顿帧计时；准备、全屏进场、暂停、三选一、离场与结算期间不累计。零头在本局暂停/复活后保留，新战斗重新计时，不按系统时间补发后台经验。发放安排在本帧战斗子步之后，已有暂停或结算状态下不发放；等待胜利演出收尾时停止时间经验。

本轮修改限于 `HUD.ts`、`BattleProgressBar.ts`、`BattleDirector.ts` 和 `GameConfig.ts`，不新增素材、不改变其他进度条配色，保留上一版退出、击杀反馈及出手气流修复。`before/` 与 [增量源码](source-review.diff) 保存本轮基线与差异。

仅执行源码与构建产物审阅、Cocos web-mobile 构建、DPR 补丁及 Wrangler main 发布。依项目约定不运行测试、模拟、游戏、浏览器或线上视觉验收；显示效果及经验节奏由用户人工确认。
