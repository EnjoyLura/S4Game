## 火法技能

原技能在施法时取同一个怪物的旧坐标，再沿整排偏移方向直线飞行；只有学了火区的最后一颗才设置 groundTarget，其他火球打空后会一直飞出屏幕。现在所有技能火球都有有限的地面落点，到达即爆炸，复用原地面命中/爆炸/声音/灼烧处理。

每颗实际发射前重新检索技能范围内、已进入可见作战区的存活怪，按照预测落点附近可覆盖的怪物簇评分；同分优先防线前方。按当前减速、冻结和眩晕估算飞行时的移动，每颗目标 x 限制在 [-330,330]，y 在防线+24到刘海下136范围内。升级后的数量保持，0.12秒逐颗发射；仅在 ±12 以内交替微偏移，让火球可辨认，不再按总数量向两侧无限展开。无合法目标或弹体池满就等待并重新判断，避免凭空消耗额外火球。

技能伤害、溅射倍率、范围强化、原冷却及火区卡保持；只有最后一颗实际落地才生成技能火区，最多4块。普攻和大招陨石的既有轨迹/规划保持，不增加飞行中的自动追踪。

## 灼烧伤害和反馈

静态追查确认原有每0.5秒扣血路径存在，未找到「陨石灼烧一律不扣血」的代码依据；实际问题包括灼烧伤害没有进入英雄伤害统计，以及所有 DoT 飘字全场上限6、密集命中占满容量或文字避让时直接被丢弃。

灼烧现记录当前最强 DPS 的来源英雄，普通弹、溅射、地面爆炸透传来源；每次真实扣血后把 `lastDamageTaken` 加入该英雄统计。抗性、感电、易伤等仍走原 `takeDamage`，不额外补扣一份伤害；最大DPS不叠加、持续刷新和禁疗规则保持。只有实际损失生命才增加 burnPulse，与原火焰动画事件绑定，过滤非有限DPS/时长。

灼烧飘字改暖橙色，周期飘字最多12，同时总上限仍30、保留6个暴击名额。正常数字占满非暴击槽时，可回收已完成入场的最老普通数字给真实周期伤害；周期文字多尝试上下两侧避让，找到最小遮挡位置后不再因严格的普通文字拥挤阈值而消失。75ms同目标合并保持。极端超过预算时仍可能省略数字，不承诺同时为60只怪显示独立飘字；实际扣血和英雄统计不受文字预算影响。原0.62秒灼烧完整动画、0.5秒伤害节拍及命中特效资源/音频保持。

## 怪物 Tips

原代码将 `getUILocation` 的左下角设计坐标直接送入 `convertToNodeSpaceAR`，而本项目战场和相机使用居中世界坐标，导致点击位置与怪物主体不一致。现在使用实际 Canvas 相机，将物理屏幕坐标 screenToWorld 后再转到点击层局部坐标，兼容长屏、桌面留边以及战场镜头位移。

保留按下锁定实例/出生编号、身体及边缘容错、拖动取消和单指处理；抬起显示固定左侧148宽窄栏，内容为名字、类型、生命、物抗/法抗、简短介绍与状态。关闭/同一目标再次点击/击败保留简介规则保持。允许大招演出期间检查怪物，仍受三选一、暂停、结算、引导、GM和转场的原HUD状态保护。普通HUD及掉落拾取仍在点击层之上。
