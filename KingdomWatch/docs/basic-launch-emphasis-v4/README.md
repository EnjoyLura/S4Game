# 普攻发射特效强化

用户希望现有纯程序普攻发射更夸张、更明显。本版沿用自定义 Shader 和完整弹道方向，以尺寸、持续时间、亮芯与元素层次强化发射瞬间。

| 英雄 | 原缩放 → 新缩放 | 原时长 → 新时长 |
| --- | --- | --- |
| 弓箭手 | 1 → 1.45 | 0.24 → 0.32 秒 |
| 重弩手 | 1.2 → 1.7 | 0.28 → 0.36 秒 |
| 火法师 | 1 → 1.5 | 0.25 → 0.34 秒 |
| 雷法师 | 1 → 1.5 | 0.22 → 0.30 秒 |
| 冰法师 | 1 → 1.5 | 0.28 → 0.36 秒 |

Shader 的发射透明度系数增至 1.4（钳制在 1 以内），衰减指数由 1.35 调至 0.95，让中段持续可见；起手约 12–14ms，结束仍完全透明。发射位置、实际攻击方向和强化普攻的额外比例保持。元素改动如下：

- 弓箭／重弩：加粗带柔边的白青压力前沿，增加稍后展开的第二层前沿，增强两侧气流与最初短促亮芯。
- 火法：向前焰流更长更宽，橙色柔边与浅黄亮芯增强，余烬由 5 条增至 8 条。
- 雷法：由 2 支增加到 3 支连通电弧，左右分叉，更长、更宽，保持紫边与白色细芯。
- 冰法：霜气压力前沿更明显，晶片由 4 颗增至 6 颗，并扩大切面。

Graphics 载入回退同步使用新缩放／时长、更慢衰减、更强透明度与碎屑数量。36 槽池、战斗模拟时钟、方向、场景销毁方式保持；没有增加逐发 Node、Tween、资源下载或 AI 调用。英雄素材与动作、现有弹体和飞行拖尾、伤害／攻速／弹速／碰撞／索敌、技能大招、命中特效、防线显示及上一轮配乐和音效保持。

按用户持续要求，仅改动、构建 web-mobile、DPR 补丁与发布，不运行测试、游戏、浏览器或线上效果验收。最终效果由用户人工查看。
