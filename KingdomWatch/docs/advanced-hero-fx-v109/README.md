## 爆炸

v108的平面叠色火团替换为程序化着色器：受扰动的火焰轮廓、收小的炽亮核心、分离弯曲火舌、较迟出现的低透明度烟团。地面压力前沿、焦灰与短暂热裂纹和空中火焰分层，均为视觉，不附加持续伤害。

碎片不再等角度排成一圈。普攻/技能22枚、导弹30枚、二段14枚视觉碎片，含8片较大的金属壳与细余烬；不均匀角度/速度/高度，旋转、翻转变窄、明暗切面、热边、短拖光、贴地影子、精确第一次落地和较小反弹。物理位置由年龄闭式计算，不依赖逐帧Euler积分；无额外战斗随机数。普攻/技能/大招/二段的实际伤害、范围、抗性、音效、0.35秒二段、大招导弹数量/0.26秒错峰/充能与落点逻辑保持。

## 吸取

原机械符环与粉色细线改为暗紫雾边、三股不规则细流、明暗能量段、目标处抽离旋流；中部柔和弯曲、靠敌人处稍散，向施法者收束。起点使用静态立绘抬起的手掌位置，并跟随整人镜像。大招只增强视觉粗细/端点，不改变伤害方式。

较大的精华尾迹仍由真实扣血>0触发，同一出生实例同一子步多通道合并视觉，伤害独立。实际回复>0才出现掌心汇聚；生命法师原0.25秒扣血、锁定至死亡/离场、增伤、分流、法抗削减与回血上限不变。

- 新增一个小型EffectAsset，不新增PNG/WebP/序列帧/视频或游戏运行库。2×2白载体由内存生成，未就绪时始终隐藏，不会露出白矩形。

- 逐战斗子步推进状态，每显示帧最后一次伤害/弹道结算后绘制。随暂停/选卡停止，无系统时间、独立Tween或额外伤害事件。碎片复用、颜色复用；着色器失败保留稳定的矢量回退。已出生爆炸固定绘制模式，不因异步完成突然换形。
