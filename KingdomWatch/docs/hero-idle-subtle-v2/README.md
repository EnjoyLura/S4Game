# 待机身体动作幅度修正 v2

2026-10-14 最新速度已调整：两位英雄待机统一提速 30%，当前单轮约 3.076923 秒；下文四秒为初版历史值。见 [待机速度调整](../hero-idle-speed-v1/README.md)。

2026-10-14 用户确认两位英雄的新站姿图片可以，但否定当前待机中的奇怪、夸张身体动作。本轮保留两张红底母版、武器握持、弓箭手全部素材、重弩手当前攻击、尺寸和脚底，只替换重弩手／雷法师待机序列与当前预览。

这次直接控制进入图集的动作范围，没有提交新视频任务，也没有再次生成图片。之前项目 MiniMax H3 生成视频的整段身体动作幅度并未遵守提示词的一两像素要求。此前将整段 56 帧全部用于往返播放，也将后半段的肩甲抬动、腰部变化、手臂移动反复带入循环，不能靠降低速度解决。

用头部、肩甲／领口、腰带、手腕、靴子及武器上的局部参考图块选择安静的连续开头段。以原游戏显示尺度下标记位移预算 0.55 为制作范围依据，重弩手保留段的最大标记位移约 0.187、雷法师约 0.497；两段原片最大标记位移分别约 2.344、2.338。该记录是制作时筛选源帧的依据，仅衡量所列局部图块，不能代表全身形变的完整判断或视觉验收。记录见 [重弩手选帧](sniper-motion-selection.json)、[雷法师选帧](volt-motion-selection.json)。

完整 RGBA 帧原像素重排入新图集，不拆分身体，不拼接肢体，不生成中间姿势，不进行逐帧缩放或透明度过渡。保留原取景、比例、画内高度、512×512 格子及脚底 `(256,496)`，节点脚底沿用 `(0,-76)`，与当前重弩攻击完全沿用同一缩放基准。相邻帧前进／回退，用四秒缓慢循环及端点缓和，末尾与开头相邻。重弩手图集 4096×1024，雷法师 4096×512。

源视频与已确认站姿仍保存在 [重弩手制作目录](../sniper-stance-idle-v3/) 和 [雷法师制作目录](../volt-stance-idle-v2/)，任务分别为 `task_ZfW2nZiUwOEf2dNqB99lQDQqyq1Ealx1`、`task_ciPdQdcFk87jCS8UmqSL7tBfPMm7YKGX`，原片与历史素材完整保留。新的动画仍等待用户人工查看，图片认可不代表动画认可。

正式逻辑沿用范围内无目标且无待发／攻击／收势才播放待机，整人直接左右镜像。只修改两位播放器的待机资源路径。暂停、弹道、伤害、射速、技能、大招和声音保留。
