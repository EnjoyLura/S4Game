# 英雄战斗动作与暂停统计修复

本次用户要求让战斗英雄动作更自然、增强战斗表现，血条上移，并修复暂停页伤害统计压住页签的问题。

## 动作

复用 `battle_heroes_v2` 中五位英雄的攻击姿态，作为稳定的战斗准备底形。过去每次攻击都会在 idle 与 attack 两张不同轮廓之间突然跳换；现在由 `HeroBattleMotion.ts` 和 `fx/hero-motion.effect` 连续驱动上身、肩膀／武器和衣摆。弓箭手有拉弓与放弦后的回位，狙击手有短促后坐，三位法师有抬杖、发力和稍慢的回位。各英雄呼吸与衣摆错相位，快速连射延续当前动作，重施法不被紧接的轻攻击打断。

动画只作用于图集内的 UV。肩部旋转保持显示宽高比，脚踝以下权重归零；英雄节点、脚底锚点、碰撞坐标、弹道起点和攻击间隔不随演出移动。图集矩形统一扩展 12 个源像素透明留白，绘制高度仍为原 146，避免武器运动裁边。战斗帧禁止动态图集搬运，以保持 UV 坐标稳定。材质与图集无论哪一个先加载，都在资源就绪时写入正确的帧范围；场景销毁时释放每英雄材质。

这是一套基于已有绘画的轻量连续局部形变，没有新 AI 生图或视频、没有增加序列帧下载，也没有新增整个人物缩放或摆动。局限是肩部和衣摆的运动幅度较小，不能代替重新绘制的完整骨骼动作。

## HUD 与暂停页

防线血条整组由底基 176 上移到 198：血条、耐久值、护盾图形与护盾数值一起上移 22 个设计像素。英雄与防线锚点保持原位置。

暂停页伤害统计使用原 520..764 内容区，按 1–4 名英雄安排间距，完整显示四名英雄。头像与行内文字／占比条随行高适配，统计区和连体页签之间至少留出 12 个设计像素。暂停标题、奖励、设置、页签、退出／继续按钮，以及胜败结算和三选一的布局与文案延续资源替换 v2。伤害 tips 保持原背板与文本。

## 验证与预览

`check_motion.cjs` 用独立存档和静态战场素材加载真实 Cocos 组件，未启动波次或 `BattleDirector.start()`。430×932、375×600、430×760 分别检查 1–4 人统计不覆盖标题、相邻行或页签；检查血条位置。五位英雄的受控动作时间轴检查同一帧与节点稳定、连续回位；真实 Hero.tick 的四秒固定目标检查射击次数、间隔、起点和未解锁技能／大招状态。

另外比较真实 GPU 渲染前后像素：脚底区域基本不变，上身确实产生运动，避免只有数值变化而材质未生效。结果见 [ui-validation.json](ui-validation.json)。
